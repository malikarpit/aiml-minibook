MAIN-U2-C16 — Hypothesis Classes, Inductive Bias & K-Nearest Neighbours

Main Book: AI & Machine Learning — Visual + Mathematical Self-Learning Textbook
Unit: II — Machine Learning Fundamentals
Topic ID: ML-U2-C16
Prerequisites: ML-U2-C14 What Is Machine Learning, ML-U2-C15 Machine Learning Paradigms
Primary course source: Lecture08.pdf — Supervised Learning: Hypothesis Class & Bias-Variance Trade-off, Prof. Subrahmanya Swamy Peruru, IIT Kanpur
Source status: Course-grounded; K-NN algorithm details below include a clearly marked universal expansion because the supplied lecture establishes the local-similarity assumption and identifies K-NN as the resulting method, but does not provide the complete algorithm.

1. Why This Chapter Exists

You already know the basic supervised-learning story:

Training examples
      ↓
      ML model
      ↓
Prediction on new data

But there is a hidden question:

What is the model allowed to be?

Suppose you give a computer 100 examples of house size and house price. You tell it to find a function that predicts price.

Could it choose any possible function in existence?

If you allow that, something strange can happen.

The system can simply memorize every training point:

Input                    Prediction
────────────────────────────────────
House A                  Exact price of A
House B                  Exact price of B
House C                  Exact price of C
...

Any unseen input         Whatever the arbitrary function says

Training error can become zero while the model may behave terribly on new houses.

This is the central problem that this chapter solves conceptually:

Learning is not merely about fitting the training data. It is about learning a useful rule that generalizes to unseen data.

Your Lecture 8 starts from precisely this issue: without restrictions on the function structure, the learner can memorize the training data and obtain zero training error without learning a useful general rule. Course source: Lecture08.pdf, slides 2–3.

2. One-Minute Intuition

English

A hypothesis is a candidate rule/model that could map an input to an output.

A hypothesis class is the collection of candidate rules we are willing to consider.

Inductive bias is the set of assumptions that tells us which kinds of rules are reasonable.

👨‍🏫 Hinglish
Socho teacher tumhe 20 questions dekar bolta hai: > “In examples se pattern find karke agla answer predict karo.” Agar tum har question ke liye bas alag-alag answer yaad kar lo, tum examples ko **memorize** kar rahe ho. Lekin agar tum samajh lo ki: > “Jin students ne zyada practice ki hai, unka performance usually better hota hai,” toh tum ek **general rule** bana rahe ho. ML mein humein isi tarah ka useful pattern chahiye.

How to read this

The important idea is that the learner does not search an unlimited universe of arbitrary functions.

Instead:

  1. Decide what kinds of functions are allowed.
  2. Learn the best function within that family.
  3. Use that learned function on unseen inputs.

4. Why Zero Training Error Can Be a Bad Result

Suppose training data contains:

Input x Target y
1 10
2 20
3 30

An unrestricted learner can create a weird function:

x = 1 → 10
x = 2 → 20
x = 3 → 30
x ≠ 1,2,3 → arbitrary value

Its training error can be exactly zero.

But suppose a new test input is:

\[ x=2.5 \]

What should it predict?

The memorizing function may have no meaningful answer.

This is why:

Low training error is not the same thing as good learning.

5. The Universal Vocabulary

5.1 Hypothesis

A hypothesis is a candidate predictive function.

We may write it as:

\[ h : \mathcal{X}\rightarrow\mathcal{Y} \]

Meaning:

h takes an input from the input space X and returns a prediction in the output space Y.

👨‍🏫 Hinglish
> Hypothesis ko simple language mein **possible prediction rule** samjho.

5.2 Hypothesis Class

A hypothesis class \(\mathcal H\) is the collection of functions that the learning algorithm is allowed to choose from.

Instead of:

“Choose any possible function.”

we say:

“Choose the best function from this family of functions.”

The Lecture 8 formal objective is:

\[ \boxed{ \hat f \in \arg\min_{f\in\mathcal H} \frac{1}{n} \sum_{i=1}^{n} \big(f(x_i)-y_i\big)^2 } \]

for the squared-error example used in the lecture. Course source: Lecture08.pdf, slides 2–3.

6. What Does “Class” Mean Here?

Do not interpret “class” as a Python class.

It means:

A family or collection of possible functions/models.

Examples:

H₁ = all straight-line functions
H₂ = all quadratic functions
H₃ = all degree-15 polynomial functions

The class controls what the learner can represent.

7. Real-World Analogy — Hiring a Person

Imagine you want to predict how well a candidate will perform in a job.

You could create an absurd model that memorizes every candidate.

Or you might decide beforehand:

“I will consider only models that relate performance smoothly to experience, education and test score.”

That restriction is a form of inductive bias.

You are saying:

“I believe these kinds of relationships are more plausible than arbitrary memorization.”

The same idea appears in ML.

8. What Is Inductive Bias?

Your Lecture 8 defines inductive bias as assumptions about function structure that are introduced so that the learned model can generalize to unseen data. These assumptions may come from domain knowledge or mathematical principles such as smoothness. Course source: Lecture08.pdf, slide 3.

Formal intuition

Inductive bias is the set of assumptions that restrict the learner toward certain kinds of solutions.

👨‍🏫 Hinglish
> Dataset humein limited examples deta hai. Unseen cases ke liye prediction karne ke liye humein kuch assumptions karni padti hain. **Ye assumptions inductive bias hain.**

9. Why Does Inductive Bias Help?

Without bias:

Anything goes
    ↓
Memorization is possible
    ↓
Training error can be tiny
    ↓
Generalization can be poor

With useful bias:

Reasonable assumptions
    ↓
Smaller / structured hypothesis space
    ↓
Less freedom to memorize arbitrary noise
    ↓
Better chance of generalizing

This does not mean “more bias is always better.”

An overly restrictive hypothesis class can also fail to represent the real relationship.

That tension leads directly to bias and variance, which is the next chapter.

10. Two Important Types of Assumptions in Your Lecture

Your lecture gives two particularly clear examples.

Example A — Local Similarity

Problem:

Predict house price from location.

Assumption:

\[ x\approx x_i \Rightarrow y\text{ is likely close to }y_i \]

In words:

Nearby inputs tend to have similar outputs.

Consequence:

Predict using nearby examples → K-NN style methods.

Course source: Lecture08.pdf, slide 4.

Example B — Global Linearity

Problem:

Predict salary from experience.

Assumption:

The relationship is approximately linear across the input range.

Model:

\[ f(x)=wx+b \]

Course source: Lecture08.pdf, slide 5.

So:

Assumption                     Model family
──────────────────────────────────────────────
Nearby things are similar  →   K-NN
Relationship is linear     →   Linear model

This is one of the most important ideas in this entire section of the course.

11. The Big Mental Model

A supervised learner is solving two related questions:

Question 1

What functions are allowed?

That is the role of the hypothesis class.

Question 2

Which assumptions make those functions reasonable?

That is the role of inductive bias.

Then:

Choose the function that fits the training data best within that allowed family.

12. Formal Learning Picture

Suppose the training dataset is:

\[ \mathcal{S}= \{(x_1,y_1),\ldots,(x_n,y_n)\} \]

and the hypothesis class is:

\[ \mathcal H \]

Then the learner may solve:

\[ \boxed{ \hat f \in \arg\min_{f\in\mathcal H} \frac{1}{n} \sum_{i=1}^{n} \ell(f(x_i),y_i) } \]

where:

  • \(\mathcal S\) = training data
  • \(\mathcal H\) = allowed hypothesis class
  • \(\ell\) = loss function
  • \(\hat f\) = learned function
👨‍🏫 Hinglish
> Pehle rules/family decide karo → phir us family mein best function dhoondo.

13. What Happens If the Class Is Too Large?

Very large H
      ↓
More expressive functions
      ↓
Can fit training data very closely
      ↓
Can memorize noise
      ↓
Possible overfitting

The model has lots of freedom.

That freedom can be useful when the true relationship is complex—but dangerous when the model starts fitting noise instead of structure.

14. What Happens If the Class Is Too Small?

Very small / restrictive H
      ↓
Not enough expressive power
      ↓
Cannot capture real relationship
      ↓
High systematic error
      ↓
Possible underfitting

This is why “use the simplest model possible” is not the whole story.

The model must be simple enough to generalize and expressive enough to represent the real pattern.

15. K-Nearest Neighbours — Why It Appears Here

Source boundary: Your Lecture 8 establishes local similarity and says this assumption leads to nearest-neighbor methods. The complete algorithm below is a universal expansion so the concept is self-contained.

Imagine predicting the price of a house in a neighborhood.

You look at nearby houses:

₹90L
                ●

      ₹82L ●         ● ₹88L

               ?
            New house
               ○

      ₹79L ●         ● ₹84L

The basic assumption is:

Similar inputs tend to have similar outputs.

So instead of learning one global equation, we can search for the closest training examples.

16. What Does “K” Mean?

In K-NN, K tells us how many neighbours we will use.

Examples:

  • K=1 → use the nearest example.
  • K=3 → use the three nearest examples.
  • K=5 → use the five nearest examples.

The larger K becomes, the more surrounding data points influence the prediction.

17. K-NN for Classification

Suppose the task is:

Is this email Spam or Not Spam?

For K=5, suppose the five nearest examples are:

Spam       ✓
Spam       ✓
Not Spam   ✗
Spam       ✓
Not Spam   ✗

Votes:

  • Spam = 3
  • Not Spam = 2

Prediction:

\[ \boxed{Spam} \]
👨‍🏫 Hinglish
> “Mere nearest 5 neighbours mein majority kis class ki hai?” Jis class ke votes zyada, wahi prediction.

18. K-NN for Regression

Suppose the nearby houses have prices:

\[ 80,\;82,\;86 \]

For a simple K-NN regression rule, use their average:

\[ \hat y = \frac{80+82+86}{3} =82.67 \]

So:

\[ \boxed{\hat y\approx82.67} \]

The exact weighting scheme can vary; the simple average is the basic teaching version.

19. Distance — the Mathematical Heart of K-NN

We need a way to decide what “near” means.

For two points:

\[ x=(x_1,x_2),\qquad z=(z_1,z_2) \]

one common choice is Euclidean distance:

\[ \boxed{ d(x,z)= \sqrt{(x_1-z_1)^2+(x_2-z_2)^2} } \]

For d dimensions:

\[ \boxed{ d(x,z)= \sqrt{\sum_{j=1}^{d}(x_j-z_j)^2} } \]
👨‍🏫 Hinglish
> Har feature mein kitna difference hai → square karo → add karo → square root lo.

20. Why Feature Scaling Matters for K-NN

Suppose one feature is:

Age: 18–60

and another is:

Salary: 20,000–2,000,000

Distance may become dominated by salary simply because the numeric scale is much larger.

That can distort who counts as a “nearest” neighbour.

This is why feature scaling can be important before distance-based methods.

Your Lecture 9 later gives formal treatments of standardization and min-max scaling; this chapter only needs the intuition. [Course connection: Lecture09.pdf.]

21. The Effect of K

Think of K as a neighbourhood size.

Small K

K = 1

Very local
↓
Highly sensitive to individual examples

Larger K

K = 25

More neighbourhood information
↓
Prediction becomes smoother

But too small or too large can both be problematic depending on the data.

The exact bias-variance consequences are developed fully in the next chapter.

22. K-NN as a Form of Local Learning

Compare two assumptions:

Linear model

One global relationship describes the whole dataset reasonably well.

K-NN

Local neighbourhoods contain useful information about local predictions.

Visual idea:

GLOBAL VIEW
────────────────────────
One model for everything

LOCAL VIEW
────────────────────────
Different neighbourhoods
influence different predictions

This is why the Lecture 8 example calls the K-NN assumption local similarity.

23. Hypothesis Class vs Model Parameters

These are easy to mix up.

Suppose:

\[ f(x)=wx+b \]

The hypothesis class might be:

All linear functions of the form \(wx+b\).

The parameters are:

\[ w,b \]

So:

Hypothesis class
= which forms of function are allowed?

Parameters
= which specific member of that family do we choose?

Example

H = all straight lines

w = 2, b = 1
        ↓
One particular line

24. Hypothesis Class Is a Design Decision

Choosing a hypothesis class is not just an implementation detail.

It encodes what you believe about the problem.

Examples:

Belief / assumption Possible model family
Relationship is roughly linear Linear model
Nearby points are similar K-NN
Decision can be represented by nested rules Decision tree
Complex nonlinear representations are useful Neural network

Different model families correspond to different assumptions about what kinds of patterns are plausible.

25. A Powerful Everyday Analogy — Maps

Imagine you are trying to draw the shape of a coastline.

Very coarse map

You use only a few straight segments.

Easy to store.

But it misses many details.

Extremely detailed map

You copy every tiny rock and irregularity.

It matches your current measurement perfectly—but perhaps includes noise that is irrelevant to navigation.

The useful map is somewhere between these extremes.

This is the same intuition behind model flexibility and generalization.

26. Connection to Training Error and Test Error

Remember:

Training error

“How well did I fit the examples I saw?”

Test/generalization performance

“How well do I perform on examples I did not train on?”

A hypothesis class influences both.

Change H
   ↓
Change model flexibility
   ↓
Change what can be fitted
   ↓
Change training + unseen-data behaviour

The supplied lecture explicitly says test data should approximate generalization performance and must not be used to fit the model or decide the hypothesis class. Course source: Lecture08.pdf, slide 6.

27. A Small Mathematical Example

Suppose we compare two classes.

Class A

\[ \mathcal H_1= \{wx+b\} \]

Class B

\[ \mathcal H_2= \{w_0+w_1x+w_2x^2+\cdots+w_{15}x^{15}\} \]

Class B is much more expressive.

It can represent far more shapes.

That extra flexibility may:

  • reduce training error;
  • but also increase sensitivity to the particular training set.

This leads directly into the next chapter's bias-variance framework.

28. Common Misconceptions

Misconception 1

“Hypothesis class means the labels/classes in classification.”

Wrong. Here it means a family of candidate functions/models.

Misconception 2

“Inductive bias is a mistake or unwanted bias.”

Not in this context.

Here it means assumptions that make generalization possible.

Misconception 3

“A more expressive hypothesis class is always better.”

No. More flexibility can make fitting easier but can also increase overfitting.

Misconception 4

“K-NN has no assumptions.”

It makes an important assumption: local similarity is useful.

Misconception 5

“K-NN means choose one nearest point for every problem.”

Not necessarily. K can be greater than one, and the aggregation rule depends on regression vs classification and implementation.

29. Comparison — Hypothesis Class vs Inductive Bias

Concept Meaning
Hypothesis One candidate function
Hypothesis class Collection of candidate functions
Inductive bias Assumptions restricting which structures are considered reasonable
Model flexibility How much variety the class can represent
Generalization Performance on unseen data

Memory anchor:

Hypothesis = one possibility.
Hypothesis class = all allowed possibilities.
Inductive bias = why we allow those possibilities.

32. University Exam Lens

2-mark answers

Define hypothesis class.

A hypothesis class \(\mathcal H\) is a collection of candidate functions from which the learning algorithm selects a model.

Define inductive bias.

Inductive bias is the set of assumptions imposed on the structure of possible functions to enable useful generalization to unseen data.

What is K-NN?

K-Nearest Neighbours is a local method that predicts a new example using the outputs/classes of nearby training examples.

37. Memory Card

Hypothesis = one candidate function.

Hypothesis class = allowed family of functions.

Inductive bias = assumptions that make generalization possible.

Local similarity → K-NN.

Global linearity → linear model.

More flexibility can fit more—but can also overfit more.
