1. Why This Chapter Exists

The previous chapter introduced the Recurrent Neural Network (RNN).

An RNN gives a model a form of memory:

sequence
   ↓
x₁ → RNN → h₁
          ↓
x₂ → RNN → h₂
          ↓
x₃ → RNN → h₃
          ↓
       ...

The important idea is that information from earlier time steps can influence later predictions through the hidden state.

But this creates a major difficulty.

When a sequence becomes long, the training signal may struggle to travel backward through many recurrent steps. This can contribute to vanishing gradients, making it difficult for a basic RNN to learn long-range dependencies.

LSTM was designed as a recurrent architecture with a more controlled memory mechanism.

The central question is:

How can a recurrent model decide what information to remember, what to forget, and what to expose as output?

LSTM answers this by introducing a dedicated cell state and learnable gates.

2. One-Minute Intuition

English

Imagine reading a long paragraph.

Some information matters for a long time.

Some information is useful only temporarily.

Some old information should be discarded.

A basic RNN has a hidden state that gets repeatedly transformed. LSTM adds a more explicit memory pathway and control mechanisms that learn when to:

KEEP information
FORGET information
WRITE new information
OUTPUT useful information

So the mental model is:

RNN = recurrent memory
LSTM = recurrent memory with learned gates for controlled information flow

This is an intuition, not a claim that LSTM literally stores human-like memories.

Hinglish

Socho tum ek long conversation padh rahe ho.

Kuch details bahut important hain aur 20 lines baad bhi yaad rehni chahiye.

Kuch details sirf current sentence ke liye useful hain.

Aur kuch purani information ko ignore kar dena chahiye.

LSTM ka basic idea hai ki network khud learn kare:

“Kya yaad rakhna hai? Kya bhoolna hai? Kya abhi output mein dikhana hai?”

Isliye LSTM ko ek smart memory controller ki intuition se samajhna useful hai.

3. The Problem with a Basic RNN

An RNN can be written conceptually as:

\[ \boxed{ h_t=\phi(W_{xh}x_t+W_{hh}h_{t-1}+b_h) } \]

where:

  • \(x_t\) = current input;
  • \(h_{t-1}\) = previous hidden state;
  • \(h_t\) = current hidden state;
  • \(W_{xh}\) = input-to-hidden parameters;
  • \(W_{hh}\) = recurrent parameters;
  • \(\phi\) = nonlinear activation.

The same recurrent mechanism is applied again and again through time.

During backpropagation through time, the gradient can involve repeated multiplication by derivative/Jacobian factors.

Very roughly:

gradient at t
     ↓
 × recurrent derivative
     ↓
 × recurrent derivative
     ↓
 × recurrent derivative
     ↓
 × ... many times ...
     ↓
gradient at an earlier time

Repeated multiplication can make gradient magnitudes become extremely small or extremely large.

The small-gradient case is the vanishing-gradient problem.

The large-gradient case is the exploding-gradient problem.

LSTM was introduced to make the flow of information and gradients more manageable through its gated memory design.

4. The Core LSTM Idea

An LSTM maintains two important states:

\[ \boxed{h_t}\qquad\text{hidden state} \]

and

\[ \boxed{c_t}\qquad\text{cell state} \]

Think of them differently:

Quantity Intuition Role
\(c_t\) long-lived memory pathway carries information across time
\(h_t\) current exposed state used for current computation/output

The cell state is the key architectural idea.

Instead of forcing all information through one repeatedly transformed hidden state, LSTM creates a path where information can be selectively retained or removed.

6. The Three Main Gates

The standard LSTM formulation uses sigmoid gates.

Because sigmoid outputs values in

\[ (0,1), \]

a gate can be interpreted as a soft control value:

0       ≈ block almost completely
0.5     ≈ partial passage
1       ≈ allow almost completely

There are three commonly named gates.

6.1 Forget Gate

The forget gate decides how much of the old cell state should remain.

\[ \boxed{ f_t=\sigma(W_f[h_{t-1},x_t]+b_f)} \]

Interpretation:

“How much of the old memory should I keep?”

If a component of \(f_t\) is close to 1, that component of the old memory is largely retained.

If it is close to 0, that component is largely removed.

6.2 Input Gate

The input gate decides how strongly new information should be written.

\[ \boxed{ i_t=\sigma(W_i[h_{t-1},x_t]+b_i)} \]

Interpretation:

“How much new information should be written into memory?”

6.3 Output Gate

The output gate controls how much of the internal memory becomes part of the hidden state.

\[ \boxed{o_t=\sigma(W_o[h_{t-1},x_t]+b_o)} \]

Interpretation:

“How much of the current memory should be exposed?”

7. The Candidate Memory

The network also creates a candidate update.

A standard formulation is:

\[ \boxed{ \tilde c_t= anh(W_c[h_{t-1},x_t]+b_c) } \]

The candidate says:

“Here is new information that could be written into the cell state.”

The word candidate matters.

The model does not necessarily accept all of it.

The input gate controls how much is actually written.

8. Updating the Cell State

PYTHON
import numpy as np

class LSTMCell:
    def __init__(self, input_dim, hidden_dim):
        self.hidden_dim = hidden_dim
        concat_dim = input_dim + hidden_dim
        
        # Initialize gate weights
        self.Wf = np.random.randn(hidden_dim, concat_dim) * 0.01 # Forget
        self.Wi = np.random.randn(hidden_dim, concat_dim) * 0.01 # Input
        self.Wc = np.random.randn(hidden_dim, concat_dim) * 0.01 # Candidate
        self.Wo = np.random.randn(hidden_dim, concat_dim) * 0.01 # Output
        
        self.bf = np.ones((hidden_dim, 1)) # Initialize forget bias to 1.0 (Jozefowicz 2015)
        self.bi = np.zeros((hidden_dim, 1))
        self.bc = np.zeros((hidden_dim, 1))
        self.bo = np.zeros((hidden_dim, 1))

    def sigmoid(self, z):
        return 1.0 / (1.0 + np.exp(-z))

    def step(self, x_t, h_prev, c_prev):
        # Concatenate hidden state and input
        concat = np.vstack((h_prev, x_t))

        # 1. Forget Gate
        f_t = self.sigmoid(np.dot(self.Wf, concat) + self.bf)
        # 2. Input Gate & Candidate
        i_t = self.sigmoid(np.dot(self.Wi, concat) + self.bi)
        c_cand = np.tanh(np.dot(self.Wc, concat) + self.bc)
        # 3. Additive Cell State Update (The Highway!)
        c_t = f_t * c_prev + i_t * c_cand
        # 4. Output Gate & Hidden State
        o_t = self.sigmoid(np.dot(self.Wo, concat) + self.bo)
        h_t = o_t * np.tanh(c_t)

        return h_t, c_t, (f_t, i_t, o_t)

# Run a test step
cell = LSTMCell(input_dim=5, hidden_dim=10)
x_test = np.random.randn(5, 1)
h_init = np.zeros((10, 1))
c_init = np.zeros((10, 1))

h_next, c_next, gates = cell.step(x_test, h_init, c_init)
print("LSTM Step executed successfully!")
print("New Hidden State h_t shape:", h_next.shape)
print("New Cell State C_t shape:  ", c_next.shape)
print("Mean Forget Gate Activation (near 1.0 keeps memory):", gates[0].mean().round(3))

The central memory equation is:

\[ \boxed{ c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t } \]

where \(\odot\) means element-wise multiplication.

This equation deserves serious attention.

It says:

new memory
   =
kept old memory
   +
selected new information

More formally:

\[ \underbrace{f_t\odot c_{t-1}}_{\text{retain old information}} + \underbrace{i_t\odot\tilde c_t}_{\text{write selected new information}} \]

This is the heart of the LSTM idea.

9. Producing the Hidden State

After updating the cell state, the output gate determines what is exposed:

\[ \boxed{ h_t=o_t\odot\tanh(c_t) } \]

So:

cell state cₜ
     ↓ tanh
candidate visible representation
     ↓ × output gate
hidden state hₜ

The hidden state can then be used for:

  • the next recurrent step;
  • sequence prediction;
  • classification;
  • sequence-to-sequence processing;
  • other downstream tasks.

10. Full LSTM Equations — Formula Card

Let

\[ q_t=[h_{t-1},x_t] \]

represent concatenation of the previous hidden state and current input.

Then:

Forget gate

\[ \boxed{f_t=\sigma(W_fq_t+b_f)} \]

Input gate

\[ \boxed{i_t=\sigma(W_iq_t+b_i)} \]

Candidate cell content

\[ \boxed{\tilde c_t=\tanh(W_cq_t+b_c)} \]

Cell update

\[ \boxed{c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t} \]

Output gate

\[ \boxed{o_t=\sigma(W_oq_t+b_o)} \]

Hidden state

\[ \boxed{h_t=o_t\odot\tanh(c_t)} \]

12. Why Use Sigmoid for Gates?

The sigmoid is:

\[ \boxed{ \sigma(z)=\frac{1}{1+e^{-z}} } \]

and satisfies:

\[ 0\lt \sigma(z)\lt 1. \]

That makes it useful for soft gating.

A gate does not have to say only:

“Yes” or “No.”

It can say:

“Pass about 80%.”

That gives the model differentiable control.

13. Why Use Tanh for the Candidate?

\[ \tanh(z)\in(-1,1). \]

The candidate therefore provides signed information.

Conceptually:

sigmoid → how much?
         (control)

tanh    → what content?
         (candidate information)

This is a helpful mental model, not a complete description of learned representations.

14. A Numerical Micro-Example

To understand the memory equation without doing a complete matrix calculation, suppose one memory component has:

\[ f_t=0.9, \qquad c_{t-1}=2, \qquad i_t=0.4, \qquad \tilde c_t=0.5. \]

Then:

\[ c_t =0.9(2)+0.4(0.5) \]
\[ =1.8+0.2 \]
\[ \boxed{c_t=2.0} \]

Interpretation:

  • most of the previous memory was kept;
  • some new information was written;
  • the final memory is their controlled combination.

15. Another Numerical Micro-Example: Forgetting

Suppose:

\[ f_t=0.1, \qquad c_{t-1}=5, \qquad i_t=0. \]

Then:

\[ c_t=0.1(5)=0.5. \]

Most of the old memory component has been suppressed.

This shows why the forget gate is conceptually important.

16. The “Memory Conveyor Belt” Analogy

Imagine a conveyor belt carrying information through time.

A worker can:

  1. remove some old items;
  2. place selected new items;
  3. inspect the belt and expose selected items.

Map that to LSTM:

Analogy LSTM
conveyor-belt memory cell state \(c_t\)
remove old items forget gate
decide what new items enter input gate
proposed new items candidate state
show selected items output gate
visible worker state hidden state \(h_t\)

Where the analogy breaks

A real LSTM does not manipulate symbolic objects or “understand” what a memory component means.

The states are numerical vectors learned from data.

17. LSTM vs Basic RNN

Property Basic RNN LSTM
Hidden state Yes Yes
Explicit cell state No Yes
Learnable gates No standard gated memory Yes
Long-range dependency handling Can be difficult Designed to improve this
Architecture simpler more complex
Parameters per recurrent unit fewer more
Main idea recurrent transformation gated recurrent memory

Important:

LSTM does not magically guarantee perfect long-range learning.

It provides an architecture designed to make memory preservation and gradient flow more manageable than a plain recurrent formulation.

18. LSTM vs GRU — Beyond the Syllabus Core

A related architecture is the Gated Recurrent Unit (GRU).

Both use gating to control recurrent information.

A high-level contrast is:

LSTM GRU
Separate cell state Yes No separate cell state in the standard formulation
Main states \(h_t,c_t\) primarily \(h_t\)
Gate structure more explicit more compact
Historical teaching value classic gated-memory model simplified alternative

This is enrichment. The official Unit III syllabus item is LSTM.

19. Sequence Tasks Where LSTM Can Be Used

Typical sequence tasks include:

Many-to-one

x₁ x₂ x₃ x₄ → LSTM → one label

Example intuition:

sentence → sentiment class

Many-to-many

x₁ → y₁
x₂ → y₂
x₃ → y₃
x₄ → y₄

Many-to-one time-series prediction

past measurements → LSTM → future prediction

The choice of architecture depends on the task, data and objective.

LSTM is still trained using gradient-based optimization.

sequence
   ↓

   ↓

   ↓

   ↓

   ↓

21. Why LSTM Is More Complex

LSTM adds several parameterized transformations.

At a high level, the gates require multiple weight matrices and biases.

Therefore, relative to a simple RNN of the same hidden width, an LSTM typically has substantially more trainable parameters.

The extra complexity buys a more expressive mechanism for controlling information flow.

This leads to a general engineering principle:

More expressive architecture often means more parameters, more computation and more opportunities for training difficulty.

22. Common Misconceptions

Misconception 1

“LSTM remembers everything.”

No.

It learns selective information flow.

Misconception 2

“The forget gate permanently deletes a human-readable memory.”

No.

It scales numerical components of the cell state.

Misconception 3

“LSTM has solved vanishing gradients completely.”

No.

Its architecture is designed to improve the situation, not to eliminate every optimization problem.

Misconception 4

“The cell state and hidden state are the same thing.”

No.

They have distinct roles in the standard LSTM architecture.

Misconception 5

“Every LSTM output is automatically the final prediction.”

No.

The hidden state may be passed to another layer, another time step, or an output head.

23. Failure Modes and Practical Caveats

Even though LSTM was designed to address limitations of plain RNNs, training can still involve:

  • exploding gradients;
  • poor hyperparameter choices;
  • overfitting;
  • unnecessary computational cost;
  • difficulty handling very long contexts compared with newer sequence architectures;
  • sensitivity to data representation and sequence length.

Modern systems often use other sequence architectures too, but that is beyond the core Unit III route here.

28. LSTM Memory Card

FORGET decides what old information remains.
INPUT decides what new information enters.
CANDIDATE proposes new content.
CELL STATE carries the controlled memory.
OUTPUT decides what becomes visible as the hidden state.

A compact mnemonic:

FORGET → KEEP?
INPUT  → WRITE?
CANDIDATE → WHAT?
OUTPUT → SHOW?
