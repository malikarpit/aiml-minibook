1. Why This Chapter Exists

You already know what supervised learning is:

  • we have examples;
  • each example contains input information x;
  • we have a target y;
  • we want a model that can predict y for new x.

Now we need to answer a very concrete question:

How do we actually choose a mathematical function that predicts a continuous numerical value?

Suppose we want to predict:

  • house price from area;
  • salary from experience;
  • electricity consumption from temperature;
  • crop yield from rainfall and fertilizer usage.

A natural first attempt is a line.

That simple idea leads to linear regression.

Your Lecture 9 introduces linear regression as a model whose parameters are chosen to best fit the training data. It then develops vector notation, a squared-loss objective, gradients, convexity and the least-squares solution. Course source: Lecture09.pdf, slides 10–21.

2. One-Minute Intuition

English

Linear regression tries to draw the best-fitting straight-line relationship between input features and a continuous target.

For one feature:

price
  ↑
  |          •
  |       •
  |    •       •
  |  •
  |________________→ area
          line

The line will rarely pass through every point.

Instead, we choose the line whose predictions are, according to our chosen loss, collectively as close as possible to the observed targets.

👨‍🏫 Hinglish
Socho tumhare paas bahut saare houses ka data hai: > area pata hai, price pata hai. Tum dekhte ho ki generally area badhne par price bhi badhta hai. Ab tum ek **seedhi line** kheenchna chahte ho jo overall data ke trend ko represent kare. Ye line har point ko perfectly touch nahi karegi. Goal ye hai: > **“Aisi line choose karo jo overall mistakes ko minimum kare.”** Yahi linear regression ka central idea hai.

3. What Does “Linear” Mean?

The word linear refers to the form of the model with respect to its parameters/features in the lecture's formulation.

For one feature:

\[ \boxed{f(x)=w_1x+w_2} \]

This is a straight line.

You may recognize the school formula:

\[ y=mx+c \]

The correspondence is:

School mathematics Linear regression
\(m\) slope / learned weight
\(c\) intercept / bias term
\(x\) input feature
\(y\) predicted output
👨‍🏫 Hinglish
> `m` batata hai line kitni tez upar/neeche ja rahi hai. > `c` batata hai line vertically kahan se start ho rahi hai. ML bas isko **data se learn** karne wala framework bana deta hai.

4. What Are We Actually Learning?

Suppose the model is:

\[ f(x)=w_1x+w_2 \]

The data gives us x and y.

The unknown quantities are:

\[ w_1,\;w_2 \]

These are the model's parameters.

Training means:

Find parameter values that make the model fit the training data according to the chosen objective.

So the basic learning problem is:

Training data
     ↓
Choose model form
     ↓
Unknown parameters
     ↓
Find parameters that minimise loss
     ↓
Trained linear model

This is the bridge from supervised learning as an abstract idea to an actual mathematical model.

5. Real-World Analogy — Fitting a Ruler to a Cloud of Points

Imagine you throw a lot of tiny paper clips onto a table.

You want to place one straight ruler through the collection so that the ruler represents the overall direction of the cloud.

You can rotate the ruler.

You can move it up and down.

Different positions create different distances between the ruler and the points.

Linear regression asks:

Which position/orientation gives the best overall fit according to our error measure?

👨‍🏫 Hinglish
> Data points ko ek crowd samjho. Regression line ek ruler hai. Tum ruler ko aise set karna chahte ho ki overall crowd se uski distance/error minimum ho.

6. A Single-Feature Example

Suppose the feature is house area and the target is price.

House Area \(x\) Price \(y\)
A 1 2
B 2 4
C 3 5
D 4 8

A candidate model could be:

\[ f(x)=1.8x \]

At x=3:

\[ f(3)=5.4 \]

Observed value:

\[ y=5 \]

Prediction error:

\[ 5.4-5=0.4 \]

A different line would produce different errors.

Training is the process of choosing the parameters systematically rather than guessing them.

7. From One Feature to Many Features

Real prediction problems usually have more than one useful input.

For a salary model, we might use:

  • years of experience;
  • education level;
  • location;
  • job level.

For multiple features, the lecture writes a linear model such as:

\[ f(\mathbf{x}) = w_1x_1+w_2x_2+\cdots+w_{d-1}x_{d-1}+w_d \]

For two input features this gives a plane:

\[ f(x_1,x_2)=w_1x_1+w_2x_2+w_3 \]

For still more features, the geometric object is a hyperplane.

Course source: Lecture09.pdf, slide 11.

8. What Is a Feature?

A feature is an input variable used by the model.

Example:

House prediction

x₁ = area
x₂ = number of bedrooms
x₃ = distance from metro
x₄ = age of building

Then one observation might be:

\[ \mathbf{x}= \begin{bmatrix} 1200\\ 3\\ 1.8\\ 5 \end{bmatrix} \]

and the model combines these values using learned weights.

9. The Weight Intuition

Consider:

\[ f(\mathbf{x})=w_1x_1+w_2x_2+w_3 \]

The weight tells us how strongly a feature contributes within the model.

If:

\[ w_1=4 \]

then changing x₁ by one unit changes the model output by 4 units, holding the other inputs fixed.

This interpretation assumes the feature is expressed in the given units and the model is used within its intended setting.

👨‍🏫 Hinglish
> Weight ko feature ka “importance knob” samajhna useful intuition hai, lekin blindly ye mat maan lena ki bada weight always greater real-world importance prove karta hai. Units aur feature scaling matter karte hain.

10. The Intercept / Bias Term

A line such as

\[ f(x)=w_1x+b \]

has an intercept b.

Your Lecture 9 simplifies notation by adding a dummy feature with value 1.

Instead of separately writing b, define:

\[ \tilde{x} = \begin{bmatrix} x_1\\x_2\\\vdots\\x_{d-1}\\1 \end{bmatrix} \]

and include the intercept inside the weight vector.

Then:

\[ \boxed{f(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x}} \]

where the last component of x is 1.

Course source: Lecture09.pdf, slide 12.

Why do this?

It turns:

\[ w_1x_1+w_2x_2+\cdots+b \]

into a single dot product.

That makes later matrix/vector derivations much cleaner.

👨‍🏫 Hinglish
> Extra `1` ko ek mathematical trick samjho. Isse intercept bhi normal weight ke saath same dot-product expression mein aa jata hai.

11. Vector Notation — The Version You Should Recognize Instantly

The lecture's notation can be summarized as:

\[ \mathbf{w} = \begin{bmatrix} w_1\\w_2\\\vdots\\w_d \end{bmatrix} \]

and

\[ \mathbf{x} = \begin{bmatrix} x_1\\x_2\\\vdots\\x_{d-1}\\1 \end{bmatrix} \]

Therefore:

\[ \boxed{f(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x}} \]

Expanding the dot product:

\[ \mathbf{w}^{\top}\mathbf{x} = w_1x_1+w_2x_2+\cdots+w_{d-1}x_{d-1}+w_d \]

This is not a new model.

It is the same model written compactly.

12. Why Are We Writing Everything With Vectors?

Because ML datasets contain many examples and many features.

Writing everything one variable at a time quickly becomes unreadable.

Vector notation lets us move from:

one prediction

to:

all predictions

and eventually to:

matrix operations on the entire dataset

This is why the linear algebra from your Lecture04 matters here.

13. What Does “Best Fit” Mean?

We need a definition of best.

The lecture chooses squared prediction error.

For training examples:

\[ (\mathbf{x}_1,y_1), (\mathbf{x}_2,y_2), \ldots, (\mathbf{x}_n,y_n) \]

prediction for example i is:

\[ f(\mathbf{x}_i)=\mathbf{w}^{\top}\mathbf{x}_i \]

The residual/error is:

\[ \boxed{ \mathbf{w}^{\top}\mathbf{x}_i-y_i } \]

The squared-loss objective in the lecture is:

\[ \boxed{ L(\mathbf{w}) = \frac{1}{n} \sum_{i=1}^{n} \left(\mathbf{w}^{\top}\mathbf{x}_i-y_i\right)^2 } \]

Training asks for the parameter vector that minimizes this quantity.

Course source: Lecture09.pdf, slide 12.

14. Why Square the Error?

Suppose errors are:

\[ +3,\quad -3 \]

If we simply add them:

\[ 3+(-3)=0 \]

It would appear that the model made no error overall, even though both predictions were wrong.

Squaring fixes the cancellation:

\[ 3^2=9, \qquad (-3)^2=9 \]

So squared error treats both positive and negative deviations as positive contributions to loss.

It also makes larger errors count disproportionately more.

👨‍🏫 Hinglish
> `+3` aur `-3` ko direct add karoge toh cancel ho jayenge. Square karne se dono error positive ban jate hain, aur bada error aur zyada punish hota hai.

15. The Geometry of Linear Regression

For one feature:

y
 ↑
 |             •
 |          •     •
 |       •
 |    •
 |  /──────────────  fitted line
 | /
 +──────────────────→ x

For two features:

z = w₁x₁ + w₂x₂ + b
                 ↑
              plane
             /\
            /  \
           /____\
         x₁      x₂

For more features, we cannot draw the geometry directly, but the algebra remains the same.

16. What the Model Is Actually Doing

The model performs this sequence:

Input features
     ↓
Multiply each feature by its weight
     ↓
Add the contributions
     ↓
Add the intercept/bias
     ↓
Produce prediction

For example:

\[ x_1=2,\quad x_2=5 \]
\[ w_1=3,\quad w_2=4,\quad b=1 \]

Then:

\[ f(x)=3(2)+4(5)+1 \]
\[ =6+20+1=27 \]

Prediction:

\[ \boxed{27} \]

The training algorithm's job is to discover better values of w and b from data.

17. A Complete Tiny Example

Suppose:

x y
1 2
2 3
3 5

Candidate model:

\[ f(x)=1.4x+0.2 \]

Predictions:

  • x=1 → 1.6
  • x=2 → 3.0
  • x=3 → 4.4

Errors:

\[ -0.4,\quad 0,\quad -0.6 \]

Squared errors:

\[ 0.16,\quad 0,\quad 0.36 \]

Mean squared error:

\[ \frac{0.16+0+0.36}{3} = \frac{0.52}{3} \approx0.1733 \]

This is how a candidate model can be quantitatively evaluated.

Important: a low MSE for one candidate does not prove it is the best possible parameter setting. Training searches for the minimizer.

18. The Optimization View

Linear regression is not only a drawing exercise.

It is an optimization problem:

\[ \boxed{ \min_{\mathbf{w}} L(\mathbf{w}) } \]

with:

\[ L(\mathbf{w}) = \frac1n\sum_{i=1}^{n} \left(\mathbf{w}^{\top}\mathbf{x}_i-y_i\right)^2 \]

We are changing the parameters w until the loss is as small as possible.

That creates the connection:

Linear regression
      ↓
Loss function
      ↓
Optimization problem
      ↓
Gradient / closed-form solution

The detailed mathematics belongs in C19.

19. Convexity — Why Linear Regression Is Pleasant Mathematically

Your Lecture 9 introduces convexity before computing the gradient.

A function g is convex when, informally, it has a bowl-like structure rather than a collection of deceptive local valleys.

The course writes the formal condition as:

\[ g(\lambda\mathbf{x}+(1-\lambda)\mathbf{y}) \le \lambda g(\mathbf{x})+(1-\lambda)g(\mathbf{y}) \]

for all relevant x, y and \(\lambda\in[0,1]\).

The important optimization consequence stated in the lecture is:

For a differentiable convex function, a point with zero gradient is a global minimizer.

Course source: Lecture09.pdf, slide 13.

👨‍🏫 Hinglish
> Bowl ke bottom ko imagine karo. Agar function convex hai, gradient zero wala stationary point global minimum ko represent karta hai under the lecture's conditions. This is a major reason least-squares linear regression is mathematically tractable.

20. Data Preprocessing Is Part of the Workflow

Before fitting a linear model, the raw data may not be ready to use.

Your Lecture 9 explicitly covers:

  • categorical data;
  • one-hot encoding;
  • ordinal encoding;
  • standardization;
  • min-max scaling.

Course source: Lecture09.pdf, slides 5–9.

21. Categorical Data

Some features are not naturally numeric.

Examples:

Colour = Red / Blue / Green

or:

Severity = Mild / Moderate / Severe

The lecture distinguishes two types.

Nominal

There is no natural order.

Example:

  • Red
  • Blue
  • Green

You cannot meaningfully say:

Red < Blue < Green

Ordinal

There is a meaningful order.

Example:

  • Mild
  • Moderate
  • Severe

The order carries information.

22. One-Hot Encoding

Suppose:

Colour ∈ {Red, Blue, Green}

One-hot encoding can represent each category with indicator columns:

Colour Red Blue Green
Red 1 0 0
Blue 0 1 0
Green 0 0 1

Why?

Because assigning:

Red = 1
Blue = 2
Green = 3

would incorrectly suggest numerical distance/order.

👨‍🏫 Hinglish
> One-hot ka idea hai category ko number ki fake ranking dene ke bajaye separate yes/no indicators use karna.

23. Ordinal Encoding

For genuinely ordered categories, numeric encoding may be meaningful.

Example:

Mild     → 1
Moderate → 2
Severe   → 3

The ordering carries information.

But the exact numeric spacing should not automatically be interpreted as a scientifically meaningful distance unless the application supports that interpretation.

24. Why Feature Scaling Matters

Imagine two features:

Temperature: 97–102
Salary:      100,000–5,000,000

Their numerical scales are vastly different.

The Lecture 9 example demonstrates that without scaling, a distance calculation can be dominated by a large-scale feature.

This matters especially for distance-based algorithms such as K-NN.

It also matters for optimization because poorly scaled parameters/features can produce inefficient optimization geometry.

Course source: Lecture09.pdf, slides 7–9.

25. Standardization

The lecture gives:

\[ \boxed{ x_j\leftarrow\frac{x_j-\mu_j}{\sigma_j}} \]

where:

  • \(\mu_j\) = mean of feature j;
  • \(\sigma_j\) = standard deviation of feature j.

The intent is to produce approximately:

  • zero mean;
  • unit variance.
👨‍🏫 Hinglish
> Feature ko uske average se compare karo aur phir us feature ke spread se divide karo. Isse different units ko more comparable scale mil jata hai.

26. Min-Max Scaling

The lecture gives:

\[ \boxed{ x_j \leftarrow \frac{x_j-\min(x_j)}{\max(x_j)-\min(x_j)}} \]

This maps the observed feature range to:

\[ [0,1] \]

When is this intuitive?

When a bounded scale is useful or when you explicitly want the feature represented relative to its observed minimum and maximum.

27. Train/Test Split Before Scaling

This is an important methodological rule.

The test set is supposed to represent unseen data.

Therefore, statistics used to preprocess the training data should not leak information from the final test set into the training process.

The safe conceptual workflow is:

Full data
   ↓
Train / validation / test split
   ↓
Fit preprocessing parameters on training data
   ↓
Transform training data
   ↓
Use the same fitted transformation on validation/test data

This keeps the test set genuinely held out.

28. Feature Scaling and Optimization

Your Lecture 9 explicitly connects feature scaling with optimization.

Poorly scaled features can create an optimization landscape with very different scales in different directions.

A gradient-based method can then move inefficiently.

After more appropriate scaling, the contours can become easier to traverse.

Conceptually:

Poor scaling                    Better scaling

      ______                         ______
    /        \                     /        \
   /          \                   /          \
  /            \                 /            \
  \            /                 \            /
   \          /                   \          /
    \________/                     \________/

long narrow contours              more balanced contours

Course source: Lecture09.pdf, slide 9.

This is one reason mathematics, preprocessing and optimization cannot be studied as isolated topics.

29. Linear Regression and Hypothesis Classes

Connect this chapter back to C16.

A hypothesis class specifies which functions the learner is allowed to consider.

Linear regression chooses from a class of linear functions.

All possible functions
        │
        ├── arbitrary functions
        │
        ├── decision trees
        │
        ├── K-NN functions
        │
        ├── neural networks
        │
        └── linear functions
                    ↑
             Linear regression

This restriction is not automatically a weakness.

It is an inductive bias.

If the true relationship is approximately linear, restricting the model can improve generalization.

If the relationship is strongly nonlinear, the restriction may create high bias.

This connects directly to C17.

30. Linear Regression and Overfitting

A simple linear model has limited flexibility.

You can make it more flexible by expanding the feature representation, for example with polynomial features.

Suppose:

\[ f(x)=w_0+w_1x+w_2x^2+w_3x^3 \]

The function is nonlinear in x, even though it is still linear in the parameters w.

This subtle distinction matters.

A richer feature representation can reduce bias, but too much flexibility can increase variance and overfitting.

Your Lecture 10 continues this exact story through feature expansion and the motivation for regularization.

31. What “Linear in the Parameters” Means

Consider:

\[ f(x)=w_0+w_1x+w_2x^2 \]

The model is nonlinear as a function of x because of \(x^2\).

But each parameter appears only linearly:

\[ w_0, \quad w_1, \quad w_2 \]

There are no terms such as:

\[ w_1^2 \]

or

\[ w_1w_2 \]

in the parameterization.

This is why polynomial-feature regression can still be treated through a linear-model framework.

32. Error, Residual, and Loss — Do Not Mix Them Up

These words are related but not identical.

Residual / prediction error for one observation

\[ \boxed{e_i=\hat y_i-y_i} \]

Squared error

\[ e_i^2 \]

Total squared error

\[ \sum_i e_i^2 \]

Mean squared error

\[ \frac1n\sum_i e_i^2 \]

The Lecture 9 least-squares derivation uses the summed squared error in some derivation steps and the averaged version when defining the learning objective.

Multiplying the objective by a positive constant does not change its minimizer.

33. What the Gradient Will Tell Us

For a multivariable objective:

\[ L(\mathbf{w}) \]

we need to know how changing each parameter changes the loss.

That information is represented by the gradient:

\[ \nabla_{\mathbf{w}}L(\mathbf{w}) \]

The Lecture 9 derivation uses the gradient to locate a stationary point:

\[ \boxed{\nabla_{\mathbf{w}}L(\mathbf{w})=0} \]

Because the least-squares objective is convex under the course formulation, this stationary point corresponds to the global minimum when the relevant differentiability/convexity conditions hold.

The complete derivation is the subject of C19.

35. English Teacher Explanation — The Whole Chapter

Linear regression is a supervised learning method for predicting a numerical target.

We choose a linear function of the input features. The parameters of the function are unknown. We use labelled training data to determine parameters that minimize a squared-error objective.

For a single input, the model is a line.

For multiple inputs, the model is a hyperplane in the corresponding feature space.

The model can be written compactly as:

\[ f(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x} \]

when the intercept has been absorbed using the dummy feature trick used in the lecture.

The training problem becomes an optimization problem over w.

36. Hinglish Teacher Explanation — The Whole Chapter

Linear regression basically bolta hai: input features lo, unko learned weights ke saath combine karo, aur numerical output predict karo.

For example:

Area + bedrooms + location information → house price.

Model line/plane banata hai.

Phir dekhta hai:

“Meri prediction actual value se kitni door hai?”

Sab examples ki squared mistakes combine karke loss banta hai.

Phir parameters aise choose kiye jate hain ki ye loss minimum ho.

Toh complete story:

Data → model → prediction → error → loss → parameter fitting.

37. Common Misconceptions

Misconception 1

“Linear regression means only one feature.”

Wrong.

It can use many features.

Misconception 2

“Linear regression always produces a visually straight line.”

Only in one input dimension.

With two features it produces a plane; with more features, a hyperplane.

Misconception 3

“Linear means linear in the input only.”

The important formal idea is linearity in the model parameters in this framework.

Polynomial features can still be fitted with a linear model in the parameters.

Misconception 4

“The fitted line must pass through every training point.”

No.

The goal is to minimize the chosen loss, not necessarily to interpolate every observation.

Misconception 5

“A bigger weight always means the feature is more important.”

Not directly. Units and scaling affect numerical weight magnitude.

Misconception 6

“Scaling changes the underlying information in the data.”

A properly applied scaling transformation changes representation/units; it does not inherently create new information.

Misconception 7

“We can calculate the scaling mean and standard deviation using the entire dataset before the split.”

For a properly held-out final test set, that can leak information from the test set into preprocessing. Fit preprocessing parameters on the training data and apply the learned transformation to held-out data.

Linear model — one feature

\[ \boxed{f(x)=w_1x+b} \]

Linear model — multiple features

\[ \boxed{f(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x}+b} \]

Lecture's dummy-feature notation

\[ \boxed{f(\mathbf{x})=\mathbf{w}^{\top}\mathbf{x}} \]

with the final component of x equal to 1.

Prediction error

\[ \boxed{e_i=\hat y_i-y_i} \]

Mean squared error objective

\[ \boxed{ L(\mathbf{w}) = \frac1n\sum_{i=1}^{n} (\mathbf{w}^{\top}\mathbf{x}_i-y_i)^2 } \]

Standardization

\[ \boxed{x_j\leftarrow\frac{x_j-\mu_j}{\sigma_j}} \]

Min-max scaling

\[ \boxed{x_j\leftarrow\frac{x_j-\min(x_j)}{\max(x_j)-\min(x_j)}} \]

47. Memory Card

LINEAR REGRESSION

Input features → weighted sum → prediction

\[ \gt \hat y=\mathbf{w}^{\top}\mathbf{x} \gt \]

Compare prediction with truth:

\[ \gt e_i=\hat y_i-y_i \gt \]

Measure squared error:

\[ \gt L(\mathbf{w})=\frac1n\sum_i e_i^2 \gt \]

Learn parameters by minimizing the loss.

Data preparation matters: encode categories and scale features appropriately.
