Main Book: AI & Machine Learning — Visual + Mathematical Self-Learning Textbook

Prerequisites: ML-U2-C22 Decision Trees, basic probability, fractions, logarithms, expectation/weighted average
University syllabus: Unit II — Decision Trees
Primary note status: The supplied lecture set does not contain a dedicated decision-tree mathematics lecture; this chapter is therefore an explicitly marked universal/external expansion.
External academic basis: NPTEL decision-tree material, An Introduction to Statistical Learning, and scikit-learn's mathematical formulation of classification-tree impurity.
Coding: Intentionally omitted here; implementation belongs to your separate coding workflow.

1. Why This Mathematics Matters

C22 gave you the picture:

At every node, choose a useful question.

But “useful” is vague.

We need a number that lets us compare two candidate splits.

That creates the mathematical problem:

How mixed is this node?
        ↓
How mixed are the children after a split?
        ↓
Did the split reduce the mixing?
        ↓
Choose the split with the better reduction

Three ideas become central:

  1. Entropy
  2. Information Gain
  3. Gini Impurity

The same basic story sits underneath all three:

Measure impurity → evaluate a candidate split → choose a split that makes the child nodes cleaner.

2. Math Prerequisite: Probabilities Inside a Node

Suppose a node contains:

  • 8 examples of class A;
  • 2 examples of class B.

Total:

\[ 8+2=10 \]

The class proportions are:

\[ p_A=\frac{8}{10}=0.8 \]
\[ p_B=\frac{2}{10}=0.2 \]

These proportions behave like a probability distribution over the classes inside that node.

Node
├── A: 80%
└── B: 20%
👨‍🏫 Hinglish
> Node ke andar kaun kitna hai, uska percentage nikaalo. Ye percentages hi baad mein impurity calculate karne ke liye use honge.

3. The Pure Node

Suppose a node contains:

10 A
0 B

Then:

\[ p_A=1, \qquad p_B=0 \]

There is no class uncertainty.

The model can say:

“Everything reaching this node is class A.”

So the node is pure.

A good impurity measure should therefore assign its minimum value to a pure node.

For entropy and Gini impurity, that minimum is 0.

4. The Most Mixed Two-Class Node

Suppose a node contains:

5 A
5 B

Then:

\[ p_A=0.5, \qquad p_B=0.5 \]

The node is maximally uncertain for the two-class case.

This gives the basic visual relationship:

Pure                  Most mixed
100/0    90/10   70/30   50/50
  ↓        ↓       ↓       ↓
Low impurity  ─────────→  High impurity

Entropy and Gini quantify this idea differently.

5. Entropy — First Intuition

Entropy measures uncertainty in a probability distribution.

For a classification node:

High entropy = classes are mixed.
Low entropy = one class dominates.

Everyday analogy

Imagine a bag containing coloured balls.

Bag A

10 red
0 blue

You already know what you will pull.

Very little uncertainty.

Bag B

5 red
5 blue

You are much less certain.

Higher uncertainty → higher entropy.

6. Entropy Formula

For a node with classes \(1,2,\dots,K\):

\[ \boxed{ H(S)=-\sum_{k=1}^{K}p_k\log_2 p_k } \]

where:

  • \(S\) = node/data subset;
  • \(K\) = number of classes;
  • \(p_k\) = proportion of examples belonging to class \(k\).

Important convention

When:

\[ p_k=0 \]

we take:

\[ p_k\log p_k=0 \]

by the standard limiting convention.

7. Formula Card — Entropy

Formula

\[ H(S)=-\sum_{k=1}^{K}p_k\log_2p_k \]

Meaning

Average uncertainty associated with the class distribution.

Hinglish

“Node kitna mixed hai?”

Pure node

\[ H=0 \]

Two-class 50/50 node

\[ H=1 \]

using \(\log_2\).

Why base 2?

Using base 2 expresses entropy in bits.

The choice of log base changes the numerical scale consistently, not the basic ranking of splits when the same base is used throughout.

8. Entropy Worked Example — Pure Node

Suppose:

10 A
0 B

Then:

\[ p_A=1, \quad p_B=0 \]

So:

\[ H =-\left(1\log_2 1+0\log_2 0\right) \]

Using the standard zero-term convention:

\[ \log_2 1=0 \]

therefore:

\[ \boxed{H=0} \]

Interpretation

No class uncertainty.

9. Entropy Worked Example — 50/50 Node

Suppose:

5 A
5 B

Then:

\[ p_A=0.5, \qquad p_B=0.5 \]

Therefore:

\[ H =-\left(0.5\log_2 0.5+0.5\log_2 0.5\right) \]

Because:

\[ \log_2 0.5=-1 \]

we get:

\[ H =-\left(0.5(-1)+0.5(-1)\right) \]
\[ =1 \]

So:

\[ \boxed{H=1\text{ bit}} \]

Interpretation

For a binary class distribution, this is the maximum entropy.

10. Entropy Worked Example — 80/20

Suppose:

8 A
2 B

Then:

\[ p_A=0.8, \qquad p_B=0.2 \]

Entropy:

\[ H=-\left(0.8\log_2 0.8+0.2\log_2 0.2\right) \]

Numerically:

\[ H\approx0.722 \]

Therefore:

\[ \boxed{H\approx0.722\text{ bits}} \]

This is lower than 1 because the node is less mixed than a 50/50 node.

11. Why Entropy Is a Good Fit for Trees

At a decision-tree node, we want to know:

“How much uncertainty remains about the class?”

Entropy gives us exactly a number for that.

Then we can compare:

Parent entropy
       ↓
Candidate split
       ↓
Child entropies
       ↓
How much uncertainty disappeared?

That last question is information gain.

12. Information Gain — Intuition

Imagine a teacher gives you a box containing mixed red and blue balls.

Before asking a question, you are uncertain.

After asking a useful question, the boxes become much cleaner.

The information gained is related to:

How much uncertainty did the split remove?

So:

Information Gain
      =
Parent uncertainty
      −
Weighted child uncertainty

13. Information Gain Formula

For parent dataset \(S\) split into children \(S_1,S_2,\dots,S_m\):

\[ \boxed{ IG(S,A)=H(S)- \sum_{j=1}^{m}\frac{|S_j|}{|S|}H(S_j) } \]

where:

  • \(A\) = candidate splitting rule/attribute;
  • \(H(S)\) = parent entropy;
  • \(|S_j|/|S|\) = fraction of examples sent to child \(j\);
  • \(H(S_j)\) = entropy of child \(j\).

The weighting is crucial.

A tiny child with zero entropy should not automatically make a split look perfect if it contains almost no data.

14. Why Do We Need the Weighted Average?

Suppose a split creates:

Child A → 99 samples
Child B → 1 sample

Imagine Child A is moderately pure and Child B is perfectly pure.

Should the 1-example child dominate our decision?

No.

The split criterion should reflect how the whole dataset is distributed.

Hence:

\[ \frac{|S_j|}{|S|} \]

acts as a weight.

👨‍🏫 Hinglish
> “Ek 1-example leaf ko 99-example leaf ke barabar importance nahi de sakte.”

15. Information Gain Worked Example

Let's use a simple parent node.

Parent

10 examples
5 A
5 B

Therefore:

\[ H(parent)=1 \]

Now suppose a candidate split produces:

Left child

4 A
1 B

Right child

1 A
4 B

Both children have the same class proportions:

\[ (0.8,0.2) \]

so both have entropy approximately:

\[ 0.722 \]

Each child contains 5 of the 10 examples.

Weighted child entropy:

\[ \frac5{10}(0.722)+\frac5{10}(0.722) =0.722 \]

Therefore:

\[ IG=1-0.722 \]
\[ \boxed{IG\approx0.278} \]

The split reduced uncertainty by about 0.278 bits.

16. Perfect Split Example

Suppose the same parent:

5 A
5 B

is split into:

Left  → 5 A, 0 B
Right → 0 A, 5 B

Then:

\[ H(left)=0 \]
\[ H(right)=0 \]

Weighted child entropy:

\[ 0 \]

Therefore:

\[ IG=1-0 \]
\[ \boxed{IG=1} \]

This is the maximum possible information gain for this binary parent with equal class proportions.

17. A Bad Split

Suppose the parent is:

5 A
5 B

and a split creates:

Left  → 3 A, 2 B
Right → 2 A, 3 B

The children are still mixed.

Their entropy is around the same value for both children and therefore the information gain is much smaller than in the perfect split case.

Mental rule

If the children look almost like the parent, the split did not teach us much.

18. Decision-Tree Split Selection

Put everything together:

For each candidate split:

      Parent
        │
        ▼
    Calculate H(parent)
        │
        ▼
   Split the examples
      /      \
     /        \
 Child 1    Child 2
    ↓           ↓
calculate    calculate
entropy      entropy
     \         /
      \       /
    weighted child
       entropy
           ↓
      information gain
           ↓
   compare candidates
           ↓
 choose best split

This is the mathematical heart of an information-gain decision-tree learner.

19. Gini Impurity — Why Another Measure?

Entropy is not the only way to quantify node impurity.

A second popular criterion is Gini impurity.

It answers a related question:

How mixed is this node?

A pure node has:

\[ Gini=0 \]

More mixed nodes have larger Gini values.

Current scikit-learn documentation uses Gini as a standard classification-tree criterion and gives its mathematical formulation in terms of class proportions.

20. Gini Formula

For a node containing class proportions \(p_1,p_2,\dots,p_K\):

\[ \boxed{ Gini(S)=1- \sum_{k=1}^{K}p_k^2 } \]

An equivalent expression often appears as:

\[ Gini(S)= \sum_{k=1}^{K}p_k(1-p_k) \]

because:

\[ \sum_k p_k(1-p_k) = \sum_k p_k- \sum_k p_k^2 =1- \sum_k p_k^2 \]

since:

\[ \sum_k p_k=1. \]

scikit-learn presents the equivalent class-proportion formulation in its tree documentation.

21. Gini Worked Example — Pure Node

Suppose:

10 A
0 B

Then:

\[ p_A=1, \qquad p_B=0 \]

Therefore:

\[ Gini =1-(1^2+0^2) \]
\[ =1-1 \]
\[ \boxed{Gini=0} \]

As desired.

22. Gini Worked Example — 50/50

For:

\[ p_A=0.5, \qquad p_B=0.5 \]

we get:

\[ Gini=1-(0.5^2+0.5^2) \]
\[ =1-(0.25+0.25) \]
\[ =0.5 \]

Therefore:

\[ \boxed{Gini=0.5} \]

For a binary classification node, 0.5 is the maximum Gini impurity.

23. Gini Worked Example — 80/20

For:

\[ p_A=0.8, \qquad p_B=0.2 \]
\[ Gini=1-(0.8^2+0.2^2) \]
\[ =1-(0.64+0.04) \]
\[ =0.32 \]

Therefore:

\[ \boxed{Gini=0.32} \]

Compare:

Distribution  Entropy   Gini
100/0         0         0
80/20         0.722     0.32
50/50         1         0.50

The numerical scales differ, but the qualitative story is the same: more mixing → more impurity.

24. Lower Gini Is Better for a Node

Remember:

For Gini impurity, lower means cleaner.

But when comparing splits, we generally compare the weighted child impurity.

So the split-selection idea becomes:

\[ \boxed{ \text{Choose the split with the smallest weighted child Gini} } \]

Equivalently, we can describe a reduction in impurity:

\[ \text{Gini reduction} = Gini(parent)-weighted\ child\ Gini. \]

Different textbooks and implementations phrase this selection criterion slightly differently, but the underlying optimization idea is the same.

25. Entropy vs Gini

Property Entropy Gini impurity
Measures Uncertainty / impurity Impurity
Pure node 0 0
Binary 50/50 1 bit 0.5
Typical tree use Split criterion Split criterion
Formula \(-\sum p_k\log p_k\) \(1-\sum p_k^2\)
Intuition Information/uncertainty Probability of incorrect random-label assignment under the standard interpretation
Numerical scale Depends on log base 0 to <1 for common finite-class formulation

scikit-learn explicitly supports both Gini and entropy/log-loss as classification criteria.

Important exam point

Do not say:

“Entropy is correct and Gini is an approximation of it.”

Better:

Entropy and Gini are different impurity criteria that often produce similar tree-splitting behaviour, but they are not the same function.

26. Another Analogy — Cleaning a Classroom

Imagine a classroom containing:

  • 20 students from Section A;
  • 20 students from Section B.

Before separating them, the room is mixed.

You can divide the room by asking:

“Which side of the hallway does the student sit on?”

If one side becomes mostly A and the other mostly B, the split is useful.

Entropy/Gini quantify how mixed the groups are.

Information gain measures how much cleaner the split made the groups.

👨‍🏫 Hinglish
> Parent room kitna mixed tha? > Split ke baad rooms kitne clean hue? > Difference = split se kitna benefit hua.

27. A Full Small Numerical Problem

We will calculate a candidate split completely.

Parent node

12 examples
7 A
5 B

Therefore:

\[ p_A=\frac7{12} \]
\[ p_B=\frac5{12} \]

Parent entropy:

\[ H(P) =-\frac7{12}\log_2\frac7{12} -\frac5{12}\log_2\frac5{12} \]

Approximate value:

\[ H(P)\approx0.980 \]

Now suppose a candidate split creates:

Left

6 examples
5 A
1 B

Right

6 examples
2 A
4 B

Their entropies are approximately:

\[ H(L)\approx0.650 \]
\[ H(R)\approx0.918 \]

Weighted child entropy:

\[ \frac6{12}(0.650)+\frac6{12}(0.918) \]
\[ =0.784 \]

Therefore:

\[ IG \approx0.980-0.784 \]
\[ \boxed{IG\approx0.196} \]

Interpretation

The split removed roughly 0.196 bits of entropy.

28. The Same Problem with Gini

Parent:

\[ Gini(P)=1- \left[ \left(\frac7{12}\right)^2+ \left(\frac5{12}\right)^2 \right] \]
\[ \approx1-(0.3403+0.1736) \]
\[ \boxed{Gini(P)\approx0.4861} \]

Left child:

\[ Gini(L) =1-\left[ \left(\frac56\right)^2+ \left(\frac16\right)^2 \right] \]
\[ \approx0.2778 \]

Right child:

\[ Gini(R) =1-\left[ \left(\frac26\right)^2+ \left(\frac46\right)^2 \right] \]
\[ \approx0.4444 \]

Weighted child Gini:

\[ \frac6{12}(0.2778)+ \frac6{12}(0.4444) \]
\[ \approx0.3611 \]

Gini reduction:

\[ 0.4861-0.3611 \approx0.125 \]

Therefore:

\[ \boxed{Gini\ reduction\approx0.125} \]

Notice that entropy gain and Gini reduction have different numerical scales. That is expected.

29. Information Gain Is Not “Information” in Every Possible Sense

The phrase can sound grander than it is.

Here, information gain means the reduction in entropy produced by a candidate split.

It does not mean:

“This feature contains all the information about the dataset.”

It is specifically a split-selection criterion built from entropy.

30. Why a Single Numerical Threshold Is Often Enough to Split

Suppose the feature is age:

18, 21, 24, 29, 33, 36, 42, 50

A tree can consider threshold candidates such as:

\[ Age\lt 30 \]

or

\[ Age\lt 40 \]

and compare how each threshold changes impurity.

The best threshold is the one that gives the best criterion under the chosen tree-learning method.

This is why decision trees can naturally create nonlinear/piecewise decision boundaries.

31. The Geometry Behind Splits

Suppose the tree first uses:

\[ x_1\lt 5 \]

Then the input space is divided into two regions.

A second split might use:

\[ x_2\lt 3 \]

Now one region is divided again.

Conceptually:

x2 ↑
   │   ┌───────────────┐
   │   │       B       │
 3 ├───┼───────────────┤
   │ A │       C       │
   └───┴───────────────┴──→ x1
       5

The exact shape depends on the sequence of splits.

In the common axis-aligned tree formulation, these regions are rectangular/hyperrectangular partitions in feature space.

32. Why Trees Can Represent Interactions Naturally

Consider:

Approve the applicant only when income is high AND credit score is high.

A tree can naturally represent this through sequential decisions:

Income high?
   │
  YES
   │
Credit high?
   │
  YES
   ↓
Approve

The second split is interpreted within the region created by the first split.

That creates an interaction between conditions without requiring us to explicitly write a product term such as:

\[ x_1x_2. \]

This is one reason trees can represent complex nonlinear rules.

33. Statistical-Learning Connection

Now connect the math to the previous chapters.

Candidate split
      ↓
Impurity calculation
      ↓
Split selection
      ↓
Tree growth
      ↓
Hypothesis class becomes richer
      ↓
Training error can fall
      ↓
Generalization must still be checked

So entropy/Gini do not solve the complete model-selection problem.

They help construct the tree.

Validation, pruning and other complexity controls address generalization.

34. Entropy and Probability Connection

This chapter deliberately depends on the probability work from your earlier math track.

You need to recognize:

\[ p_k=\frac{\text{number of class-}k\ examples}{\text{total examples}} \]

Then entropy simply consumes those probabilities.

So:

Counts
 ↓
Proportions
 ↓
Probability distribution
 ↓
Entropy / Gini
 ↓
Split decision

That is why your Probability/Statistics foundation is not a disconnected math side quest.

35. Logarithm Refresher

Entropy uses logarithms.

You should know:

\[ \log_2 1=0 \]
\[ \log_2 0.5=-1 \]
\[ \log_2 0.25=-2 \]

and more generally:

\[ \log_b(xy)=\log_bx+\log_by. \]

For entropy questions, you will often use a calculator for logarithms.

The conceptual requirement is more important than mental arithmetic:

Entropy becomes large when multiple classes have substantial probability and becomes zero when one class has probability 1.

36. Why the Negative Sign Is There

Entropy is written as:

\[ H=-\sum p_k\log p_k \]

Since for probabilities between 0 and 1:

\[ \log(p_k)\le0, \]

the raw term:

\[ p_k\log(p_k) \]

is non-positive.

The negative sign makes the overall entropy non-negative.

👨‍🏫 Hinglish
> Probability 0 aur 1 ke beech mein hai, toh log generally negative aayega. Isliye minus sign lagake entropy ko positive quantity banate hain.

37. A Very Important Distinction: Node Impurity vs Split Quality

Do not confuse these.

Entropy / Gini

Describe one node.

Information gain / impurity reduction

Compares a parent with its children after a split.

So:

NODE METRIC
Entropy / Gini

        ↓

SPLIT METRIC
Information gain / impurity reduction

This distinction appears frequently in exam questions.

38. What Happens with More Than Two Classes?

Suppose a node has:

Class A = 40%
Class B = 35%
Class C = 25%

Then entropy is:

\[ H =-\left( 0.4\log_2 0.4+ 0.35\log_2 0.35+ 0.25\log_2 0.25 \right) \]

And Gini becomes:

\[ Gini =1-(0.4^2+0.35^2+0.25^2). \]

Nothing fundamental changes.

The formulas already handle \(K\gt 2\).

39. Maximum Entropy for K Classes

When all \(K\) classes are equally likely:

\[ p_k=\frac1K \]

then entropy becomes:

\[ H =-K\left(\frac1K\log_2\frac1K\right) \]
\[ =\log_2K. \]

Therefore:

\[ \boxed{H_{max}=\log_2K} \]

This is a useful higher-level fact.

Example: 4 classes

\[ H_{max}=\log_2 4=2\text{ bits}. \]

40. Maximum Gini for K Classes

If all \(K\) classes are equally likely:

\[ p_k=\frac1K. \]

Then:

\[ Gini =1-K\left(\frac1K\right)^2 \]
\[ =1-\frac1K \]

So:

\[ \boxed{Gini_{max}=1-\frac1K} \]

For binary classification:

\[ 1-\frac12=0.5. \]

41. Entropy vs Gini: Which One Should You Memorize?

For your university exam, know both because the syllabus says Decision Trees and external formulations can use either.

Memorize:

\[ \boxed{Entropy=-\sum p_k\log_2 p_k} \]

and:

\[ \boxed{Gini=1-\sum p_k^2} \]

Then know the selection intuition:

Entropy: choose splits that reduce entropy / maximize information gain.
Gini: choose splits that reduce weighted Gini impurity.

The current scikit-learn documentation confirms that its classification tree implementation supports gini, entropy and log_loss criteria.

42. Common Calculation Trap — Forgetting the Weights

Wrong:

\[ \frac{H(L)+H(R)}2 \]

This assumes equal-sized children.

Correct:

\[ \boxed{ \frac{|L|}{|P|}H(L) + \frac{|R|}{|P|}H(R) } \]

More generally:

\[ \boxed{ \sum_j\frac{|S_j|}{|S|}H(S_j) } \]
👨‍🏫 Hinglish
> “Har child ko equal marks nahi milenge. Jis child mein zyada samples hain, uska weight zyada hoga.”

43. Common Calculation Trap — Choosing the Wrong Direction

For information gain:

Higher is better.

Because:

\[ IG=H(parent)-weighted\ child\ entropy. \]

For weighted child entropy:

Lower is better.

For Gini impurity:

Lower is better.

For Gini reduction:

Higher is better.

Master table

Quantity Better direction
Parent entropy Descriptive, not chosen directly
Child entropy Lower
Weighted child entropy Lower
Information gain Higher
Gini impurity Lower
Weighted child Gini Lower
Gini reduction Higher

44. A Complete Split-Selection Workflow

When given an exam problem:

Step 1 — Count classes in the parent

Step 2 — Convert counts to probabilities

Step 3 — Calculate parent entropy or Gini

Step 4 — Apply the candidate split

Step 5 — Count classes in every child

Step 6 — Calculate each child's entropy/Gini

Step 7 — Weight children by their sample counts

Step 8 — Calculate information gain or impurity reduction

Step 9 — Repeat for the other candidate splits

Step 10 — Choose the best split according to the criterion

👨‍🏫 Hinglish memory
> **Count → proportion → impurity → split → child impurity → weight → compare.**

45. Exam Numerical Template

If the question says:

“Calculate the information gain for attribute A.”

Write:

1. Parent entropy

\[ H(S)=... \]

2. Child entropy

\[ H(S_1)=... \]
\[ H(S_2)=... \]

3. Weighted child entropy

\[ H_{after}=... \]

4. Information gain

\[ IG=H(S)-H_{after} \]

5. Final conclusion

“Attribute A gives information gain = X.”

If comparing attributes, choose the larger information gain.

46. Comparison Numerical — Two Candidate Splits

Suppose:

\[ H(parent)=0.95. \]

Candidate A gives weighted child entropy:

\[ 0.40. \]

Candidate B gives:

\[ 0.65. \]

Then:

\[ IG_A=0.95-0.40=0.55 \]
\[ IG_B=0.95-0.65=0.30 \]

So:

\[ \boxed{IG_A\gt IG_B} \]

Therefore A provides the larger information gain.

👨‍🏫 Hinglish
> A ke baad uncertainty zyada reduce hui, toh A better split hai.

47. Why Entropy and Gini Can Disagree Numerically but Similar in Practice

They map the same class proportions to different numerical values.

For example, at 80/20:

\[ Entropy\approx0.722 \]

while:

\[ Gini=0.32. \]

These numbers cannot be compared directly.

The scales are different.

What matters for split selection is the relative quality under the chosen criterion.
