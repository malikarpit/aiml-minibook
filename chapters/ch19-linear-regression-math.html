1. Why This Chapter Exists

C18 answered:

What is linear regression?

Now we ask:

How can mathematics actually find the best parameters?

This chapter is one of the most important mathematical bridges in the entire AI/ML book.

It connects:

Linear model
    ↓
Loss function
    ↓
Calculus
    ↓
Gradient
    ↓
Stationary point
    ↓
Linear algebra
    ↓
Least-squares solution

Your Lecture 9 walks through precisely this sequence: it introduces convexity, defines the gradient as stacked partial derivatives, differentiates the least-squares objective using gradient linearity and the chain rule, sets the gradient to zero, and rearranges the result into a matrix-form solution. Course source: Lecture09.pdf, slides 13–21.

The purpose here is not to memorize a normal-equation-looking formula.

The purpose is to understand where the solution comes from.

2. The Problem We Want to Solve

Suppose our model is:

\[ \hat y_i=\mathbf{w}^{\top}\mathbf{x}_i \]

and our training data is:

\[ (\mathbf{x}_1,y_1),\ldots,(\mathbf{x}_n,y_n) \]

The squared-loss objective is:

\[ \boxed{ L(\mathbf{w}) = \sum_{i=1}^{n} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right)^2 } \]

The lecture also uses the averaged version in the model-training formulation:

\[ \frac1nL(\mathbf{w}) \]

The minimizer is unchanged by multiplying the objective by the positive constant \(1/n\).

Our goal is:

\[ \boxed{ \mathbf{w}^* = \arg\min_{\mathbf{w}}L(\mathbf{w}) } \]

3. Before Calculus: What Are We Optimizing?

Imagine a bowl.

The horizontal axes represent possible parameter choices.

The vertical axis represents loss.

Loss
              ↑
              │       ╭──────╮
              │      /        \
              │     /          \
              │    /            \
              │___/______●_______\___
                         ↑
                       minimum
              └──────────────────────→ parameters

The best parameter vector is at the bottom of the bowl.

If we can mathematically identify the point where the slope becomes zero, we have a candidate for the minimum.

But this only becomes globally reliable because the least-squares objective here is convex.

4. Math You Need Now — Derivative

For a single-variable function:

\[ f(x) \]

the derivative:

\[ f'(x) \]

tells us the local rate at which the function changes as x changes.

Very roughly:

  • positive derivative → increasing;
  • negative derivative → decreasing;
  • zero derivative → horizontal tangent.

For example:

\[ f(x)=x^2 \]
\[ f'(x)=2x \]

At:

\[ x=0 \]

we have:

\[ f'(0)=0 \]

and x=0 is the global minimum.

👨‍🏫 Hinglish
> Derivative basically batata hai ki function kis direction mein ja raha hai aur kitni speed se change ho raha hai. Minimum ke bottom par slope zero ho sakta hai.

5. Why One Derivative Is Not Enough

Linear regression can have many parameters:

\[ \mathbf{w} = (w_1,w_2,\ldots,w_d) \]

So there is not one input variable to differentiate with respect to.

We need:

\[ \frac{\partial L}{\partial w_1}, \frac{\partial L}{\partial w_2}, \ldots, \frac{\partial L}{\partial w_d} \]

These are partial derivatives.

They tell us:

What happens to the loss if I change one parameter while treating the others as fixed?

6. The Gradient

Stack all partial derivatives into a vector.

For:

\[ g(\mathbf{w}):\mathbb{R}^d\to\mathbb{R} \]

the lecture defines:

\[ \boxed{ \nabla_{\mathbf{w}}g(\mathbf{w}) = \begin{bmatrix} \frac{\partial g}{\partial w_1}\\ \frac{\partial g}{\partial w_2}\\ \vdots\\ \frac{\partial g}{\partial w_d} \end{bmatrix}} \]

Meaning

The gradient collects all local slope information into one vector.

👨‍🏫 Hinglish
> Ek parameter ka slope nahi, **har parameter ka slope ek saath** chahiye. Un sabko ek vector mein stack kar do — that's the gradient. Course source: `Lecture09.pdf`, slide 14.

7. Direction of the Gradient

The gradient points in the direction of greatest local increase of the scalar function.

Therefore the opposite direction:

\[ -\nabla L \]

points locally toward decrease.

This is why gradient descent later uses:

\[ \boxed{ \mathbf{w}_{new} = \mathbf{w}_{old} - \eta\nabla L(\mathbf{w}_{old}) } \]

where \(\eta\gt 0\) is a learning rate.

Important: this update is a general iterative optimization idea. The current lecture uses the gradient primarily to derive the least-squares stationary condition.

8. The First Small Derivative We Need

Let:

\[ g(\mathbf{w})=\mathbf{w}^{\top}\mathbf{x} \]

Expand it:

\[ \mathbf{w}^{\top}\mathbf{x} = w_1x_1+w_2x_2+\cdots+w_dx_d \]

Now differentiate with respect to each parameter.

\[ \frac{\partial}{\partial w_1} (\mathbf{w}^{\top}\mathbf{x})=x_1 \]
\[ \frac{\partial}{\partial w_2} (\mathbf{w}^{\top}\mathbf{x})=x_2 \]

and so on.

Therefore:

\[ \boxed{ \nabla_{\mathbf{w}}(\mathbf{w}^{\top}\mathbf{x}) =\mathbf{x} } \]

Course source: Lecture09.pdf, slide 15.

This result is worth memorizing with understanding.

Gradient with respect to w of wᵀx is x.

Why?

Because each w_j is multiplied by x_j.

9. The Other Small Rule — Gradient of a Sum

The lecture uses linearity:

\[ \boxed{ \nabla_{\mathbf{w}} \sum_i f_i(\mathbf{w}) = \sum_i\nabla_{\mathbf{w}}f_i(\mathbf{w}) } \]

This means we can differentiate every sample's loss contribution separately and add the gradients.

👨‍🏫 Hinglish
> Sab examples ko ek saath differentiate karne ki zarurat nahi. Har example ka contribution nikalo, phir sab add kar do.

10. Chain Rule — The Critical Tool

Suppose:

\[ z=z(\mathbf{w}) \]

and we want the gradient of:

\[ z^2 \]

Then:

\[ \boxed{ \nabla_{\mathbf{w}}z^2 = 2z\nabla_{\mathbf{w}}z } \]

This is the multivariable version of the chain rule used in the Lecture 9 derivation.

Everyday analogy

Think of a factory pipeline:

w
 ↓
z(w)
 ↓
z(w)^2

If the final output changes, we need to account for how the inner stage changes the input to the outer stage.

👨‍🏫 Hinglish
> Chain rule ka simple idea: agar output ek function ke andar doosre function ka result hai, toh derivatives ko chain ki tarah multiply karna padta hai.

11. Start the Least-Squares Derivation

Define:

\[ L(\mathbf{w}) = \sum_{i=1}^{n} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right)^2 \]

We want:

\[ \nabla_{\mathbf{w}}L(\mathbf{w}) \]

Step 1 — Differentiate the sum

Using linearity:

\[ \nabla_{\mathbf{w}}L(\mathbf{w}) = \sum_{i=1}^{n} \nabla_{\mathbf{w}} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right)^2 \]

12. Step 2 — Apply the Chain Rule

For each term:

\[ z_i(\mathbf{w}) = y_i-\mathbf{w}^{\top}\mathbf{x}_i \]

Then:

\[ \nabla_{\mathbf{w}}z_i^2 = 2z_i\nabla_{\mathbf{w}}z_i \]

Therefore:

\[ \nabla_{\mathbf{w}}L(\mathbf{w}) = \sum_{i=1}^{n} 2\left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right) \nabla_{\mathbf{w}} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right) \]

13. Step 3 — Differentiate the Inside

We need:

\[ \nabla_{\mathbf{w}} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right) \]

y_i is a constant with respect to w, so its gradient is zero.

And:

\[ \nabla_{\mathbf{w}}(\mathbf{w}^{\top}\mathbf{x}_i) =\mathbf{x}_i \]

Therefore:

\[ \boxed{ \nabla_{\mathbf{w}} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right) =-\mathbf{x}_i } \]

Substitute:

\[ \boxed{ \nabla_{\mathbf{w}}L(\mathbf{w}) = -2\sum_{i=1}^{n} \left(y_i-\mathbf{w}^{\top}\mathbf{x}_i\right)\mathbf{x}_i } \]

Equivalent form:

\[ \boxed{ \nabla_{\mathbf{w}}L(\mathbf{w}) = 2\sum_{i=1}^{n} \left(\mathbf{w}^{\top}\mathbf{x}_i-y_i\right)\mathbf{x}_i } \]

These are algebraically identical.

Course source: Lecture09.pdf, slides 17–18.

14. What Does This Gradient Mean?

Look at one contribution:

\[ 2(\hat y_i-y_i)\mathbf{x}_i \]

It has two important pieces:

Error

\[ \hat y_i-y_i \]

How wrong are we?

Input direction

\[ \mathbf{x}_i \]

Which feature directions produced the prediction?

So, loosely:

parameter gradient = error × input, accumulated across examples.

This pattern will become extremely important in neural networks.

👨‍🏫 Hinglish
> Prediction kitni galat hai × input kis direction mein tha — ye contributions sab examples se add hote hain aur batate hain ki weights ko kis direction mein change karna chahiye.

15. The Stationary-Point Condition

At an optimum of the differentiable least-squares objective, the gradient is zero.

So set:

\[ \nabla_{\mathbf{w}}L(\mathbf{w})=0 \]

Using the equivalent gradient form:

\[ 2\sum_{i=1}^{n} (\mathbf{w}^{\top}\mathbf{x}_i-y_i)\mathbf{x}_i =0 \]

or:

\[ \sum_{i=1}^{n} (\mathbf{w}^{\top}\mathbf{x}_i-y_i)\mathbf{x}_i =0 \]

Rearrange:

\[ \sum_{i=1}^{n} (\mathbf{w}^{\top}\mathbf{x}_i)\mathbf{x}_i = \sum_{i=1}^{n}y_i\mathbf{x}_i \]

Course source: Lecture09.pdf, slide 18.

16. Why Can We Move the Scalar Around?

Notice:

\[ \mathbf{w}^{\top}\mathbf{x}_i \]

is a scalar.

So:

\[ (\mathbf{w}^{\top}\mathbf{x}_i)\mathbf{x}_i = \mathbf{x}_i(\mathbf{w}^{\top}\mathbf{x}_i) \]

Then use inner-product symmetry:

\[ \mathbf{w}^{\top}\mathbf{x}_i = \mathbf{x}_i^{\top}\mathbf{w} \]

Therefore:

\[ \mathbf{x}_i(\mathbf{x}_i^{\top}\mathbf{w}) \]

can be written as:

\[ (\mathbf{x}_i\mathbf{x}_i^{\top})\mathbf{w} \]

using matrix multiplication associativity.

17. The Key Matrix Equation

We arrive at:

\[ \sum_{i=1}^{n} (\mathbf{x}_i\mathbf{x}_i^{\top})\mathbf{w} = \sum_{i=1}^{n}y_i\mathbf{x}_i \]

Move the sum inside:

\[ \left( \sum_{i=1}^{n} \mathbf{x}_i\mathbf{x}_i^{\top} \right)\mathbf{w} = \sum_{i=1}^{n}y_i\mathbf{x}_i \]

This is the central normal-equation structure emerging from the course derivation.

Let's give the two large pieces names:

\[ \mathbf{A} = \sum_i\mathbf{x}_i\mathbf{x}_i^{\top} \]

and

\[ \mathbf{b} = \sum_i y_i\mathbf{x}_i \]

Then:

\[ \boxed{\mathbf{A}\mathbf{w}=\mathbf{b}} \]

This is a linear system in the unknown parameter vector w.

18. If the Matrix Is Invertible

If:

\[ \sum_i\mathbf{x}_i\mathbf{x}_i^{\top} \]

is invertible, then:

\[ \boxed{ \mathbf{w} = \left( \sum_i\mathbf{x}_i\mathbf{x}_i^{\top} \right)^{-1} \left( \sum_i y_i\mathbf{x}_i \right) } \]

This is the solution shown by the Lecture 9 derivation in its per-sample notation.

If the matrix is not invertible, the lecture notes using a pseudoinverse instead of an ordinary inverse.

Course source: Lecture09.pdf, slides 19–20.

19. Why Can the Matrix Be Non-Invertible?

A matrix may fail to be invertible when the feature representation does not provide independent information in the required linear-algebra sense.

For example, imagine two features:

\[ x_2=2x_1 \]

for every training example.

Then the two feature columns are linearly dependent.

The model has redundant information.

This connects directly to the linear independence material from Lecture04.pdf.

👨‍🏫 Hinglish
> Agar do features basically ek hi information ko duplicate kar rahe hain, toh matrix ke columns dependent ho sakte hain. Tab normal inverse directly exist nahi karta.

20. Dataset Matrix Notation

Instead of keeping every \(\mathbf{x}_i\) separately, put the samples into a matrix.

Suppose:

  • n = 5 samples;
  • d = 3 features.

Then:

\[ \mathbf{X}\in\mathbb{R}^{5\times3} \]

with one sample per row.

The target vector is:

\[ \mathbf{y}\in\mathbb{R}^{5} \]

and parameter vector:

\[ \mathbf{w}\in\mathbb{R}^{3} \]

Your Lecture 9 explicitly uses this matrix view. Course source: Lecture09.pdf, slide 20.

21. Prediction for the Entire Dataset

For one example:

\[ \hat y_i=\mathbf{w}^{\top}\mathbf{x}_i \]

For all samples at once:

\[ \boxed{\hat{\mathbf{y}}=\mathbf{X}\mathbf{w}} \]

This is one of the most useful transitions in practical ML mathematics.

Instead of:

sample 1 → prediction
sample 2 → prediction
sample 3 → prediction
...

we write:

X → w → all predictions

through one matrix multiplication.

22. Residual Vector

Define:

\[ \boxed{ \mathbf{r}=\mathbf{X}\mathbf{w}-\mathbf{y} } \]

This stores every prediction error in one vector.

For example:

\[ \mathbf{r} = \begin{bmatrix} \hat y_1-y_1\\ \hat y_2-y_2\\ \vdots\\ \hat y_n-y_n \end{bmatrix} \]

Your Lecture 9 explicitly constructs this residual vector before expressing squared error with a vector norm. Course source: Lecture09.pdf, slide 21.

23. Squared Error as a Norm

The squared Euclidean norm is:

\[ \|\mathbf{r}\|_2^2 = \sum_i r_i^2 \]

Since:

\[ \mathbf{r}=\mathbf{X}\mathbf{w}-\mathbf{y} \]

we get:

\[ \boxed{ \sum_i (\mathbf{x}_i^{\top}\mathbf{w}-y_i)^2 = \|\mathbf{X}\mathbf{w}-\mathbf{y}\|_2^2 } \]

Therefore the least-squares problem can be written compactly as:

\[ \boxed{ \min_{\mathbf{w}} \|\mathbf{X}\mathbf{w}-\mathbf{y}\|_2^2 } \]

This is the clean matrix statement of ordinary least squares.

24. The Matrix Normal-Equation Form

Starting from:

\[ \min_{\mathbf{w}} \|\mathbf{X}\mathbf{w}-\mathbf{y}\|_2^2 \]

and differentiating gives the familiar matrix condition:

\[ \boxed{ \mathbf{X}^{\top}\mathbf{X}\mathbf{w} = \mathbf{X}^{\top}\mathbf{y} } \]

When \(\mathbf{X}^{\top}\mathbf{X}\) is invertible:

\[ \boxed{ \mathbf{w} = (\mathbf{X}^{\top}\mathbf{X})^{-1} \mathbf{X}^{\top}\mathbf{y} } \]

This form is the standard matrix shorthand for the per-sample derivation.

Important source distinction: your Lecture 9 primarily walks through the per-sample vector derivation and then shows the matrix/data view. This chapter adds the compact \(X^{\top}X\) form as a universal matrix shorthand for the same least-squares result.

25. Why These Two Solutions Look Different

You may see:

\[ \left(\sum_i\mathbf{x}_i\mathbf{x}_i^\top\right)^{-1} \left(\sum_i y_i\mathbf{x}_i\right) \]

and:

\[ (\mathbf{X}^{\top}\mathbf{X})^{-1} \mathbf{X}^{\top}\mathbf{y} \]

These are not two unrelated algorithms.

They are two representations of the same least-squares structure under the corresponding arrangement of data vectors in X.

The identity is:

\[ \boxed{ \mathbf{X}^{\top}\mathbf{X} = \sum_i\mathbf{x}_i\mathbf{x}_i^{\top} } \]

and:

\[ \boxed{ \mathbf{X}^{\top}\mathbf{y} = \sum_i y_i\mathbf{x}_i } \]

when samples are stored as rows.

26. A Tiny Matrix Example

Suppose:

\[ \mathbf{X} = \begin{bmatrix} 1&1\\ 1&2\\ 1&3 \end{bmatrix} \]

The first column can represent the dummy intercept feature.

Suppose:

\[ \mathbf{y} = \begin{bmatrix} 2\\3\\5 \end{bmatrix} \]

Then:

\[ \mathbf{X}^{\top}\mathbf{X} = \begin{bmatrix} 1&1&1\\ 1&2&3 \end{bmatrix} \begin{bmatrix} 1&1\\ 1&2\\ 1&3 \end{bmatrix} \]

and:

\[ \mathbf{X}^{\top}\mathbf{y} = \begin{bmatrix} 1&1&1\\ 1&2&3 \end{bmatrix} \begin{bmatrix} 2\\3\\5 \end{bmatrix} \]

You do not need to rush the arithmetic.

The important point is to recognize the dimensions and the sequence of matrix operations.

27. Dimension Check — A Powerful Error Detector

Suppose:

\[ X\in\mathbb{R}^{n\times d} \]

Then:

\[ X^{\top}\in\mathbb{R}^{d\times n} \]

So:

\[ X^{\top}X \in \mathbb{R}^{d\times d} \]

and:

\[ X^{\top}y \in \mathbb{R}^{d} \]

Therefore:

\[ (X^{\top}X)^{-1}X^{\top}y \in \mathbb{R}^{d} \]

which matches the parameter vector:

\[ \mathbf{w}\in\mathbb{R}^{d} \]

Exam habit

Whenever a matrix equation feels confusing, check the dimensions.

👨‍🏫 Hinglish
> Matrix dimensions ko “units check” ki tarah use karo. Agar multiplication mathematically possible hi nahi hai, somewhere tumhara notation ya orientation galat hai.

28. Why Convexity Matters Again

The lecture's convexity point becomes important now.

Least-squares linear regression gives a convex quadratic objective in the parameters under the standard formulation.

So there is not the same type of non-convex maze that appears in many later neural-network optimization problems.

Conceptually:

Least squares
     ↓
Convex objective
     ↓
Stationary point
     ↓
Global minimum

under the relevant mathematical conditions.

This is why the calculus derivation is not merely producing “some” stationary point.

29. What Happens If the Matrix Is Singular?

If:

\[ X^{\top}X \]

is not invertible, writing:

\[ (X^{\top}X)^{-1} \]

is not valid.

The lecture explicitly says to use a pseudo-inverse when the matrix is not invertible.

Conceptually:

XᵀX invertible
     ↓
ordinary inverse
     ↓
closed-form parameter solution

XᵀX not invertible
     ↓
pseudoinverse
     ↓
least-squares solution can still be represented

The precise pseudoinverse machinery is a deeper linear-algebra topic and can be treated separately in the Math Companion.

30. The Derivation in One Picture

L(w)
 │
 │ differentiate
 ▼
∇L(w)
 │
 │ set = 0
 ▼
stationary equation
 │
 │ use dot-product symmetry
 │ matrix associativity
 ▼
(Σ xᵢxᵢᵀ)w = Σ yᵢxᵢ
 │
 │ write all samples as X
 ▼
XᵀXw = Xᵀy
 │
 │ solve
 ▼
w = (XᵀX)⁻¹Xᵀy

This is the entire mathematical story of ordinary least squares in compressed form.

32. Why the Formula Is More Than a Formula

Do not memorize:

\[ (X^TX)^{-1}X^Ty \]

as a magic spell.

Understand the ingredients:

\(X\)

What the dataset looks like.

\(w\)

What parameters we are trying to learn.

\(Xw\)

Predictions for all training examples.

\(Xw-y\)

Residual vector.

\(\|Xw-y\|^2\)

Total squared error.

\(X^TXw=X^Ty\)

Stationary condition from minimizing that squared error.

\((X^TX)^{-1}X^Ty\)

The parameter solution when the required inverse exists.

33. Connection to Gradient Descent

There are two important ways to think about solving an optimization problem.

Closed-form route

For ordinary least squares under the standard conditions:

\[ X^TXw=X^Ty \]

can be solved directly.

Iterative route

Start with some w and repeatedly update:

\[ \mathbf{w}_{t+1} = \mathbf{w}_t - \eta\nabla L(\mathbf{w}_t) \]

The first is a closed-form/analytical solution approach.

The second is an iterative optimization approach.

Your Lecture 9's mathematical derivation is primarily establishing the stationary condition and closed-form least-squares solution; later neural-network chapters will rely heavily on the iterative gradient-descent viewpoint.

34. Important Connection to Neural Networks

This chapter is not isolated from Unit III.

A neuron computes a weighted combination of its inputs:

\[ z=\mathbf{w}^{\top}\mathbf{x}+b \]

That is exactly the basic linear-combination structure we have just studied.

A neural network then adds:

  • nonlinear activation functions;
  • multiple layers;
  • more parameters;
  • iterative optimization/backpropagation.

So:

Linear regression
       ↓
weighted sum
       ↓
vector/matrix mathematics
       ↓
loss minimization
       ↓
gradient
       ↓
neural network
       ↓
backpropagation

This is one of the reasons mastering C19 is worth the effort.

35. Common Misconceptions

Misconception 1

“Gradient zero always means global minimum.”

Not for arbitrary functions.

The lecture makes the global-minimum conclusion because the relevant function is convex (with the required differentiability conditions).

Misconception 2

“The gradient is the derivative.”

More precisely:

  • derivative is the one-variable/general local-rate idea;
  • gradient is the vector of partial derivatives for a scalar function of multiple variables.

Misconception 3

“A matrix inverse always exists.”

No.

Invertibility depends on the matrix.

The lecture explicitly notes the pseudoinverse when the relevant matrix is not invertible.

Misconception 4

“The least-squares formula is just a computational trick.”

No.

It is derived from minimizing the squared-error objective.

Misconception 5

“The formulas with \(X\) and the formulas with \(x_i\) are different methods.”

No.

The matrix version is a compact representation of the sample-wise version.

Misconception 6

“Gradient descent and the normal equation are the same procedure.”

No.

They are two different ways of solving/minimizing the same least-squares objective in suitable settings.

36. Worked Example — One Parameter

Suppose:

\[ L(w)=(2w-6)^2 \]

Expand:

\[ L(w)=4w^2-24w+36 \]

Derivative:

\[ \frac{dL}{dw}=8w-24 \]

Set to zero:

\[ 8w-24=0 \]
\[ 8w=24 \]
\[ \boxed{w=3} \]

Check:

\[ L(3)=(6-6)^2=0 \]

This tiny example is not the full regression derivation, but it shows the basic pattern:

loss → derivative → zero → parameter

37. Worked Example — Simple Vector Gradient

Let:

\[ \mathbf{w}=\begin{bmatrix}w_1\\w_2\end{bmatrix}, \qquad \mathbf{x}=\begin{bmatrix}3\\5\end{bmatrix} \]

Then:

\[ \mathbf{w}^{\top}\mathbf{x} =3w_1+5w_2 \]

Therefore:

\[ \frac{\partial}{\partial w_1}=3 \]

and:

\[ \frac{\partial}{\partial w_2}=5 \]

so:

\[ \boxed{ \nabla_{\mathbf{w}}(\mathbf{w}^{\top}\mathbf{x}) = \begin{bmatrix}3\\5\end{bmatrix} =\mathbf{x} } \]

This is exactly the pattern used in the course derivation.

38. Worked Example — Gradient Contribution From One Sample

Suppose:

\[ \mathbf{x} = \begin{bmatrix}2\\4\end{bmatrix}, \qquad \hat y=7, \qquad y=5 \]

Then residual:

\[ \hat y-y=2 \]

The squared-error gradient contribution, ignoring the overall factor convention, has the form:

\[ 2(\hat y-y)\mathbf{x} \]

Therefore:

\[ 2(2) \begin{bmatrix}2\\4\end{bmatrix} = \begin{bmatrix}8\\16\end{bmatrix} \]

Interpretation:

This sample contributes a gradient pointing in the positive direction of both parameters because the model's prediction is too high relative to the chosen residual convention.

Important: when using the opposite residual convention (y - ŷ), the gradient expression receives the corresponding negative sign. The final stationary condition is equivalent when handled consistently.

39. Exam-Level Derivation Checklist

If asked to derive the least-squares solution, your thought process should be:

1. Write L(w)
       ↓

       ↓
