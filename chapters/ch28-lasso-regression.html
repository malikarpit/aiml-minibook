MAIN-U2-C28 — Lasso Regression

Core question: What changes when the regularization penalty is based on the absolute values of the model coefficients rather than their squares?

Lasso Regression answers this question with the L1 penalty. Its distinctive mathematical behaviour is that it can drive some coefficients exactly to zero, which makes it useful for sparse models and feature selection.

1. Why This Chapter Exists

In the previous chapter, Ridge Regression introduced the idea:

\[ \text{fit the data} + \text{penalize large coefficients} \]

Ridge uses a squared penalty:

\[ \lambda\sum_j w_j^2. \]

That produces smooth coefficient shrinkage, but normally does not make coefficients exactly zero.

Now ask:

Can we control complexity while also encouraging a model to use fewer features?

Lasso changes the penalty to:

\[ \lambda\sum_j |w_j|. \]

This is the L1 penalty.

The central story is:

Flexible model
      ↓
Possible overfitting
      ↓
Regularization
      ↓
Penalize coefficient magnitude
      ↓
L1 penalty
      ↓
Some coefficients can become exactly 0
      ↓
Sparse model / feature selection

3. One-Minute Intuition

English

Imagine a linear regression model using many features:

\[ \hat y=w_1x_1+w_2x_2+\cdots+w_dx_d+b. \]

A highly flexible model can give large, complicated coefficient patterns.

Lasso says:

“Fit the observations, but pay a cost for every unit of absolute coefficient magnitude.”

Because the absolute-value penalty has a sharp corner at zero, optimization can prefer landing exactly at zero for some coefficients.

So Lasso can produce a model such as:

\[ \hat y=3.1x_1+0x_2-0.8x_3+0x_4+1.4x_5. \]

The zero coefficients effectively remove those features from the fitted prediction.

Hinglish Teacher Explanation

Socho tumhare paas 20 features hain, lekin actual prediction mein shayad sirf 5 useful hain.

Lasso model ko bolta hai:

“Data ko fit karo, lekin unnecessary coefficients ko zero tak push karne ki permission do.”

Isliye Ridge aur Lasso ka basic difference yaad rakho:

Ridge → weights ko chhota karta hai
Lasso → weights ko chhota kar sakta hai aur kuch ko 0 bana sakta hai

Important: “Lasso always removes many features” galat statement hai. Whether coefficients become zero depends on the data, scaling, the value of \(\lambda\), and the optimization setup.

4. The Model Before Regularization

Start with ordinary linear regression:

\[ \hat y_i=w^Tx_i+b. \]

In matrix-style notation, after representing the intercept separately or augmenting the feature vector:

\[ \hat y=Xw. \]

Ordinary least squares can be written as:

\[ J_{OLS}(w)=\|Xw-y\|_2^2. \]

It only asks:

How well do the predictions fit the observed targets?

Regularization adds another concern:

Can we discourage unnecessary model complexity?

5. Lasso Objective

The standard Lasso objective is:

\[ \boxed{ J_{Lasso}(w)=\|Xw-y\|_2^2+\lambda\|w\|_1 } \]

where

\[ \boxed{ \|w\|_1=\sum_{j=1}^{d}|w_j| } \]

Therefore:

\[ J_{Lasso}(w) = \|Xw-y\|_2^2 + \lambda\sum_{j=1}^{d}|w_j|. \]

Convention note

Different textbooks scale the data-loss term by constants such as \(1/2\) or \(1/n\), and may correspondingly rescale the meaning of \(\lambda\). The conceptual structure remains:

\[ \boxed{\text{data-fit term}+\lambda\times\text{L1 complexity penalty}} \]

For numerical questions, always use the exact objective convention stated in the question.

6. What Does the L1 Norm Actually Measure?

For

\[ w=(w_1,w_2,w_3), \]

we have

\[ \|w\|_1=|w_1|+|w_2|+|w_3|. \]

Example:

\[ w=(2,-3,4) \]

then

\[ \|w\|_1=|2|+|-3|+|4|=2+3+4=9. \]

If

\[ \lambda=0.5, \]

then the penalty contribution is

\[ 0.5(9)=4.5. \]

Memory anchor

L1 = add absolute values.

Do not square them.

7. Formula Card — Lasso in One Box

LASSO FORMULA CARD

Objective

\[ \gt J(w)=\|Xw-y\|_2^2+\lambda\|w\|_1 \gt \]

Penalty

\[ \gt \|w\|_1=\sum_j|w_j| \gt \]

\(\lambda\)

Controls the strength of regularization.

Large \(\lambda\)

Stronger pressure toward small/sparse coefficients.

Small \(\lambda\)

Closer to ordinary least squares.

Characteristic behaviour

Some coefficients can become exactly zero.

8. Why Absolute Value Changes the Mathematics

For one coefficient \(w\):

\[ f(w)=|w|. \]

This behaves differently from

\[ f(w)=w^2. \]

Squared penalty

\[ \frac{d}{dw}w^2=2w. \]

The function is smooth at zero.

Absolute-value penalty

For \(w\gt 0\):

\[ \frac{d}{dw}|w|=1. \]

For \(w\lt 0\):

\[ \frac{d}{dw}|w|=-1. \]

At

\[ w=0, \]

ordinary differentiation is not defined.

This is called a non-differentiable point or kink.

That small-looking mathematical detail is one of the reasons Lasso behaves differently from Ridge.

9. Subgradient — The Minimum You Need to Know

You do not need to fear the word subgradient.

For the absolute value,

\[ \partial |w| = \begin{cases} \{1\}, & w\gt 0\\[4pt] [-1,1], & w=0\\[4pt] \{-1\}, & w\lt 0. \end{cases} \]

The key idea is:

At zero, there is a whole interval of allowable slope values rather than one ordinary derivative.

This allows the optimization conditions to be satisfied at exactly

\[ w=0. \]
👨‍🏫 Hinglish
Ridge ka penalty smooth hai. Lasso ke zero par ek sharp corner hai. Isi corner ki wajah se optimum zero par “sit” kar sakta hai. Exam mein full convex-analysis proof usually required nahi hota unless specifically taught, but the **non-differentiability at zero** is an important mathematical explanation for sparsity.

10. Geometry — The Most Visual Explanation

Consider two coefficients \(w_1,w_2\).

L2 constraint

Ridge corresponds to a circular constraint:

\[ w_1^2+w_2^2\le t. \]

L1 constraint

Lasso corresponds to a diamond-shaped constraint:

\[ |w_1|+|w_2|\le t. \]

Conceptually:

Ridge / L2                  Lasso / L1

        _____                  /\
     .-'     '-.              /  \
   .'           '.            /    \
  /       •      \           /  •   \
  \               /           \      /
   '.           .'             \    /
     '-._____.-'                \/

smooth boundary             sharp corners

The corners of the L1 region lie on coordinate axes.

That means an optimum can occur where:

\[ w_1=0 \quad\text{or}\quad w_2=0. \]

This geometric argument gives intuition for why Lasso can create exact zeros.

11. Constraint View of Lasso

A regularized problem can often be viewed in an equivalent constrained form.

Instead of:

\[ \min_w\;\|Xw-y\|_2^2+\lambda\|w\|_1, \]

think conceptually of:

\[ \boxed{ \min_w\;\|Xw-y\|_2^2 \quad\text{subject to}\quad \|w\|_1\le t } \]

for a suitable relationship between \(t\) and \(\lambda\).

Interpretation:

Penalized view
→ “Every unit of L1 size costs something.”

Constrained view
→ “The total L1 size cannot exceed a budget.”

You do not need to prove the exact mapping between \(t\) and \(\lambda\) to understand the regularization idea.

12. A Real-Life Analogy — Packing a Backpack

Suppose you need to travel with many items.

You want everything useful, but the backpack has a limited complexity/burden budget.

Ridge-like thinking

Almost every useful item can stay, but you reduce how heavily you rely on each item.

Lasso-like thinking

You also allow some items to be removed entirely.

In ML terms:

Feature → item
Coefficient magnitude → dependence on that item
L1 budget → total absolute dependence allowed
Zero coefficient → feature effectively unused

The analogy is only intuition; Lasso does not literally delete columns from the dataset during the optimization process. It produces fitted coefficients whose exact zeros make those features inactive in the prediction rule.

13. What “Feature Selection” Means Here

Suppose the fitted model is:

\[ \hat y=2.8x_1+0x_2-1.1x_3+0x_4+0.7x_5. \]

The model depends on:

\[ x_1,x_3,x_5. \]

Features \(x_2\) and \(x_4\) have zero fitted coefficients.

Thus Lasso has performed embedded feature selection as part of model fitting.

Important distinction

Feature selection means selecting which variables the fitted model uses.

It does not necessarily mean:

  • the features are globally useless,
  • the selected set is unique,
  • or the model has discovered causal variables.

It only means the fitted optimization result assigned zero coefficient to those features under the chosen setup.

14. Ridge vs Lasso at the Coefficient Level

Suppose a model has coefficients:

\[ (4,-2,0.7,-0.1). \]

Ridge

The squared penalty strongly discourages large values and tends to continuously shrink coefficients toward zero.

A typical result might conceptually look like:

\[ (2.9,-1.5,0.5,-0.07). \]

Lasso

The absolute-value penalty can produce exact zeros.

A conceptual result might look like:

\[ (2.6,-1.2,0.3,0). \]

These numbers are illustrative, not universal predictions.

The important structural difference is:

Ridge → shrinkage
Lasso → shrinkage + possible exact zeros

15. A Simple 1D Mathematical Example

To see sparsity without a full matrix derivation, consider the normalized one-variable objective:

\[ J(w)=\frac12(z-w)^2+\lambda|w|. \]

This is a standard soft-thresholding form.

For \(z\gt 0\), the solution is:

\[ \hat w= \begin{cases} z-\lambda,& z\gt \lambda\\ 0,& 0\le z\le \lambda. \end{cases} \]

Symmetrically, for negative \(z\):

\[ \boxed{ \hat w=\operatorname{sign}(z)\max(|z|-\lambda,0) } \]

Example

Let

\[ z=3, \qquad \lambda=1. \]

Then:

\[ \hat w=(+1)(3-1)=2. \]

Now let

\[ z=0.6, \qquad \lambda=1. \]

Then:

\[ |z|-\lambda=0.6-1=-0.4. \]

The maximum with zero is zero:

\[ \boxed{\hat w=0}. \]

What did we learn?

Small signals can be pushed all the way to zero when the regularization pressure is strong enough.

Convention warning

This exact soft-threshold formula belongs to the displayed normalized objective \(\frac12(z-w)^2+\lambda|w|\). Do not copy the same threshold into a differently scaled Lasso objective without adjusting the constants.

16. Worked Numerical Example — Computing the Objective

Suppose:

\[ \|Xw-y\|_2^2=12 \]

and

\[ w=(2,-1,3). \]

Let:

\[ \lambda=0.4. \]

First calculate the L1 norm:

\[ \|w\|_1=|2|+|-1|+|3|=6. \]

Penalty:

\[ \lambda\|w\|_1=0.4(6)=2.4. \]

Therefore:

\[ J(w)=12+2.4=14.4. \]
\[ \boxed{J(w)=14.4} \]

Exam habit

Always separate:

  1. data-fit term,
  2. norm calculation,
  3. regularization term,
  4. total objective.

17. Worked Numerical Example — Compare Two Candidate Coefficient Vectors

Suppose two models have the same data loss:

Model Data loss Coefficients
A 5 \((3,-2,0,1)\)
B 5.5 \((2, -1.5, 0, 0.2)\)

Let:

\[ \lambda=0.5. \]

Model A

\[ \|w_A\|_1=3+2+0+1=6 \]

so

\[ J_A=5+0.5(6)=8. \]

Model B

\[ \|w_B\|_1=2+1.5+0+0.2=3.7 \]

so

\[ J_B=5.5+0.5(3.7) =5.5+1.85 =7.35. \]

Therefore, under this regularized objective:

\[ \boxed{J_B\lt J_A}. \]

Notice something important:

Model B has higher data loss but lower regularized objective.

Regularized learning does not simply choose the smallest training error.

18. Why Scaling Matters for Lasso

Suppose:

  • feature \(x_1\) is measured in kilograms,
  • feature \(x_2\) is measured in grams.

Their numeric scales differ greatly.

Regularization penalizes coefficient magnitudes:

\[ \sum_j|w_j|. \]

But coefficient magnitude depends on the unit of the corresponding feature.

A feature rescaled by 100 can often use a coefficient around 1/100 of the previous magnitude while producing the same prediction.

Therefore the penalty would treat the two parameterizations differently even though the underlying information is unchanged.

This is why feature scaling is important before regularized regression.

Your Lecture09.pdf explicitly discusses standardization and min-max scaling and explains that scaling matters for models and optimization.

Common preprocessing choice

Standardization:

\[ \boxed{ x_j\leftarrow\frac{x_j-\mu_j}{\sigma_j} } \]

Then fit the regularized model.

19. What Does \(\lambda\) Do?

The regularization parameter controls the trade-off between fit and simplicity.

\[ J(w)=\text{data loss}+\lambda\times\text{L1 penalty}. \]

\(\lambda=0\)

Then:

\[ J(w)=\text{data loss}. \]

The Lasso penalty disappears, giving the corresponding ordinary least-squares objective.

Small positive \(\lambda\)

The model is encouraged to keep coefficients modest, but data fit still dominates relatively strongly.

Larger \(\lambda\)

The penalty matters more.

More coefficients may shrink strongly, and some may become exactly zero.

Extremely large \(\lambda\)

The model is pushed toward very small coefficients and can lose useful signal, producing underfitting.

Memory anchor

λ ↑
→ penalty matters more
→ stronger shrinkage pressure
→ potentially more zeros
→ too much can underfit

Do not memorize “larger \(\lambda\) always means better sparsity” as an evaluative claim. Larger \(\lambda\) means stronger regularization; whether the resulting model is useful depends on the data and validation procedure.

20. Why Lasso Is Connected to Overfitting

From the earlier generalization chapters:

Model too flexible
      ↓
Can fit peculiarities of training data
      ↓
Higher overfitting risk

Regularization introduces a preference for simpler coefficient configurations.

Lasso specifically uses:

\[ \lambda\sum_j|w_j|. \]

So the learner balances:

Explain the observations
          +
Keep total coefficient magnitude controlled

This is the same overall regularization philosophy introduced in C26, but with an L1 penalty.

21. Bias-Variance Connection

Regularization usually makes a model less free to fit the training sample.

That can increase bias while reducing variance.

Conceptually:

No / weak regularization
→ more freedom
→ lower restriction
→ potentially higher variance

Stronger regularization
→ more restriction
→ potentially lower variance
→ potentially higher bias

Lasso does not magically eliminate the bias-variance trade-off.

It changes the hypothesis-selection process by adding a complexity penalty.

The supplied Lecture08.pdf provides the broader bias-variance framework.

22. Lasso Is Not the Same as “Delete the Weakest Features”

A common oversimplification is:

“Lasso calculates feature importance and deletes the least important features.”

That is not the mathematical definition.

Lasso solves a joint optimization problem:

\[ \min_w \left[ \text{loss}(w)+\lambda\sum_j|w_j| \right]. \]

The coefficients interact through the prediction loss.

As a result, the selected/non-selected status emerges from the optimization rather than from a separate ranking-and-deletion step.

23. Correlated Features — A Subtle Case

Suppose two features carry very similar information:

\[ x_1\approx x_2. \]

Lasso may assign weight to one feature and a much smaller or zero weight to the other.

But which feature gets selected is not guaranteed to be uniquely determined by the underlying concept alone.

With strongly correlated predictors, small changes in:

  • the data,
  • preprocessing,
  • \(\lambda\),
  • or optimization details

can influence the selected subset.

Therefore:

A zero Lasso coefficient should not automatically be interpreted as proof that the corresponding real-world variable is irrelevant.

This is an important statistical interpretation safeguard.

24. Intercept Treatment

Many standard implementations do not penalize the intercept.

Suppose:

\[ \hat y=Xw+b. \]

A typical objective is:

\[ J(w,b)=\|Xw+b\mathbf1-y\|_2^2+\lambda\|w\|_1. \]

Notice that the penalty is on \(w\), not \(b\).

Why?

The intercept represents a baseline offset rather than a feature contribution. Penalizing it can distort the baseline unnecessarily.

For an exam, follow the exact convention in the question.

25. Optimization — Why Ordinary Closed-Form OLS Reasoning Does Not Transfer Directly

For OLS, the objective is smooth and differentiable, so we can write:

\[ \nabla J(w)=0 \]

and obtain a closed-form stationary-point equation.

For Lasso, the absolute-value term is non-differentiable at zero:

\[ |w_j|. \]

Therefore the optimization requires methods designed to handle the L1 structure, such as coordinate descent and other convex optimization techniques.

The key learning point for this course is not to invent an OLS-style inverse formula such as:

\[ (X^TX+\lambda I)^{-1}X^Ty \]

for Lasso.

That formula is the Ridge closed-form solution, not the Lasso solution.

Memory trap

Ridge → differentiable L2 penalty → closed-form solution available
Lasso → kinked L1 penalty → no analogous simple closed-form vector formula

26. Coordinate Descent — Intuition

A useful way to understand Lasso optimization is coordinate descent.

Instead of changing every coefficient simultaneously:

  1. hold all coefficients except one fixed,
  2. optimize the chosen coefficient,
  3. move to the next coefficient,
  4. repeat until the objective stabilizes.

The one-dimensional L1 update has the soft-thresholding form introduced earlier.

Conceptually:

Start with coefficients
        ↓
Optimize w₁ while others fixed
        ↓
Optimize w₂
        ↓
Optimize w₃
        ↓
...
        ↓
Repeat
        ↓
Converge to a Lasso solution

This explains why the one-variable soft-thresholding example is more than a trick: it captures an important building block of Lasso optimization.

27. Algorithm Template — Lasso Regression

Problem

Fit a linear regression model while controlling coefficient magnitude using an L1 penalty.

Inputs

  • training feature matrix \(X\),
  • target vector \(y\),
  • regularization strength \(\lambda\).

Objective

\[ \min_w \|Xw-y\|_2^2+\lambda\|w\|_1. \]

High-level procedure

1. Prepare the data.
2. Scale features when appropriate.
3. Choose candidate λ values.
4. Fit the Lasso objective for each candidate.
5. Evaluate using validation / cross-validation.
6. Select λ using the validation procedure.
7. Refit on the permitted training data if required.
8. Evaluate once on the held-out test set.

Critical evaluation rule

Do not repeatedly choose \(\lambda\) using the final test set. The role of validation data/cross-validation belongs to the generalization framework from Lecture08.pdf.

28. L1 vs L2 — Mathematical Table

Property L1 / Lasso L2 / Ridge
Penalty \(\sum |w_j|\) \(\sum w_j^2\)
Norm \(\|w\|_1\) \(\|w\|_2^2\) in the common objective
Boundary geometry Diamond-like Circular/spherical
Smooth at zero? No Yes
Exact zeros Can occur Usually not the defining behaviour
Feature selection Can occur naturally Not usually exact selection
Main intuition Shrink + sparsify Smooth shrinkage
Simple closed form like Ridge? No Yes, for standard least-squares Ridge formulation

29. Lasso vs OLS

Property OLS Lasso
Data-fit objective Yes Yes
Complexity penalty No Yes, L1
Coefficients shrink because of penalty No Yes
Exact zeros encouraged No Yes, possible
Regularization parameter No \(\lambda\)
Typical purpose Fit least-squares relationship Fit + control complexity + possible sparsity

The central conceptual transition is:

\[ \boxed{OLS\rightarrow Lasso=OLS\;fit\;+\;L1\;regularization} \]

30. Worked Conceptual Example — 8 Features

Imagine a prediction problem with:

\[ x_1,x_2,\ldots,x_8. \]

Suppose a Lasso fit produces:

\[ \hat w=(1.9,0,-0.7,0,0.3,0,0.04,-1.2). \]

How should you read this?

Active coefficients

\[ 1.9,-0.7,0.3,0.04,-1.2 \]

Zero coefficients

\[ w_2=w_4=w_6=0. \]

Therefore the corresponding features are inactive in this fitted linear prediction function.

But note that \(0.04\) is not zero. Lasso may shrink it strongly without eliminating it.

Important distinction

small coefficient ≠ zero coefficient

Do not casually round a small number to zero unless the question explicitly tells you to do so.

31. What Happens as \(\lambda\) Changes?

Think of a regularization path conceptually.

λ very small

w = [large, moderate, small, small, moderate]

        ↓ increase λ

w = [smaller, smaller, 0, 0, moderate]

        ↓ increase λ further

w = [small, 0, 0, 0, very small]

This is an intuition, not a guarantee of the exact number or order of zeros for arbitrary data.

The general trend is stronger penalty pressure as \(\lambda\) increases.

32. Common Misconceptions

Misconception 1

“Lasso is just Ridge with absolute values substituted mechanically.”

The objectives differ in a mathematically important way because L1 is non-differentiable at zero.

Misconception 2

“Lasso always makes most coefficients zero.”

No. Sparsity depends on the data, \(\lambda\), scaling, and model setup.

Misconception 3

“A zero Lasso coefficient proves the feature has no real-world meaning.”

No. It means the fitted model under the chosen objective assigned zero weight to that feature.

Misconception 4

“Larger \(\lambda\) means better model.”

No. Larger \(\lambda\) means stronger regularization and can eventually cause underfitting.

Misconception 5

“The Ridge formula can be reused for Lasso.”

No. The standard Ridge closed-form formula does not become a Lasso formula by changing the exponent.

Misconception 6

“Scaling is optional.”

Scaling can materially affect the regularization because the penalty acts on coefficient magnitudes.

Misconception 7

“Lasso deletes columns before learning.”

Not in the standard formulation. The optimization produces coefficients, some of which may be exactly zero.

It controls the strength of the L1 regularization penalty.
