1. Why This Chapter Exists

In the MLP chapter, we reached the point where a neuron computes:

\[ z=w^Ta+b \]

and then applies an activation:

\[ a=\sigma(z). \]

We also know that a neural network ultimately needs to make predictions.

Two questions now become unavoidable:

What transformation should a neuron apply to \(z\)?

and:

How do we quantify how wrong the prediction is?

The first question leads to activation functions.

The second leads to loss functions.

Together they form a crucial chain:

Input
  ↓
Weighted sum + bias
  ↓
z
  ↓
Activation
  ↓
Prediction / representation
  ↓
Loss
  ↓
“How wrong are we?”
  ↓
Optimization

The supplied practical resource is explicitly mapped to neurons, weights/bias, activations and losses. The course resource guide also marks activation/loss concepts as part of the Unit III core, alongside gradient descent and backpropagation.

2. One-Minute Intuition

English

An activation function is a rule that transforms what a neuron computed.

A loss function is a rule that tells us how undesirable the prediction is compared with the target.

Think of a cricket score analyst.

The model produces:

predicted runs = 145

Reality:

actual runs = 160

The difference can be turned into a numerical loss.

Meanwhile, inside the network, activations transform intermediate signals so that the network can represent nonlinear relationships.

So:

Activation shapes the computation. Loss evaluates the result.

Hinglish

Activation function ko neuron ka response rule samjho.

Neuron ne raw weighted sum nikala:

\[ z=wx+b. \]

Ab seedha wahi value aage bhejne ke bajay activation function decide karta hai ki us signal ko kis form mein pass karna hai.

Loss function alag kaam karta hai.

Woh bolta hai:

“Prediction kitni galat hai?”

Yaad rakho:

Activation → network ke andar signal ko transform karta hai
Loss      → final behaviour ko measure karta hai

Dono ka role alag hai.

3. Why Not Use Only Linear Activations?

This is the key connection to the MLP chapter.

Suppose every layer applies only:

\[ a=z=W x+b. \]

Then composing layers gives another affine transformation.

So even a deep network would effectively behave like a single linear/affine model.

That limits its ability to represent nonlinear relationships.

Therefore, hidden layers usually need nonlinear activation functions.

The central idea is:

\[ \boxed{\text{Nonlinearity prevents deep composition from collapsing into one affine map.}} \]

There is no single universal requirement that makes one activation “best.” Different choices have different mathematical and optimization properties. Useful questions include: 1. Is it nonlinear? 2. Is it computationally simple? 3. What range does it produce? 4. What is its derivative? 5. Does it saturate? 6. Can gradients remain useful? 7. Is the output naturally suited to the intended task? We will study these properties through specific functions.

5. Sigmoid Function

The sigmoid function is:

\[ \boxed{ \sigma(z)=\frac{1}{1+e^{-z}} } \]

Its output lies strictly between 0 and 1:

\[ 0\lt \sigma(z)\lt 1. \]

Shape intuition

output
 1 |                 ______
   |              __/
   |           __/
0.5|----------●------------
   |        _/
   |      _/
 0 |_____/__________________
          z

Important points

\[ \sigma(0)=0.5. \]

For large positive \(z\):

\[ \sigma(z)\approx1. \]

For large negative \(z\):

\[ \sigma(z)\approx0. \]

6. Sigmoid as a Probability-Like Output

For binary classification, one common interpretation is:

\[ \hat p=P(y=1\mid x). \]

Then:

\[ \hat p=\sigma(z). \]

Example:

\[ z=2.2. \]

Then approximately:

\[ \sigma(2.2)\approx0.900. \]

So the model may output:

probability-like score ≈ 0.90

A classification decision can then use a threshold such as 0.5, depending on the chosen decision rule.

Important:

The sigmoid output itself is continuous; converting it into a hard class is a separate decision step.

7. Sigmoid Derivative — A Very Important Formula

The derivative can be written elegantly as:

\[ \boxed{ \sigma'(z)=\sigma(z)(1-\sigma(z)) } \]

This is worth understanding rather than merely memorizing.

Because the sigmoid output is between 0 and 1, its derivative is largest around the middle and becomes small near the extremes.

At:

\[ z=0, \]

we have:

\[ \sigma(0)=0.5, \]

so:

\[ \sigma'(0)=0.5(1-0.5)=0.25. \]

The derivative becomes small when the sigmoid saturates near 0 or 1.

That becomes important when we later discuss gradient-based learning.

8. Tanh Function

The hyperbolic tangent is:

\[ \boxed{ \tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}} } \]

Its output lies between:

\[ -1\lt \tanh(z)\lt 1. \]

And:

\[ \tanh(0)=0. \]

Its derivative is:

\[ \boxed{ \frac{d}{dz}\tanh(z)=1-\tanh^2(z) } \]

Intuition

Unlike sigmoid, which is shifted to the positive range:

sigmoid: 0 → 1

tanh is centered around zero:

tanh: -1 → 1

This can sometimes be useful for hidden representations.

9. ReLU

The Rectified Linear Unit is:

\[ \boxed{ ReLU(z)=\max(0,z) } \]

So:

\[ ReLU(z)= \begin{cases} 0,&z\lt 0\\ z,&z\ge0 \end{cases} \]

Visual intuition

output
  |
  |          /
  |         /
  |        /
  |_______/____________ z
          0

ReLU is one of the most important modern neural-network activations because it is simple and provides a nonlinearity without sigmoid-like saturation on the positive side.

10. ReLU Derivative

PYTHON
import numpy as np

def sigmoid(z):
    s = 1.0 / (1.0 + np.exp(-np.clip(z, -30, 30)))
    d_s = s * (1.0 - s)
    return s, d_s

def tanh(z):
    t = np.tanh(z)
    d_t = 1.0 - t**2
    return t, d_t

def relu(z):
    r = np.maximum(0, z)
    d_r = (z > 0).astype(float)
    return r, d_r

def leaky_relu(z, alpha=0.01):
    lr = np.where(z > 0, z, alpha * z)
    d_lr = np.where(z > 0, 1.0, alpha)
    return lr, d_lr

def softmax(z):
    e_z = np.exp(z - np.max(z, axis=0, keepdims=True))
    return e_z / np.sum(e_z, axis=0, keepdims=True)

# Test gradients at saturation points (z = 5.0 and z = -5.0)
z_test = np.array([-5.0, 0.0, 5.0])
_, d_sig = sigmoid(z_test)
_, d_relu = relu(z_test)
print(f"z = {z_test}")
print(f"Sigmoid gradients: {d_sig.round(4)} (Notice severe vanishing at extremes!)")
print(f"ReLU gradients:    {d_relu.round(4)} (Notice gradient stays strictly 1.0 for z > 0!)")

For \(z\gt 0\):

\[ ReLU'(z)=1. \]

For \(z\lt 0\):

\[ ReLU'(z)=0. \]

At \(z=0\), the ordinary derivative is not uniquely defined.

In practical optimization systems, a specific convention/subgradient treatment is used.

For introductory analysis, remember:

z < 0 → gradient contribution 0
z > 0 → gradient contribution 1

This immediately gives intuition for a common ReLU issue.

11. The “Dead ReLU” Intuition

Suppose a neuron repeatedly receives strongly negative pre-activation values:

\[ z\lt 0. \]

Then ReLU outputs:

\[ 0. \]

and its local derivative is:

\[ 0. \]

That can make gradient-based updates ineffective for that unit under those conditions.

This is commonly described as the dead ReLU problem.

Do not overgeneralize this into:

“ReLU neurons always die.”

It is a possible training issue, not an inevitable outcome.

12. A Small Activation Comparison

Function Formula Output range Key property Common role
Sigmoid \(1/(1+e^{-z})\) \((0,1)\) Probability-like output Binary output in many formulations
Tanh \((e^z-e^{-z})/(e^z+e^{-z})\) \((-1,1)\) Zero-centered Historical/selected hidden layers
ReLU \(\max(0,z)\) \([0,\infty)\) Simple piecewise linear nonlinearity Common hidden-layer choice

This table is an exam memory aid, not a claim that one activation is universally superior.

13. Softmax — Multi-Class Output

For \(K\) classes, define:

\[ \boxed{ softmax(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}} } \]

for each class \(i\).

The outputs satisfy:

\[ 0\lt p_i\lt 1 \]

and

\[ \sum_i p_i=1. \]

So the output vector can be interpreted as a categorical probability distribution under the model.

Example

Suppose:

\[ z=(2,1,0). \]

Then:

\[ e^2\approx7.39, \quad e^1\approx2.72, \quad e^0=1. \]

The denominator is approximately:

\[ 7.39+2.72+1=11.11. \]

Hence:

\[ p_1\approx0.665, \quad p_2\approx0.245, \quad p_3\approx0.090. \]

The probabilities sum to approximately 1.

14. Softmax Is Not Just “Many Sigmoids”

The softmax outputs are coupled through the denominator:

\[ \sum_j e^{z_j}. \]

Increasing one logit changes the normalization shared by all outputs.

This is different from independently applying sigmoid to each logit.

This distinction matters for mutually exclusive multi-class classification.

15. What Is a Loss Function?

A loss function assigns a numerical penalty to the model's prediction relative to the target.

General notation:

\[ L(\hat y,y). \]

The training process tries to make the loss small.

For a dataset:

\[ \mathcal L(\theta) = \frac1n\sum_{i=1}^{n}L(\hat y_i,y_i). \]

The exact notation varies with the model and context, but the basic idea is always:

prediction → compare with target → numerical loss

16. Loss vs Evaluation Metric

Do not treat these as synonyms.

Loss function

Usually the quantity optimized during training.

Evaluation metric

A quantity used to assess model performance, often on held-out data.

They can be the same, but they need not be.

Examples:

Training objective → cross-entropy loss
Evaluation → accuracy / precision / recall / F1

or:

Training objective → MSE
Evaluation → MSE / MAE / R²

Your Lecture07.pdf already distinguishes regression losses and classification evaluation metrics such as accuracy, precision, recall and F1.

17. Mean Squared Error (MSE)

For regression:

\[ \boxed{ MSE = \frac1n\sum_{i=1}^{n}(y_i-\hat y_i)^2 } \]

It squares each error before averaging.

Why square the error?

It makes positive and negative errors both contribute positively and gives larger errors disproportionately larger penalties.

Example:

Errors:

\[ 1,2,4. \]

Squared:

\[ 1,4,16. \]

The error 4 becomes much more influential than error 1.

The supplied Lecture07.pdf explicitly notes that MSE is more sensitive to outliers than MAE and is differentiable, making it convenient for gradient-based optimization.

18. Mean Absolute Error (MAE)

For regression:

\[ \boxed{ MAE = \frac1n\sum_{i=1}^{n}|y_i-\hat y_i| } \]

It measures the average absolute size of the error.

Compared with MSE:

MSE → squares errors
MAE → takes absolute errors

Thus a very large error has a stronger relative impact under MSE.

19. MSE vs MAE — Numerical Example

Suppose the errors are:

\[ 1,1,5. \]

MAE

\[ MAE =\frac{1+1+5}{3} =\frac73 \approx2.33. \]

MSE

\[ MSE =\frac{1^2+1^2+5^2}{3} =\frac{27}{3} =9. \]

The large error contributes very strongly to MSE.

Memory anchor

MSE amplifies large errors because of squaring.

20. Binary Cross-Entropy

For binary classification with target \(y\in\{0,1\}\) and predicted probability \(\hat p\), binary cross-entropy is:

\[ \boxed{ L(y,\hat p) = - \left[ y\log \hat p +(1-y)\log(1-\hat p) \right] } \]

Case 1: \(y=1\)

Then:

\[ L=-\log\hat p. \]

If \(\hat p\) is close to 1, loss is small.

If \(\hat p\) is close to 0, loss becomes large.

Case 2: \(y=0\)

Then:

\[ L=-\log(1-\hat p). \]

If \(\hat p\) is close to 0, loss is small.

If \(\hat p\) is close to 1, loss becomes large.

21. Why Logarithms Appear in Cross-Entropy

Suppose the true class is 1.

Compare:

\[ \hat p=0.9 \]

versus:

\[ \hat p=0.1. \]

The model that assigns high probability to the correct class receives a low penalty.

The model that is confidently wrong receives a large penalty.

This property is important because classification is not merely about the final hard class; the confidence/probability structure matters during optimization.

22. Multi-Class Cross-Entropy

For one-hot target vector \(y\) and predicted class probabilities \(\hat p_i\):

\[ \boxed{ L =-\sum_{i=1}^{K}y_i\log \hat p_i } \]

If the true class is class \(k\), then \(y_k=1\) and all other \(y_i=0\), so:

\[ L=-\log \hat p_k. \]

Thus the loss is controlled by the probability assigned to the correct class.

23. Why Softmax and Cross-Entropy Often Appear Together

For multi-class classification, a common pipeline is:

logits z
   ↓
softmax
   ↓
class probabilities
   ↓
cross-entropy
   ↓
loss

This combination is mathematically convenient and widely used.

The important conceptual chain is:

logits → normalized class probabilities → compare with target distribution

Later, backpropagation will show how gradients flow through this pipeline.

24. Loss Landscape Intuition

Imagine the network parameters as coordinates in a huge space.

For every possible parameter setting, the model has a loss.

Conceptually:

Loss
                  ↑
                  │          /
                  │        /   \
                  │      /       \
                  │  ___●_________\__
                  │      minimum
                  └────────────────────→ parameters

Training tries to move parameters toward lower-loss regions.

This prepares us for gradient descent.

25. A Key Distinction: Logits, Probabilities, Predictions

These three words are frequently mixed up.

Logit

A raw output before probability normalization.

For binary classification:

\[ z=w^Tx+b. \]

Probability-like output

After an appropriate transformation such as sigmoid or softmax.

Prediction

The final decision or estimated target produced from the output representation.

Example:

z = 2.2
↓ sigmoid
p ≈ 0.90
↓ threshold 0.5
class = 1

These are three different stages.

26. Activation Function vs Output Function

It is helpful to distinguish:

Hidden-layer activation

Controls the transformation of internal representations.

Common examples:

  • ReLU
  • tanh
  • sigmoid in some architectures

Output-layer transformation

Chosen according to the output semantics of the task.

Examples:

  • linear for many regression problems,
  • sigmoid for many binary-classification formulations,
  • softmax for mutually exclusive multi-class classification.

Do not assume the same activation belongs everywhere.

27. Worked Example — Sigmoid + Binary Loss

Suppose:

\[ y=1 \]

and the model produces:

\[ z=1.5. \]

The sigmoid output is approximately:

\[ \hat p=\sigma(1.5)\approx0.818. \]

Binary cross-entropy becomes:

\[ L=-\log(0.818). \]

This is approximately:

\[ L\approx0.201. \]

The loss is relatively small because the model assigned high probability to the correct class.

Now imagine the model instead predicts:

\[ \hat p=0.1. \]

Then:

\[ L=-\log(0.1)\approx2.303. \]

The confidently wrong prediction is penalized much more heavily.

28. Worked Example — Multi-Class Cross-Entropy

Suppose there are three classes and the target is class 2.

The target vector is:

\[ y=(0,1,0). \]

Suppose the model predicts:

\[ \hat p=(0.2,0.7,0.1). \]

Then:

\[ L =-[0\log0.2+1\log0.7+0\log0.1] \]

so:

\[ \boxed{L=-\log0.7} \]

approximately:

\[ L\approx0.357. \]

If the model instead assigned only 0.05 to the correct class, the loss would be much larger.

29. Activation Saturation

A function is said to saturate in regions where its output changes only very slowly as its input changes.

For sigmoid:

large negative z → output near 0 → small derivative
large positive z → output near 1 → small derivative

This matters because gradient-based training depends on useful derivatives.

The broad chain is:

small derivative
      ↓
small local gradient contribution
      ↓
weaker parameter update

This does not mean sigmoid is “bad.” It means its mathematical properties create trade-offs.

30. Zero-Centered Activations

Sigmoid outputs are positive:

\[ (0,1). \]

Tanh outputs values around zero:

\[ (-1,1). \]

That difference affects the geometry and optimization behaviour of hidden representations.

Again, avoid absolute statements such as:

“Zero-centered is always better.”

Architecture, initialization, optimizer, scale and task all matter.

31. Loss Function Choice Must Match the Task

A useful first-pass map is:

Regression
   ↓
MSE / MAE / other regression losses

Binary classification
   ↓
sigmoid + binary cross-entropy (common formulation)

Multi-class classification
   ↓
softmax + categorical cross-entropy (common formulation)

These pairings connect the numerical output representation to the meaning of the target.

32. Why MSE Is Not the Default Answer to Everything

A common beginner mistake is:

“Loss means squared error, so always use MSE.”

That is not generally correct.

MSE is natural for many regression settings because the target is numeric and differences can be measured directly.

Classification has a different probabilistic structure.

For example, in binary classification the model is often trying to represent a Bernoulli probability, making a log-loss formulation a natural choice.

So loss should be tied to the prediction problem.

33. The Hidden Connection: Loss Determines the Learning Signal

Suppose a prediction is wrong.

The loss tells us:

“How wrong?”

But gradient descent needs something even more specific:

“In which direction should the parameters move to reduce the loss?”

That information comes from derivatives/gradients.

Therefore:

Prediction
   ↓
Loss
   ↓
Derivative / gradient
   ↓
Parameter update

This is the bridge to the next chapter.

34. Why the Derivative of the Activation Matters

Consider one neuron:

\[ a=\sigma(z) \]

and:

\[ z=wx+b. \]

A small change in \(w\) changes \(z\), which changes \(a\), which changes the loss.

By the chain rule:

\[ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \frac{\partial a}{\partial z} \frac{\partial z}{\partial w}. \]

The term:

\[ \frac{\partial a}{\partial z} \]

is the activation derivative.

So activation functions are not merely arbitrary nonlinear wrappers; their derivatives directly participate in learning.

35. Math You Need Now — Chain Rule Preview

For composed functions:

\[ y=f(g(x)), \]

we have:

\[ \boxed{ \frac{dy}{dx} = \frac{dy}{dg} \frac{dg}{dx} } \]

In a neural network, there can be many nested operations:

\[ x \rightarrow z^{(1)} \rightarrow a^{(1)} \rightarrow z^{(2)} \rightarrow a^{(2)} \rightarrow \hat y \rightarrow L. \]

Backpropagation is largely the systematic application of this idea through the network.

37. Common Misconceptions

⚠️ Misconception 1
**“Sigmoid is the activation for every neural-network layer.”** No. Hidden and output layers can use different transformations.
⚠️ Misconception 2
**“Softmax always means the most probable class is immediately selected.”** Softmax produces a probability-like distribution. The final class decision is a separate step such as selecting the largest output.
⚠️ Misconception 3
**“Loss and accuracy are the same thing.”** No. Loss is an optimization quantity; accuracy is an evaluation metric.
⚠️ Misconception 4
**“ReLU is nonlinear everywhere.”** It is piecewise linear: nonlinear as a whole, but exactly linear on each side of zero.
⚠️ Misconception 5
**“MSE and MAE differ only by notation.”** No. Squaring makes MSE much more sensitive to large errors.
⚠️ Misconception 6
**“A low loss always means a good deployed model.”** Training loss alone does not guarantee generalization.

40. Formula Cards

Formula Card A — Sigmoid

\[ \boxed{\sigma(z)=\frac1{1+e^{-z}}} \]

Symbols:

  • \(z\) = pre-activation
  • \(e\) = Euler's number

Range:

\[ (0,1). \]

Derivative:

\[ \boxed{\sigma'(z)=\sigma(z)(1-\sigma(z))} \]

Exam trigger: binary output / activation derivative.

Formula Card B — Tanh

\[ \boxed{\tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}}} \]

Range:

\[ (-1,1). \]

Derivative:

\[ \boxed{1-\tanh^2(z)} \]

Exam trigger: compare with sigmoid; zero-centered activation.

Formula Card C — ReLU

\[ \boxed{ReLU(z)=\max(0,z)} \]

Derivative for ordinary nonzero regions:

\[ ReLU'(z)= \begin{cases} 0,&z\lt 0\\ 1,&z\gt 0 \end{cases} \]

Exam trigger: hidden-layer activation; dead-neuron discussion.

Formula Card D — Softmax

\[ \boxed{ softmax(z_i)=\frac{e^{z_i}}{\sum_j e^{z_j}} } \]

Properties:

\[ 0\lt p_i\lt 1, \qquad \sum_i p_i=1. \]

Exam trigger: multi-class classification.

Formula Card E — MSE

\[ \boxed{ MSE=\frac1n\sum_i(y_i-\hat y_i)^2 } \]

Exam trigger: regression loss.

Formula Card F — MAE

\[ \boxed{ MAE=\frac1n\sum_i|y_i-\hat y_i| } \]

Exam trigger: regression; compare robustness to large errors relative to MSE.

Formula Card G — Binary Cross-Entropy

\[ \boxed{ L=-[y\log\hat p+(1-y)\log(1-\hat p)] } \]

Exam trigger: binary classification with probability output.

Formula Card H — Multi-Class Cross-Entropy

\[ \boxed{ L=-\sum_i y_i\log\hat p_i } \]

For a one-hot target with true class \(k\):

\[ \boxed{L=-\log\hat p_k} \]

Exam trigger: softmax + multi-class classification.
