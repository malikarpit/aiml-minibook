1. Why Does Logistic Regression Exist?

Before learning the equation, understand the problem.

Suppose you build a system that must answer:

Is this email spam?

The answer is not a continuous quantity like ₹42,531 or 73.5 kg.

It is a class:

spam
not spam

Or:

cancer / not cancer
fraud / legitimate
pass / fail
cat / dog

Linear regression is designed primarily for predicting a continuous numerical target. Logistic regression is designed for classification, especially binary classification.

Real-life analogy

Imagine a security guard deciding whether someone should enter a restricted area.

The guard may internally become increasingly convinced:

very unlikely → unlikely → uncertain → likely → very likely

but the final decision may still be:

ALLOW / DENY

Logistic regression works similarly:

First produce a quantity that can be interpreted as a probability between 0 and 1; then apply a decision rule to obtain a class.

2. One-Minute Intuition

English

Logistic regression takes input features, computes a linear score, converts that score into a value between 0 and 1 using the sigmoid function, and interprets that value as a probability for a chosen class.

The flow is:

Input features
      ↓
Linear score z = wᵀx + b
      ↓
Sigmoid σ(z)
      ↓
Probability
      ↓
Decision threshold
      ↓
Predicted class
👨‍🏫 Hinglish
Socho pehle model ek **score** banata hai: > "Mujhe lag raha hai ye spam hai — kitna strongly?" Lekin raw score kabhi `-20` ho sakta hai aur kabhi `+20`. Hume probability chahiye: > "Spam hone ka chance 0.92 hai." Sigmoid raw score ko probability-like range `[0,1]` mein convert karta hai. Then threshold lagao: > 0.92 → spam > 0.21 → not spam

3. Regression vs Classification

This distinction should be automatic.

Problem Output Example Typical model family
Regression Continuous number house price Linear regression
Classification Class label / class probability spam or not spam Logistic regression

Important nuance

Logistic regression does not directly learn the class label as a straight line.

It models a probability derived from a linear score.

4. The Input to the Model

A data point can contain multiple features:

\[ x = [x_1,x_2,\ldots,x_d]^T \]

The model has learned parameters:

\[ w=[w_1,w_2,\ldots,w_d]^T \]

and an intercept/bias:

\[ b \]

The first stage computes:

\[ \boxed{z = w^T x+b} \]

or explicitly:

\[ z=w_1x_1+w_2x_2+\cdots+w_dx_d+b \]
👨‍🏫 Hinglish
Har feature model ko thoda influence karta hai. `weight × feature` = us feature ka contribution. Sab contributions add karo + bias add karo → raw score `z`.

5. Why Can't We Just Use the Linear Score?

Suppose:

\[ z=w^Tx+b \]

The score could be:

-12
-3
0
+2.7
+19

A probability should normally be represented between 0 and 1.

So we need a squashing function.

That function is the sigmoid.

6. The Sigmoid Function

\[ \boxed{ \sigma(z)=\frac{1}{1+e^{-z}} } \]

Properties:

\[ 0\lt \sigma(z)\lt 1 \]

and:

\[ \sigma(0)=0.5 \]

As z becomes very positive:

\[ \sigma(z)\rightarrow 1 \]

As z becomes very negative:

\[ \sigma(z)\rightarrow 0 \]

Visual mental model

Probability
1.0 |                         ______
    |                      __/
    |                   __/
0.5 |------------------*----------------
    |               __/
    |            __/
0.0 |___________/
    +------------------------------------→ z
              0

The sigmoid turns the unbounded score into a bounded value.

7. What Does the Sigmoid Value Mean?

For binary classification, we commonly write:

\[ \boxed{ P(Y=1\mid x)=\sigma(w^Tx+b) } \]

That means:

Given input x, the model's estimated probability of class 1 is the sigmoid of the linear score.

Example

Suppose:

\[ z=2 \]

Then:

\[ \sigma(2)=\frac{1}{1+e^{-2}} \approx0.881 \]

So the model estimates roughly:

\[ P(Y=1\mid x)\approx0.881 \]

or about 88.1% under the model.

👨‍🏫 Hinglish
`z = 2` ka matlab direct "2 probability" nahi hai. Sigmoid us score ko probability range mein map karta hai.

8. The Decision Threshold

A probability is not yet a final class label.

A simple decision rule is:

\[ \hat y= \begin{cases} 1,&P(Y=1\mid x)\ge 0.5\\ 0,&P(Y=1\mid x)\lt 0.5 \end{cases} \]

Because:

\[ \sigma(0)=0.5 \]

the threshold 0.5 corresponds to the linear score:

\[ z=0 \]

Therefore the decision boundary is:

\[ \boxed{w^Tx+b=0} \]

This is an extremely important connection:

Logistic regression gives a nonlinear probability curve, but its binary decision boundary in feature space is linear.

9. Real-World Analogy — Exam Pass/Fail

Imagine predicting whether a student will pass based on:

  • attendance;
  • internal marks;
  • assignment completion.

The model creates a score:

\[ z=w_1x_1+w_2x_2+w_3x_3+b \]

Then sigmoid converts it:

raw score → probability of passing

Example:

z = -3  → probability ≈ 0.047
z = 0   → probability = 0.500
z = +3  → probability ≈ 0.953

So the model transitions smoothly from unlikely to likely.

10. Why Is the Decision Boundary Linear?

Start from the standard threshold:

\[ P(Y=1\mid x)=0.5 \]

The sigmoid equals 0.5 exactly when:

\[ z=0 \]

and:

\[ z=w^Tx+b \]

Therefore:

\[ w^Tx+b=0 \]

For two features:

\[ w_1x_1+w_2x_2+b=0 \]

which describes a line in 2D.

For three features it describes a plane.

For higher dimensions it is a hyperplane.

Visual

Class 0       |       Class 1
○ ○ ○         |         ● ● ●
○ ○           |       ● ● ●
○             |     ● ●
--------------|----------------
       linear decision boundary

11. Where Does the Probability Formula Come From?

A useful equivalent form is the log-odds / logit relation.

Start with:

\[ p=\sigma(z)=\frac{1}{1+e^{-z}} \]

Then:

\[ \boxed{ \log\left(\frac{p}{1-p}\right)=z } \]

Since:

\[ z=w^Tx+b \]

we get:

\[ \boxed{ \log\left(\frac{p}{1-p}\right)=w^Tx+b } \]

This says:

The log-odds are modeled as a linear function of the input features.

You do not need to force yourself to memorize this before understanding sigmoid and the decision boundary, but it is a major formal relationship.

12. What Is a Loss Function?

During training, the model needs a way to measure:

How wrong are my predicted probabilities?

A common loss for binary logistic regression is binary cross-entropy / log loss.

For one example:

\[ \boxed{ \ell(y,p)=-\left[y\log p+(1-y)\log(1-p)\right] } \]

where:

  • y is the true label, usually 0 or 1;
  • p is the predicted probability of class 1.

For n observations, the average loss is:

\[ \boxed{ L(w,b)= -\frac1n\sum_{i=1}^{n} \left[y_i\log p_i+(1-y_i)\log(1-p_i)\right] } \]

with:

\[ p_i=\sigma(w^Tx_i+b) \]

13. Why Does Cross-Entropy Make Sense?

Consider a true label:

\[ y=1 \]

Then:

\[ \ell=-\log p \]

If the model predicts:

p = 0.99 → very small loss
p = 0.80 → moderate loss
p = 0.10 → very large loss

This makes sense.

If the event really happened, confidently assigning it a tiny probability should be heavily penalized.

👨‍🏫 Hinglish
Agar actual answer `1` hai aur model bol raha hai: > "Probability 1 hone ki 0.99 hai" good. But if it says: > "Probability sirf 0.01 hai" then model **confidently wrong** hai, so loss bahut bada hona chahiye.

14. Training Logistic Regression

Conceptually:

Training data
     ↓
Choose initial w,b
     ↓
Compute z = wᵀx+b
     ↓
Compute p = σ(z)
     ↓
Compute loss
     ↓
Compute how parameters should change
     ↓
Update parameters
     ↓
Repeat

The optimization goal is:

\[ \boxed{ \min_{w,b}L(w,b) } \]

Gradient-based methods are commonly used to find parameters that reduce the loss.

This is where your mathematics from Lecture 9 becomes directly relevant:

  • vectors;
  • inner products;
  • derivatives;
  • gradients;
  • chain rule;
  • optimization.

15. A Small Complete Numerical Example

Suppose we use one feature:

hours studied → probability of passing

Let:

\[ w=1, \qquad b=-2 \]

and a student studied:

\[ x=3 \]

Step 1 — Linear score

\[ z=wx+b \]
\[ z=(1)(3)-2=1 \]

Step 2 — Sigmoid

\[ p=\frac{1}{1+e^{-1}} \]
\[ p\approx0.731 \]

So:

Estimated probability of passing ≈ 73.1%.

Step 3 — Classification

Using threshold 0.5:

\[ 0.731\gt 0.5 \]

therefore:

\[ \hat y=1 \]

Mental flow

x = 3
 ↓
z = 1
 ↓
σ(1) ≈ 0.731
 ↓
73.1%
 ↓
Pass / class 1

16. What Happens When the Score Changes?

With the same model:

\[ z=x-2 \]
x z sigmoid(z) approx. class using 0.5
0 -2 0.119 0
1 -1 0.269 0
2 0 0.500 1*
3 1 0.731 1
4 2 0.881 1

* Depending on the chosen tie convention at exactly 0.5; state the rule you are using.

Notice the important shape:

The probability changes smoothly, while the final class can change abruptly at the decision threshold.

17. What Do the Weights Mean?

Suppose:

\[ P(Y=1\mid x)=\sigma(w_1x_1+w_2x_2+b) \]

If w1 is positive, increasing x1 increases the linear score z, holding other inputs fixed.

Since sigmoid is increasing, that tends to increase the predicted probability of class 1.

If w1 is negative, increasing x1 tends to decrease that probability.

Important caution

Do not immediately interpret the magnitude of a weight as a simple real-world effect in the original units when features are differently scaled. Your Lecture 9 explicitly discusses feature scaling because feature magnitudes and units can matter for ML computations. Course source: Lecture09.pdf, pp. 7–9.

18. Logistic Regression vs Linear Regression

Property Linear Regression Logistic Regression
Main task Regression Classification
Basic model score wᵀx+b wᵀx+b
Output mapping Identity Sigmoid for binary probability
Typical target Continuous Binary class / probability
Common loss Squared error Log loss / cross-entropy
Decision boundary Not the main concept wᵀx+b=0 for 0.5 threshold

Key insight

The linear score is shared.

What changes is how the score is interpreted and trained for the target type.

19. Logistic Regression Is a Linear Classifier

This sounds contradictory at first.

"But sigmoid is nonlinear!"

Correct: sigmoid is nonlinear.

However, the decision condition:

\[ \sigma(w^Tx+b)\ge0.5 \]

is equivalent to:

\[ w^Tx+b\ge0 \]

So the separating boundary is linear in the original feature space.

👨‍🏫 Hinglish
Probability curve nonlinear hai, but boundary banane wala rule linear hai. Isi liye logistic regression ko **linear classification model** kaha jata hai.

20. Multiclass Extension — Know the Idea

Your syllabus only says logistic regression, and a binary treatment is the basic starting point.

For more than two classes, common extensions include:

  • one-vs-rest strategies;
  • multinomial/softmax logistic regression.

For K classes, a softmax model can produce:

\[ P(Y=k\mid x)= \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}} \]

The probabilities sum to 1.

This is conceptually useful because you will meet softmax again in neural networks.

Do not confuse the binary sigmoid case with the multiclass softmax case.

21. Common Misconceptions

Misconception 1

"Logistic regression predicts only 0 or 1."

The model can produce a probability; a threshold converts the probability into a class label.

Misconception 2

"The sigmoid itself makes the decision boundary nonlinear."

The sigmoid is nonlinear, but the standard binary decision boundary remains a hyperplane.

Misconception 3

"A predicted probability of 0.8 means the event definitely occurs 80% of the time in every situation."

Interpret it as the model's estimated conditional probability under its assumptions/data/model quality; it is not a guarantee.

Misconception 4

"Logistic regression is just linear regression followed by rounding."

No. It uses a different probabilistic formulation and a different training objective.

Misconception 5

"Probability must always be 0 or 1."

No. Probability is naturally continuous between 0 and 1; the class decision can be discrete.

24. Exam Lens

2-mark questions

  • Define logistic regression.
  • Write the sigmoid function.
  • What is the output of sigmoid?
  • What is the decision boundary for binary logistic regression?
  • Differentiate linear and logistic regression.

5-mark question

Explain logistic regression with sigmoid function.

Recommended structure:

  1. Define binary classification.
  2. Give linear score z=wᵀx+b.
  3. Introduce sigmoid.
  4. Give probability interpretation.
  5. Give threshold/decision rule.
  6. Draw the sigmoid.

10-mark question

Explain logistic regression mathematically and derive the decision boundary.

Recommended structure:

  1. Problem definition.
  2. Input vector and parameters.
  3. Linear score.
  4. Sigmoid equation.
  5. Probability interpretation.
  6. Loss function.
  7. Training objective.
  8. Threshold rule.
  9. Derive wᵀx+b=0 for threshold 0.5.
  10. Advantages/limitations or comparison with linear regression.

Exam trap

Do not write:

"The sigmoid is the decision boundary."

Write:

"The sigmoid maps the linear score to a probability; for the standard 0.5 threshold, the corresponding decision boundary is wᵀx+b=0."
