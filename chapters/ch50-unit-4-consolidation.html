5. MDP — The Language of Sequential Decisions

A Markov Decision Process is represented as:

\[ \boxed{(S,A,P,R,\gamma)} \]

where:

  • \(S\) = states;
  • \(A\) = actions;
  • \(P(s'|s,a)\) = transition model;
  • \(R\) = reward function;
  • \(\gamma\) = discount factor.

The point is not to memorize five letters mechanically.

The point is to answer:

Where am I, what can I do, what may happen next, what reward do I receive, and how much do I value future rewards?

6. MDP Example

Suppose a robot is in a grid.

+---+---+---+
| S |   | G |
+---+---+---+

State:

\[ s=\text{current cell} \]

Action:

\[ a\in\{\text{up, down, left, right}\} \]

Reward:

ordinary move → small/zero reward
goal           → positive reward
collision      → negative reward

The state-transition model tells us what can happen after an action.

7. The Markov Idea

The Markov assumption says, informally:

Given the current state, the future does not require the entire past history separately.

Formally:

\[ P(s_{t+1}\mid s_t,a_t,s_{t-1},a_{t-1},\ldots) = P(s_{t+1}\mid s_t,a_t) \]
👨‍🏫 Hinglish memory hook
Agar current state mein future ko predict karne ke liye required information already captured hai, to puri history ko separately carry karna necessary nahi hai.

Important limitation

Whether a problem truly has a Markov state depends on how the state is defined.

A badly designed state may hide important history.

8. Return and Discounting

The discounted return from time \(t\) is:

\[ \boxed{ G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+\cdots } \]

Why discount?

A future reward may be considered less valuable than an immediate reward.

If:

\[ \gamma=0, \]

only the immediate reward matters.

If:

\[ \gamma\approx1, \]

longer-term rewards receive more weight.

9. Value Functions

State value

\[ V^\pi(s) \]

means the expected return starting from state \(s\) and following policy \(\pi\).

Action value

\[ Q^\pi(s,a) \]

means the expected return from taking action \(a\) in state \(s\), then following policy \(\pi\).

Core distinction

V(s)
“how good is this state?”

Q(s,a)
“how good is this action from this state?”

10. Bellman Idea

The value of a state can be described recursively:

\[ V^\pi(s) = \sum_a\pi(a|s) \sum_{s'}P(s'|s,a) \left[ R(s,a,s') + \gamma V^\pi(s') \right] \]

The important idea is:

value now
=
immediate reward
+
discounted future value

This recursive structure is the bridge from MDP theory to Q-learning.

11. Q-Learning — Learning Action Values

Q-learning learns an approximation to the optimal action-value function:

\[ Q^*(s,a). \]

The central update is:

\[ \boxed{ Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r+\gamma\max_{a'}Q(s',a') - Q(s,a) \right] } \]

where:

  • \(\alpha\) = learning rate;
  • \(r\) = immediate reward;
  • \(\gamma\) = discount factor;
  • \(s'\) = next state.

12. Break the Q-Learning Equation Apart

Define the target:

\[ \boxed{ y=r+\gamma\max_{a'}Q(s',a') } \]

Then define the temporal-difference error:

\[ \boxed{ \delta=y-Q(s,a) } \]

The update becomes:

\[ Q(s,a)\leftarrow Q(s,a)+\alpha\delta \]

So the full story is:

current estimate
      ↓
look at reward + best future estimate
      ↓
construct target
      ↓
difference = TD error
      ↓
move current estimate toward target

13. Worked Q-Learning Update

Suppose:

\[ Q(s,a)=2 \]
\[ r=4 \]
\[ \gamma=0.5 \]

and the best next-state value is:

\[ \max_{a'}Q(s',a')=6. \]

Let:

\[ \alpha=0.2. \]

Target:

\[ y=4+0.5(6)=7. \]

TD error:

\[ \delta=7-2=5. \]

Update:

\[ Q_{\text{new}}=2+0.2(5)=3. \]

Therefore:

\[ \boxed{Q_{\text{new}}=3} \]

14. Exploration vs Exploitation

An RL agent must balance:

EXPLOIT
“take what currently looks best”

with

EXPLORE
“try actions so I can learn”

A common mechanism is epsilon-greedy:

\[ \pi(a|s)= \begin{cases} \text{random action}, & \text{with probability }\epsilon\\ \arg\max_aQ(s,a), & \text{with probability }1-\epsilon \end{cases} \]

Often \(\epsilon\) is reduced over training, but the schedule is problem-dependent.

15. Q-Learning vs Policy Gradient

Property Q-learning Policy gradient
Learns action values policy parameters
Main object \(Q(s,a)\) \(\pi_\theta(a|s)\)
Typical update TD/Bellman-style gradient ascent on return
Action choice derive from Q values sample/choose from policy
Natural strength discrete action-value problems direct policy optimization
Exploration often epsilon-greedy etc. often built into stochastic policy

Do not memorize “Q-learning = old, policy gradient = new.”

They solve related sequential-decision problems with different parameterizations and learning mechanisms.

16. Policy Gradients

Suppose a policy is parameterized by:

\[ \pi_\theta(a|s). \]

The objective is expected return:

\[ J(\theta)=\mathbb E_{\pi_\theta}[G]. \]

Gradient ascent gives:

\[ \boxed{ \theta\leftarrow\theta+\alpha\nabla_\theta J(\theta) } \]

The sign is different from gradient descent because we are maximizing expected reward.

This is a common exam trap.

17. REINFORCE Intuition

A policy-gradient method can estimate:

\[ \nabla_\theta J(\theta) \]

using sampled trajectories.

A standard form is:

\[ \boxed{ \nabla_\theta J(\theta) \approx \frac{1}{N} \sum_i G_i \nabla_\theta \log \pi_\theta(a_i|s_i) } \]

The basic intuition:

action produced
      ↓
observe outcome / return
      ↓
good outcome?
increase tendency toward that action
      ↓
poor outcome?
decrease tendency

The return weights the learning signal.

18. Q-Learning vs Policy Gradient — The Deep Difference

Think of:

Q-learning

“First learn how good each state-action choice is.”

Policy gradient

“Directly learn how the policy should choose actions.”

This is one of the most useful conceptual contrasts in Unit IV.

19. NLP — The Language Pipeline

A language system starts with text:

RAW TEXT
   ↓
preprocessing
   ↓
tokens
   ↓
representation
   ↓
model
   ↓
prediction

Typical downstream tasks include:

  • classification;
  • sentiment analysis;
  • spam detection;
  • intent classification;
  • information extraction;
  • search/retrieval.

20. Tokenization

Tokenization transforms text into units.

Example:

“Machine learning is useful.”

Word-level conceptual tokenization:

[Machine, learning, is, useful]

Subword tokenization might produce a different sequence.

Character tokenization would produce individual characters.

Key idea

There is no universal tokenization that is best for every NLP task.

21. Stemming vs Lemmatization

Stemming

A heuristic process that may cut words toward a common stem.

studies
studying
studied

may be reduced toward related stems.

Lemmatization

Attempts to map word forms to linguistically meaningful base lemmas.

The outputs therefore need not be identical.

Aspect Stemming Lemmatization
Typical method heuristic truncation linguistic/base-form analysis
Output may be non-word generally meaningful lemma
Complexity often simpler often richer
Main goal reduce word-form variation obtain normalized lexical form

22. Text Normalization

Depending on task, preprocessing may include:

  • lowercasing;
  • punctuation handling;
  • whitespace normalization;
  • stop-word treatment;
  • stemming/lemmatization;
  • handling URLs or special tokens.

But preprocessing must be task-aware.

For example, punctuation, capitalization and stop words can contain useful information in some problems.

Therefore:

Do not apply every preprocessing step automatically.

23. Bag of Words

The bag-of-words representation ignores most word order.

Suppose vocabulary:

\[ V=[cat,dog,fish]. \]

Sentence:

“cat dog cat”

could become:

\[ [2,1,0]. \]

This is easy to understand and useful as a classical baseline.

But:

“dog bites man”

and

“man bites dog”

can be difficult to distinguish using a simple bag-of-words representation.

24. TF-IDF

TF-IDF increases weight for terms that are important to a document but less common across the document collection.

A common formulation is:

\[ TFIDF(t,d)=TF(t,d)\times IDF(t) \]

with an IDF form such as:

\[ IDF(t)=\log\frac{N}{df(t)} \]

where:

  • \(N\) = number of documents;
  • \(df(t)\) = number of documents containing term \(t\).

Interpretation

A term that appears in nearly every document tells us less about which document is special.

25. Text Classification

The basic supervised-learning structure is:

\[ D=\{(x_i,y_i)\}_{i=1}^{n} \]

where:

  • \(x_i\) = text representation;
  • \(y_i\) = label.

Train:

\[ f_\theta(x)\rightarrow \hat y \]

and evaluate on unseen data.

Examples:

email → spam / not spam
review → positive / negative
message → support / billing / fraud

26. Autoencoders — Learn to Reconstruct

An autoencoder contains:

input x
  ↓
ENCODER
  ↓
latent representation z
  ↓
DECODER
  ↓
reconstruction x̂

The training objective is to make:

\[ \hat x\approx x. \]

A reconstruction loss can be:

\[ \boxed{ L(x,\hat x)=\|x-\hat x\|_2^2 } \]

or another appropriate reconstruction measure.

27. Why the Bottleneck Matters

Suppose:

100-dimensional input
        ↓
10-dimensional latent vector
        ↓
100-dimensional reconstruction

The 10-dimensional representation creates pressure to preserve important structure rather than simply copying every coordinate.

Analogy

Imagine summarizing a 100-page report in 10 lines.

You cannot preserve every detail.

You must retain information that helps reconstruct the important structure.

Boundary

A latent representation is not automatically “the true meaning” of the data. What it captures depends on architecture, objective and training data.

28. Autoencoder vs PCA

A classic conceptual comparison:

Property PCA Autoencoder
Main idea linear dimensionality reduction learned encoder-decoder reconstruction
Representation linear subspace can be nonlinear
Objective variance/reconstruction structure depending formulation reconstruction loss
Nonlinearity no possible
Typical use linear representation baseline nonlinear representation/anomaly/generative extensions

A linear autoencoder under certain conditions is closely related to PCA, but a general autoencoder is much more flexible.

29. Anomaly Detection with Autoencoders

If the model is trained mostly on normal examples:

normal input
   ↓
encoder
   ↓
decoder
   ↓
good reconstruction

An unusual example may produce:

unusual input
   ↓
encoder
   ↓
decoder
   ↓
poor reconstruction

Define reconstruction error:

\[ E(x)=\|x-\hat x\|. \]

If:

\[ E(x)\gt t, \]

the item can be flagged as anomalous.

The threshold \(t\) must be chosen using the actual application and validation data.

30. GANs — Two Networks in Competition

A GAN has:

random noise z
       ↓
   GENERATOR
       ↓
 fake sample ─────────┐
                      │
real sample ─────────► DISCRIMINATOR
                      │
                      ▼
               real / fake signal

The generator tries to produce realistic samples.

The discriminator tries to distinguish real from generated samples.

31. GAN Roles

Generator \(G\)

\[ G(z) \]

maps latent noise to a generated sample.

Discriminator \(D\)

\[ D(x) \]

outputs a score representing how strongly the model treats \(x\) as real, under the chosen GAN formulation.

The central competition is:

Generator:
“make fakes hard to distinguish”

Discriminator:
“detect the fakes”

32. Classical GAN Objective

A standard minimax form is:

\[ \boxed{ \min_G\max_D V(D,G) = \mathbb E_{x\sim p_{data}} [\log D(x)] + \mathbb E_{z\sim p_z} [\log(1-D(G(z)))] } \]

Do not memorize this as a giant symbol block.

Understand the roles:

  • \(D\) wants correct discrimination;
  • \(G\) wants generated samples that fool \(D\).

Different GAN variants modify the objective and training behaviour.

33. Autoencoder vs GAN

Question Autoencoder GAN
Main idea reconstruct input generate realistic samples
Main components encoder + decoder generator + discriminator
Training signal reconstruction error adversarial feedback
Latent representation explicit bottleneck latent input to generator
Typical learning goal representation/reconstruction generation
Common challenge bottleneck/objective limitations instability/mode collapse

34. Mode Collapse

A GAN may generate outputs that are individually plausible but lack variety.

Conceptually:

Desired:
A B C D E F G

Mode collapse:
        A A A A A

The generator has captured part of the data distribution without representing its diversity adequately.

This is a common GAN limitation.

35. Why GAN Training Is Difficult

The two models are coupled.

A simplified loop is:

train D
   ↓
train G
   ↓
new fake samples
   ↓
train D again
   ↓
repeat

Potential problems include:

  • unstable optimisation;
  • oscillatory dynamics;
  • discriminator overpowering generator;
  • mode collapse;
  • sensitivity to architecture/hyperparameters.

53. Formula Map for Unit IV

MDP

\[ (S,A,P,R,\gamma) \]

Return

\[ G_t= r_{t+1} +\gamma r_{t+2} +\gamma^2r_{t+3} +\cdots \]

State value

\[ V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s] \]

Action value

\[ Q^\pi(s,a)=\mathbb E_\pi[G_t\mid s_t=s,a_t=a] \]

Bellman-style decomposition

\[ V^\pi(s) = \mathbb E_\pi \left[ R+\gamma V^\pi(s') \mid s \right] \]

Q-learning

\[ \boxed{ Q(s,a) \leftarrow Q(s,a)+ \alpha \left[ r+\gamma\max_{a'}Q(s',a')-Q(s,a) \right] } \]

Policy gradient

\[ \boxed{ \theta\leftarrow \theta+\alpha\nabla_\theta J(\theta) } \]

REINFORCE-style gradient

\[ \boxed{ \nabla_\theta J(\theta) \approx \frac1N \sum_i G_i\nabla_\theta\log\pi_\theta(a_i|s_i) } \]

TF-IDF

\[ TFIDF(t,d)=TF(t,d)\times IDF(t) \]
\[ IDF(t)=\log\frac{N}{df(t)} \]

Autoencoder reconstruction

\[ \hat x=D(E(x)) \]
\[ L(x,\hat x)=\|x-\hat x\|_2^2 \]

GAN

\[ \min_G\max_D \; \mathbb E_{x\sim p_{data}} [\log D(x)] + \mathbb E_{z\sim p_z} [\log(1-D(G(z)))] \]

55. Sign-Convention Trap

One of the easiest Unit IV numerical mistakes:

Gradient descent

Minimize:

\[ L \]

so:

\[ \theta \leftarrow \theta-\alpha\nabla L \]

Policy gradient

Maximize:

\[ J \]

so:

\[ \theta \leftarrow \theta+\alpha\nabla J \]

Q-learning

Not ordinary gradient descent on a simple scalar objective in the basic tabular formulation:

\[ Q\leftarrow Q+\alpha[\text{target}-Q] \]

Remember:

minimize → move against gradient
maximize → move with gradient
Q-learning → move estimate toward target

57. Unit IV Common Confusions

1. MDP is an algorithm

No.

MDP is a mathematical formulation/framework.

2. Q-learning needs a known transition model

Basic tabular Q-learning is model-free.

It can learn from observed experience without explicitly knowing \(P(s'|s,a)\).

3. Q-learning and policy gradient are the same

No.

One primarily learns action values; the other directly optimizes a policy.

4. Stemming and lemmatization are identical

No.

They use different normalization ideas and can produce different outputs.

5. Autoencoder = GAN

No.

Autoencoder is primarily reconstruction/representation-oriented.

GAN is adversarial generation.

6. Anomaly = fraud

No.

Anomaly detection identifies unusual behaviour, not automatically malicious behaviour.

7. High benchmark accuracy = safe deployment

No.

Safety depends on the whole system, error types, operating conditions and safeguards.

8. Removing a sensitive feature eliminates bias

No.

Proxy variables and biased data can still produce unequal outcomes.

9. Model score = decision

No.

Policies, thresholds, human review and operational constraints may sit downstream.

10. Historical performance guarantees future performance

No.

Generalization, shift, leakage and changing environments matter.
