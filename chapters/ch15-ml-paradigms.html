MAIN-U2-C15 — Machine Learning Paradigms

Main Book: AI & Machine Learning — Visual + Mathematical Self-Learning Textbook
Unit: II — Machine Learning Fundamentals
Topic ID: ML-U2-C15
Prerequisites: MAIN-U2-C14 — What is Machine Learning?
Primary course source: Lecture07.pdf — Machine Learning Paradigms and Performance Metrics, Prof. Subrahmanya Swamy Peruru, IIT Kanpur
Next: MAIN-U2-C16 — Hypothesis Classes, Inductive Bias & K-NN

1. Why are there different kinds of learning?

In the previous chapter, you learned the basic ML pipeline.

Now ask:

What information does the machine actually receive while it learns?

Suppose you show a computer:

Image → CAT
Image → DOG
Image → CAT

The correct answers are already attached.

But now imagine giving it:

Image
Image
Image
Image

with no answers.

That is a fundamentally different learning situation.

And imagine a game-playing agent that receives a reward after taking actions:

State → Action → Reward → New state

That is different again.

These are the three core paradigms emphasized in your Lecture 7:

  1. Supervised learning
  2. Unsupervised learning
  3. Reinforcement learning

Course source: Lecture07.pdf, slides 2 and 12.

2. The one-picture mental model

MACHINE LEARNING
                                │
              ┌─────────────────┼─────────────────┐
              │                 │                 │
              ▼                 ▼                 ▼
        SUPERVISED        UNSUPERVISED    REINFORCEMENT
              │                 │                 │
       Has target y?       Has target y?      Gets reward?
              │                 │                 │
              YES               NO              YES
              │                 │                 │
      Learn x → y        Find structure       Learn actions
              │                 │              through feedback
        ┌─────┴─────┐      ┌────┴────┐
        ▼           ▼      ▼         ▼
   Regression   Classification  Clustering  Dimensionality
                                            reduction
👨‍🏫 Hinglish
> Sabse easy trick: **labels hain? → supervised. Labels nahi hain, structure dhoondhna hai? → unsupervised. Action karke reward mil raha hai? → reinforcement learning.** It is a memory rule, not a complete definition of every modern learning setup.

3. Paradigm 1 — Supervised Learning

The core idea

In supervised learning, the training data contains examples with known targets.

Your Lecture 7 writes:

\[ \mathcal D=\{(\mathbf x_i,y_i)\}_{i=1}^{n} \]

The model tries to learn a function:

\[ \hat f:\mathcal X\rightarrow\mathcal Y \]

so it can predict \(y\) accurately for unseen \(\mathbf x\). Course source: Lecture07.pdf, slide 5.

4. Visualizing supervised learning

TRAINING

   Input x                Known target y
      │                         │
      └──────────┬──────────────┘
                 ▼
            Training data
                 │
                 ▼
         Learning algorithm
                 │
                 ▼
             MODEL \hat f


                INFERENCE

            New input x
                 │
                 ▼
             MODEL \hat f
                 │
                 ▼
             Prediction y-hat

The important difference is that during supervised training, the correct target is available for the training examples.

5. Real-life analogy — teacher and student

Imagine a teacher gives you:

Question → Correct answer
Question → Correct answer
Question → Correct answer

You can compare your answer against the known answer and learn from the difference.

That is similar to supervised learning.

👨‍🏫 Hinglish
> Teacher ke paas answer key hai. Tum answer do, teacher compare karega, aur tumhe pata chalega kaha galti hui. Again, this is only an analogy. The algorithm uses a mathematical loss/objective rather than human classroom feedback.

6. Two common supervised settings

Your Lecture 7 explicitly identifies:

Regression

The target is continuous:

\[ y\in\mathbb R \]

Examples:

  • area → house price
  • hours studied → expected score
  • temperature → energy demand

Classification

The target is a class:

\[ y\in\{1,\ldots,K\} \]

Examples:

  • email → spam/not spam
  • image → cat/dog
  • transaction → legitimate/fraud

Course source: Lecture07.pdf, slide 6.

7. Regression vs classification — do not mix them up

Question Regression Classification
What is predicted? Numerical quantity Class/category
Example House price Spam/not spam
Typical output 245000 Spam
Mathematical target Continuous Discrete

Quick memory rule

Regression → “How much?”
Classification → “Which class?”

That rule is useful, but some real tasks can be formulated in more complicated ways.

8. Supervised learning workflow

Collect labelled examples
         ↓
Represent features x
         ↓
Choose model family
         ↓
Train using targets y
         ↓
Compute loss
         ↓
Fit parameters
         ↓
Evaluate on unseen data
         ↓
Predict future examples

You will later see this same pattern with:

  • linear regression;
  • logistic regression;
  • decision trees;
  • neural networks.

The model changes, but the learning skeleton remains recognizable.

9. Paradigm 2 — Unsupervised Learning

Now remove the labels.

The training data becomes:

\[ \mathcal D=\{\mathbf x_i\}_{i=1}^{n} \]

There is no target \(y\) provided for the learning task.

So what can the model learn?

Instead of asking:

“What label should this input receive?”

we can ask:

“What structure is hidden inside the data?”

Your Lecture 7 names several unsupervised goals:

  • clustering;
  • dimensionality reduction;
  • density estimation.

Course source: Lecture07.pdf, slides 7–10.

10. Clustering

Suppose you have data about houses:

780
820
840
980
1020
1050
1250
1380
1450

but there is no target such as price.

One possible task is to discover groups of similar observations.

For example:

Cluster 1 → ~750–850 sqft
Cluster 2 → ~950–1050 sqft
Cluster 3 → ~1200–1500 sqft

The supplied lecture uses essentially this example. Course source: Lecture07.pdf, slide 9.

Analogy

Imagine walking into a classroom and being told:

“You don't know anyone's role. Just group students who seem similar based on the information you have.”

You are looking for structure, not predicting a known answer key.

👨‍🏫 Hinglish
> Label nahi diya gaya. Bas data diya hai. Ab algorithm ko khud dekhna hai ki **kaun kis group ka part lagta hai**.

11. Dimensionality reduction

Suppose every example has four features:

\[ \mathbf x\in\mathbb R^4 \]

but those features are highly correlated.

The data may effectively live near a lower-dimensional structure.

The goal can be:

represent the data using fewer dimensions while retaining important information.

Your Lecture 7 gives the example of house data with area and price-related features. Course source: Lecture07.pdf, slide 10.

Why is this useful?

Fewer dimensions can help with:

  • visualization;
  • compression;
  • reducing redundancy;
  • making some learning tasks easier.

You will later encounter PCA as a major mathematical tool here.

12. Density estimation — what does that mean?

Density estimation tries to learn something about how data is distributed.

Conceptually:

Observed data points
        ↓
Estimate where data is concentrated
        ↓
Learn a probability-density model

Your Lecture 7 lists density estimation as an unsupervised task that models \(p(\mathbf x)\). Course source: Lecture07.pdf, slide 8.

At this stage, you only need the intuition:

Where does the data tend to occur, and with what density?

A deeper probability treatment belongs to the Math Companion and later ML topics.

13. Paradigm 3 — Reinforcement Learning

Now the setup changes again.

The agent is not simply handed a correct answer for every situation.

Instead:

STATE
            ↓
        Agent chooses
          ACTION
            ↓
       ENVIRONMENT
            ↓
   NEW STATE + REWARD
            ↓
          repeat

Your Lecture 7 uses this exact type of state-action-reward loop. Course source: Lecture07.pdf, slide 11.

14. What is reinforcement learning trying to learn?

The lecture states the goal as learning a policy that maximizes cumulative reward.

Conceptually:

Learn which action to take in different states so that total future reward is as large as possible.

The lecture writes the cumulative objective schematically as a sum of rewards:

\[ \sum_t R_t \]

Course source: Lecture07.pdf, slide 11.

15. Real-world analogy — training a dog

Imagine teaching a dog to sit.

You do not tell it a mathematical function for every possible situation.

Instead:

Dog observes situation
        ↓
Takes action
        ↓
Gets reward / no reward
        ↓
Adjusts future behaviour

That is a useful analogy for reinforcement learning.

👨‍🏫 Hinglish
> “Sahi action kiya → reward mila. Galat action ya useful result nahi → reward nahi mila. Time ke saath system seekhta hai ki kaunsi situation mein kya karna useful hai.” The actual RL framework is more formal: the environment generates state transitions and rewards, and the learner seeks a policy with good long-term return.

16. The three paradigms side by side

Question Supervised Unsupervised Reinforcement
Are target labels given? Yes No No fixed target label for each action/state pair
Main signal Correct target Data structure Reward/penalty feedback
Typical task Predict Discover structure Choose actions
Example Spam classification Clustering Game playing / sequential control
Typical output \(\hat y\) Group/representation/model Policy/action decisions

The deepest distinction

SUPERVISED
“What should the answer be?”
          ↓
learn from known answers

UNSUPERVISED
“What structure exists here?”
          ↓
learn from the data itself

REINFORCEMENT
“What action should I take?”
          ↓
learn from consequences/reward

17. Semi-supervised learning

Your Lecture 7 then introduces additional paradigms.

In many real problems:

collecting input data is easy, but obtaining labels is expensive or slow.

Examples from the lecture include:

  • spam detection;
  • medical imaging.

So we may have:

\[ \mathcal D_L=\{(\mathbf x_i,y_i)\} \]

for labelled data and:

\[ \mathcal D_U=\{\mathbf x_j\} \]

for unlabelled data, with many more unlabelled examples than labelled ones.

Course source: Lecture07.pdf, slide 13.

18. Self-training — a simple semi-supervised idea

The lecture gives a simple method:

Small labelled dataset
        ↓
Train classifier
        ↓
Predict labels for unlabelled data
        ↓
Keep only high-confidence predictions
        ↓
Add them to labelled set
        ↓
Retrain
        ↓
Repeat

The important idea is:

Use the model's confident predictions to make additional training information available.

This can be useful when labelled data is scarce.

But it can also propagate errors if the model is confidently wrong, so “confidence” is not synonymous with “truth.”

19. Self-supervised learning

Your Lecture 7 then describes a different idea.

There may be no human-provided labels, but the training signal is constructed from the data itself.

The lecture's text example is:

Original:
“Machine learning is very useful.”

Hide a word:
“Machine learning is very [MASK].”

Target:
“useful”

The model learns to predict the missing word and in doing so can learn useful representations. Course source: Lecture07.pdf, slide 15.

Important distinction

Self-supervised learning is not the same thing as ordinary unsupervised clustering.

The training target is constructed from the data itself.

👨‍🏫 Hinglish
> Data khud apna question aur answer generate kar raha hai. Human ko har example ka label manually nahi dena pad raha.

22. A common confusion: reinforcement learning vs supervised learning

Someone may ask:

“If reinforcement learning gets feedback, isn't that just supervised learning?”

Not quite.

In supervised learning, the training example generally provides a target associated with the input:

\[ (\mathbf x,y) \]

In reinforcement learning, the agent acts and receives reward as a consequence of its interaction with the environment:

\[ S_t,A_t\rightarrow S_{t+1},R_{t+1} \]

The learning problem includes sequential consequences and long-term reward.

That difference is fundamental.

23. Another common confusion: unsupervised learning vs “no answer”

Unsupervised learning does not mean:

“The algorithm does nothing because there is no label.”

It means the learning objective is different.

The system can still discover meaningful structure:

  • groups;
  • compressed representations;
  • density patterns;
  • relationships among observations.

The absence of a target changes what is learned and how success is defined.

24. A visual memory trick

Think of three teachers.

Teacher A — Supervised

“Here is the question. Here is the correct answer. Learn the mapping.”

Teacher B — Unsupervised

“Here is a pile of information. Find meaningful structure.”

Teacher C — Reinforcement

“You decide what to do. I will show you the consequences.”

This is a powerful beginner memory anchor.

25. Mathematical lens

Supervised

\[ \mathcal D=\{(\mathbf x_i,y_i)\}_{i=1}^n \]

The target is available.

Unsupervised

\[ \mathcal D=\{\mathbf x_i\}_{i=1}^n \]

No target \(y\) is supplied for the learning task.

Reinforcement

A useful conceptual transition is:

\[ (S_t,A_t)\rightarrow(S_{t+1},R_{t+1}) \]

The exact probability model and MDP formalization will come later in Unit IV.

Exam trap

Do not write:

“Unsupervised learning has no feedback.”

Better:

“In the basic unsupervised formulation, there is no externally supplied target label for each example; the objective is to discover structure or representations from the data.”
