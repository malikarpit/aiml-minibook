1. Why This Chapter Exists

Unit III contains many terms that can initially feel unrelated:

  • neuron;
  • perceptron;
  • MLP;
  • activation function;
  • loss function;
  • gradient descent;
  • backpropagation;
  • CNN;
  • RNN;
  • LSTM.

But these are not ten unrelated topics.

They form a progression.

NEURAL NETWORKS
                        │
          ┌─────────────┴─────────────┐
          │                           │
     COMPUTATION                 LEARNING
          │                           │

          ↓                           ↓
        MLP                    backpropagation

The unit becomes much easier once you understand the role each topic plays.

2. The One-Sentence Meaning of Every Topic

Topic One-sentence meaning
Artificial neuron A weighted computation followed by a bias and activation.
Perceptron A threshold-based linear decision unit and an early learnable neuron model.
MLP A feedforward composition of multiple parameterized layers.
Activation A function that transforms a neuron's pre-activation output.
Loss A numerical measure of how wrong a prediction is.
Gradient descent An optimization rule that changes parameters toward lower loss.
Backpropagation Efficiently computes gradients of the loss through a layered computation graph.
CNN A neural architecture that exploits local structure and shared filters, especially useful for grid-like data such as images.
RNN A recurrent architecture that carries state across sequence positions.
LSTM A gated recurrent architecture with explicit cell-state memory.

Memorize these meanings before memorizing detailed formulas.

The architecture tells you **how information flows forward**. Backpropagation tells you **how derivative information flows backward**. Gradient descent tells you **how parameters are changed using that derivative information**. This distinction is crucial.

4. Three Different Questions That Students Commonly Mix Up

Question 1: What does the network compute?

Answer:

The forward pass.

Question 2: How do we know which parameters should change?

Answer:

Backpropagation computes gradients.

Question 3: How are the parameters actually changed?

Answer:

An optimizer, such as gradient descent or a variant, updates them.

Therefore:

Forward pass
   = compute prediction

Backpropagation
   = compute gradient information

Gradient descent / optimizer
   = update parameters

These are related but not identical.

5. Neuron → Perceptron → MLP

5.1 Artificial neuron

The generic pre-activation is:

\[ z=w^Tx+b. \]

Then:

\[ a=\phi(z). \]

A neuron therefore performs:

weighted combination
        ↓
      + bias
        ↓
      activation
        ↓
       output

5.2 Perceptron

A perceptron uses a threshold-type decision.

Conceptually:

\[ \hat y= \begin{cases} 1,&w^Tx+b\ge 0\\ 0,&w^Tx+b\lt 0 \end{cases} \]

Its decision boundary satisfies:

\[ \boxed{w^Tx+b=0} \]

This is a linear decision boundary.

5.3 MLP

An MLP stacks transformations:

\[ z^{(1)}=W^{(1)}x+b^{(1)} \]
\[ a^{(1)}=\phi^{(1)}(z^{(1)}) \]
\[ z^{(2)}=W^{(2)}a^{(1)}+b^{(2)} \]
\[ a^{(2)}=\phi^{(2)}(z^{(2)}) \]

and so on.

The power comes from composition and, crucially, nonlinearity.

6. Why Nonlinearity Matters

Suppose you stack two purely linear transformations:

\[ z_1=W_1x \]
\[ z_2=W_2z_1 \]

Then:

\[ z_2=W_2W_1x. \]

The composition is still linear in \(x\) (or affine if biases are included appropriately).

So simply adding many linear layers does not automatically create the expressive power associated with deep neural networks.

Activation functions introduce nonlinearity.

Linear → Linear → Linear
          ↓
 still collapsible conceptually

Linear → Nonlinear → Linear
          ↓
 richer function class

7. Activation Functions — What Each One Is For

Function Common role Range / property
Step threshold decisions discrete output
Sigmoid binary probability-style output; gates \((0,1)\)
Tanh signed hidden representation \((-1,1)\)
ReLU common hidden-layer nonlinearity \([0,\infty)\)
Softmax multi-class probability distribution positive values summing to 1

Remember:

The appropriate output transformation depends on the prediction task.

For example:

binary classification
        ↓
 sigmoid-style output

multi-class classification
        ↓
 softmax-style output

hidden layers
        ↓
 often ReLU-family activation

The exact architecture is task-dependent.

8. Loss Functions — The Network Needs a Learning Signal

A neural network needs to know how wrong it is.

That is the role of the loss.

Mean Squared Error

\[ \boxed{ MSE=\frac1n\sum_{i=1}^{n}(y_i-\hat y_i)^2 } \]

Useful for many regression settings.

Mean Absolute Error

\[ \boxed{ MAE=\frac1n\sum_{i=1}^{n}|y_i-\hat y_i| } \]

Binary cross-entropy

\[ \boxed{ L=-\left[y\log(\hat p)+(1-y)\log(1-\hat p)\right] } \]

for a single binary example.

Multi-class cross-entropy

\[ \boxed{ L=-\sum_{k=1}^{K}y_k\log(\hat p_k) } \]

for one-hot target vector \(y\).

The loss answers:

How undesirable is the current prediction?

9. Gradient Descent — The Parameter-Movement Rule

Suppose the model parameters are collected in \(\theta\).

The generic update is:

\[ \boxed{ \theta\leftarrow\theta-\eta\nabla_\theta L(\theta) } \]

where:

  • \(\theta\) = trainable parameters;
  • \(L\) = loss;
  • \(\nabla_\theta L\) = gradient;
  • \(\eta\) = learning rate.

The minus sign matters.

The gradient points toward local increase.

We move in the opposite direction to reduce the objective.

10. Learning Rate — Why Step Size Matters

Imagine walking downhill.

Very small learning rate

small step
small step
small step
small step
...

Learning may be slow.

Very large learning rate

overshoot
←──────→
overshoot
←──────→

The optimization can become unstable or fail to settle near a useful minimum.

So learning rate is a hyperparameter, not a learned weight.

11. Backpropagation — The Chain Rule in Action

Consider a simple composition:

\[ x\rightarrow a\rightarrow b\rightarrow L. \]

The chain rule gives:

\[ \boxed{ \frac{\partial L}{\partial a} = \frac{\partial L}{\partial b} \frac{\partial b}{\partial a} } \]

and similarly through deeper layers.

For a network:

input
  ↓
layer 1
  ↓
layer 2
  ↓
layer 3
  ↓
output
  ↓
loss

Backpropagation reuses intermediate derivative information so the gradients with respect to many parameters can be computed efficiently.

A common mistake is to define backpropagation as “the opposite of forward propagation.”

That is too vague.

A better exam definition is:

Backpropagation is an efficient application of the chain rule that computes gradients of a network's loss with respect to its parameters by propagating derivative information backward through the computational graph.

12. Parameter Gradient vs Parameter Update

graph TD
    PROB{"What is your input data structure?"}
    PROB -->|Tabular / Structured Features| MLP["Multi-Layer Perceptron (MLP)
Fully connected layers, ReLU activations"]
    PROB -->|Spatial Grids / 2D Images / Video| CNN["Convolutional Neural Network (CNN)
Kernels, parameter sharing, MaxPool, translation invariance"]
    PROB -->|Sequential / Time-Series / Text| SEQ{"Long-term dependency needed?"}
    SEQ -->|Short Sequences (< 10 steps)| RNN["Vanilla RNN
Simple recurrence, susceptible to vanishing gradients"]
    SEQ -->|Long Sequences (> 10 steps)| LSTM["LSTM / GRU
Gating mechanisms, additive cell state highway"]

Suppose:

\[ \frac{\partial L}{\partial w}=4 \]

and

\[ \eta=0.1. \]

Then the update is:

\[ w_{new}=w-0.1(4)=w-0.4. \]

Notice the two stages:

gradient
  = 4

update
  = −0.4

Gradient and update are not the same thing.

13. CNN — Why Convolution Changes the Architecture

A standard dense layer connects many inputs to many neurons.

For an image, this can ignore useful spatial structure.

CNNs introduce operations based on local receptive fields and shared filters.

Conceptually:

image
  ↓
local filter / kernel
  ↓
feature map
  ↓
activation
  ↓
pooling / downsampling (when used)
  ↓
more feature extraction
  ↓
classification/regression head

The important conceptual idea is:

A CNN exploits spatial locality and parameter sharing to detect patterns across a grid-like input.

14. CNN Vocabulary You Must Not Mix Up

Term Meaning
Kernel / filter learned local weight pattern used in convolution
Feature map result produced by applying a filter across the input
Stride how far the filter moves between positions
Padding additional border values used to control spatial behaviour
Receptive field input region influencing a unit
Pooling local aggregation/downsampling operation
Channel one feature plane/depth slice of an input or feature map

A common exam trap is to call the output of a convolution “the kernel.”

The kernel is the learned operator; the output is the feature map.

15. RNN — Why Recurrence Changes the Architecture

A feedforward network treats examples as fixed inputs.

A sequence has order.

RNN introduces state:

\[ \boxed{h_t=f(x_t,h_{t-1})} \]

Therefore:

current input
    +
previous state
    ↓
current state

That lets the model carry information through a sequence.

Typical applications include:

  • time-series modelling;
  • sequential classification;
  • sequence prediction;
  • language-related sequence tasks.

16. LSTM — Why the Gates Matter

Basic RNN:

xₜ + hₜ₋₁
      ↓
     hₜ

LSTM:

xₜ + hₜ₋₁
      ↓
 ┌─────────────────┐
 │ forget gate     │
 │ input gate      │
 │ candidate       │
 │ output gate     │
 └────────┬────────┘
          ↓
       cell state cₜ
          ↓
       hidden hₜ

The key conceptual advance is controlled information flow.

17. CNN vs RNN vs LSTM vs MLP

Property MLP CNN RNN LSTM
Main structure feedforward dense layers local filters + shared weights recurrent state gated recurrent state
Natural data geometry generic fixed vectors grids/images sequences sequences
Explicit recurrent state No No Yes Yes
Cell state No No No Yes
Local spatial sharing No standard mechanism Yes Not the defining idea Not the defining idea
Main strength general nonlinear mapping spatial pattern extraction sequential dependence controlled sequential memory
Main cost dense connectivity can be large convolution computation recurrence more recurrent parameters than basic RNN

The table is conceptual. Modern architectures can combine or replace these ideas.

18. The Architecture Selection Mental Model

Do not memorize architectures as random names.

Ask:

What structure does the data have?

Fixed feature vector

A dense MLP may be appropriate.

Spatial/grid structure

A CNN-style model may be useful.

Ordered sequence

An RNN/LSTM-style model is historically important and syllabus-relevant.

More complex modern systems

Other architectures may be used, but learning those is beyond the core route here.

19. A Single Worked Training Story

Suppose a model is classifying an image.

Step 1 — Input

\[ x=\text{image pixels} \]

Step 2 — Forward computation

A CNN transforms the image into learned feature maps.

Step 3 — Prediction

The output head produces class probabilities.

Step 4 — Loss

Cross-entropy measures the mismatch between the true class and predicted distribution.

Step 5 — Backpropagation

The loss derivative is propagated backward through the output layer, convolutional layers and nonlinearities.

Step 6 — Gradient descent

Weights are updated.

Step 7 — Repeat

The network gradually changes its parameters based on training data.

This gives the complete computational story:

image
 ↓
representation
 ↓
prediction
 ↓
loss
 ↓
backpropagation
 ↓
gradients
 ↓
optimizer
 ↓
updated model

21. Unit III Formula Map

Neuron

\[ z=w^Tx+b \]
\[ a=\phi(z) \]

Perceptron boundary

\[ w^Tx+b=0 \]

Dense layer

\[ z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)} \]

\[ \sigma(z)=\frac{1}{1+e^{-z}} \]

\[ \operatorname{ReLU}(z)=\max(0,z) \]

\[ \tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}} \]

\[ c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t \]

\[ h_t=o_t\odot\tanh(c_t) \]

22. Parameter Counting — A Core Exam Skill

For a fully connected layer mapping:

n_in inputs → n_out neurons

the number of weights is:

\[ n_{in}n_{out} \]

and biases:

\[ n_{out}. \]

Therefore total parameters:

\[ \boxed{ n_{in}n_{out}+n_{out} } \]

or:

\[ \boxed{n_{out}(n_{in}+1)} \]

Example

5 inputs → 4 neurons:

Weights:

\[ 5\times4=20 \]

Biases:

\[ 4 \]

Total:

\[ \boxed{24} \]

This is independent of the particular numeric values of the parameters.

23. Shape Reasoning

Suppose:

\[ x\in\mathbb R^d \]

and a dense layer has \(m\) neurons.

Then:

\[ W\in\mathbb R^{m\times d} \]

and:

\[ b\in\mathbb R^m. \]

Therefore:

\[ Wx+b\in\mathbb R^m. \]

Dimension reasoning prevents many matrix-multiplication mistakes.

When confused, write the shapes.

(m × d)(d × 1) = (m × 1)

24. Unit III Common Confusions

Perceptron vs neuron

A perceptron is a specific threshold-style model built around a weighted sum and decision rule.

A generic artificial neuron may use a different activation.

MLP vs neural network

An MLP is a particular feedforward neural-network architecture.

“Neural network” is broader.

Loss vs accuracy

Loss is typically the optimization objective signal.

Accuracy is an evaluation metric for classification.

They are not interchangeable.

Backpropagation vs gradient descent

Backpropagation computes gradients.

Gradient descent uses gradients to update parameters.

CNN vs convolution

A CNN is an architecture.

Convolution is an operation used within many CNNs.

RNN vs LSTM

LSTM is a gated recurrent architecture designed to provide more controlled information flow than a basic RNN.

25. The Unit III “Why” Chain

This is one of the best memory anchors for the entire unit.

Why a neuron?
→ basic learnable computation

Why a perceptron?
→ learn a threshold decision boundary

Why an MLP?
→ represent richer nonlinear relationships

Why activations?
→ introduce nonlinearity / task-appropriate transformation

Why a loss?
→ quantify prediction error

Why gradient descent?
→ minimize the loss by changing parameters

Why backpropagation?
→ compute parameter gradients efficiently

Why CNN?
→ exploit local spatial structure + shared filters

Why RNN?
→ model ordered sequences with state

Why LSTM?
→ control recurrent information flow with gated memory

If you can recreate this chain, you understand the architecture of Unit III rather than merely recalling vocabulary.

39. Exam-Day Formula Sheet

Core neuron

\[ \boxed{z=w^Tx+b} \]
\[ \boxed{a=\phi(z)} \]

Dense layer

\[ \boxed{z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)}} \]

Sigmoid

\[ \boxed{\sigma(z)=\frac1{1+e^{-z}}} \]

ReLU

\[ \boxed{\max(0,z)} \]

MSE

\[ \boxed{\frac1n\sum_i(y_i-\hat y_i)^2} \]

Gradient descent

\[ \boxed{\theta\leftarrow\theta-\eta\nabla_\theta L} \]

LSTM

\[ f_t=\sigma(W_fq_t+b_f) \]
\[ i_t=\sigma(W_iq_t+b_i) \]
\[ \tilde c_t=\tanh(W_cq_t+b_c) \]
\[ c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t \]
\[ o_t=\sigma(W_oq_t+b_o) \]
\[ h_t=o_t\odot\tanh(c_t) \]
