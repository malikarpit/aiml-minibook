MAIN-U3-C37 — Recurrent Neural Networks (RNNs)

Main Book: AI & Machine Learning — Visual + Mathematical Self-Learning Textbook
Unit: III — Neural Networks and Deep Learning
Topic ID: ML-U3-C37
Prerequisites: C30–C35 neural-network foundations, MLP, activations/losses, gradient descent, backpropagation
Syllabus position: Unit III — RNN
Coverage status: CORE + STANDARD EXPANSION

1. Why This Chapter Exists

Many problems are not naturally represented by one fixed vector.

Examples include:

  • a sentence;
  • a stock-price sequence;
  • sensor readings over time;
  • speech;
  • a sequence of events;
  • a time series.

In these problems, order matters.

Compare:

“dog bites man”

with:

“man bites dog”

The same words appear, but their order changes the meaning.

A standard feedforward network does not automatically maintain a persistent state from one time step to the next.

An RNN introduces a recurrent hidden state.

The central idea is:

An RNN processes a sequence step by step while carrying information forward through a hidden state.

Conceptual flow:

x₁ → RNN → h₁
          ↓
x₂ → RNN → h₂
          ↓
x₃ → RNN → h₃
          ↓
...

Each hidden state can depend on:

  • the current input;
  • the previous hidden state.

3. One-Minute Intuition

English

Imagine reading a sentence word by word.

When you reach the word:

“because”

you may need information from earlier words to understand what comes next.

An RNN maintains a hidden state:

past information
      ↓
 hidden state
      ↓
current input
      ↓
new hidden state

The hidden state is therefore a learned summary of information carried through the sequence.

Hinglish

RNN ko ek student samjho jo sentence ko ek-ek word karke padh raha hai.

word 1 → student remembers
word 2 → student remembers previous + current
word 3 → previous memory + current
...

Har step pe student ke paas ek internal memory-like state hoti hai.

Important:

RNN ki hidden state human-like memory nahi hai.

It is simply a vector of learned numerical state.

4. Sequence Notation

Let a sequence be:

\[ x_1,x_2,\ldots,x_T. \]

Here:

  • \(T\) = sequence length;
  • \(x_t\) = input at time step \(t\).

The RNN produces hidden states:

\[ h_1,h_2,\ldots,h_T. \]

Depending on the task, we may produce outputs:

\[ y_1,y_2,\ldots,y_T \]

or only a final output.

5. The Core RNN Equations

A basic RNN can be written as:

\[ \boxed{ h_t= \phi(W_{xh}x_t+W_{hh}h_{t-1}+b_h) } \]

and:

\[ \boxed{ y_t= \psi(W_{hy}h_t+b_y) } \]

where:

Symbol Meaning
\(x_t\) current input
\(h_{t-1}\) previous hidden state
\(h_t\) current hidden state
\(W_{xh}\) input-to-hidden weights
\(W_{hh}\) hidden-to-hidden recurrent weights
\(W_{hy}\) hidden-to-output weights
\(b_h\) hidden bias
\(b_y\) output bias
\(\phi\) hidden activation
\(\psi\) output transformation

The most important term to understand is:

\[ W_{hh}h_{t-1}. \]

It is the mechanism through which information from the previous step influences the current state.

7. Parameter Sharing Through Time

Suppose a sequence has 100 time steps.

An RNN does not normally learn a completely different \(W_{xh}\) and \(W_{hh}\) for every time step.

Instead:

time 1 ──┐
time 2 ──┤
time 3 ──┤──→ shared parameters
...      │
time 100 ┘

This allows the same learned transition rule to be applied throughout the sequence.

This is analogous in spirit to CNN parameter sharing, but the structure being shared is different:

  • CNN: shared across spatial locations;
  • RNN: shared across time steps.

8. A Small Numerical Example

Suppose:

\[ x_t=2, \qquad h_{t-1}=1. \]

Let:

\[ W_{xh}=0.5, \qquad W_{hh}=0.4, \qquad b_h=0. \]

Then:

\[ z_t = 0.5(2)+0.4(1) \]
\[ =1+0.4 \]
\[ =1.4. \]

Using ReLU:

\[ h_t=\max(0,1.4)=1.4. \]

So the current state depends on both:

current input
+
previous state

That is the core recurrence.

9. Why the Hidden State Matters

Imagine:

"The movie was not ... "

When the model later encounters:

"... good"

the earlier word not may matter.

A recurrent state provides a mechanism for information to persist:

"not"
  ↓
hidden state
  ↓
...
  ↓
"good"
  ↓
new hidden state / output

The model does not explicitly store a sentence as words.

It stores numerical state that is learned to be useful for the training objective.

10. Types of RNN Input/Output Structures

flowchart LR
    G5["∂ℒ/∂h₅"] -->|× Wₕₕᵀ| G4["∂ℒ/∂h₄"]
    G4 -->|× Wₕₕᵀ| G3["∂ℒ/∂h₃"]
    G3 -->|× Wₕₕᵀ| G2["∂ℒ/∂h₂"]
    G2 -->|× Wₕₕᵀ| G1["∂ℒ/∂h₁"]
    G1 -->|× Wₕₕᵀ| G0["∂ℒ/∂h₀ ≈ 0 (Vanished!)"]
PYTHON
import numpy as np

class VanillaRNNCell:
    def __init__(self, input_dim, hidden_dim, output_dim):
        self.W_xh = np.random.randn(hidden_dim, input_dim) * 0.01
        self.W_hh = np.random.randn(hidden_dim, hidden_dim) * 0.01
        self.W_hy = np.random.randn(output_dim, hidden_dim) * 0.01
        self.b_h  = np.zeros((hidden_dim, 1))
        self.b_y  = np.zeros((output_dim, 1))

    def forward_sequence(self, X_seq):
        hidden_dim = self.W_hh.shape[0]
        h_t = np.zeros((hidden_dim, 1))
        outputs = []

        for x_t in X_seq:
            h_t = np.tanh(np.dot(self.W_xh, x_t) + np.dot(self.W_hh, h_t) + self.b_h)
            y_t = np.dot(self.W_hy, h_t) + self.b_y
            outputs.append(y_t)
        return outputs, h_t

seq = [np.random.randn(4, 1) for _ in range(3)]
rnn = VanillaRNNCell(input_dim=4, hidden_dim=8, output_dim=2)
outs, final_h = rnn.forward_sequence(seq)
print(f"Processed sequence of length {len(seq)}.")
print("Final hidden state shape:", final_h.shape)
print("Output at step 3 shape:", outs[-1].shape)

RNNs can be used in several patterns.

Many-to-one

Sequence:

x₁ → x₂ → x₃ → x₄

produces one output:

→ y

Example:

sentiment classification of an entire sentence.

One-to-many

One input produces a sequence.

x → RNN → y₁ → y₂ → y₃

Example:

a conceptual sequence-generation setup.

Many-to-many, aligned

Each input step has an output:

x₁ → y₁
x₂ → y₂
x₃ → y₃

Example:

sequence labeling.

Many-to-many, sequence-to-sequence

Input and output sequences may have different lengths:

x₁ x₂ x₃ x₄
      ↓
encoder/decoder system
      ↓
y₁ y₂ y₃

This idea appears in sequence-to-sequence architectures.

11. RNN and Text

Text is discrete.

A neural network normally works with numerical vectors.

So a simplified text pipeline is:

words / tokens
      ↓
numerical representation
      ↓
RNN
      ↓
hidden states
      ↓
output

The token representation may come from one-hot vectors, learned embeddings, or other representations.

For a basic RNN chapter, the crucial idea is:

RNN operates on numerical representations of sequence elements, not raw words as strings.

12. RNN and Embeddings

Suppose:

"cat"

is converted to a vector:

\[ x_t\in\mathbb{R}^d. \]

The RNN receives:

\[ x_t \]

rather than the literal word.

This allows matrix operations:

\[ W_{xh}x_t. \]

Embedding details belong more naturally with the later NLP section, but the connection is important.

13. The Hidden State as a Function of History

Because:

\[ h_t=f(x_t,h_{t-1}), \]

and:

\[ h_{t-1}=f(x_{t-1},h_{t-2}), \]

the current state indirectly depends on earlier inputs:

\[ h_t = f(x_t,x_{t-1},x_{t-2},\ldots,x_1). \]

This is why RNNs can model sequence context.

14. Backpropagation Through Time

RNN training uses gradient-based learning.

Because the same recurrent computation occurs repeatedly, the network can be unrolled through time.

Then ordinary backpropagation can be applied to this computational graph.

This is called:

Backpropagation Through Time (BPTT).

Conceptually:

forward through time
x₁ → h₁ → h₂ → h₃ → ... → hT
                         ↓
                       loss
                         ↓
backward through the unrolled graph

The important connection is:

RNN recurrence
      ↓
unrolled computation graph
      ↓
backpropagation
      ↓
shared parameter gradients
      ↓
gradient descent

15. Why RNN Training Becomes Difficult

Suppose information must travel through many time steps.

During backpropagation, derivatives involve repeated multiplication through the recurrent computation.

Repeated multiplication can cause gradients to become:

  • extremely small;
  • extremely large.

These are known as:

Vanishing gradients

The gradient becomes very small.

Then early time steps receive very weak learning signals.

Exploding gradients

The gradient becomes very large.

This can make optimization unstable.

16. A Simple Gradient Intuition

Suppose, very roughly, a repeated derivative factor is:

\[ 0.5. \]

After 10 steps:

\[ 0.5^{10}\approx0.00098. \]

The signal becomes tiny.

If the repeated factor were:

\[ 2, \]

then:

\[ 2^{10}=1024. \]

The signal becomes huge.

Real RNNs involve matrices and nonlinear derivatives, so the actual mathematics is richer than this scalar example.

But the repeated-transformation intuition is essential.

17. Why Long-Term Dependencies Are Difficult

Consider:

The students who studied very hard for the final examination
because they wanted a scholarship eventually ...

A useful prediction may depend on information many steps earlier.

A basic RNN can theoretically carry information over long sequences, but optimization difficulties can make learning such long-range dependencies hard.

This limitation is one of the main motivations for gated recurrent architectures such as LSTM.

18. RNN vs Feedforward Network

Property Feedforward network RNN
Natural input Fixed vector Sequence
Persistent hidden state No Yes
Parameter sharing through time No Yes
Order sensitivity Not inherently sequential Yes
Typical use Fixed-size prediction Sequence/time-series problems
Main training issue Standard optimization Can suffer from vanishing/exploding gradients

19. RNN vs CNN

Property CNN RNN
Main structure Spatial Sequential
Shared across Locations Time steps
Core mechanism Local filters Recurrent hidden state
Typical data Images/spatial signals Text/time series/sequences
Important concept Receptive field Hidden state
Major classic challenge Spatial computation/architecture Long-term dependencies

Modern systems can combine these ideas.

20. Output Design

The output function depends on the task.

For binary classification, an output might use:

\[ \hat p_t=\sigma(W_{hy}h_t+b_y). \]

For multi-class classification:

\[ \hat{\mathbf p}_t = \operatorname{softmax}(W_{hy}h_t+b_y). \]

For regression:

\[ \hat y_t=W_{hy}h_t+b_y \]

may be appropriate.

The architecture does not determine the task by itself.

21. Shapes — Exam Skill

Suppose:

  • input dimension = \(d_x\);
  • hidden-state size = \(d_h\).

Then:

\[ W_{xh}\in\mathbb{R}^{d_h\times d_x} \]

and:

\[ W_{hh}\in\mathbb{R}^{d_h\times d_h}. \]

For output dimension \(d_y\):

\[ W_{hy}\in\mathbb{R}^{d_y\times d_h}. \]

Including biases, parameter count is:

\[ d_hd_x+d_h^2+d_yd_h+d_h+d_y. \]

Example

Let:

\[ d_x=3,\quad d_h=4,\quad d_y=2. \]

Then:

\[ W_{xh}:4\times3=12 \]
\[ W_{hh}:4\times4=16 \]
\[ W_{hy}:2\times4=8 \]

Biases:

\[ 4+2=6. \]

Total:

\[ 12+16+8+6 = \boxed{42}. \]

23. RNN Mathematics Summary

Hidden state

\[ \boxed{ h_t= \phi(W_{xh}x_t+W_{hh}h_{t-1}+b_h) } \]

Output

\[ \boxed{ y_t= \psi(W_{hy}h_t+b_y) } \]

Parameter count

\[ \boxed{ d_hd_x+d_h^2+d_yd_h+d_h+d_y } \]

when one bias vector is used for each affine transformation.

Sequence dependency

\[ \boxed{ h_t=f(x_t,h_{t-1}) } \]

24. Common Mistakes

⚠️ Mistake 1
Thinking an RNN has a different network for every time step. **Correction:** the recurrent parameters are shared.
⚠️ Mistake 2
Thinking hidden state equals stored raw text. **Correction:** it is a numerical learned state.
⚠️ Mistake 3
Thinking RNN automatically remembers everything. **Correction:** basic RNNs can struggle with long-term dependencies.
⚠️ Mistake 4
Confusing hidden state and output. **Correction:** 
hidden state → internal recurrent representation
output       → task-specific prediction
⚠️ Mistake 5
Thinking BPTT is a completely different learning algorithm from backpropagation. **Correction:** BPTT applies backpropagation to the network unrolled across time.
⚠️ Mistake 6
Thinking vanishing gradients only happen in RNNs. **Correction:** vanishing/exploding gradients can occur in deep computational graphs more generally; they are especially important historically in recurrent networks.
