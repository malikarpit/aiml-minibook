MAIN-U2-C17 — Generalization, Bias-Variance, Overfitting & Underfitting

Main Book: AI & Machine Learning — Visual + Mathematical Self-Learning Textbook
Unit: II — Machine Learning Fundamentals
Topic ID: ML-U2-C17
Prerequisites: ML-U2-C14, ML-U2-C15, ML-U2-C16
Primary course source: Lecture08.pdf — Supervised Learning: Hypothesis Class & Bias-Variance Trade-off, Prof. Subrahmanya Swamy Peruru, IIT Kanpur
Supporting course source: Lecture09.pdf for the later connection between model flexibility and polynomial fitting.
Practical connection: pract_6_bias_and_hypothesis_class.ipynb, as listed in your supplied resource set.

1. Why This Chapter Exists

You now know that a hypothesis class controls what kinds of models the learner can choose.

But that immediately creates a new question:

How flexible should the model be?

Imagine drawing a curve through measured data.

One model gives a straight line.

Another gives a gentle curve.

Another gives a wild curve that passes through nearly every training point.

Which one is actually learning the underlying relationship?

This chapter gives the mathematical language to discuss that problem.

The central story is:

Too simple
   ↓
Underfitting
   ↓
Too complex
   ↓
Overfitting

Goal:
Good generalization

Your Lecture 8 explicitly asks why test error first decreases and then increases as model flexibility changes, and then develops the bias-variance decomposition. Course source: Lecture08.pdf, slides 18–23.

2. One-Minute Intuition

English

A model can fail in two broad ways:

  • Underfitting: it is too restrictive to capture the real relationship.
  • Overfitting: it is so flexible that it adapts too closely to the particular training data.

The best model is not the one that fits the training data most aggressively.

It is the one that performs well on data it did not see during training.

👨‍🏫 Hinglish
Socho tum exam ke liye padh rahe ho.

Underfitting

Tumne bas 2–3 formulas yaad kiye aur concept nahi padha.

Question thoda change hua → answer nahi aaya.

Overfitting

Tumne previous year's exact questions aur their answers rat liye.

Same question aaya → perfect.

Thoda wording change hua → problem.

Generalization

Tumne underlying concept samjha, isliye new question bhi solve kar pa rahe ho.

ML mein bhi target new/unseen data par achha perform karna hai.

3. Training Error vs Test Error

Suppose we train a model on:

\[ \mathcal S_{train} \]

and keep separate data:

\[ \mathcal S_{test} \]

Training error

Measures how well the model fits the training data.

Test error

Measures performance on held-out data used as a proxy for unseen examples.

The Lecture 8 definition is:

\[ \boxed{ TestError = \frac1m\sum_{i=1}^{m} \ell(f(x_i),y_i) } \]

for the test set. Course source: Lecture08.pdf, slide 6.

4. The Most Important Rule About the Test Set

Your test set should be treated like an exam paper you have not seen.

It should not be used to:

  • fit the model;
  • choose the hypothesis class;
  • repeatedly tune flexibility;
  • decide hyperparameters.

The supplied lecture explicitly warns that the test set is held out and should simply serve as a proxy for unseen data during evaluation. Course source: Lecture08.pdf, slide 6.

👨‍🏫 Hinglish
> Test set ko practice notebook mat banao. Test set ko **final exam** ki tarah rakho.

5. The Classroom Analogy: Training vs Validation vs Test

Your Lecture 8 gives an especially useful analogy:

Using the test set to decide model complexity is like peeking at the exam paper to decide how much to study.

Instead, use a mock exam.

That maps to:

Available labelled data
        │
        ├── Training set
        │       ↓
        │   Fit model
        │
        └── Validation set
                ↓
       Choose model flexibility /
       hyperparameters

Final untouched test set
        ↓
   Final evaluation

Course source: Lecture08.pdf, slide 24.

6. Why Do We Need a Validation Set?

Suppose you are deciding between:

  • a line,
  • a degree-3 polynomial,
  • a degree-10 polynomial.

If you repeatedly use the test set to choose among them, the test set is no longer a clean measure of unseen performance.

Instead:

Training chooses the parameters; validation helps choose the model configuration; test estimates final generalization.

This distinction becomes extremely important later for hyperparameters such as:

  • polynomial degree,
  • K in K-NN,
  • regularization strength \(\lambda\),
  • neural-network architecture.

7. Model Flexibility

Think of flexibility as:

How many different patterns/shapes can the model represent?

A low-flexibility model may only represent smooth/simple patterns.

A high-flexibility model can bend and adapt much more.

LOW FLEXIBILITY
───────────────
Few possible shapes

MEDIUM FLEXIBILITY
──────────────────
More possible shapes

HIGH FLEXIBILITY
─────────────────
Huge number of possible shapes

The hypothesis-class idea from C16 and flexibility are closely related.

8. The Famous U-Shaped Test-Error Story

As flexibility increases, two things can happen:

Error
 ↑
 │        Test error
 │       /\
 │      /  \
 │     /    \
 │____/      \____
 │
 └────────────────────→ Model flexibility
      low   good   high

Conceptually:

  • At very low flexibility → model is too simple → high test error.
  • At moderate flexibility → model captures useful structure → lower test error.
  • At very high flexibility → model can fit idiosyncrasies/noise → test error rises again.

Your Lecture 8 explicitly frames the question as:

Why does test error first decrease and then increase?

The answer is developed through the bias-variance trade-off. Course source: Lecture08.pdf, slides 18–23.

9. Underfitting

Definition

Underfitting occurs when a model is too restrictive or inflexible to represent the important structure in the data.

Typical symptom:

Training error → high
Test error     → high

Intuition

The model has not learned enough.

👨‍🏫 Hinglish
> Model bol raha hai: “Mujhe itna simple pattern hi aata hai, main actual data ka relation capture nahi kar pa raha.”

10. Overfitting

Definition

Overfitting occurs when a model adapts too closely to the training data and captures patterns that do not generalize well.

Typical symptom:

Training error → very low
Test error     → relatively high

Intuition

The model has learned the training set extremely specifically rather than learning a robust general rule.

👨‍🏫 Hinglish
> “Training examples ko itna closely yaad kar liya ki naye examples par general rule fail ho gaya.”

11. A Visual Continuum

Model flexibility

LOW ---------------------------------------------- HIGH

Too simple             Useful range             Too complex
    │                      │                        │
    ▼                      ▼                        ▼
Underfitting        Generalization            Overfitting
    │                      │                        │
High bias            Balanced behaviour       High variance

The supplied lecture explicitly associates less-flexible models with higher bias/lower variance and highly flexible models with lower bias/higher variance. Course source: Lecture08.pdf, slide 23.

12. What Is Bias?

Here “bias” does not mean unfairness between social groups.

That is a different usage of the word.

In this chapter:

Bias describes systematic error caused by restrictive modelling assumptions.

The lecture describes bias as the systematic mismatch between the expected learned model and the true regression function. Course source: Lecture08.pdf, slides 20–21.

Intuition

Suppose the true relationship is curved but you force a straight line.

The model's assumptions are systematically too restrictive.

👨‍🏫 Hinglish
> Model mein ek built-in simplification hai jo baar-baar same direction mein error create kar rahi hai.

13. What Is Variance?

Variance here means:

How sensitive the learned model is to the particular training set.

Imagine training the same algorithm on several different datasets sampled from the same underlying distribution.

If the learned model changes dramatically each time, the model has high variance.

Visual

Dataset 1 → Model A
Dataset 2 → Model B
Dataset 3 → Model C
Dataset 4 → Model D

If A, B, C, D are very different:
→ high variance

The lecture defines variance as arising from sensitivity to the training data. Course source: Lecture08.pdf, slides 20–21.

14. Bias vs Variance — Everyday Analogy

Imagine four students trying to estimate the average difficulty of a semester.

High bias

One student always says:

“Every subject is easy.”

The assumption is too simplistic.

High variance

Another student changes their estimate wildly depending on which single class they attended that week.

Their estimate is very sensitive to the particular sample of experience.

Better generalization

A better approach captures the underlying pattern without being rigid or wildly unstable.

15. The Third Term: Irreducible Error

The Lecture 8 decomposition contains three terms:

\[ \boxed{ Expected\ Test\ Error = Bias^2+Variance+Irreducible\ Error } \]

The third term matters because not everything in the target can be explained by the available features.

The lecture describes irreducible error as error caused by factors that the features cannot explain and that cannot be removed by simply changing the model or adding more data. Course source: Lecture08.pdf, slide 21.

Example

Suppose you predict a person's exact commute time using only:

  • day of week
  • distance

But the true commute also depends on:

  • an unexpected accident
  • a temporary road closure
  • a sudden weather event.

Those unobserved influences can create unavoidable uncertainty.

16. The Mathematical View of Supervised Learning

The Lecture 8 introduces an underlying data distribution:

\[ (X,Y)\sim\mathcal D \]

The true regression function is defined as:

\[ \boxed{ f^* = \arg\min_f \mathbb E_{(X,Y)\sim\mathcal D} [(Y-f(X))^2] } \]

The lecture notes that we generally do not know the true distribution \(\mathcal D\), so we cannot directly compute the true optimal function.

Instead, we sample training data and use a learning algorithm to obtain an approximate function \(\hat f_{\mathcal S}\). Course source: Lecture08.pdf, slide 19.

17. Why Is the True Regression Function \(f^*(X)=E[Y|X]\)?

The lecture gives the exercise:

Show that the true regression function is:

\[ \boxed{ f^*(X)=\mathbb E[Y\mid X] } \]

This is an important mathematical result.

Intuition first

Suppose the same input value \(X=x\) can correspond to several possible target values.

Then the best single prediction under squared error is the conditional average of those outcomes.

Tiny example

For students with exactly 80% attendance, suppose observed exam scores are:

\[ 70,\;75,\;80 \]

A simple squared-error-optimal prediction for that input condition is the average:

\[ \frac{70+75+80}{3}=75 \]

So the conditional mean naturally appears.

18. Bias-Variance Decomposition

Fix a test input \(x\).

The Lecture 8 decomposition is:

\[ \mathbb E_{\mathcal S,Y} \left[(Y-\hat f_{\mathcal S}(x))^2\mid X=x\right] \]

which can be decomposed as:

\[ \boxed{ \underbrace{ \left(\mathbb E_{\mathcal S}[\hat f_{\mathcal S}(x)]-f^*(x)\right)^2 }_{Bias^2} + \underbrace{ \mathbb E_{\mathcal S} \left[ \hat f_{\mathcal S}(x)- \mathbb E_{\mathcal S}[\hat f_{\mathcal S}(x)] \right]^2 }_{Variance} + \underbrace{Var(Y\mid X=x)}_{Irreducible\ Error} } \]

Course source: Lecture08.pdf, slide 20.

19. Breaking the Formula Down

Term 1 — Bias²

\[ \left(E[\hat f(x)]-f^*(x)\right)^2 \]

Question:

Across many training sets, is the average learned prediction systematically away from the true regression function?

If yes → bias.

Term 2 — Variance

\[ E\left[(\hat f(x)-E[\hat f(x)])^2\right] \]

Question:

How much does the learned prediction move around when the training set changes?

Large movement → high variance.

Term 3 — Irreducible Error

\[ Var(Y|X=x) \]

Question:

Even knowing X, how much unavoidable variation remains in Y?

20. Hinglish Formula Explanation

Think of the total expected prediction error as three sources:

Model ki soch ki galti + dataset ke badalne se model ki instability + data mein unavoidable randomness.

So:

Total error
   │
   ├── Bias²
   │     “Model ki assumption hi galat / too simple”
   │
   ├── Variance
   │     “Dataset badla toh model bhi bahut badal gaya”
   │
   └── Irreducible error
         “Input se sab kuch explain hi nahi hota”

21. Why Bias Is Squared

The decomposition uses:

\[ Bias^2 \]

not just bias.

Why?

Because the underlying derivation is based on squared prediction error, and the squared difference between the average prediction and the target contributes to the total mean-squared error.

For intuition:

bias = systematic offset
bias² = contribution to squared error

You do not need to invent a new story here: the square comes from the MSE framework itself.

22. The Bias-Variance Trade-Off

This is called a trade-off because increasing model flexibility can move bias and variance in opposite directions.

Typically:

Increase flexibility
        ↓
Bias tends to decrease
Variance tends to increase

Conversely:

Decrease flexibility
        ↓
Bias tends to increase
Variance tends to decrease

The Lecture 8 summary states:

  • less-flexible models → higher bias, lower variance;
  • highly flexible models → lower bias, higher variance. Course source: Lecture08.pdf, slide 23.

23. Visualizing the Trade-Off

ERROR
                   ↑
                   │            Test error
                   │          /¯¯¯¯¯¯¯\
                   │         /         \
                   │        /           \
                   │       /             \
                   │      /               \
                   └────────────────────────────→ FLEXIBILITY
                         low     ideal      high

             Bias²  →  generally decreases
             Variance → generally increases

Do not memorize the exact shape as a universal physical law.

The important course concept is the qualitative relationship:

More flexibility can reduce systematic bias but increase sensitivity to the training set.

24. Polynomial Regression as a Mental Model

Suppose a target really follows a curved relationship.

Degree 1

\[ f(x)=w_0+w_1x \]

Very limited flexibility.

Degree 3

\[ f(x)=w_0+w_1x+w_2x^2+w_3x^3 \]

More flexible.

Degree 15

\[ f(x)= \sum_{j=0}^{15}w_jx^j \]

Much more flexible.

This gives a convenient way to visualize the bias-variance trade-off.

Your practical resource pract_6_bias_and_hypothesis_class.ipynb is intended to reinforce this idea experimentally.

25. Why Test Error Can Fall Before It Rises

At very low flexibility:

The model cannot represent enough of the real pattern.

So bias dominates.

As flexibility increases:

The model becomes capable of representing important structure.

Test error can fall.

At very high flexibility:

The model can fit training-specific quirks and become highly sensitive to the particular sample.

Variance increases.

Test error can rise.

26. Training Error vs Flexibility

Training error typically has a different trend.

As the model becomes more flexible, it generally becomes easier to fit the training data.

Conceptually:

Training error
 ↑
 │\
 │ \
 │  \
 │   \________
 │
 └────────────────────→ Flexibility

This creates an important contrast:

More flexibility
   ↓
Training error tends to decrease

But

More flexibility
   ↓
Test error may eventually increase

That divergence is one of the central signals of overfitting.

27. Why Test Error Is More Important Than Training Error

Imagine two students.

Student A can reproduce every practice question exactly.

Student B understands the principle and solves unfamiliar questions.

On the practice sheet:

Student A may look better.

On an unseen paper:

Student B may generalize better.

ML asks the same kind of question:

What happens on data the model has not seen?

28. Generalization

Definition

Generalization is the ability of a learned model to perform well on unseen data drawn from the same task/distributional setting.

Formal intuition

Training performance:

\[ Error_{train} \]

Generalization performance:

\[ Error_{unseen} \]

Because unseen data is not available in advance, we estimate it using a held-out test set.

29. Cross-Validation — Course Connection

Your Lecture 8 ends by introducing cross-validation after discussing the need for a validation set.

At a high level, cross-validation repeatedly partitions the available data into training/validation portions so model selection can be evaluated more robustly.

You do not need to treat cross-validation as identical to a final test set.

Mental model:

Validation / cross-validation
→ model selection

Final test
→ final evaluation

30. A Critical Distinction: Bias in ML vs Bias in AI Ethics

You will encounter the word bias again in Unit IV.

These are related only at a broad linguistic level.

This chapter

Statistical/model bias = systematic modelling error.

Unit IV ethics

Societal/algorithmic fairness bias = systematic disparities or unfairness concerns in data or system outcomes.

Do not mix their definitions in an exam.

31. Common Misconceptions

Misconception 1

“Overfitting means the training error is high.”

Usually the opposite: overfit models can have very low training error.

Misconception 2

“Underfitting means the test set is bad.”

No. It usually means the model is too restrictive for the relationship it needs to represent.

Misconception 3

“Bias is always bad.”

In statistical learning, some inductive bias is necessary to generalize from finite data.

Misconception 4

“Variance means variance of the labels.”

Not here. In the bias-variance framework, it refers to variability of the learned model/predictions across training datasets.

Misconception 5

“The test set is for choosing hyperparameters.”

No. Use training/validation procedures for that. Preserve the final test set for final evaluation.

Misconception 6

“Zero test error is required.”

Not necessarily. Real data can contain irreducible uncertainty.

32. Comparison Table

Concept Main question Typical symptom
Underfitting Is the model too simple? High train error + high test error
Good generalization Does the model capture reusable structure? Low enough unseen-data error
Overfitting Is the model too tailored to training data? Very low train error + higher unseen-data error
Bias Are assumptions systematically too restrictive? Systematic mismatch
Variance Does the model change strongly with the training sample? Instability across datasets
Irreducible error What cannot be explained from available inputs? Unavoidable residual uncertainty

33. Step-by-Step Diagnostic Flow

When a model performs poorly, ask:

1. Is training error high?
      │
      ├── YES → possible underfitting / high bias
      │
      └── NO
           │
           ▼
2. Is test error much worse than training error?
      │
      ├── YES → possible overfitting / high variance
      │
      └── NO → investigate data, noise, representation,
                optimisation, distribution shift, etc.

This is a diagnostic mental model, not a substitute for actual model evaluation.

34. Math Worked Example — Simple Bias Calculation

Suppose the true regression value at a fixed input is:

\[ f^*(x)=10 \]

Across many training sets, the average prediction is:

\[ E[\hat f(x)]=8 \]

Then:

\[ Bias = 8-10=-2 \]

and:

\[ Bias^2=(-2)^2=4 \]

So the squared-bias contribution is:

\[ \boxed{4} \]
👨‍🏫 Hinglish
> Average prediction actual value se 2 units neeche hai, isliye bias = -2. Bias squared = 4.

35. Math Worked Example — Variance

Suppose predictions from five different training sets are:

\[ 8,\;9,\;10,\;11,\;12 \]

Mean prediction:

\[ \bar f=10 \]

The predictions vary around 10.

The variance measures the average squared deviation from 10.

The point to understand is more important than memorizing this particular arithmetic:

Variance quantifies prediction instability caused by changes in the training sample.

36. A Complete Mental Picture

MODEL FLEXIBILITY
                                │
             ┌──────────────────┼──────────────────┐
             ▼                  ▼                  ▼
          Too low             Useful             Too high

This is the central picture to remember.

39. University Exam Lens

2-mark answers

Define overfitting.

Overfitting occurs when a model fits the training data too closely and performs poorly on unseen data.

Define underfitting.

Underfitting occurs when a model is too restrictive to capture the important structure in the data, leading to poor training and unseen-data performance.

Define bias.

Bias is systematic error arising from restrictive modelling assumptions.

Define variance.

Variance is error due to the sensitivity of the learned model to the particular training dataset.

5-mark question

Explain the bias-variance trade-off.

Recommended answer:

  1. Define model flexibility.
  2. Explain low-flexibility models.
  3. Explain high-flexibility models.
  4. State bias trend.
  5. State variance trend.
  6. Connect to underfitting/overfitting.

Derive/explain the bias-variance decomposition of expected test error.

Recommended structure:

  1. Define underlying distribution.
  2. Define true regression function.
  3. Define learned function over a random training set.
  4. State expected squared test error.
  5. Add and subtract the mean prediction.
  6. Separate the error terms.
  7. Identify Bias².
  8. Identify Variance.
  9. Identify Irreducible Error.
  10. Interpret the result and connect it to model flexibility.

40. Math Lens

This is one of the mathematically important chapters in Unit II.

You need:

Expectation

\[ E[Z] \]

Variance

\[ Var(Z)=E[(Z-E[Z])^2] \]

Conditional expectation

\[ E[Y\mid X=x] \]

Conditional variance

\[ Var(Y\mid X=x) \]

Bias

\[ Bias(x)=E_{\mathcal S}[\hat f_{\mathcal S}(x)]-f^*(x) \]

Bias²

\[ Bias^2(x)= \left(E_{\mathcal S}[\hat f_{\mathcal S}(x)]-f^*(x)\right)^2 \]

Total decomposition

\[ \boxed{ E[(Y-\hat f(X))^2] = Bias^2+Variance+Irreducible\ Error } \]

46. Memory Card

GENERALIZATION

Train error asks: “Did I fit what I saw?”
Test/generalization asks: “Can I handle what I haven't seen?”

BIAS

Too restrictive → systematic mismatch.

VARIANCE

Too sensitive → changes with the training sample.

OVERFITTING

Very low training error + poor unseen-data performance.

UNDERFITTING

Model too restrictive → poor fit and poor generalization.

DECOMPOSITION

\[ \gt Test\ Error = Bias^2 + Variance + Irreducible\ Error \gt \]
