Main Book: AI & Machine Learning — Visual + Mathematical Self-Learning Textbook

Topic ID: ML-U3-C36

1. Why This Chapter Exists

A fully connected neural network can process image pixels, but it does not naturally encode the spatial structure of an image.

If an image is represented as a large vector:

[pixel1, pixel2, pixel3, ...]

a dense layer treats the input through learned connections without explicitly preserving the idea that:

  • nearby pixels are related;
  • the same visual pattern may occur at different locations;
  • a useful local pattern can be reused across the image.

A Convolutional Neural Network (CNN) introduces architectural structure for these kinds of spatial patterns.

The central idea is:

Instead of connecting every neuron to every input pixel in the same way, a CNN learns small filters that scan across an input and produce feature maps.

Typical conceptual progression:

Image
  ↓
Local receptive fields
  ↓
Convolution / learned filters
  ↓
Feature maps
  ↓
Nonlinearity
  ↓
Pooling / downsampling (when used)
  ↓
Deeper feature extraction
  ↓
Classifier / output

Course grounding

The supplied University of Delhi DSC-14 resource guide places CNN explicitly in Unit III and identifies CNN as a topic that requires gap-filling beyond the supplied neural-network practical and lecture material.

The resource guide also recommends Stanford CS231n and deep-learning resources for CNN study.

2. One-Minute Intuition

English

Imagine looking at a photograph.

You do not normally recognize the entire image by comparing every pixel independently.

You can notice:

  • an edge;
  • a corner;
  • a small curve;
  • a texture;
  • a shape;
  • a combination of shapes.

A CNN builds this kind of hierarchy computationally.

raw pixels
   ↓
simple local patterns
   ↓
more complex patterns
   ↓
parts
   ↓
object-level evidence

This is an intuition, not a guarantee that every hidden feature has a clean human interpretation.

Hinglish

Image ko ek huge puzzle samjho.

Agar tum poori image ek saath samajhne ki koshish karo, problem difficult hai.

CNN image ko chhote local regions mein dekhkar useful patterns seekhta hai.

small region
    ↓
edge?
    ↓
texture?
    ↓
shape?
    ↓
larger pattern?

Phir deeper layers pehle se nikle patterns ko combine karti hain.

👨‍🏫 Teacher explanation — Hinglish
Standard MLP images par fail ho jaata hai kyunki agar $1000 imes 1000$ image ko flatten karoge toh 1 million inputs ban jaayenge, aur pehle layer ke hi trillions of weights ho jaayenge! CNN iska ilaaj do concepts se karta hai: 1. **Local Receptive Fields:** Filter sirf $3 imes 3$ ya $5 imes 5$ ke chote patch ko dekhta hai. 2. **Weight Sharing:** Wahi same filter poori image par slide karta hai. Agar ek filter se aankh ya kaan detect ho raha hai, toh image ke kisi bhi kone mein aankh ho, wo detect kar lega! A CNN is not simply: > "A neural network for images." A better mental model is: > **A neural network whose architecture uses local connectivity and shared parameters to learn spatial features efficiently.** Three ideas are especially important: | Idea | Meaning | |---|---| | Local connectivity | A unit looks at a local region rather than the entire image | | Parameter sharing | The same filter parameters are reused at different locations | | Hierarchical representation | Later layers can combine earlier features | These three ideas explain much of the usefulness of CNNs.

4. Image as a Tensor

A grayscale image can be represented as a matrix:

\[ X\in\mathbb{R}^{H\times W} \]

where:

  • \(H\) = height;
  • \(W\) = width.

A colour RGB image has three channels:

\[ X\in\mathbb{R}^{H\times W\times 3}. \]

For example:

RGB image

height
  ↓
┌───────────────────┐
│ R channel         │
│ G channel         │
│ B channel         │
└───────────────────┘
          → width

In deep-learning notation, a batch may add another dimension:

\[ X\in\mathbb{R}^{B\times H\times W\times C} \]

where \(B\) is batch size and \(C\) is the number of channels.

Different software libraries may order these dimensions differently. The mathematical idea is unchanged.

5. Why Not Just Use a Dense Network?

Suppose an RGB image has:

\[ 224\times224\times3 \]

input values.

That is:

\[ 224\cdot224\cdot3=150528 \]

input values.

A dense layer with only 1000 neurons would require approximately:

\[ 150528\times1000 \]

weights, before counting biases.

That is about:

\[ 150,528,000 \]

weights.

A CNN can instead use small filters such as:

\[ 3\times3 \]

and reuse them across spatial locations.

This does not mean CNNs are always computationally cheap; modern CNNs can be very large. The key point is that convolution imposes a useful structural assumption and shares parameters.

6. The Convolution Filter

Consider a simple grayscale patch:

\[ X= \begin{bmatrix} 1&2&0\\ 0&1&3\\ 2&1&1 \end{bmatrix} \]

and a filter:

\[ K= \begin{bmatrix} 1&0\\ 0&-1 \end{bmatrix}. \]

A local operation multiplies corresponding values and sums them.

For the top-left \(2\times2\) region:

\[ \begin{bmatrix} 1&2\\ 0&1 \end{bmatrix} \]

the response is:

\[ 1(1)+2(0)+0(0)+1(-1)=0. \]

The filter is then moved to another location.

Input

┌───┬───┬───┐
│ 1 │ 2 │ 0 │
├───┼───┼───┤
│ 0 │ 1 │ 3 │
├───┼───┼───┤
│ 2 │ 1 │ 1 │
└───┴───┴───┘
  ↑
  └── local window

        ↓ filter moves

┌───┬───┐
│ ? │ ? │
├───┼───┤
│ ? │ ? │
└───┴───┘

feature map

The resulting matrix is called a feature map (or activation map).

7. What Does a Filter Learn?

A filter is not normally manually assigned in a trained CNN.

Its parameters are learned from data.

Early filters may learn patterns that resemble:

  • edges;
  • orientations;
  • local contrasts;
  • simple textures.

Deeper layers can combine earlier feature responses.

A useful conceptual picture is:

Layer 1
edge-like / local patterns
        ↓
Layer 2
textures / combinations
        ↓
Layer 3
parts / larger structures
        ↓
Later layers
task-relevant high-level evidence

Do not memorize this as a rigid rule. Learned features depend on the dataset, architecture and training objective.

8. Convolution Operation

For a 2D input \(X\) and kernel \(K\), a common deep-learning cross-correlation form is:

\[ S(i,j) = \sum_{m}\sum_{n} X(i+m,j+n)K(m,n). \]

Important terminology note

Many deep-learning libraries call this operation convolution, although mathematically it is often cross-correlation because the kernel is not explicitly flipped.

For an introductory course, the important skill is understanding the sliding-window multiply-and-sum operation and knowing the terminology distinction.

9. Stride

Stride tells us how far the filter moves between positions.

Stride 1

→ one position at a time

Stride 2

→ skip every other starting position

Larger stride generally reduces spatial dimensions.

For an input size \(N\), kernel size \(F\), padding \(P\), and stride \(S\):

\[ \text{Output size} = \left\lfloor \frac{N+2P-F}{S} \right\rfloor+1. \]

For height and width, apply the formula separately.

10. Padding

Without padding, repeated convolution operations can shrink spatial dimensions.

Padding adds values around the boundary, commonly zeros in basic examples.

Before padding

████████
████████
████████

After padding

░░░░░░░░░░
░████████░
░████████░
░████████░
░░░░░░░░░░

Common terminology:

Valid

No padding.

Same

Padding is selected so that, under common stride-1 settings, output spatial dimensions match input dimensions.

Do not assume "same" always means identical dimensions for arbitrary strides; the exact convention depends on the framework and stride.

11. Multiple Channels

A colour image has multiple channels.

A filter therefore also has a depth/channel dimension.

If the input is:

\[ H\times W\times C_{in} \]

then one filter has dimensions approximately:

\[ F_h\times F_w\times C_{in}. \]

For example, for RGB input:

\[ 3\times3\times3. \]

The filter produces one output feature map.

If we learn \(C_{out}\) filters, we obtain:

\[ H_{out}\times W_{out}\times C_{out}. \]

12. Number of Convolution Parameters

For:

  • kernel height \(F_h\);
  • kernel width \(F_w\);
  • input channels \(C_{in}\);
  • output channels \(C_{out}\);

the number of weights is:

\[ F_hF_wC_{in}C_{out}. \]

If each output channel has one bias:

\[ \text{parameters} = F_hF_wC_{in}C_{out}+C_{out}. \]

Example

Input channels:

\[ C_{in}=3 \]

Kernel:

\[ 3\times3 \]

Number of filters:

\[ 32. \]

Weights:

\[ 3\cdot3\cdot3\cdot32=864. \]

Biases:

\[ 32. \]

Total:

\[ 896. \]

Compare this with a dense layer connected to a large image: parameter sharing is the crucial structural difference.

13. Feature Maps

If a layer contains several filters:

Input image
     ↓
 ┌───┼───┬───┐
 ↓   ↓   ↓   ↓
K1  K2  K3  K4
 ↓   ↓   ↓   ↓
M1  M2  M3  M4

each filter creates a different feature map.

One filter may respond strongly to one learned local pattern, another to a different pattern.

The collection of feature maps becomes the input to later processing.

14. ReLU After Convolution

A common block is:

Input
  ↓
Convolution
  ↓
ReLU
  ↓
Feature map

ReLU:

\[ \operatorname{ReLU}(z)=\max(0,z). \]

Example:

\[ [-2,\ 1,\ 4,\ -3] \]

becomes:

\[ [0,\ 1,\ 4,\ 0]. \]

The activation introduces nonlinearity, allowing stacked layers to represent more complex functions.

PYTHON
import numpy as np

def conv2d_single_channel(image, kernel, stride=1, padding=0):
    if padding > 0:
        image = np.pad(image, ((padding, padding), (padding, padding)), mode='constant')
    
    H, W = image.shape
    kH, kW = kernel.shape
    out_H = (H - kH) // stride + 1
    out_W = (W - kW) // stride + 1
    output = np.zeros((out_H, out_W))

    for i in range(out_H):
        for j in range(out_W):
            h_start = i * stride
            w_start = j * stride
            patch = image[h_start:h_start+kH, w_start:w_start+kW]
            output[i, j] = np.sum(patch * kernel)
    return output

sobel_v = np.array([[-1, 0, 1],
                    [-2, 0, 2],
                    [-1, 0, 1]])

img = np.array([
    [10, 10, 10, 0, 0],
    [10, 10, 10, 0, 0],
    [10, 10, 10, 0, 0],
    [10, 10, 10, 0, 0],
    [10, 10, 10, 0, 0]
], dtype=float)

feat_map = conv2d_single_channel(img, sobel_v)
print("Input Image Shape:", img.shape)
print("Feature Map Shape:", feat_map.shape)
print("Feature Map Output (Bright positive edge detected):\n", feat_map)

Pooling is a downsampling operation.

The classic example is max pooling.

For:

\[ \begin{bmatrix} 1&5\\ 2&3 \end{bmatrix} \]

max pooling gives:

\[ 5. \]

A larger feature map becomes smaller.

4 × 4 feature map
       ↓
2 × 2 max pooling
       ↓
2 × 2 feature map

Pooling can:

  • reduce spatial resolution;
  • reduce computation in later layers;
  • provide some tolerance to small spatial shifts.

Pooling is common in classical CNN teaching, but modern architectures may use strided convolutions or other downsampling mechanisms instead.

16. Max Pooling Worked Example

Given:

\[ X= \begin{bmatrix} 1&3&2&4\\ 5&6&1&2\\ 7&2&8&3\\ 1&4&5&9 \end{bmatrix} \]

Use \(2\times2\) max pooling with stride 2.

Top-left:

\[ \max \begin{bmatrix} 1&3\\ 5&6 \end{bmatrix} =6. \]

Top-right:

\[ \max \begin{bmatrix} 2&4\\ 1&2 \end{bmatrix} =4. \]

Bottom-left:

\[ \max \begin{bmatrix} 7&2\\ 1&4 \end{bmatrix} =7. \]

Bottom-right:

\[ \max \begin{bmatrix} 8&3\\ 5&9 \end{bmatrix} =9. \]

Therefore:

\[ \boxed{ \begin{bmatrix} 6&4\\ 7&9 \end{bmatrix}} \]

18. Why Parameter Sharing Matters

Suppose a vertical edge appears:

██
██
██

If the same learned filter can detect a vertical edge at many positions, we do not need a completely different set of parameters for each location.

The same kernel is reused:

position 1 → same filter
position 2 → same filter
position 3 → same filter
...

This is called parameter sharing.

It reduces parameter count and builds a useful inductive bias: the same local pattern may matter regardless of where it occurs.

19. Translation Equivariance — Careful Understanding

A convolutional feature map tends to move when the input pattern moves.

Conceptually:

pattern at left
     ↓
activation at left

pattern moves right
     ↓
activation moves right

This is related to translation equivariance.

Pooling/downsampling and later stages can introduce some degree of translation tolerance/invariance, but these concepts are not identical.

Do not say:

"CNNs are completely translation invariant."

That is too strong.

A safer statement is:

Convolution naturally preserves spatial correspondence and provides translation-equivariant feature extraction, while architectural choices can provide some tolerance to small spatial shifts.

20. Receptive Field

A neuron's receptive field is the region of the original input that can influence it.

A shallow convolution may see a small region.

After several layers, a unit can depend on a much larger region.

Layer 1
small local view

      ↓

Layer 2
larger effective view

      ↓

Layer 3
still larger effective view

This helps explain how CNNs can move from local patterns toward larger structures.

21. CNN vs Fully Connected Network

Property Dense network CNN
Local connectivity Not structurally enforced Yes
Parameter sharing Usually no spatial sharing Yes
Spatial structure Flattening can obscure it Preserved by architecture
Typical use General tabular/vector data Images/spatial data
Feature extraction Learned Learned
Parameter efficiency for images Often poor Often better

Neither architecture is universally superior. The appropriate inductive bias depends on the data and task.

22. Worked End-to-End Shape Example

Suppose:

Input: 32 × 32 × 3
Kernel: 3 × 3
Filters: 16
Stride: 1
Padding: 1

Output spatial size:

\[ \frac{32+2(1)-3}{1}+1 = 32. \]

So:

\[ \boxed{32\times32\times16} \]

Parameter count

\[ 3\cdot3\cdot3\cdot16+16 \]
\[ =432+16 \]
\[ =\boxed{448}. \]

This kind of shape and parameter calculation is highly useful for exams.

23. CNN Mathematics You Need Now

Output dimension

\[ \boxed{ N_{out} = \left\lfloor \frac{N+2P-F}{S} \right\rfloor+1 } \]

Convolution/cross-correlation response

\[ \boxed{ S(i,j) = \sum_m\sum_n X(i+m,j+n)K(m,n) } \]

Convolution parameters

\[ \boxed{ F_hF_wC_{in}C_{out}+C_{out} } \]

when biases are included.

24. Common Mistakes

⚠️ Mistake 1
Thinking the filter is a fixed image-processing mask. **Correction:** in a trained CNN, filter values are learned parameters.
⚠️ Mistake 2
Thinking every filter produces one scalar for the whole image. **Correction:** a filter is scanned over spatial positions and produces a feature map.
⚠️ Mistake 3
Confusing kernel size with output size. **Correction:** use the output-size formula.
⚠️ Mistake 4
Forgetting input channels. A \(3\times3\) filter for RGB input is not merely \(3\times3\); its learned weights span the input channels.
⚠️ Mistake 5
Assuming pooling is mandatory. It is common but not a mathematical requirement for every CNN architecture.
