1. Why This Chapter Exists

You have already studied models such as linear regression, logistic regression and decision trees. A natural question now appears:

What if the relationship between inputs and outputs is too complicated for one simple model?

A neural network gives us a way to build a composition of simple computational units so that the complete model can represent much richer relationships.

The central progression is:

Raw input
   ↓
Weighted combinations
   ↓
Activation functions
   ↓
Intermediate representations
   ↓
More transformations
   ↓
Prediction

The important conceptual shift is not merely:

“A neural network has many neurons.”

It is:

A neural network learns a useful representation of the input and then uses that representation to make predictions.

This connects directly to Lecture10 copy.pdf, where the supplied lecture describes a neural network through a learned feature map:

\[ \phi_\theta(x) \]

followed by a final prediction such as

\[ f(x)=w^T\phi_\theta(x). \]

The supplied resource guide identifies prac_7_neural_network.ipynb as covering neurons, weights/bias, activations, losses and gradient-descent concepts, while CS6910 Lecture 2 covers biological/artificial neurons, threshold logic, perceptrons, the learning algorithm, MLPs and representation power. [AI_ML_Master_Learning_Resource_Guide.pdf]

2. One-Minute Intuition

English

A neuron is a small computation unit.

It receives numbers, gives different importance to those numbers using weights, adds a bias, and then passes the result through an activation function.

A network connects many such units.

One layer can extract a simple pattern. Later layers can combine those patterns into more useful patterns.

For example, in image recognition:

pixels
  ↓
edges
  ↓
shapes
  ↓
parts
  ↓
object

That is only an intuition; real learned representations are not necessarily so cleanly interpretable.

Hinglish

Neuron ko ek chhota decision-making calculator samjho.

Uske paas kuch inputs aaye. Har input kitna important hai, woh weight batata hai. Phir neuron sab weighted inputs ko combine karta hai, bias add karta hai, aur activation function decide karta hai ki output kis form mein niklega.

Ek neuron simple kaam kar sakta hai.

Bahut saare neurons milkar complicated pattern bana sakte hain.

Bilkul waise jaise ek team mein:

person 1 → ek clue
person 2 → doosra clue
person 3 → teesra clue
             ↓
          manager
             ↓
        final decision

Neural network ka power combination + learned weights + nonlinear transformations se aata hai.

3.1 Biological inspiration

Artificial neural networks were inspired by the idea that biological nervous systems contain interconnected processing units.

A biological neuron receives signals through its inputs and produces an output signal. An artificial neuron keeps only a highly simplified mathematical abstraction of this idea.

Important caution

Do not interpret the artificial neuron as a faithful simulation of a biological neuron.

It is a mathematical model inspired by the broad idea of weighted signal aggregation and thresholding.

4. The Artificial Neuron

Suppose a neuron receives an input vector

\[ x=(x_1,x_2,\ldots,x_d). \]

It has weights

\[ w=(w_1,w_2,\ldots,w_d) \]

and a bias

\[ b. \]

First compute the weighted sum:

\[ z=w^Tx+b \]

or explicitly:

\[ z=w_1x_1+w_2x_2+\cdots+w_dx_d+b. \]

Then apply an activation function:

\[ \boxed{a=\phi(z)}. \]

So the artificial neuron can be summarized as:

x1 ──× w1 ─┐
          x2 ──× w2 ─┤
          x3 ──× w3 ─┤
                     ├── Σ ── + b ── φ ──→ a
          ... ───────┤
          xd ──× wd ─┘

👨‍🏫 Teacher explanation — Hinglish
Neuron ko ek simple decision-maker samjho. Har input $x_i$ ek evidence hai, aur weight $w_i$ us evidence ki importance (vajan) hai. Bias $b$ neuron ka personal threshold hai — agar inputs zero bhi hon, toh neuron kitna eager hai fire karne ke liye. Jab tak weighted sum $z$ bias ke sath milkar threshold cross nahi karta, neuron chup rehta hai! When looking at a neuron diagram, identify four things in this order:

1. Inputs

\[ x_1,x_2,\ldots,x_d \]

These are the available features.

2. Weights

\[ w_1,w_2,\ldots,w_d \]

They determine how strongly each input contributes.

3. Bias

\[ b \]

It shifts the neuron's pre-activation value.

4. Activation

\[ \phi(z) \]

It transforms the weighted sum before the output is passed onward.

6. What Does a Weight Actually Mean?

Suppose:

\[ z=2x_1-0.5x_2+1. \]

Then:

  • \(w_1=2\): increasing \(x_1\) tends to increase \(z\).
  • \(w_2=-0.5\): increasing \(x_2\) tends to decrease \(z\).
  • larger absolute weight magnitude means a stronger contribution to the weighted sum, all else equal.

Important nuance

A weight is not automatically a causal importance score.

Its interpretation depends on scaling, architecture, interactions, activation functions and the learned representation.

For exam intuition, however:

Weight = learned strength and direction of an input's contribution to the pre-activation.

7. What Is the Bias?

Without a bias:

\[ z=w^Tx. \]

With a bias:

\[ z=w^Tx+b. \]

The bias gives the neuron an additional adjustable offset.

Geometry

For a threshold-style neuron,

\[ w^Tx+b=0 \]

defines a decision boundary.

Changing \(b\) shifts that boundary.

So an intuitive interpretation is:

Weights control orientation; bias controls position.

For a two-dimensional input, the decision boundary is a line. In higher dimensions, it becomes a hyperplane.

8. A First Numerical Example

PYTHON
import numpy as np

class ArtificialNeuron:
    def __init__(self, weights, bias, activation_fn):
        self.w = np.array(weights, dtype=float)
        self.b = float(bias)
        self.act = activation_fn

    def forward(self, x):
        z = np.dot(self.w, x) + self.b
        return self.act(z)

# Step function (McCulloch-Pitts / Heaviside)
step = lambda z: 1 if z >= 0 else 0

# (A) Logic AND Gate: Fires only when both inputs are 1
neuron_and = ArtificialNeuron(weights=[1.0, 1.0], bias=-1.5, activation_fn=step)
print("AND Gate Tests:")
for x in [[0,0], [0,1], [1,0], [1,1]]:
    print(f"  Inputs {x} -> Output {neuron_and.forward(x)}")

# (B) Logic OR Gate: Fires when at least one input is 1
neuron_or = ArtificialNeuron(weights=[1.0, 1.0], bias=-0.5, activation_fn=step)
print("OR Gate Tests:")
for x in [[0,0], [0,1], [1,0], [1,1]]:
    print(f"  Inputs {x} -> Output {neuron_or.forward(x)}")

Let

\[ x_1=2,\quad x_2=3, \]
\[ w_1=0.5,\quad w_2=-1, \]

and

\[ b=1. \]

Then:

\[ z=(0.5)(2)+(-1)(3)+1. \]

Therefore,

\[ z=1-3+1=-1. \]

If the activation is ReLU,

\[ \operatorname{ReLU}(z)=\max(0,z), \]

so:

\[ a=\operatorname{ReLU}(-1)=0. \]

      ↓

      ↓

9. Why Do We Need an Activation Function?

This is one of the most important questions in the chapter.

Suppose every neuron only computes

\[ z=w^Tx+b \]

and there is no nonlinear activation between layers.

A sequence of linear/affine transformations can be collapsed into another affine transformation.

For example,

\[ z_1=W_1x+b_1 \]

and then

\[ z_2=W_2z_1+b_2. \]

Substitute:

\[ z_2=W_2(W_1x+b_1)+b_2 \]
\[ z_2=(W_2W_1)x+(W_2b_1+b_2). \]

That is still just another affine transformation.

So simply stacking linear layers does not give the expressive power usually associated with deep neural networks.

Central insight

Nonlinearity is what allows layered networks to model nonlinear relationships.

10. Activation Functions

The activation function transforms

\[ z \]

into

\[ a=\phi(z). \]

The course's neural-network resource set highlights activations; the broader course structure includes common functions such as sigmoid, ReLU and tanh. [AI_ML_Master_Learning_Resource_Guide.pdf]

11. Step / Threshold Activation

The simplest threshold idea is:

\[ \phi(z)= \begin{cases} 1,&z\ge 0\\ 0,&z\lt 0 \end{cases} \]

Interpretation:

z < 0  →  0
z ≥ 0  →  1

This is closely connected to threshold logic and the perceptron material identified in CS6910 Lecture 2.

Advantage

Very intuitive for binary decisions.

Limitation

Its discontinuous nature is inconvenient for gradient-based learning with ordinary derivatives.

That motivates smoother or piecewise-differentiable activations in modern neural networks.

12. Sigmoid

The sigmoid function is

\[ \boxed{ \sigma(z)=\frac{1}{1+e^{-z}} } \]

Its output lies between 0 and 1:

\[ 0\lt \sigma(z)\lt 1. \]

Behaviour

large negative z → output near 0
z = 0             → output 0.5
large positive z → output near 1

Intuition

Sigmoid smoothly converts an unrestricted real number into a bounded score in the interval \((0,1)\).

It is especially natural in binary classification output layers when the value is interpreted as a probability-like quantity under the model.

13. Tanh

\[ \boxed{ \tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}} } \]

Its output lies in

\[ (-1,1). \]

Compared with sigmoid, tanh is zero-centered.

A useful mental picture:

sigmoid → 0 to 1
 tanh   → -1 to 1

14. ReLU

The Rectified Linear Unit is

\[ \boxed{ \operatorname{ReLU}(z)=\max(0,z) } \]

So:

\[ \operatorname{ReLU}(z)= \begin{cases} 0,&z\lt 0\\ z,&z\ge 0 \end{cases} \]

Why it is intuitive

Negative pre-activation → suppressed to zero.

Positive pre-activation → passed through unchanged.

Simple trace

\(z\) ReLU\((z)\)
-3 0
-0.5 0
0 0
2 2
5 5

15. Activation Comparison Card

Function Range Shape idea Common intuition
Step typically \(\{0,1\}\) hard threshold yes/no decision
Sigmoid \((0,1)\) S-shaped probability-like output
Tanh \((-1,1)\) centered S-shape signed bounded signal
ReLU \([0,\infty)\) zero then line keep positive signal

Memory anchor

Step decides. Sigmoid squashes. Tanh centers. ReLU gates.

16. What Is a Layer?

A layer is a group of neurons that processes a representation and passes the result onward.

A basic feedforward network contains:

Input Layer
     ↓
Hidden Layer(s)
     ↓
Output Layer

Input layer

Receives the feature vector.

Hidden layer

Performs learned transformations that are not directly the final prediction.

Output layer

Produces the task output.

17. Feedforward Neural Network

In a feedforward network, information moves from earlier layers toward later layers.

There is no recurrent loop in the basic feedforward architecture.

A one-hidden-layer network can be written as:

\[ h=\phi(W_1x+b_1) \]

followed by

\[ \hat y=g(W_2h+b_2). \]

Therefore:

\[ \boxed{ \hat y=g\left(W_2\phi(W_1x+b_1)+b_2\right) } \]

This compact equation is worth understanding deeply.

18. Reading the MLP Equation

For

\[ h=\phi(W_1x+b_1), \]

identify:

  • \(x\): input vector
  • \(W_1\): weights connecting input to hidden layer
  • \(b_1\): hidden-layer bias
  • \(\phi\): hidden-layer activation
  • \(h\): learned hidden representation

For the output:

\[ \hat y=g(W_2h+b_2), \]

identify:

  • \(W_2\): hidden-to-output weights
  • \(b_2\): output bias
  • \(g\): output activation
  • \(\hat y\): prediction

19. Matrix Dimensions — The Fastest Way to Catch Errors

Suppose:

  • input dimension = \(d\)
  • hidden layer width = \(m\)
  • output dimension = \(k\)

Then typically:

\[ x\in\mathbb R^d \]
\[ W_1\in\mathbb R^{m\times d} \]
\[ b_1\in\mathbb R^m \]
\[ h\in\mathbb R^m \]
\[ W_2\in\mathbb R^{k\times m} \]
\[ b_2\in\mathbb R^k. \]

Check:

\[ (m\times d)(d\times1)=m\times1. \]

Then:

\[ (k\times m)(m\times1)=k\times1. \]

Exam habit

Whenever you see a neural-network matrix equation, write the dimensions beside every term.

20. Parameters vs Hyperparameters

Parameters

Learned from training data.

Examples:

  • weights
  • biases

Hyperparameters

Set by the practitioner/training configuration rather than directly learned as ordinary model weights.

Examples include:

  • learning rate
  • number of hidden layers
  • hidden-layer width
  • batch size
  • number of epochs

Memory anchor

Parameters are learned; hyperparameters control how learning is done.

21. What Does a Neural Network Learn?

A common beginner picture is:

“The network learns the answer.”

A better picture is:

The network learns parameters that transform the input into a useful representation and prediction.

The supplied Lecture10 copy.pdf is particularly important here. It presents the idea that a neural network can learn a feature representation in which the target becomes easier to model.

Conceptually:

\[ x \xrightarrow{\phi_\theta} \text{learned representation} \xrightarrow{w^T} \text{prediction} \]

This is one reason neural networks are sometimes described as representation-learning systems.

22. Representation Power — Why Multiple Layers Matter

Consider a classification problem where the original input coordinates do not make the classes linearly separable.

A useful learned transformation can map the inputs into a new representation:

\[ x\rightarrow z=\phi_\theta(x) \]

where the classes may become easier to separate.

Lecture10 copy.pdf specifically gives the intuition that original inputs can be non-linearly separable while a learned feature representation can become linearly separable. [Lecture10 copy.pdf]

Visual mental model

Original space

A  B  A
 B A B
A  B   A

messy boundary
       ↓
learned transformation
       ↓
New feature space

AAAA     BBBB
AAAA     BBBB

simple boundary

The point is not that every neural network produces two neat clusters. The point is that changing the representation can make the prediction problem easier.

23. Why a Single Neuron Is Limited

A single threshold neuron creates a single linear decision boundary:

\[ w^Tx+b=0. \]

For two-dimensional inputs, this is a line.

A single linear decision boundary cannot represent every possible classification pattern.

This gives the motivation for connecting multiple neurons.

One neuron
    ↓
simple boundary

Many neurons + nonlinear activations
    ↓
composed nonlinear representation
    ↓
more expressive decision functions

This distinction is fundamental:

Adding more neurons is useful because they are combined through nonlinear transformations, not merely because there are more arithmetic operations.

24. Forward Pass

The process of taking an input through the network to produce a prediction is the forward pass or forward propagation.

For a simple MLP:

input x
  ↓
linear combination
  ↓
activation
  ↓
hidden representation
  ↓
linear combination
  ↓
output activation
  ↓
prediction ŷ

Mathematically:

\[ z_1=W_1x+b_1 \]
\[ h=\phi(z_1) \]
\[ z_2=W_2h+b_2 \]
\[ \hat y=g(z_2). \]

25. Worked Forward-Pass Example

Take a tiny network with two inputs and two hidden neurons.

Let

\[ x= \begin{bmatrix} 1\\2 \end{bmatrix} \]

and

\[ W_1= \begin{bmatrix} 1&1\\ 2&-1 \end{bmatrix}, \qquad b_1= \begin{bmatrix} 0\\1 \end{bmatrix}. \]

Compute:

\[ z_1=W_1x+b_1 \]
\[ = \begin{bmatrix} 1(1)+1(2)\\ 2(1)-1(2) \end{bmatrix} + \begin{bmatrix} 0\\1 \end{bmatrix} \]
\[ = \begin{bmatrix} 3\\1 \end{bmatrix}. \]

Using ReLU:

\[ h=\begin{bmatrix}3\\1\end{bmatrix}. \]

Suppose output weights are

\[ W_2=\begin{bmatrix}2&-1\end{bmatrix} \]

and

\[ b_2=0. \]

Then:

\[ z_2=2(3)-1(1)=5. \]

A linear output would therefore be

\[ \hat y=5. \]

The exact output interpretation depends on the task and output function.

26. Loss Function: Why Do We Need One?

A network generates a prediction \(\hat y\), but training requires a way to measure how different the prediction is from the target \(y\).

That measurement is provided by a loss function.

Generic notation:

\[ L(y,\hat y). \]

Examples:

Regression

Mean squared error:

\[ MSE=\frac1n\sum_{i=1}^{n}(y_i-\hat y_i)^2. \]

Binary classification

A common choice is binary cross-entropy:

\[ L=-\left[y\log(\hat p)+(1-y)\log(1-\hat p)\right] \]

for one example.

The exact choice should match the task and output interpretation.

27. Training Loop — Big Picture

The neural-network training idea can be visualized as:

┌──────────────┐
        │ Training data│
        └──────┬───────┘
               ↓
          Forward pass
               ↓
           Prediction
               ↓
           Loss value
               ↓
        Compute gradients
               ↓
       Update parameters
               ↓
          Repeat many times

In symbols:

\[ \theta \leftarrow \theta-\eta\nabla_\theta L \]

where:

  • \(\theta\) = collection of trainable parameters
  • \(\eta\) = learning rate
  • \(\nabla_\theta L\) = gradient of loss with respect to parameters

Backpropagation will later explain how these gradients are computed efficiently through a layered network.

28. The Three Words You Must Keep Separate

Students often mix these concepts:

Forward pass

Compute prediction.

Loss

Measure prediction error.

Backpropagation

Compute gradients of the loss with respect to parameters.

Then an optimizer such as gradient descent uses those gradients to update the parameters.

Memory chain:

Forward
  ↓
Prediction
  ↓

29. Neural Network as Function Composition

A neural network can be viewed mathematically as repeated function composition.

For example:

\[ f(x)=g_2(g_1(x)) \]

where each \(g_i\) may contain:

  1. a linear/affine transformation;
  2. an activation function.

A deep network is therefore not mysterious mathematics. It is a composition of parameterized transformations.

For a three-layer example:

\[ h_1=\phi_1(W_1x+b_1) \]
\[ h_2=\phi_2(W_2h_1+b_2) \]
\[ \hat y=g(W_3h_2+b_3). \]

30. What Makes a Network “Deep”?

There is no single universal cutoff such as “three layers means deep.”

In common usage, a network is called deep when it contains multiple layers of learned transformations.

The important conceptual distinction is:

Shallow model → few transformations
Deep model    → many stacked transformations

More layers can increase representational power, but also make optimization and generalization more challenging.

32. Why Matrix Multiplication Matters So Much

For a layer:

\[ z=Wx+b, \]

matrix multiplication performs many weighted sums at once.

This is the bridge between the single-neuron view and the real neural-network view.

Single neuron

\[ z=w^Tx+b \]

Multiple neurons

\[ z=Wx+b \]

One row of \(W\) can be viewed as the weight vector for one neuron.

Therefore:

A dense layer is essentially many neurons performing their weighted sums in parallel.

33. Numerical Dimension Example

Suppose:

  • 4 input features
  • 3 hidden neurons
  • 2 output values

Then:

\[ x\in\mathbb R^4 \]
\[ W_1\in\mathbb R^{3\times4} \]
\[ b_1\in\mathbb R^3 \]
\[ W_2\in\mathbb R^{2\times3} \]
\[ b_2\in\mathbb R^2. \]

The hidden representation has size 3 and the output has size 2.

Parameter count

Ignoring any special parameter sharing:

First layer:

\[ 3\times4+3=15. \]

Second layer:

\[ 2\times3+2=8. \]

Total:

\[ \boxed{23\text{ trainable parameters}} \]

This kind of counting question is useful in exams and for understanding model capacity.

34. Neural Networks and Model Capacity

Recall the Unit II discussion of hypothesis classes, flexibility and overfitting.

Neural networks expand the range of functions that can be represented.

But:

More expressive does not automatically mean better generalization.

A sufficiently flexible model can fit complex training patterns, including patterns that do not generalize.

This is why training neural networks later requires concepts such as:

  • regularization;
  • validation;
  • early stopping;
  • suitable architecture choices;
  • optimization methods;
  • data quality and scale.

Do not treat these as separate topics with no connection to Unit II. They are the continuation of the same generalization problem.

36. Common Misconceptions

Misconception 1 — “A neural network is just a large collection of if-else rules.”

Not exactly. It is a parameterized numerical function built from transformations and nonlinearities.

Misconception 2 — “More layers always improve accuracy.”

No. More capacity can help represent complex relationships, but architecture, data, optimization and regularization matter.

Misconception 3 — “Weights are manually assigned.”

Normally they are learned from training data through an optimization procedure.

Misconception 4 — “The activation function is optional.”

For a multilayer network intended to obtain nonlinear representational power, nonlinear activations are crucial.

Misconception 5 — “A hidden layer stores the final answer.”

A hidden layer produces an intermediate representation. Its meaning is determined by the complete learned network and may not have a simple human-readable interpretation.

Misconception 6 — “Forward propagation and backpropagation are the same thing.”

No.

Forward pass computes predictions.

Backpropagation computes gradients used for learning.
