1. Why This Chapter Exists

In supervised learning, the usual story is:

data → prediction → loss → parameter update

In reinforcement learning, the story changes:

environment
                    ↑   ↓
                 reward  state
                    ↑   ↓
                  action
                    ↑
                   agent

The agent is not simply given the correct answer for every situation.

Instead, it repeatedly:

  1. observes a situation;
  2. chooses an action;
  3. receives a reward or penalty;
  4. moves to another situation;
  5. uses experience to improve future decisions.

An MDP is the mathematical framework used to describe this kind of sequential decision problem.

The central idea is:

An MDP represents decision making as states, actions, probabilistic transitions, rewards, and a rule for choosing actions.

This chapter is the bridge from the general idea of reinforcement learning to Q-learning in C41.

3. The One-Minute Intuition

Imagine a robot in a small warehouse.

At every moment the robot is in some location.

It can choose actions such as:

UP
DOWN
LEFT
RIGHT

Some moves are safe and useful. Others may take it closer to a wall. Some actions may accidentally slip and produce a different next location. Reaching the charging station gives a positive reward. Hitting a restricted zone gives a negative reward.

The robot therefore needs to answer:

“Given where I am now, what should I do, knowing that my action changes what situation I will face next?”

That is exactly the kind of problem an MDP describes.

4. Real-World Analogy — Choosing a Route During a Trip

Suppose you are travelling through a city.

State

Where you are now.

Metro station A

Action

What you decide to do.

Take metro
Take bus
Walk

Transition

What happens after your choice.

The bus may take you to station B with high probability, but traffic can cause different outcomes.

Reward

A numerical signal for how desirable the result was.

For example:

Arrive quickly          +10
Small delay              +2
Major delay              -5
Missed connection      -20

Policy

Your rule for deciding what action to take from each state.

At A → take metro
At B → walk
At C → take bus

This is not yet “the best policy.” It is simply a policy.

The mathematics of an MDP allows us to define and evaluate such policies.

6. State — “Where Am I?”

A state contains the information needed to describe the agent's current decision situation.

Examples:

  • robot location;
  • board configuration in a game;
  • current inventory level;
  • current traffic condition;
  • current position of a game character.

We write a state as:

\[ s\in\mathcal S. \]

The set of all possible states is:

\[ \mathcal S. \]

Important distinction

A state is not necessarily the entire history of everything that has happened.

An MDP relies on the Markov property so that the relevant future can be conditioned on the current state rather than requiring the entire history.

7. The Markov Property

The word “Markov” is the key word in MDP.

The simplified intuition is:

Given the current state and action, the distribution of the next state does not need the entire past history.

Formally:

\[ P(S_{t+1}=s'\mid S_t=s,A_t=a,S_{t-1},A_{t-1},\ldots) = P(S_{t+1}=s'\mid S_t=s,A_t=a). \]

The past is not necessarily irrelevant in the real world; rather, the state is assumed to summarize all past information needed for the future transition dynamics.

Example

If the state is:

current chess board position

then we do not need the complete move history to define the legal next moves in ordinary chess mechanics.

But if some hidden historical information changes the rules or available actions, then the chosen state representation may be insufficient.

8. Action — “What Can I Do?”

An action is a choice available to the agent.

We write:

\[ a\in\mathcal A(s) \]

when the set of legal actions depends on the current state.

In some simplified treatments we use one global action set \(\mathcal A\).

Examples:

Robot:       {up, down, left, right}
Game agent:  {move 1, move 2, move 3, ...}
Finance:     {buy, hold, sell}

The important point is that the agent chooses actions, unlike ordinary supervised learning where the target label is supplied in advance.

9. Transition Model — “Where Do I Go Next?”

The transition model describes how an action changes the state.

For a stochastic MDP:

\[ \boxed{P(s'\mid s,a)} \]

means:

the probability that the next state is \(s'\) when action \(a\) is taken in state \(s\).

For every fixed \((s,a)\), the transition probabilities over all possible next states should satisfy:

\[ P(s'\mid s,a)\ge 0 \]

and:

\[ \sum_{s'\in\mathcal S}P(s'\mid s,a)=1 \]

for a finite state space.

10. Deterministic vs Stochastic Transitions

Deterministic

The chosen action produces exactly one next state.

s --a--> s'

Probability:

\[ P(s'\mid s,a)=1. \]

Stochastic

The same action can lead to multiple possible next states.

→ s₁  (0.8)
s --a--------→ s₂  (0.15)
             → s₃  (0.05)

The environment contains uncertainty.

This distinction matters because expected future reward depends on the transition distribution.

11. Reward — “How Good Was That Consequence?”

A reward is a numerical feedback signal associated with the agent's interaction.

A simple notation is:

\[ R(s,a,s') \]

meaning the reward associated with taking action \(a\) in state \(s\) and transitioning to \(s'\).

Some simplified formulations write:

\[ R(s,a) \]

instead.

Important idea

Reward is not the same as a label such as “cat” or “class 2.”

It is a signal that tells the agent how desirable the outcome is.

positive reward → encourage behaviour
negative reward → discourage behaviour
zero/small reward → little immediate signal

The meaning of a “good” reward comes entirely from the reward design.

12. Policy — “What Will I Do?”

A policy defines how the agent chooses actions based on states.

A deterministic policy can be written as:

\[ \boxed{\pi(s)=a} \]

A stochastic policy is represented as:

\[ \boxed{\pi(a\mid s)} \]

which means the probability of choosing action \(a\) in state \(s\).

Deterministic policy

state A → action RIGHT
state B → action LEFT

Stochastic policy

state A:
RIGHT = 0.8
UP    = 0.2

Policy gradients in a later Unit IV chapter work directly with parameterized stochastic policies, so understanding this definition now is important.

13. Return — Immediate Reward Is Not the Whole Story

Suppose an agent receives rewards:

rₜ       now
rₜ₊₁     next step
rₜ₊₂     later
...

The cumulative discounted return from time \(t\) is commonly defined as:

\[ \boxed{ G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots } \]

where:

\[ 0\le \gamma\lt 1 \]

is the discount factor in the usual infinite-horizon setting.

The agent therefore does not simply ask:

“Which action gives the biggest immediate reward?”

It asks, conceptually:

“Which action leads to the largest expected long-term return?”

14. Why Do We Discount the Future?

⚠️ Misconception — Common Exam Trap
**Mistake:** Discount factor $\gamma$ ko log sirf ek arbitrary mathematical trick samajhte hain. **Reality:** Discount factor $0 \le \gamma < 1$ ke teen zaroori maksad hain: 1. **Convergence:** Infinite-horizon tasks mein infinite rewards ka sum finite banata hai ($\sum_{t=0}^{\infty} \gamma^t R_{max} = \frac{R_{max}}{1 - \gamma}$). 2. **Uncertainty:** Future inherently uncertain hota hai; kal milne wala 10 rupaye aaj milne wale 10 rupaye se kam valuable hai. 3. **Animal & Human Psychology:** Immediate gratification ko prioritize karne ki natural tendency ko accurately model karta hai.
⚠️ Misconception — Common Exam Trap
**Mistake:** Discount factor $\gamma$ ko log sirf ek arbitrary mathematical trick samajhte hain. **Reality:** Discount factor $0 \le \gamma < 1$ ke teen zaroori maksad hain: 1. **Convergence:** Infinite-horizon tasks mein infinite rewards ka sum finite banata hai ($\sum_{t=0}^{\infty} \gamma^t R_{max} = \frac{R_{max}}{1 - \gamma}$). 2. **Uncertainty:** Future inherently uncertain hota hai; kal milne wala 10 rupaye aaj milne wale 10 rupaye se kam valuable hai. 3. **Animal & Human Psychology:** Immediate gratification ko prioritize karne ki natural tendency ko accurately model karta hai. The discount factor \(\gamma\) controls how strongly future rewards matter relative to immediate rewards.

\(\gamma\approx0\)

The agent behaves almost myopically.

reward now >>> reward later

\(\gamma\approx1\)

Future rewards matter much more.

reward now ≈ reward later

Simple calculation

Suppose:

\[ r_t=5, \qquad r_{t+1}=10, \qquad \gamma=0.5. \]

Then:

\[ G_t=5+0.5(10)=10. \]

Notice that the future reward contributes 5 rather than 10.

15. Value Function — “How Good Is This State?”

A value function estimates expected future return from a state under a policy.

The state-value function is:

\[ \boxed{ V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s] } \]

Read this as:

“Starting in state \(s\), and following policy \(\pi\), what is the expected discounted return?”

This is a central idea because a state can be valuable even when its immediate reward is small.

Example intuition

State A → immediate reward 0, then excellent future
State B → immediate reward +5, then terrible future

A short-sighted agent may prefer B. An agent maximizing long-term return may prefer A.

Value functions let us mathematically express this difference.

16. Action-Value Function — “How Good Is This State-Action Choice?”

The action-value function is:

\[ \boxed{ Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a] } \]

It answers:

“If I am in state \(s\), take action \(a\) now, and then continue according to policy \(\pi\), what return should I expect?”

This distinction is critical for Q-learning.

V(s)
= value of being in state s

Q(s,a)
= value of taking action a in state s

Q-learning learns an approximation of the optimal action-value function.

17. The Relationship Between V and Q

For a deterministic policy:

\[ V^\pi(s)=Q^\pi(s,\pi(s)). \]

For a stochastic policy:

\[ V^\pi(s) = \sum_a\pi(a\mid s)Q^\pi(s,a). \]

So the state value can be understood as an average of action values according to the policy's action probabilities.

18. Bellman Idea — Break a Long Problem Into One Step + The Rest

The Bellman viewpoint is one of the most important mathematical ideas in reinforcement learning.

Instead of evaluating the entire long sequence at once, we write:

value now
   =
immediate reward
   +
 discounted value of what comes next

For a policy \(\pi\), the Bellman expectation equation is:

\[ \boxed{ V^\pi(s)= \sum_a\pi(a\mid s) \sum_{s'}P(s'\mid s,a) \left[R(s,a,s')+\gamma V^\pi(s')\right] } \]

This formula combines all four core quantities:

  • policy;
  • transition probabilities;
  • reward;
  • discount factor.

19. Reading the Bellman Equation Slowly

Look at:

\[ V^\pi(s)= \sum_a\pi(a\mid s) \sum_{s'}P(s'\mid s,a) [R(s,a,s')+\gamma V^\pi(s')]. \]

Read from the inside out.

Step 1

\[ R(s,a,s') \]

Immediate reward.

Step 2

\[ \gamma V^\pi(s') \]

Discounted value after the transition.

Step 3

\[ R+\gamma V \]

Total one-step-plus-future value.

Step 4

Multiply by:

\[ P(s'\mid s,a) \]

because some next states may be more likely than others.

Step 5

Average over actions using:

\[ \pi(a\mid s). \]

That gives the expected value of following policy \(\pi\).

20. Bellman Optimality Idea

PYTHON
import numpy as np

def value_iteration_step(num_states, num_actions, P, R, gamma, V):
    """
    Performs one synchronous Bellman Optimality backup across all states:
    V(s) = max_a sum_{s'} P(s'|s, a) * [R(s, a, s') + gamma * V(s')]
    """
    new_V = np.zeros(num_states)
    for s in range(num_states):
        action_values = []
        for a in range(num_actions):
            # Q(s, a) = sum_{s'} P(s'|s,a) * (R(s,a,s') + gamma * V(s'))
            expected_return = np.sum(P[s, a] * (R[s, a] + gamma * V))
            action_values.append(expected_return)
        new_V[s] = np.max(action_values)
    return new_V

# Toy 3-state chain MDP demonstration
num_states, num_actions, gamma = 3, 2, 0.90
V = np.zeros(num_states)
# Transition and Reward matrices
P = np.zeros((num_states, num_actions, num_states))
R = np.zeros((num_states, num_actions, num_states))
# Define transitions: Action 0 moves left, Action 1 moves right toward goal state 2
P[0, 1, 1] = 1.0; P[1, 1, 2] = 1.0; R[1, 1, 2] = 10.0
P[2, :, 2] = 1.0  # Terminal absorb

for step in range(5):
    V = value_iteration_step(num_states, num_actions, P, R, gamma, V)
    print(f"Iteration {step+1}: V = {np.round(V, 2)}")

Suppose we are not evaluating a fixed policy.

Suppose instead we want the best achievable value.

Then the optimal state-value function is:

\[ \boxed{ V^*(s)= \max_a \sum_{s'}P(s'\mid s,a) \left[R(s,a,s')+\gamma V^*(s')\right] } \]

The optimal action-value function satisfies:

\[ \boxed{ Q^*(s,a)= \sum_{s'}P(s'\mid s,a) \left[R(s,a,s')+\gamma\max_{a'}Q^*(s',a')\right] } \]

This equation is especially important because the Q-learning update later uses the same structure without requiring the transition model to be explicitly known.

21. Worked Example 1 — Simple Deterministic Chain

Consider:

S₀ --RIGHT--> S₁ --RIGHT--> GOAL

Rewards:

S₀ → S₁       reward 0
S₁ → GOAL     reward +10

Let:

\[ \gamma=0.9. \]

Then the return from \(S_1\) for the action leading to the goal is:

\[ G_1=10. \]

From \(S_0\):

\[ G_0=0+0.9(10)=9. \]

So the first state can have value 9 even though its immediate reward is 0.

Memory anchor:

A state can be valuable because of what it makes possible later.

22. Worked Example 2 — Stochastic Transition

Suppose state \(S\) has one action \(a\).

The environment behaves as:

S --a--> S₁ with probability 0.8
S --a--> S₂ with probability 0.2

Rewards:

\[ R(S,a,S_1)=5 \]
\[ R(S,a,S_2)=-2 \]

Suppose:

\[ V(S_1)=10, \qquad V(S_2)=4, \qquad \gamma=0.5. \]

The expected value is:

\[ V(S) = 0.8[5+0.5(10)] + 0.2[-2+0.5(4)]. \]

First branch:

\[ 5+5=10. \]

Second branch:

\[ -2+2=0. \]

Therefore:

\[ V(S)=0.8(10)+0.2(0)=8. \]

The agent evaluates not only the reward of each outcome but also its probability.

23. Worked Example 3 — Why Greedy Immediate Reward Can Fail

Suppose there are two choices from state \(S\):

Action A → immediate reward +5 → terminal

Action B → immediate reward +1 → state T
          state T → reward +20 → terminal

With \(\gamma=0.9\):

Action A return:

\[ G_A=5. \]

Action B return:

\[ G_B=1+0.9(20)=19. \]

Therefore long-term return distinguishes the two choices.

The important reinforcement-learning lesson is not the particular numbers.

It is:

An action should be judged by its consequences over time, not just by the next reward.

24. MDP as a Graph

A useful visual model is a directed state-transition graph.

action a₁
      ┌─────────────────┐
      │                 ▼
   [S₀] ────────────→ [S₁]
     │                  │
     │ action a₂        │ action a₃
     ▼                  ▼
   [S₂] ────────────→ [GOAL]

Each transition can carry:

  • action label;
  • probability;
  • reward.

For example:

S₀ --a / p=0.8 / r=+2--> S₁

This graph representation is especially useful for exam questions where you are given a tiny environment and asked to calculate values.

25. Episodic vs Continuing Tasks

Episodic

The interaction eventually reaches a terminal condition.

Examples:

  • a game round;
  • a maze solved or failed;
  • a robot delivery episode.

Conceptually:

start → states → terminal

Continuing

There may be no natural terminal state.

Examples:

  • continuous traffic control;
  • server resource allocation;
  • long-running industrial control.

The return formulation and convergence considerations can differ depending on the task formulation.

26. Terminal State

A terminal state ends an episode.

It has no ordinary future actions after termination.

A common convention is:

\[ V(terminal)=0 \]

when there is no additional reward beyond termination.

Then the final transition is simply interpreted through its immediate reward.

Exam trap

Do not automatically insert a future value term after a terminal state.

If the next state is terminal and its continuation value is defined as zero:

\[ R+\gamma(0)=R. \]

27. Why an MDP Is More Than a Markov Chain

A Markov chain describes stochastic transitions between states but does not give the agent explicit control through chosen actions in the same way.

An MDP adds decision making:

Markov chain
state → probabilistic next state

MDP
state + chosen action → probabilistic next state + reward

This is a useful conceptual distinction.

28. Why the MDP Model Matters for Reinforcement Learning

The MDP creates a formal language for asking:

What is the environment?
What can the agent do?
What happens after each action?
How desirable is each consequence?
How should immediate and future reward be balanced?

Once those questions are formalized, reinforcement-learning algorithms can be defined.

MDP
 │
 ├── states
 ├── actions
 ├── transitions
 ├── rewards
 └── discounting
       │
       ↓
 value / Q-value concepts
       │
       ↓
 Bellman relationships
       │
       ↓
 Q-learning

29. MDP vs Supervised Learning

Feature Supervised learning MDP / RL setting
Feedback target label/value reward signal
Basic unit independent/structured examples sequential interaction
Correct action explicitly given? Usually yes through target No direct target action
Future consequences matter? Not inherently sequential Yes
State transition Not usually central Central
Policy Not the central object Central
Value function Not normally required Central

This is why reinforcement learning deserves its own mathematical framework.

30. MDP vs Contextual Decision Making

A one-step decision problem asks:

observe situation → choose action → receive reward

An MDP adds repeated consequences:

state₀
  ↓ action
reward + state₁
  ↓ action
reward + state₂
  ↓
...

The action now changes the future state distribution.

That is what makes sequential decision making fundamentally different.

31. Policy Evaluation vs Control

Two broad questions appear repeatedly in reinforcement learning.

Policy evaluation

Given a policy \(\pi\), how good is it?

That means estimating:

\[ V^\pi(s) \]

or:

\[ Q^\pi(s,a). \]

Control

How can we find a policy that is optimal, or approaches optimal behaviour?

That means seeking:

\[ V^*(s),\qquad Q^*(s,a). \]

Q-learning belongs to the control family because it learns action values that support choosing high-value actions.

32. Exploration vs Exploitation — Preview

An RL agent faces a basic conflict.

Exploitation

Choose the action currently believed to be best.

Exploration

Try another action to learn whether its value is actually better.

Exploit
→ use current knowledge

Explore
→ gather new knowledge

This will become explicit in Q-learning through strategies such as epsilon-greedy action selection.

The detailed update rule belongs to C41.

33. Formula Card — Discounted Return

Formula

\[ \boxed{ G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k} } \]

Symbols

Symbol Meaning
\(G_t\) return from time \(t\)
\(r_{t+k}\) reward received \(k\) steps after \(t\)
\(\gamma\) discount factor
\(k\) how far into the future we look

Why it exists

It converts a sequence of rewards into one quantity that can be maximized in expectation.

Common mistake

Forgetting the powers of \(\gamma\).

Correct:

\[ r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots \]

Not:

\[ r_t+\gamma r_{t+1}+\gamma r_{t+2}+\cdots \]

34. Formula Card — State Value

\[ \boxed{ V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s] } \]

Meaning:

expected long-term return from state \(s\) under policy \(\pi\).

Memory anchor:

V → Value of the state

35. Formula Card — Action Value

\[ \boxed{ Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a] } \]

Meaning:

expected long-term return when we take action \(a\) in state \(s\), then continue according to policy \(\pi\).

Memory anchor:

Q → Quality of this state-action choice

36. Formula Card — Bellman Expectation Equation

\[ \boxed{ V^\pi(s)= \sum_a\pi(a\mid s) \sum_{s'}P(s'\mid s,a) [R(s,a,s')+\gamma V^\pi(s')] } \]

Why it exists

It expresses a long-horizon value recursively:

present value
=
expected immediate reward
+
discounted expected future value

Exam trigger

When a question gives:

  • a policy;
  • transition probabilities;
  • rewards;
  • a discount factor;

expect a Bellman-style value calculation.

37. Formula Card — Bellman Optimality for Q

\[ \boxed{ Q^*(s,a)= \sum_{s'}P(s'\mid s,a) [R(s,a,s')+\gamma\max_{a'}Q^*(s',a')] } \]

This is the model-based optimality equation.

Q-learning will use a sample-based version of its target.

That bridge is one of the most important things to understand before C41.

38. How the Mathematics Connects

The dependency chain is:

Probability
   ↓
transition probabilities
   ↓
expected reward / expected return
   ↓
value functions
   ↓
Bellman equations
   ↓
Q-values
   ↓
Q-learning update

So your earlier probability foundations are not separate from RL. They are directly used in the definition of an MDP.

39. Common Mistakes

⚠️ Mistake 1 — State = reward
Wrong. The state describes the decision situation; reward gives feedback about consequences.
⚠️ Mistake 2 — Policy = value function
Wrong. Policy chooses actions. Value evaluates states or state-action choices.
⚠️ Mistake 3 — MDP always means deterministic transitions
Wrong. MDPs may be stochastic.
⚠️ Mistake 4 — Maximizing immediate reward is always optimal
Wrong. The objective is generally long-term expected return.
⚠️ Mistake 5 — \(Q(s)\) and \(Q(s,a)\) mean the same thing
Be precise: the standard action-value notation is:
\[ Q(s,a). \]
⚠️ Mistake 6 — Markov means “future is independent of everything”
Too strong. The Markov property says the current state contains the information needed so that the future transition depends on the current state/action rather than requiring the entire past.
⚠️ Mistake 7 — Every negative reward is bad for the total objective
Not necessarily. A temporary negative reward can be worthwhile if it leads to larger future return.
