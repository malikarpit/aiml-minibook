1. Why This Chapter Exists

C40 gave us the mathematical world of reinforcement learning:

state
  ↓
choose action
  ↓
reward + next state
  ↓
repeat

It also introduced the action-value function:

\[ Q(s,a). \]

Now a much more practical question appears:

How can an agent learn which actions are good from experience, without already knowing the environment's transition probabilities?

One important answer is Q-learning.

Q-learning learns action values by repeatedly observing transitions of the form:

\[ (s,a,r,s'). \]

Its central update is:

\[ \boxed{ Q(s,a)\leftarrow Q(s,a)+\alpha \left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right] } \]

Everything in this chapter is really an explanation of that one equation.

3. The One-Minute Intuition

Imagine a student repeatedly playing a simple game.

At one point the student is in state:

S = standing near a fork in a maze

The student can choose:

LEFT
RIGHT

Initially the student does not know which choice is better.

After trying RIGHT, the student gets:

reward = +5

and reaches another state.

The student should update the belief:

“RIGHT from this situation seems useful.”

But the really important idea is that the value of an action depends not only on the immediate reward, but also on how good the next situation is.

Q-learning formalizes this:

old Q estimate
      ↓
observe reward + next state
      ↓
estimate target using best next action
      ↓
measure the difference
      ↓
move Q estimate toward target

4. What Q-Learning Learns

Q-learning attempts to learn:

\[ \boxed{Q^*(s,a)} \]

the optimal action-value function.

Recall from C40:

\[ Q^*(s,a) \]

means the best expected long-term return available when we:

  1. are in state \(s\);
  2. take action \(a\);
  3. then behave optimally afterward.

Once the agent has useful Q-values, action selection becomes conceptually simple:

\[ \boxed{ a^*=\arg\max_a Q(s,a) } \]

So the core story is:

learn Q-values
      ↓
choose high-Q actions
      ↓
obtain experience
      ↓
update Q-values
      ↓
repeat

5. Why Learn Q Instead of V?

The state value function answers:

\[ V(s)=\text{how valuable is this state?} \]

But an agent must choose an action.

The action-value function answers:

\[ Q(s,a)=\text{how valuable is taking action }a\text{ here?} \]

Therefore Q-values directly support action selection:

State S
│
├── LEFT  → Q(S,LEFT)  = 4
└── RIGHT → Q(S,RIGHT) = 9

The current greedy choice would be:

RIGHT

because:

\[ 9\gt 4. \]

This is why Q-learning is naturally expressed in terms of state-action pairs.

7. The Experience Tuple

Every Q-learning update is based on an observed transition:

\[ \boxed{(s,a,r,s')} \]

Interpretation:

Symbol Meaning
\(s\) current state
\(a\) action taken
\(r\) reward observed
\(s'\) next state

The agent does not need to know the complete transition model before learning.

It can use what actually happened.

8. Model-Based vs Model-Free Intuition

This distinction is essential for understanding why Q-learning is useful.

Model-based approach

You know or estimate:

\[ P(s'\mid s,a) \]

and potentially the reward model too.

Then you can calculate expected consequences explicitly.

Q-learning

The agent can learn from observed experience:

I tried this action.
I saw this reward.
I landed here.

It updates its Q estimate directly.

That is the core model-free intuition.

Q-learning does not require the agent to have an explicit transition model in order to perform its standard Q-value update.

9. The Bellman Optimality Equation — Where Q-Learning Comes From

From C40, the optimal Q-value satisfies the Bellman optimality relation:

\[ Q^*(s,a)= \sum_{s'}P(s'\mid s,a) \left[ R(s,a,s')+ \gamma\max_{a'}Q^*(s',a') \right]. \]

This equation says:

optimal Q now
=
expected immediate reward
+
discounted value of the best future action

But Q-learning typically does not calculate the entire expectation using the full transition model.

Instead, it observes one actual transition:

\[ (s,a,r,s'). \]

It then forms a one-step target from that experience.

10. The Q-Learning Target

For a non-terminal transition, define the target:

\[ \boxed{ T=r+\gamma\max_{a'}Q(s',a') } \]

Read it in two parts:

Part 1 — What I got now

\[ r \]

Part 2 — What I expect is best from the next state

\[ \gamma\max_{a'}Q(s',a') \]

Together:

\[ T=r+\gamma\max_{a'}Q(s',a'). \]

This is the target toward which the old Q-value is moved.

11. The Temporal-Difference Error

The current estimate is:

\[ Q(s,a). \]

The target is:

\[ T=r+\gamma\max_{a'}Q(s',a'). \]

Their difference is the temporal-difference error:

\[ \boxed{ \delta=T-Q(s,a) } \]

or:

\[ \boxed{ \delta=r+\gamma\max_{a'}Q(s',a')-Q(s,a) } \]

Interpretation:

delta > 0
→ current Q estimate is too low relative to target

 delta < 0
→ current Q estimate is too high relative to target

 delta = 0
→ target and current estimate agree

12. The Core Update Equation

⚠️ Misconception — Common Exam Trap
**Mistake:** Q-learning on-policy algorithm hai kyunki agent apne exploration policy se move karta hai. **Reality:** Q-learning strictly **OFF-POLICY** algorithm hai! Kyun? Dekho update rule:
$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$
Target mein $\max_{a'} Q(s', a')$ use hota hai — yaani agent agle step par jo marzi action le (even random action due to $\epsilon$-greedy), update hamesha **greedy best action** ki taraf hota hai. On-policy version ko **SARSA** kehte hain!
⚠️ Misconception — Common Exam Trap
**Mistake:** Q-learning on-policy algorithm hai kyunki agent apne exploration policy se move karta hai. **Reality:** Q-learning strictly **OFF-POLICY** algorithm hai! Kyun? Dekho update rule:
$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$
Target mein $\max_{a'} Q(s', a')$ use hota hai — yaani agent agle step par jo marzi action le (even random action due to $\epsilon$-greedy), update hamesha **greedy best action** ki taraf hota hai. On-policy version ko **SARSA** kehte hain! Now combine the error with the learning rate:
\[ \boxed{ Q(s,a)\leftarrow Q(s,a)+\alpha\delta } \]
Substitute the TD error:
\[ \boxed{ Q(s,a)\leftarrow Q(s,a)+\alpha [r+\gamma\max_{a'}Q(s',a')-Q(s,a)] } \]
Equivalent weighted-average form:
\[ \boxed{ Q_{new}=(1-\alpha)Q_{old}+\alpha T } \]
This second form is extremely useful for intuition. The new estimate is a blend of: 
old estimate
      +
new evidence

13. Formula Card — Every Symbol

PYTHON
import numpy as np

class QLearningAgent:
    def __init__(self, num_states, num_actions, alpha=0.1, gamma=0.95, epsilon=0.1):
        self.q_table = np.zeros((num_states, num_actions))
        self.alpha = alpha      # Learning rate
        self.gamma = gamma      # Discount factor
        self.epsilon = epsilon  # Exploration probability
        self.num_actions = num_actions

    def choose_action(self, state):
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.num_actions)  # Explore
        return int(np.argmax(self.q_table[state]))      # Exploit

    def update(self, s, a, r, s_next, done):
        td_target = r if done else r + self.gamma * np.max(self.q_table[s_next])
        td_error = td_target - self.q_table[s, a]
        self.q_table[s, a] += self.alpha * td_error
        return td_error

# Quick simulation test
agent = QLearningAgent(num_states=5, num_actions=2)
err = agent.update(s=1, a=1, r=10.0, s_next=2, done=False)
print("Updated Q-Table row for State 1:", agent.q_table[1])
print(f"TD Error observed: {err:.4f}")

14. Why the Learning Rate Appears

Suppose your current estimate is:

\[ Q_{old}=2. \]

You observe evidence suggesting:

\[ T=10. \]

Should the Q-value immediately become 10?

Q-learning usually does not have to make the entire jump.

Instead:

\[ Q_{new}=(1-\alpha)Q_{old}+\alpha T. \]

If:

\[ \alpha=0.1, \]

then:

\[ Q_{new}=0.9(2)+0.1(10)=2.8. \]

If:

\[ \alpha=1, \]

then:

\[ Q_{new}=10. \]

So \(\alpha\) controls how strongly new experience changes the estimate.

15. Fully Worked Numerical Example — One Q Update

Suppose:

\[ Q(s,a)=4. \]

The agent takes \(a\), receives:

\[ r=2 \]

and reaches \(s'\).

At \(s'\), the currently largest Q-value is:

\[ \max_{a'}Q(s',a')=6. \]

Let:

\[ \gamma=0.9, \qquad \alpha=0.5. \]

Step 1 — Calculate the target

\[ T=2+0.9(6) \]
\[ T=2+5.4=7.4. \]

Step 2 — Calculate TD error

\[ \delta=7.4-4=3.4. \]

Step 3 — Update

\[ Q_{new}=4+0.5(3.4) \]
\[ Q_{new}=5.7. \]

Therefore:

\[ \boxed{Q(s,a)=5.7} \]

after this update.

What happened intuitively?

old estimate = 4.0
      ↓
experience suggests = 7.4
      ↓
move halfway toward it
      ↓
new estimate = 5.7

16. Worked Example — Negative Reward

Suppose:

\[ Q(s,a)=5 \]

and after taking the action:

\[ r=-3. \]

Suppose:

\[ \max_{a'}Q(s',a')=2, \quad \gamma=0.9, \quad \alpha=0.5. \]

Target:

\[ T=-3+0.9(2)=-1.2. \]

TD error:

\[ \delta=-1.2-5=-6.2. \]

Update:

\[ Q_{new}=5+0.5(-6.2) \]
\[ Q_{new}=1.9. \]

The Q-value falls sharply because the observed experience was much worse than the previous estimate suggested.

17. Worked Example — Terminal State

Suppose taking action \(a\) reaches a terminal goal state and gives:

\[ r=10. \]

There is no future action after termination.

Using the conventional terminal-value treatment:

\[ \max_{a'}Q(s',a')=0. \]

So the target becomes:

\[ T=10+\gamma(0)=10. \]

Therefore:

\[ Q_{new}=Q_{old}+\alpha(10-Q_{old}). \]

Important exam point

Do not invent a future Q-value after an episode has ended.

18. The Q-Learning Algorithm

Conceptually:

Initialize Q(s,a) arbitrarily

Repeat for many episodes:
    reset environment
    observe starting state s

    Repeat until terminal:
        choose action a
        take action
        observe reward r and next state s'

        target = r + γ max_a' Q(s',a')
        error  = target - Q(s,a)
        Q(s,a) ← Q(s,a) + α × error

        s ← s'

Return learned Q-table / policy

This is intentionally written as conceptual pseudocode rather than implementation code.

19. Step-by-Step Dry Run on a Tiny Gridworld

Consider:

┌─────┬─────┬─────┐
│ S   │     │ G   │
├─────┼─────┼─────┤
│     │ X   │     │
└─────┴─────┴─────┘

where:

  • S = start;
  • G = goal;
  • X = blocked cell.

Suppose the agent at the start chooses RIGHT.

It reaches the middle cell and receives:

\[ r=0. \]

Suppose the next state's best estimated Q-value is:

\[ 1.5. \]

Let:

\[ \gamma=0.9, \qquad \alpha=0.5, \qquad Q(S,RIGHT)=0. \]

Target:

\[ T=0+0.9(1.5)=1.35. \]

Update:

\[ Q(S,RIGHT)=0+0.5(1.35)=0.675. \]

The first experience has already moved the estimate above zero.

Later episodes may revise it again and again.

20. Why Repeated Experience Matters

One update is not enough to discover a good policy in a non-trivial environment.

The basic loop is:

try
 ↓
observe
 ↓
update
 ↓
try again
 ↓
observe
 ↓
update
 ↓
...

Through repeated updates, information about later rewards can propagate backward through state-action pairs.

For example:

Goal
 ↑
near-goal state
 ↑
previous state
 ↑
start state

The Q-values near the goal may become useful first. Those estimates can then influence earlier states.

This is one reason temporal-difference learning is powerful.

21. Exploration vs Exploitation

Suppose a state has:

Q(S,LEFT)  = 4
Q(S,RIGHT) = 4.5

A purely greedy agent chooses RIGHT every time.

But what if LEFT is actually much better and the agent has simply not tried it enough?

This creates the classic dilemma.

Exploitation

Use the action currently believed to be best.

Exploration

Try other actions to gather information.

A good Q-learning agent needs a mechanism that balances these two goals.

22. Epsilon-Greedy Action Selection

A common strategy is epsilon-greedy.

With probability:

\[ \epsilon \]

choose an exploratory action.

With probability:

\[ 1-\epsilon \]

choose the currently best action.

Conceptually:

choose action
                  │
          ┌───────┴────────┐
          │                │
       prob ε           prob 1−ε
          │                │
      explore          exploit
          │                │
       random          argmax Q

Example:

\[ \epsilon=0.2. \]

Then, conceptually:

20% of decisions → exploration
80% of decisions → exploitation

The exact random-action distribution can depend on the implementation.

23. Why Epsilon Often Decays

Early in training, the agent knows little.

Exploration can therefore be valuable.

Later, once useful knowledge has accumulated, excessive random actions may interfere with exploiting that knowledge.

A common conceptual schedule is:

epsilon
  ↑
1.0│█
   │██
   │ ██
   │  █
   │   █
0.0└──────────────→ training time
       early  late

So one may begin with more exploration and gradually reduce it.

The exact decay schedule is an algorithm-design choice, not a universal law.

24. Greedy Policy from a Learned Q-Table

After learning, a simple deterministic policy can be extracted:

\[ \boxed{ \pi(s)=\arg\max_a Q(s,a) } \]

Example:

State LEFT RIGHT Best action
S₀ 3.2 5.8 RIGHT
S₁ 7.0 4.2 LEFT
S₂ 1.3 1.1 LEFT

Then:

π(S₀) = RIGHT
π(S₁) = LEFT
π(S₂) = LEFT

This gives a direct bridge:

Q-table → greedy policy

25. Why the \(\max\) Appears in Q-Learning

Look again:

\[ r+\gamma\max_{a'}Q(s',a'). \]

Why not average over the next actions?

Because Q-learning is targeting the optimal action-value function.

It asks:

“After reaching the next state, what is the value of the best action I could take?”

Therefore:

\[ \max_{a'}Q(s',a') \]

appears.

This is the mathematical expression of the idea:

current action
   ↓
next state
   ↓
assume best future action
   ↓
estimate future value

26. Why Q-Learning Is Called Off-Policy

This is a standard reinforcement-learning concept useful for understanding the algorithm's identity.

Q-learning's target uses:

\[ \max_{a'}Q(s',a'). \]

That is the value of the greedy best next action, regardless of whether the behaviour policy actually selected that action during the next interaction.

Therefore the policy generating exploratory behaviour can differ from the greedy policy being learned.

This is the reason Q-learning is called off-policy.

Contrast

Behaviour policy
= how the agent actually gathers experience

Target / learned policy
= behaviour the Q-values are aiming to evaluate

Epsilon-greedy behaviour may explore, while the update still uses the greedy maximum.

27. Q-Learning vs SARSA — Useful Conceptual Comparison

SARSA is another temporal-difference control method.

Its update is commonly written:

\[ Q(s,a)\leftarrow Q(s,a)+\alpha [r+\gamma Q(s',a')-Q(s,a)] \]

where \(a'\) is the action actually selected next.

Q-learning instead uses:

\[ \max_{a'}Q(s',a'). \]
Feature Q-learning SARSA
Target best estimated next action actual next action
Standard policy relation off-policy on-policy
Exploration affects target directly? not through the max action choice yes, through actual \(a'\)
Syllabus status Core Standard context / comparison

This comparison is helpful, but Q-learning remains the Unit IV syllabus focus here.

28. The Most Important Difference: Q-Learning vs Bellman Planning

C40 introduced:

\[ Q^*(s,a)= \sum_{s'}P(s'\mid s,a) [R+\gamma\max_{a'}Q^*(s',a')]. \]

That uses the transition model and takes an expectation over possible next states.

Q-learning observes one actual next state:

\[ (s,a,r,s') \]

and uses:

\[ \boxed{r+\gamma\max_{a'}Q(s',a')} \]

as its one-step target.

So:

Bellman optimality equation
→ expectation over environment dynamics

Q-learning
→ sample one transition and update toward a target

This is one of the most important conceptual bridges in the Unit IV sequence.

29. Parameter Roles — Do Not Mix \(\alpha\) and \(\gamma\)

Students frequently confuse these two.

Learning rate \(\alpha\)

Controls:

How strongly should this new experience change my current estimate?

Discount factor \(\gamma\)

Controls:

How much should future reward count relative to immediate reward?

They operate at different levels.

α → learning/update speed
γ → future-reward weighting

30. Parameter Roles — \(\epsilon\) Is Different Again

There are now three Greek letters to keep separate:

Symbol Role
\(\alpha\) learning rate
\(\gamma\) discount factor
\(\epsilon\) exploration probability in epsilon-greedy behaviour

Memory anchor:

alpha   → update amount
 gamma  → future importance
 epsilon → exploration

31. Numerical Mini-Question — Identify the Error

Given:

\[ Q(s,a)=8, \quad r=3, \quad \gamma=0.5, \quad \max_{a'}Q(s',a')=10. \]

Find the target and TD error.

Target:

\[ T=3+0.5(10)=8. \]

TD error:

\[ \delta=8-8=0. \]

Therefore the Q-value does not change in this update, regardless of the learning rate:

\[ Q_{new}=Q_{old}. \]

This is a useful sanity check: when target equals current estimate, correction is zero.

32. Numerical Mini-Question — One-Step Update

Given:

\[ Q(s,a)=10, \quad r=-2, \quad \gamma=0.8, \quad \max_{a'}Q(s',a')=5, \quad \alpha=0.2. \]

Target:

\[ T=-2+0.8(5)=2. \]

Error:

\[ \delta=2-10=-8. \]

Update:

\[ Q_{new}=10+0.2(-8)=8.4. \]

So:

\[ \boxed{Q_{new}=8.4} \]

33. Q-Learning as “Moving Toward a Target”

A highly useful mental model is to ignore the RL terminology temporarily.

Imagine:

Current prediction = 4
New target          = 7.4

Q-learning does not have to jump directly to the target.

It moves partway:

4 ────────→ 7.4
   ↑
   │ α controls how far

Then another experience may produce a different target.

Therefore learning becomes a sequence of corrections.

This is closely related to the update mentality you already saw in gradient-based learning, although the mathematical objects and update mechanism are different.

34. Q-Learning vs Gradient Descent

These are both learning/update ideas, but do not merge them into one concept.

Neural-network optimization Tabular Q-learning
usually minimizes a loss/objective updates Q estimates toward TD targets
gradient is central TD error is central
parameters may be weights of a network Q-values can be table entries
update uses derivatives tabular update need not use derivatives
often supervised/gradient-based learning reinforcement learning

The common high-level theme is:

use new information to improve an estimate.

The mathematical mechanism is different.

35. Q-Learning with a Small Table — Visual Update

Suppose initially:

State LEFT RIGHT
S₀ 0 0
S₁ 0 0

The agent is at \(S_0\), takes RIGHT, gets reward 1 and reaches \(S_1\).

Suppose:

\[ \gamma=0.9, \qquad \alpha=0.5, \]

and all Q-values are initially zero.

Target:

\[ T=1+0.9(0)=1. \]

Update:

\[ Q(S_0,RIGHT)=0+0.5(1)=0.5. \]

Table becomes:

State LEFT RIGHT
S₀ 0 0.5
S₁ 0 0

The agent has learned from only one experience that RIGHT from \(S_0\) has some positive value.

36. Reward Propagation Through Multiple Updates

Suppose:

S₀ --RIGHT--> S₁ --RIGHT--> GOAL

with final reward +10.

Initially all Q-values are zero.

On an experience:

S₁ → GOAL
reward = +10

the target for \(Q(S_1,RIGHT)\) becomes 10.

That raises:

\[ Q(S_1,RIGHT). \]

Later, when the agent experiences:

S₀ → S₁
reward = 0

the next-state maximum may now be positive:

\[ \max_{a'}Q(S_1,a')\gt 0. \]

Therefore the target for \(Q(S_0,RIGHT)\) becomes positive too.

So useful information can propagate backward:

GOAL reward
   ↑
near-goal Q
   ↑
earlier Q
   ↑
start-state Q

This is a powerful intuition for temporal-difference learning.

37. Convergence Intuition

In a suitable finite MDP, under standard assumptions about sufficient exploration and learning-rate behaviour, tabular Q-learning can converge toward the optimal action-value function.

For exam-level understanding, remember that convergence is not guaranteed merely because the update equation exists.

Learning behaviour depends on factors such as:

  • exploration;
  • learning-rate schedule;
  • finite vs continuous state/action spaces;
  • stochasticity;
  • sufficient experience.

Do not write:

“Q-learning always reaches the exact optimum.”

without qualification.

38. Tabular Q-Learning vs Large Modern Problems

The simple Q-table works naturally when the state-action space is small enough to store explicitly.

But consider an environment with millions or billions of possible states.

A literal table becomes impractical.

This motivates function approximation, where a model approximates:

\[ Q(s,a;\theta). \]

That broader topic leads toward methods such as deep reinforcement learning, but the Unit IV core here is the tabular Q-learning idea.

39. A Compact Algorithm Trace

Suppose:

Q(s,a) = 4
r = 2
best next Q = 6
α = 0.5
γ = 0.9

Trace it:

1. current Q
      ↓
   4.0

2. future best
      ↓
   6.0

3. discounted future
      ↓
   0.9 × 6 = 5.4

4. target
      ↓
   2 + 5.4 = 7.4

5. error
      ↓
   7.4 − 4 = 3.4

6. correction
      ↓
   0.5 × 3.4 = 1.7

7. new Q
      ↓
   4 + 1.7 = 5.7

This seven-step trace is worth mastering.

40. Common Mistakes

⚠️ Mistake 1 — Using \(\alpha\) as the discount factor
Wrong.
\[ \alpha=\text{learning rate} \]
\[ \gamma=\text{discount factor} \]
⚠️ Mistake 2 — Forgetting the old Q-value
Incorrect:
\[ Q_{new}=\alpha T. \]
Correct:
\[ Q_{new}=Q_{old}+\alpha(T-Q_{old}). \]
⚠️ Mistake 3 — Forgetting the maximum over next actions
For standard Q-learning:
\[ \max_{a'}Q(s',a') \]
is part of the target.
⚠️ Mistake 4 — Using the current state's best Q-value
The future term uses the **next state**:
\[ Q(s',a'). \]
not:
\[ Q(s,a'). \]
⚠️ Mistake 5 — Adding future value after a terminal state
For a terminal transition, the continuation value is conventionally treated as zero.
⚠️ Mistake 6 — Saying Q-learning requires transition probabilities
Standard Q-learning learns from observed transitions and does not require the transition model to be explicitly known.
⚠️ Mistake 7 — Equating Q-learning with exploration
Q-learning is the value-learning/update algorithm. Epsilon-greedy is one possible behaviour strategy used to collect experience.

41. Q-Learning Formula Card

\[ \boxed{ Q_{new}(s,a)= Q_{old}(s,a)+ \alpha \left[ r+\gamma\max_{a'}Q(s',a')-Q_{old}(s,a) \right] } \]

Trigger words

When an exam asks:

  • “update the Q-table”;
  • “calculate new Q-value”;
  • “given reward, learning rate and discount factor”;
  • “perform one Q-learning iteration”;

immediately identify:

\[ Q_{old},\;r,\;\gamma,\;\alpha,\;\max Q(s',a'). \]

Then calculate in this order:

next-state maximum
       ↓
discount it
       ↓
add reward
       ↓
subtract old Q
       ↓
× α
       ↓
add to old Q

42. Formula Card — Alternative Weighted-Average Form

\[ \boxed{ Q_{new}=(1-\alpha)Q_{old}+ \alpha[r+\gamma\max_{a'}Q(s',a')] } \]

This form is especially useful for intuition.

It says:

the new estimate is a weighted combination of old knowledge and the new target.

The weights sum to one:

\[ (1-\alpha)+\alpha=1. \]

43. Formula Card — Greedy Policy Extraction

After learning:

\[ \boxed{ \pi(s)=\arg\max_aQ(s,a) } \]

Meaning:

choose the action with the highest learned action value.

This is the connection:

Q-table
  ↓
argmax over actions
  ↓
policy

44. Formula Card — TD Error

\[ \boxed{ \delta= r+\gamma\max_{a'}Q(s',a')-Q(s,a) } \]

Interpretation:

δ = target − estimate

This is often the cleanest way to reason through a numerical problem.

50. Practice Set C — Tricky Questions

Q1

Suppose \(\alpha=0\). What happens to the Q-value?

Answer: No update occurs:

\[ Q_{new}=Q_{old}. \]

Q2

Suppose the TD error is zero. What happens?

Answer: No Q-value change, regardless of the nonzero learning rate.

Q3

Suppose \(\gamma=0\). What does the target become?

Answer:

\[ T=r. \]

Only immediate reward matters.

Q4

Suppose all next-state Q-values are negative but one is less negative than the others. Which one enters the Q-learning target?

Answer: The maximum, i.e. the least negative value.

Q5

Does epsilon-greedy change the Q-learning update equation itself?

Answer: The standard update remains the same; epsilon-greedy is a behaviour/action-selection mechanism used to collect experience.

51. Q-Learning Failure / Limitation Cases

Q-learning is powerful, but the simple tabular version has practical limits.

Huge state spaces

A literal table may become too large.

Continuous states/actions

A table cannot naturally represent infinitely many or continuously varying possibilities.

Sparse rewards

If useful rewards are rare, learning can be slow because the agent receives little informative feedback.

Poor exploration

If important state-action pairs are rarely visited, their values may remain inaccurate.

Reward design

An agent optimizes the reward specification it receives.

A poorly designed reward can encourage unintended behaviour.

These limitations motivate more advanced reinforcement-learning methods, including function approximation and policy-gradient methods.

54. Q-Learning vs Policy Gradients — Preview of C42

Q-learning learns:

\[ Q(s,a). \]

Then actions can be selected using those values.

Policy-gradient methods instead directly parameterize a policy:

Conceptually:

state → Q-values → action choice

Policy gradient
state → parameterized policy → action distribution
