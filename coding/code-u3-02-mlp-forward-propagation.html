CODE-U3-02 — MLP and Forward Propagation From Scratch

Purpose: Extend the single neuron into a multilayer perceptron (MLP), implement dense layers and nonlinear activations from scratch, and make the complete forward pass executable.

The previous chapter built one perceptron.

Now we build:

input vector
    ↓
dense layer
    ↓
activation
    ↓
hidden representation
    ↓
dense layer
    ↓
output

The critical idea is composition:

\[ x \rightarrow z^{(1)} \rightarrow a^{(1)} \rightarrow z^{(2)} \rightarrow a^{(2)} \]

This chapter stops at the forward pass. It does not train the MLP yet.

03

From One Neuron to Many Neurons

A single neuron:

\[ z=w^Tx+b \]
\[ a=\phi(z) \]

A layer with \(h\) neurons computes the same idea many times.

Using row-wise batch notation:

\[ X\in\mathbb{R}^{n\times d} \]

and:

\[ W\in\mathbb{R}^{d\times h} \]

we compute:

\[ \boxed{ Z=XW+b } \]

where the bias vector is broadcast across the \(n\) rows.

Then:

\[ \boxed{ A=\phi(Z) } \]

So:

X: n × d
     ↓
W: d × h
     ↓
Z: n × h
     ↓
activation
     ↓
A: n × h

This is the basic dense-layer pattern.

04

Why Matrix Multiplication Is the Natural Representation

Suppose there are:

  • 4 input features;
  • 3 neurons in the hidden layer.

Then:

\[ X\in\mathbb{R}^{n\times4} \]

and:

\[ W\in\mathbb{R}^{4\times3}. \]

The product:

\[ XW \]

has shape:

\[ (n\times4)(4\times3)=n\times3. \]

Each of those 3 columns corresponds to one neuron.

So:

column 1 → neuron 1 scores
column 2 → neuron 2 scores
column 3 → neuron 3 scores

The important programming habit is:

Do the dimension check before doing the multiplication.

05

Dense Layer From Scratch

Start with the smallest reusable function.

PYTHON
import numpy as np
PYTHON
def dense_forward(
    X: np.ndarray,
    W: np.ndarray,
    b: np.ndarray,
) -> np.ndarray:
    X = np.asarray(X, dtype=float)
    W = np.asarray(W, dtype=float)
    b = np.asarray(b, dtype=float)

    if X.ndim != 2:
        raise ValueError("X must be a 2D matrix.")

    if W.ndim != 2:
        raise ValueError("W must be a 2D matrix.")

    if b.ndim != 1:
        raise ValueError("b must be a 1D vector.")

    if X.shape[1] != W.shape[0]:
        raise ValueError(
            f"Feature mismatch: X has {X.shape[1]} features "
            f"but W expects {W.shape[0]}."
        )

    if W.shape[1] != b.shape[0]:
        raise ValueError(
            f"Bias mismatch: W produces {W.shape[1]} outputs "
            f"but b has length {b.shape[0]}."
        )

    return X @ W + b

This function implements:

\[ Z=XW+b. \]
06

Activation Functions

A neural layer normally does not stop at the affine transformation.

We apply an activation:

\[ A=\phi(Z). \]

Implement several common activations.

ReLU

\[ \boxed{ ReLU(z)=\max(0,z) } \]
PYTHON
def relu(z):
    z = np.asarray(z, dtype=float)
    return np.maximum(0.0, z)

Sigmoid

\[ \boxed{ \sigma(z)=\frac{1}{1+e^{-z}} } \]

A numerically safer implementation handles positive and negative inputs separately.

PYTHON
def sigmoid(z):
    z = np.asarray(z, dtype=float)

    out = np.empty_like(z)

    positive = z >= 0
    negative = ~positive

    out[positive] = 1.0 / (1.0 + np.exp(-z[positive]))

    exp_z = np.exp(z[negative])
    out[negative] = exp_z / (1.0 + exp_z)

    return out

Tanh

\[ \boxed{ \tanh(z) } \]
PYTHON
def tanh(z):
    return np.tanh(np.asarray(z, dtype=float))

For this chapter, ReLU is the main hidden-layer example.

07

Activation Sanity Tests

PYTHON
values = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])

print("ReLU:", relu(values))
print("Sigmoid:", sigmoid(values))

Expected qualitative behaviour:

ReLU
negative → 0
positive → unchanged

Sigmoid
very negative → near 0
zero          → 0.5
very positive → near 1

Tanh
very negative → near -1
zero          → 0
very positive → near 1

The goal is not just to memorize formulas.

You should be able to look at the input and predict the rough output before running the code.

08

One Hidden-Layer MLP

A simple network can be written:

\[ Z^{(1)}=XW^{(1)}+b^{(1)} \]
\[ A^{(1)}=\phi(Z^{(1)}) \]
\[ Z^{(2)}=A^{(1)}W^{(2)}+b^{(2)} \]
\[ \hat{Y}=\psi(Z^{(2)}). \]

Interpretation:

X
 ↓
affine transformation
 ↓
hidden activation
 ↓
new representation
 ↓
affine transformation
 ↓
output activation
 ↓
prediction

The superscript indicates the layer, not an exponent.

09

Choosing Dimensions

Suppose:

input features = 2
hidden neurons = 3
output neurons = 1

Then:

X     → (n, 2)
W1    → (2, 3)
b1    → (3,)

Z1    → (n, 3)
A1    → (n, 3)

W2    → (3, 1)
b2    → (1,)

Z2    → (n, 1)
Y_hat → (n, 1)

The full shape chain is:

(n,2)
  ×
(2,3)
  =
(n,3)

(n,3)
  ×
(3,1)
  =
(n,1)

This shape discipline is one of the most useful habits you can develop before moving to PyTorch.

11

Manual Trace of the First Sample

Take:

\[ x= \begin{bmatrix} 1\\ 2 \end{bmatrix}. \]

For the first hidden neuron:

\[ w_1= \begin{bmatrix} 1\\ 0 \end{bmatrix}, \quad b_1=0. \]

Then:

\[ z_1=1(1)+0(2)+0=1. \]

ReLU:

\[ a_1=\max(0,1)=1. \]

For the second hidden neuron:

\[ w_2= \begin{bmatrix} 2\\ 1 \end{bmatrix}, \quad b_2=1. \]

Then:

\[ z_2=2(1)+1(2)+1=5. \]

So:

\[ a_2=5. \]

The third neuron can be traced in the same way.

This is exactly what the matrix multiplication computes simultaneously.

12

Build a Forward-Pass Function

Now package the entire network.

PYTHON
def mlp_forward(
    X,
    W1,
    b1,
    W2,
    b2,
):
    Z1 = dense_forward(X, W1, b1)
    A1 = relu(Z1)

    Z2 = dense_forward(A1, W2, b2)
    Y_hat = sigmoid(Z2)

    cache = {
        "Z1": Z1,
        "A1": A1,
        "Z2": Z2,
        "Y_hat": Y_hat,
    }

    return Y_hat, cache

Run:

PYTHON
Y_hat, cache = mlp_forward(
    X,
    W1,
    b1,
    W2,
    b2,
)

print(Y_hat)

The cache is intentional.

Later, backpropagation will need intermediate values from the forward pass.

13

Why We Store Intermediate Values

Training a neural network requires derivatives.

Those derivatives depend on intermediate quantities such as:

\[ Z^{(1)}, A^{(1)}, Z^{(2)}. \]

So a useful forward implementation records:

input
↓
Z1
↓
A1
↓
Z2
↓
prediction

This creates a computational graph.

Backpropagation will walk backward through that graph.

Thus:

forward pass
→ produces values

backward pass
→ uses those values to compute gradients
14

Binary Classification Output

For binary classification, one common architecture is:

hidden layer → scalar output
                  ↓
               sigmoid
                  ↓
          probability-like output

Mathematically:

\[ \hat p=\sigma(z^{(2)}). \]

Interpretation:

near 0 → model strongly leans toward class 0
near 1 → model strongly leans toward class 1

The threshold used to convert \(\hat p\) into a class label is a separate decision step.

For example:

PYTHON
pred = (Y_hat >= 0.5).astype(int)

Do not confuse:

probability-like score

with:

hard class decision
15

Regression Output

A regression network often does not require a sigmoid output.

A simple pattern is:

hidden ReLU
   ↓
linear output

So:

\[ \hat y=Z^{(2)}. \]

The output is not restricted to \([0,1]\).

Implementation variation:

PYTHON
def mlp_forward_regression(
    X,
    W1,
    b1,
    W2,
    b2,
):
    Z1 = dense_forward(X, W1, b1)
    A1 = relu(Z1)

    Z2 = dense_forward(A1, W2, b2)

    cache = {
        "Z1": Z1,
        "A1": A1,
        "Z2": Z2,
    }

    return Z2, cache

The network architecture must match the task.

16

Multi-Class Output

For \(K\) mutually exclusive classes, a common output is:

\[ z\in\mathbb{R}^{K} \]

followed by softmax:

\[ \boxed{ softmax(z_i)= \frac{e^{z_i}} {\sum_{j=1}^{K}e^{z_j}} } \]

A numerically stable implementation subtracts the maximum logit:

PYTHON
def softmax(z):
    z = np.asarray(z, dtype=float)

    shifted = z - np.max(z, axis=1, keepdims=True)
    exp_z = np.exp(shifted)

    return exp_z / np.sum(
        exp_z,
        axis=1,
        keepdims=True,
    )

Why subtract the maximum?

Because adding or subtracting the same constant from every logit does not change the softmax probabilities, while subtraction can prevent extremely large exponentials.

18

Parameter Counting

For a dense layer:

inputs = d
outputs = h

weights:

\[ dh \]

biases:

\[ h \]

total:

\[ \boxed{ dh+h=h(d+1) } \]

For a network:

d input features
h hidden neurons
k output neurons

total parameters:

\[ dh+h+hk+k. \]

Example:

d = 3
h = 4
k = 2

Then:

\[ 3(4)+4+4(2)+2 \]
\[ =12+4+8+2 \]
\[ =26. \]

Code:

PYTHON
def dense_parameter_count(
    input_dim: int,
    output_dim: int,
) -> int:
    return input_dim * output_dim + output_dim


def mlp_parameter_count(
    input_dim: int,
    hidden_dim: int,
    output_dim: int,
) -> int:
    return (
        dense_parameter_count(input_dim, hidden_dim)
        + dense_parameter_count(hidden_dim, output_dim)
    )

21

Why Zero Initialization of All Weights Is a Problem for Hidden Neurons

If every hidden neuron starts with exactly identical parameters, they receive the same inputs and compute the same outputs.

They therefore have difficulty breaking symmetry and learning distinct roles.

For educational experiments:

weights → small random values
biases  → often zero initially

This is one reason neural-network initialization is more thoughtful than simply setting every parameter to zero.

22

Learned Feature Representation

A major idea from Lecture10 copy.pdf is that neural networks can be viewed as learning a feature representation.

Think of:

\[ A^{(1)}=\phi(XW^{(1)}+b^{(1)}) \]

as a transformation from the original features into a learned representation.

The original space might be difficult to separate linearly.

A learned hidden representation can make the target relationship easier to express.

Conceptually:

raw features
     ↓
learned transformation
     ↓
new feature representation
     ↓
simple output model

This is one of the deepest reasons neural networks are useful.

23

Nonlinearity Is the Critical Ingredient

Consider:

\[ A^{(1)}=XW^{(1)}+b^{(1)} \]

and:

\[ Z^{(2)}=A^{(1)}W^{(2)}+b^{(2)}. \]

If the hidden activation were removed:

\[ Z^{(2)} = (XW^{(1)}+b^{(1)})W^{(2)}+b^{(2)}. \]

Rearranging gives:

\[ Z^{(2)} = X(W^{(1)}W^{(2)}) + b^{(1)}W^{(2)} + b^{(2)}. \]

That is still affine.

So:

Depth without nonlinearity does not create the usual nonlinear representation power of an MLP.

24

A Tiny ReLU MLP Class

Now package the network in a simple educational class.

PYTHON
class TinyMLP:
    def __init__(
        self,
        input_dim: int,
        hidden_dim: int,
        output_dim: int,
        seed: int = 42,
    ):
        rng = np.random.default_rng(seed)

        self.W1 = rng.normal(
            0.0,
            0.1,
            size=(input_dim, hidden_dim),
        )
        self.b1 = np.zeros(hidden_dim)

        self.W2 = rng.normal(
            0.0,
            0.1,
            size=(hidden_dim, output_dim),
        )
        self.b2 = np.zeros(output_dim)

    def forward(self, X):
        Z1 = X @ self.W1 + self.b1
        A1 = relu(Z1)
        Z2 = A1 @ self.W2 + self.b2

        return Z2, {
            "Z1": Z1,
            "A1": A1,
            "Z2": Z2,
        }

For now this class only performs inference.

Training comes later.

Error 1 — Wrong weight orientation

PYTHON

but use:

PYTHON
X @ W1

with row-wise \(X\).

The dimensions do not match.

Choose one convention and stay consistent.

Error 2 — Wrong bias shape

For:

Z → (n, h)

the bias should represent the \(h\) output units:

b → (h,)

NumPy broadcasts it across rows.

Error 3 — Activating the wrong tensor

The normal order is:

Z → activation → A

not:

X → activation → Z

Error 4 — Forgetting the hidden nonlinearity

Then the network can collapse into an affine mapping.

Error 5 — Confusing logits and probabilities

Before sigmoid/softmax:

logit / pre-activation

After:

probability-like output

They are not the same object.

Framework Comparison Preview

Once the from-scratch logic is understood, a framework can express the same architecture more compactly.

For example, PyTorch-style code:

PYTHON

    nn.Linear(2, 4),
    nn.ReLU(),

Do not let the convenience hide the mathematics.

The framework is implementing the same computational pattern you just built:

\[ Z^{(1)}=XW^{(1)}+b^{(1)} \]
\[ A^{(1)}=ReLU(Z^{(1)}) \]
\[ Z^{(2)}=A^{(1)}W^{(2)}+b^{(2)}. \]

The coding-book rule is:

Understand first, abstract second.

Viva Questions

⚠️ University Lab Viva Trap & Runtime Gotcha
**Dimension Alignment & Missing Activation Trap:** 1. If $W_1$ is $(d, h)$ and $X$ is $(B, d)$, multiplication MUST be `X @ W1`, NOT `W1 @ X`! 2. If you forget non-linear activations (e.g., $A_1 = Z_1$), then two linear layers collapse into one: $W_2(W_1 X) = (W_2 W_1) X = W_{eff} X$, completely losing all deep learning expressive power!

Q1. What is an MLP?

A feedforward neural network containing one or more hidden layers of neurons.

Q2. What is a dense layer?

A layer in which each output unit is connected to all inputs from the preceding representation.

Q3. Why is matrix multiplication used?

It computes the weighted sums for many examples and neurons efficiently and expresses the layer compactly.

Q4. What does a hidden layer produce?

An intermediate learned representation.

Q5. Why is ReLU commonly used in hidden layers?

It introduces nonlinearity while being computationally simple.

Q6. Why can linear layers collapse?

Composition of affine transformations remains affine.

Q7. What is the difference between \(Z\) and \(A\)?

\(Z\) is the pre-activation affine output; \(A\) is the result after applying the activation.

Q8. What are logits?

The output values before a final probability-producing activation such as sigmoid or softmax.

Q9. Why store a cache?

Intermediate values are useful for later gradient computation.

Q10. Does an MLP automatically learn useful parameters when defined?

No. Definition creates an architecture; training adjusts the parameters.
