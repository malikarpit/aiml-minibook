# 3. Ownership Contract

Every layer must answer a different question.

| Layer | Owns | Does not own |
|---|---|---|
| MAIN | Full conceptual teaching | Full exam compression, detailed code |
| LEARN FAST | Selective rapid understanding | Complete derivations, full theory |
| REVISION | Rapid recall | Beginner-first teaching |
| EXAM | Answer construction and exam solving | Full textbook teaching |
| MATH | Mathematical prerequisite and derivation | General AI theory |
| CODE | Implementation and reproducibility | Full conceptual textbook |
| PRACTICE | Problem solving and transfer | Source/provenance catalogue |
| RESOURCE | Sources and further learning | Core curriculum itself |
| MASTERY | Demonstrated competence | Static teaching content |

This prevents content duplication and contradictory versions.

# 12. New Integration Requirements Caused by RAPID

The ten rapid files introduce these requirements:

### Requirement A — Rapid links

Every P1 concept must have:

```text
MAIN ↔ LEARN FAST ↔ REVISION ↔ EXAM
```

### Requirement B — Priority consistency

Priority metadata must agree across:

```text
RAPID
EXAM
MAIN
```

### Requirement C — Formula consistency

The same formula must not appear with different notation or meaning in different views.

### Requirement D — Terminology consistency

The short version may simplify wording but cannot change the concept.

### Requirement E — Revision/exam boundary

Revision must not become a duplicate Exam Book.

### Requirement F — Time-mode consistency

3-day, 2-day, 1-day and final-hours routes must be generated from priority metadata rather than hand-written independent curricula.
