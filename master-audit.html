Newly Identified Practical Gap — Officially Closed

✅ Practical Gap Resolution: CODE-U2-08

The university practical component explicitly requires Decision Trees, k-NN and SVM with controlled model comparison and evaluation metrics. While Decision Trees (`CODE-U2-04`) and Model Evaluation (`CODE-U2-07`) were built, k-NN and SVM were previously missing standalone lab implementations.

Resolution: CODE-U2-08: KNN and SVM Practical Comparison Lab was authored, sanitized, and compiled into production! It provides:

  • From-scratch k-NN with vectorized Euclidean distance calculation in pure NumPy.
  • Feature scaling sensitivity experiments proving how non-scaled features hijack distance metrics.
  • Linear and RBF Support Vector Machines via Scikit-Learn with support vector inspection.
  • Controlled Tri-Model benchmark with Decision Trees on an identical frozen train/test split.
  • Confusion matrix, macro F1, precision, recall, and decision boundary visualizations.
⚠️ Universal 8-Step Practical Explanation Chain

For any university viva or practical exam, students must be able to explain their code through this unbreakable 8-step chain:

Input (raw tabular features) →
Representation (standardized design matrix $X \in \mathbb{R}^{n \times d}$) →
Algorithm (k-NN distance / SVM max-margin / Tree entropy split) →
Parameters ($k$ neighbors / $C, \gamma$ / max depth) →
Loss / Objective (Zero-one error / Hinge loss / Gini impurity) →
Training / Update (Lazy memory / Quadratic programming / Greedy split) →
Output (discrete class $\hat{y}$ or probability $\hat{p}$) →
Evaluation (Confusion matrix, Accuracy, Macro F1, Latency).

Mid-Sem vs End-Sem Pedagogical Gates

🎯 Smart Exam Pacing Strategy

Do not overwhelm yourself trying to master deep sequence models or GANs before your Mid-Semester exams! University exams follow structured semester progression:

Gate 1 · Mid-Sem Priority (Weeks 1–8)
  • Unit I: Classical AI, Agents, Search (BFS, DFS, A*), CSP, Minimax
  • Unit II: ML Foundations, Regression, Trees, Evaluation, Regularization
  • Unit III: Foundations up to Perceptron / MLP (as per faculty cutoff)
  • Coding Focus: BFS/DFS, A*, Linear/Logistic, Decision Trees, KNN/SVM
Gate 2 · End-Sem Mastery (Weeks 9–16)
  • Unit III: Deep Learning, Backpropagation, CNNs, RNNs, LSTMs
  • Unit IV: MDPs, Q-Learning, Policy Gradients, NLP, Autoencoders, GANs, Ethics
  • Comprehensive 100-MCQ Mock Exams & Written Past Papers
  • Coding Focus: Backprop from scratch, PyTorch CNN/LSTM, FrozenLake RL
