M06 — Dot Product, Inner Product, Orthogonality

Dot product

\[ \boxed{ x^Ty= \sum_jx_jy_j } \]

Interpretation

Measures directional alignment.

For Euclidean geometry:

\[ x^Ty=\|x\|_2\|y\|_2\cos\theta. \]

Orthogonality

\[ \boxed{ x^Ty=0 } \]

means \(x\) and \(y\) are orthogonal.

Cosine similarity

\[ \boxed{ \cos\theta = \frac{x^Ty}{\|x\|_2\|y\|_2} } \]

when the vectors are nonzero.

AI/ML trigger

  • linear prediction \(w^Tx\);
  • similarity;
  • geometry;
  • neural-network linear layers;
  • basis representations.

has:

  • \(m\) rows;

Entry notation

Matrix as data

Dimension memory

M09 — Linear Systems, Inverses, and Least Squares

Linear system

\[ Ax=b. \]

Square inverse solution

If \(A^{-1}\) exists:

\[ \boxed{ x=A^{-1}b. } \]

Least squares

When an exact solution is unavailable or inappropriate, solve:

\[ \boxed{ \min_w\|Xw-y\|_2^2 } \]

Normal equations

Under the standard full-rank setting:

\[ X^TXw=X^Ty. \]

Then:

\[ \boxed{ w^*=(X^TX)^{-1}X^Ty. } \]

M10 — Probability Foundations

⚠️ University Exam Trap & Common Misconception
**Universal Dimension & Indexing Sanity Check:** Before submitting ANY derivation in exam papers: 1. Matrix Multiplication: $(A B)$ valid ONLY if columns of $A$ equal rows of $B$. Result is $(m \times k) \times (k \times n) = (m \times n)$. 2. Loss vs Gradient: $J(w)$ is a SCALAR ($1 \times 1$). Therefore $\nabla J(w)$ MUST match parameter dimension ($d \times 1$)! 3. Vector transpose: In $w^T x$, $w$ is ($d \times 1$), $w^T$ is ($1 \times d$), $x$ is ($d \times 1$), product is ($1 \times 1$) scalar. If you write $w x^T$, you get a rank-1 ($d \times d$) matrix! Always check dimensions on both sides of every equation!

Sample space

\[ \Omega \]

is the set of possible outcomes.

Event

\[ A\subseteq\Omega. \]

Probability axioms

\[ P(A)\ge0 \]
\[ P(\Omega)=1 \]

and for disjoint events:

\[ P\left(\bigcup_iA_i\right) = \sum_iP(A_i). \]

Complement

\[ \boxed{ P(A^c)=1-P(A) } \]

Union

\[ \boxed{ P(A\cup B) = P(A)+P(B)-P(A\cap B) } \]

M11 — Conditional Probability, Bayes, Total Probability

Result is $(m \times k) \times (k \times n) = (m \times n)$. 2. Loss vs Gradient: $J(w)$ is a SCALAR ($1 \times 1$). Therefore $\nabla J(w)$ MUST match parameter dimension ($d \times 1$)! 3. Conditional probability

\[ \boxed{ P(A\mid B) = \frac{P(A\cap B)}{P(B)} } \]

for \(P(B)\gt 0\).

Product rule

\[ \boxed{ P(A\cap B) = P(A\mid B)P(B) } \]

Bayes theorem

\[ \boxed{ P(A\mid B) = \frac{P(B\mid A)P(A)} {P(B)} } \]

Total probability

For a partition \(A_1,\ldots,A_k\):

\[ \boxed{ P(B)= \sum_{i=1}^{k} P(B\mid A_i)P(A_i). } \]

M12 — Independence and Conditional Independence

Independence

\[ \boxed{ P(A\cap B)=P(A)P(B) } \]

Equivalent form:

\[ P(A\mid B)=P(A) \]

when defined.

Conditional independence

Informally:

\[ \boxed{ X\perp Y\mid Z } \]

means that once \(Z\) is known, \(X\) gives no additional probabilistic information about \(Y\), under the formal definition used.

A distributional expression is:

\[ P(X,Y\mid Z) = P(X\mid Z)P(Y\mid Z). \]

Important trap

Ordinary independence does not imply conditional independence in every context, and conditional independence does not mean unconditional independence.

AI/ML trigger

  • probabilistic models;
  • graphical-model reasoning;
  • factorization.

M13 — Random Variables, PMF, PDF, CDF

Random variable

A random variable maps outcomes to numerical values.

Discrete case — PMF

\[ \boxed{ p_X(x)=P(X=x) } \]

with

\[ p_X(x)\ge0, \qquad \sum_xp_X(x)=1. \]

Continuous case — PDF

\[ \boxed{ f_X(x)\ge0 } \]

with

\[ \boxed{ \int_{-\infty}^{\infty}f_X(x)\,dx=1. } \]

For interval probability:

\[ P(a\le X\le b) = \int_a^bf_X(x)\,dx. \]

CDF

\[ \boxed{ F_X(x)=P(X\le x) } \]

and for a continuous differentiable distribution:

\[ f_X(x)=\frac{d}{dx}F_X(x). \]

Trap

A PDF value is not itself the probability of an interval of zero width.

M14 — Joint, Marginal, and Conditional Distributions

Joint distribution

\[ P(X=x,Y=y) \]

for the discrete case.

Marginalization

Discrete:

\[ \boxed{ P(X=x) = \sum_yP(X=x,Y=y) } \]

Continuous:

\[ \boxed{ f_X(x) = \int f_{X,Y}(x,y)\,dy. } \]

Conditional distribution

\[ \boxed{ P(X=x\mid Y=y) = \frac{P(X=x,Y=y)}{P(Y=y)} } \]

when defined.

M15 — Expectation

Discrete

\[ \boxed{ E[X] = \sum_xxp_X(x) } \]

Continuous

\[ \boxed{ E[X] = \int xf_X(x)\,dx. } \]

Function of a random variable

\[ \boxed{ E[g(X)] = \sum_xg(x)p_X(x) } \]

or

\[ E[g(X)] = \int g(x)f_X(x)\,dx. \]

Linearity

\[ \boxed{ E[aX+b] = aE[X]+b } \]

and more generally:

\[ \boxed{ E[X+Y]=E[X]+E[Y] } \]

even when \(X,Y\) are not independent, as long as expectations exist.

AI/ML trigger

  • expected loss;
  • expected reward;
  • risk;
  • probabilistic algorithms.
17

M16 — Variance and Standard Deviation

Variance

\[ \boxed{ \operatorname{Var}(X) = E[(X-E[X])^2] } \]

Equivalent identity:

\[ \boxed{ \operatorname{Var}(X) = E[X^2]-(E[X])^2 } \]

Standard deviation

\[ \boxed{ \sigma_X=\sqrt{\operatorname{Var}(X)}. } \]

Scaling

For scalar \(a\):

\[ \boxed{ \operatorname{Var}(aX+b) = a^2\operatorname{Var}(X) } \]

AI/ML trigger

  • uncertainty;
  • bias-variance reasoning;
  • normalization;
  • stochastic gradients.
18

M17 — Covariance and Correlation

Covariance

\[ \boxed{ \operatorname{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])] } \]

Equivalent form:

\[ \boxed{ \operatorname{Cov}(X,Y) = E[XY]-E[X]E[Y]. } \]

Correlation

\[ \boxed{ \rho_{XY} = \frac{\operatorname{Cov}(X,Y)} {\sigma_X\sigma_Y} } \]

when both standard deviations are nonzero.

Interpretation

  • positive covariance → variables tend to move together;
  • negative covariance → variables tend to move oppositely;
  • near-zero covariance → no linear association under the chosen distributional setting.

Trap

Zero correlation does not universally mean independence.

AI/ML trigger

  • multicollinearity;
  • correlated predictors;
  • covariance matrices;
  • feature relationships.

M18 — Derivatives and Rates of Change

Derivative

\[ \boxed{ f'(x)= \lim_{h\to0} \frac{f(x+h)-f(x)}{h} } \]

when the limit exists.

Power rule

\[ \boxed{ \frac{d}{dx}x^n = nx^{n-1} } \]

Constant

\[ \frac{d}{dx}c=0. \]

Sum

\[ \frac{d}{dx}[f(x)+g(x)] = f'(x)+g'(x). \]

Product

\[ \boxed{ (fg)'=f'g+fg' } \]

Quotient

\[ \boxed{ \left(\frac fg\right)' = \frac{f'g-fg'}{g^2}. } \]

AI/ML trigger

Whenever parameters need to be updated by optimization, derivatives are likely involved.

M19 — Partial Derivatives

For a multivariable function

\[ f(x_1,\ldots,x_d), \]

the partial derivative with respect to \(x_j\) changes \(x_j\) while treating the other variables as fixed.

\[ \boxed{ \frac{\partial f}{\partial x_j} } \]

Example

\[ f(x,y)=x^2+3xy+y^2. \]

Then:

\[ \frac{\partial f}{\partial x} = 2x+3y \]

and:

\[ \frac{\partial f}{\partial y} = 3x+2y. \]

AI/ML trigger

Model parameters are usually vectors, so multi-parameter optimization needs partial derivatives.

M20 — Chain Rule and Computational Graphs

Scalar chain rule

If

\[ y=f(u),\qquad u=g(x), \]

then

\[ \boxed{ \frac{dy}{dx} = \frac{dy}{du} \frac{du}{dx}. } \]

Example

\[ z=w x+b \]

and

\[ L=(z-y)^2. \]

Then:

\[ \frac{dL}{dz}=2(z-y) \]

and

\[ \frac{dz}{dw}=x. \]

Therefore:

\[ \boxed{ \frac{dL}{dw} = 2(z-y)x. } \]

This is the conceptual seed of backpropagation.

Computational graph

w ──┐
    × → z → loss
x ──┘

Backward:
loss → z → w

AI/ML trigger

  • neural networks;
  • backpropagation;
  • deep learning.

M21 — Gradients, Jacobians, Direction of Change

Gradient

For

\[ f(w_1,\ldots,w_d), \]

the gradient is

\[ \boxed{ \nabla f= \begin{bmatrix} \frac{\partial f}{\partial w_1}\\ \frac{\partial f}{\partial w_2}\\ \vdots\\ \frac{\partial f}{\partial w_d} \end{bmatrix}. } \]

Key interpretation

The gradient points in the direction of greatest local increase.

Therefore:

\[ \boxed{ -\nabla f } \]

points toward steepest local decrease.

Directional derivative

For unit direction \(u\):

\[ \boxed{ D_uf= \nabla f^Tu } \]

Jacobian

For vector-valued functions:

\[ F:\mathbb R^n\to\mathbb R^m, \]

the Jacobian is the matrix of first partial derivatives.

AI/ML trigger

  • gradient descent;
  • backpropagation;
  • parameter updates;
  • multivariable optimization.

M22 — Optimization, Loss, and Gradient Descent

Objective

\[ \boxed{ w^*\in\arg\min_wJ(w) } \]

First-order idea

Near \(w\):

\[ J(w+\Delta w) \approx J(w)+\nabla J(w)^T\Delta w. \]

To decrease \(J\), choose:

\[ \boxed{ \Delta w=-\eta\nabla J(w) } \]

with \(\eta\gt 0\).

Therefore:

\[ \boxed{ w_{t+1} = w_t-\eta\nabla J(w_t). } \]

Learning rate

\[ \eta \]

controls the step size.

Too small

  • slow progress.

Too large

  • overshooting;
  • instability;
  • possible divergence.

Convexity

For convex \(J\), every local minimum is global.

AI/ML trigger

Almost every modern differentiable ML model has an optimization story built on some variation of this idea.

M23 — SGD and Mini-Batches

Full-batch gradient

\[ \boxed{ g= \frac1n \sum_{i=1}^{n} \nabla\ell_i(w) } \]

SGD update

Choose one example \(i_t\):

\[ \boxed{ w_{t+1} = w_t - \eta\nabla\ell_{i_t}(w_t). } \]

Mini-batch gradient

For batch \(B\):

\[ \boxed{ g_B = \frac1{|B|} \sum_{i\in B} \nabla\ell_i(w) } \]

and

\[ \boxed{ w_{t+1}=w_t-\eta g_B. } \]

Regimes

Full batch
→ exact dataset gradient
→ expensive per update

SGD
→ noisy single-example estimate
→ cheap frequent updates

Mini-batch
→ compromise
→ standard deep-learning regime

Idealized variance scaling

Under simplifying assumptions:

\[ \boxed{ \operatorname{Var}(g_B)\approx\frac{\sigma^2}{b} } \]

and therefore:

\[ \boxed{ \operatorname{SD}(g_B)\approx\frac{\sigma}{\sqrt b}. } \]

The independence/common-variance assumptions matter.

M24 — L1/L2 Regularization

\[ \boxed{ J(w)=L(w)+\lambda\Omega(w) } \]

Ridge

\[ \boxed{ J_R(w) = L(w)+\lambda\|w\|_2^2 } \]

Lasso

\[ \boxed{ J_L(w) = L(w)+\lambda\|w\|_1 } \]

L1

\[ \boxed{ \|w\|_1=\sum_j|w_j| } \]

L2

\[ \boxed{ \|w\|_2 = \sqrt{\sum_jw_j^2} } \]

Squared L2

\[ \boxed{ \|w\|_2^2=\sum_jw_j^2 } \]

Geometry

L1 → diamond → corners → exact zeros possible

L2 → circle/sphere → smooth boundary → continuous shrinkage

Ridge gradient

\[ \boxed{ \nabla\|w\|_2^2=2w } \]

and therefore:

\[ \boxed{ \nabla J_R=\nabla L+2\lambda w. } \]

Soft thresholding

For

\[ J(w)=\frac12(z-w)^2+\lambda|w|, \]
\[ \boxed{ \hat w = \operatorname{sign}(z) \max(|z|-\lambda,0) } \]

AI/ML trigger

  • Ridge → L2 → shrinkage;
  • Lasso → L1 → sparsity;

The Core Chain for Ridge

Start from:

\[ \|Xw-y\|_2^2. \]

Add a penalty:

\[ +\lambda\|w\|_2^2. \]

Then:

\[ \boxed{ J_R(w) = \|Xw-y\|_2^2 + \lambda\|w\|_2^2 } \]

\[ 2X^T(Xw-y)+2\lambda w. \]

Set to zero:

\[ (X^TX+\lambda I)w=X^Ty. \]

\[ \boxed{ w^*=(X^TX+\lambda I)^{-1}X^Ty. } \]

\[ \|Xw-y\|_2^2. \]

Add:

\[ \lambda\|w\|_1. \]

\[ \boxed{ J_L(w) = \|Xw-y\|_2^2 + \lambda\sum_j|w_j|. } \]

At zero:

\[ |w_j| \]

is not differentiable.

This leads to subgradient/nonsmooth optimization methods and allows exact zeros.

Dimension-Checking Protocol

When a matrix formula looks confusing, check dimensions before algebra.

Suppose:

\[ X\in\mathbb R^{n\times d} \]

and

\[ w\in\mathbb R^d. \]

Then:

\[ Xw \in\mathbb R^n. \]

If

\[ y\in\mathbb R^n, \]

then:

\[ Xw-y \in\mathbb R^n. \]

Therefore:

\[ \|Xw-y\|_2^2 \]

is a scalar.

Now:

\[ X^T X \]

has shape:

\[ d\times d. \]

Thus:

\[ X^TX+\lambda I \]

must also be:

\[ d\times d. \]

And:

\[ (X^TX+\lambda I)^{-1}X^Ty \]

has shape:

\[ d\times1. \]

This is \(w\)'s required shape.

Rule

\[ \boxed{ \text{Check dimensions before trying to simplify the formula.} } \]

Optimization-Checking Protocol

Trap 3 — Ridge vs Lasso

Ridge:

\[ L2. \]

Lasso:

\[ L1. \]

Trap 4 — Exact sparsity

Lasso can produce exact zeros.

Ridge is not defined by exact-zero selection.

Trap 5 — Bigger lambda

Larger \(\lambda\) means stronger regularization, not automatically better accuracy.

Trap 6 — Scaling

Do not ignore feature units before coefficient regularization.

Trap 7 — Bayes denominator

The denominator is the evidence/probability of the observed event.

Trap 8 — Variance

Variance is not the standard deviation.

\[ \sigma=\sqrt{\operatorname{Var}(X)}. \]

Trap 9 — Gradient direction

\[ +\nabla J \]

usually increases locally.

For descent use:

\[ -\nabla J. \]

Trap 10 — Matrix dimensions

Never multiply matrices by visually “matching” symbols. Check dimensions.

10-Second Oral Revision

Try saying this aloud:

A vector is a point/direction in \(d\)-dimensional space. A norm measures its size. L1 adds absolute values; L2 uses Euclidean length. A learning objective minimizes data loss. Regularization adds a penalty controlled by \(\lambda\). Ridge uses squared L2 and smoothly shrinks weights. Lasso uses L1, whose cornered geometry and nonsmoothness at zero make exact zero coefficients possible. Gradients tell us the local direction of increase, so gradient descent moves opposite the gradient. SGD estimates the full gradient using sampled data. Probability and expectation quantify uncertainty and average outcomes. These ideas together provide much of the mathematical language of ML.

Master “Why” Questions

You have mastered the math more deeply when you can answer these without formulas first.

Why use norms?

To quantify size/magnitude.

Why use regularization?

To control model complexity.

Why does \(\lambda\) matter?

It determines how strongly complexity is penalized.

Why does L1 create sparsity?

Its absolute-value penalty is nonsmooth at zero and has cornered constraint geometry, allowing exact zero solutions.

Why does L2 shrink smoothly?

Its squared penalty is smooth and differentiable everywhere.

Why use gradients?

To know the local direction of fastest increase.

Why descend?

Because we want to minimize the objective.

Why use SGD?

To obtain inexpensive noisy gradient estimates from subsets of data.
