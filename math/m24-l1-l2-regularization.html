02

The Big Picture

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Regularization ko samajhne ke liye ek simple visual imagination rakho: Unconstrained least-squares solution ($w_{\text{OLS}}$) ek bada weight vector chahta hai jo training data ko overfit kar sake. Regularization ek rassi (constraint) baandh deta hai: 1. **L2 Ridge ($w_1^2 + w_2^2 \le t$):** Ye ek gol (circle/sphere) boundary banata hai. Smooth boundary par ellipse kisi bhi angle par touch kar sakti hai. Isiliye Ridge weights ko shrink zaroor karta hai, par kabhi exact zero nahi banata. 2. **L1 Lasso ($|w_1| + |w_2| \le t$):** Ye ek diamond (polytope) boundary banata hai jiske corners coordinate axes ($w_1=0$ ya $w_2=0$) par nikalte hain. Expanding ellipse sabse pehle in teekhe corners se takrati hai! Jab solution corner par touch karta hai, toh ek variable ka weight **exactly zero** ban jata hai—automatic feature selection!

Regularization is easiest to understand when it is placed inside the larger learning problem.

A supervised learning objective is commonly written as

\[ \boxed{ \hat f\in \arg\min_{f\in\mathcal H} \frac1n\sum_{i=1}^{n} \ell(f(x_i),y_i) } \]

where the model is selected by minimizing training loss over a hypothesis class.

The central problem is:

Very flexible model
       ↓
can fit training data extremely well
       ↓
may also fit noise / accidental patterns
       ↓
poor generalization

Regularization changes the optimization problem.

Instead of asking only:

“Which parameters fit the training data best?”

we ask:

“Which parameters fit the data well while also remaining controlled according to a chosen mathematical notion of size?”

The generic form is

\[ \boxed{ J(w) = L_{\text{data}}(w) + \lambda\,\Omega(w) } \]

where:

  • \(w\) = parameter vector;
  • \(L_{\text{data}}\) = data-fitting loss;
  • \(\Omega(w)\) = penalty / complexity measure;
  • \(\lambda\ge 0\) = regularization strength.

Two important choices are:

\[ \boxed{\Omega(w)=\|w\|_2^2} \qquad\text{(Ridge)} \]

and

\[ \boxed{\Omega(w)=\|w\|_1} \qquad\text{(Lasso)}. \]
03

One-Minute Intuition

English

Imagine two models that predict almost equally well.

Model A uses:

\[ w=(8,7,0.2) \]

Model B uses:

\[ w=(2.5,2.3,0.8). \]

A regularizer can express a preference for the second parameterization because its coefficients are collectively smaller.

The exact definition of “small” is determined by the norm.

  • L2 says: square the coordinates, add them, and measure the resulting magnitude.
  • L1 says: take absolute values and add them.

So the same vector can have different measured sizes under different norms.

Hinglish Teacher Explanation

Regularization ka simple idea:

“Data ko fit karna zaroori hai, lekin weights ko uncontrolled bada nahi hone dena.”

Ab question hai:

“Bada weight kaise measure karenge?”

Yahin norms enter karte hain.

L2:
weight ko square karke add karo.

L1:
weight ka absolute value lekar add karo.

Toh L1 aur L2 sirf formulas nahi hain. Yeh different mathematical ideas of parameter size hain.

04

What Is a Norm?

A norm is a mathematical function that measures the size or magnitude of a vector.

For a vector \(w\), we can write

\[ \|w\|. \]

A standard norm satisfies four important properties.

4.1 Non-negativity

\[ \boxed{\|w\|\ge 0} \]

A size cannot be negative.

4.2 Definiteness

\[ \boxed{\|w\|=0 \iff w=0} \]

Only the zero vector has zero norm.

4.3 Absolute homogeneity

For scalar \(c\),

\[ \boxed{\|cw\|=|c|\,\|w\|} \]

Scaling the vector by \(c\) scales its size by \(|c|\).

4.4 Triangle inequality

\[ \boxed{\|u+v\|\le \|u\|+\|v\|} \]

The direct route is never “larger” than going through an intermediate displacement.

Geometric meaning

In ordinary 2D geometry, the familiar Euclidean distance from the origin is the L2 norm.

But mathematics allows other legitimate ways of measuring size.

That is exactly why L1 and L2 can produce different optimization behaviour.

For

\[ w=(w_1,w_2,\ldots,w_d), \]

the L1 norm is

\[ \boxed{ \|w\|_1 = \sum_{j=1}^{d}|w_j| } \]

Plain meaning

Add the absolute magnitude of every coordinate.

👨‍🏫 Hinglish
Har coordinate ka sign hatao, magnitude lo, phir sabko add karo.

5.1 Example

Let

\[ w=(2,-3,4,-1). \]

Then

\[ \|w\|_1 = |2|+|-3|+|4|+|-1| \]
\[ =2+3+4+1 \]
\[ \boxed{\|w\|_1=10} \]
06

L2 Norm

The L2 norm is

\[ \boxed{ \|w\|_2 = \sqrt{\sum_{j=1}^{d}w_j^2} } \]

This is the ordinary Euclidean length.

For two dimensions,

\[ \|w\|_2 = \sqrt{w_1^2+w_2^2}. \]
👨‍🏫 Hinglish
Coordinates ko square karo, add karo, aur final result ka square root lo.

6.1 Example

For

\[ w=(3,-4), \]
\[ \|w\|_2 = \sqrt{3^2+(-4)^2} \]
\[ = \sqrt{9+16} \]
\[ = \sqrt{25} = \boxed{5}. \]

This is the familiar \(3\text{-}4\text{-}5\) triangle.

07

Squared L2 Norm

A very important distinction:

\[ \boxed{ \|w\|_2 = \sqrt{\sum_jw_j^2} } \]

but

\[ \boxed{ \|w\|_2^2 = \sum_jw_j^2 } \]

The squared L2 norm removes the square root.

Example

For

\[ w=(3,-4), \]
\[ \|w\|_2^2 = 3^2+(-4)^2 = 25. \]

So:

\[ \boxed{\|w\|_2=5} \]

and

\[ \boxed{\|w\|_2^2=25}. \]

Exam trap

Do not write

\[ \|w\|_2^2=\sqrt{\sum_jw_j^2}. \]

That is incorrect.

08

L1 vs L2: A Numerical Comparison

Take

\[ w=(3,-4). \]

Then:

L1

\[ \|w\|_1=|3|+|-4|=7. \]

L2

\[ \|w\|_2=\sqrt{25}=5. \]

Squared L2

\[ \|w\|_2^2=25. \]

So the same vector has:

\[ \boxed{ \|w\|_1=7,\quad \|w\|_2=5,\quad \|w\|_2^2=25 } \]

There is no contradiction.

These are different mathematical quantities.

09

Why Absolute Values Appear in L1

Suppose we used

\[ w_1+w_2+w_3 \]

as a measure of magnitude.

Then positive and negative coefficients could cancel:

\[ 5+(-5)=0. \]

That would incorrectly suggest that the vector has no magnitude.

L1 avoids this by using absolute values:

\[ |5|+|-5|=10. \]

Thus:

\[ \boxed{ \|w\|_1 = \sum_j |w_j| } \]

measures total absolute coordinate magnitude.

Consider a two-dimensional vector

\[ w=(w_1,w_2). \]

Suppose we restrict the L1 norm:

\[ \|w\|_1\le c. \]

Then

\[ |w_1|+|w_2|\le c. \]

The boundary

\[ |w_1|+|w_2|=c \]

forms a diamond.

For example, with \(c=1\):

w₂
                  ↑
                  |
                  ● (0,1)
                 / \
                /   \
               /     \
              /       \
             ●----0----●  → w₁
          (-1,0)     (1,0)
              \       /
               \     /
                \   /
                 \ /
                  ●
                 (0,-1)

The critical feature is not simply “diamond.”

It is:

\[ \boxed{\text{sharp corners on the coordinate axes}} \]

Those corners matter enormously in regularized optimization.

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

# 1. Soft-thresholding operator for Lasso coordinate descent
def soft_threshold(z, gamma):
    return np.sign(z) * np.maximum(np.abs(z) - gamma, 0.0)

# Demonstrate sparsity induction:
z_values = np.array([-3.0, -1.2, -0.4, 0.2, 1.5, 4.0])
gamma = 1.0
lasso_weights = soft_threshold(z_values, gamma)

# 2. Ridge analytical shrinkage vs Lasso
lambd = 1.0
ridge_weights = z_values / (1.0 + lambd)

print("Original unregularized values z:", z_values)
print("Ridge shrinkage (proportional): ", np.round(ridge_weights, 3))
print("Lasso soft-thresholded (sparse):", np.round(lasso_weights, 3))
print(f"Number of exact zeros in Lasso: {np.sum(lasso_weights == 0)} of {len(z_values)}")

L2 Geometry

⚠️ University Exam Trap & Common Misconception
**Analytical Solution Trap (Ridge vs Lasso):** - **Ridge ($L_2$):** Always has an analytical closed-form formula because $\|w\|_2^2$ is smooth and strictly convex everywhere:
$$w^* = (X^T X + \lambda I)^{-1} X^T y$$
Even if $X^T X$ is singular (collinear features), $(X^T X + \lambda I)$ is ALWAYS strictly positive definite and invertible! - **Lasso ($L_1$):** Does **NOT** have a closed-form formula in matrix form because $|w|$ is non-differentiable at $w=0$. It requires iterative optimization like **Coordinate Descent** with the soft-thresholding operator:
$$S(z, \gamma) = \text{sign}(z) \max(|z| - \gamma, 0)$$
In theory questions, never write an inverse formula for Lasso!

Now impose

\[ \|w\|_2\le c. \]

In two dimensions,

\[ \sqrt{w_1^2+w_2^2}\le c \]

is equivalent to

\[ w_1^2+w_2^2\le c^2. \]

That is a circle centered at the origin.

w₂
                  ↑
             .-----------.
          .-'             '-.
        .'                   '.
       /          ●            \
      |         origin          |
       \                       /
        '.                   .'
          '-.             .-'
             '-----------'
                  |
                  +----------------→ w₁

The boundary is smooth.

Memory hook

L1 → diamond → corners
L2 → circle  → smooth

Why Geometry Appears in Optimization

⚠️ University Exam Trap & Common Misconception
**Analytical Solution Trap (Ridge vs Lasso):** - **Ridge ($L_2$):** Always has an analytical closed-form formula because $\|w\|_2^2$ is smooth and strictly convex everywhere:
$$w^* = (X^T X + \lambda I)^{-1} X^T y$$
Even if $X^T X$ is singular (collinear features), $(X^T X + \lambda I)$ is ALWAYS strictly positive definite and invertible! - **Lasso ($L_1$):** Does **NOT** have a closed-form formula in matrix form because $|w|$ is non-differentiable at $w=0$. It requires iterative optimization like **Coordinate Descent** with the soft-thresholding operator:
$$S(z, \gamma) = \text{sign}(z) \max(|z| - \gamma, 0)$$
In theory questions, never write an inverse formula for Lasso!

Regularized regression can be represented in two mathematically related ways.

Penalized form

\[ \boxed{ \min_w \left[ L(w)+\lambda\Omega(w) \right] } \]

Constrained form

\[ \boxed{ \min_w L(w) \quad \text{subject to} \quad \Omega(w)\le c } \]

Informally:

Penalty form:
"Pay a cost for large parameters."

Constraint form:
"Do not leave the allowed region."

For L2:

\[ \Omega(w)=\|w\|_2^2 \]

or, depending on the convention,

\[ \Omega(w)=\|w\|_2. \]

For L1:

\[ \Omega(w)=\|w\|_1. \]

The exact numerical relationship between \(\lambda\) and \(c\) depends on the objective convention, but the conceptual equivalence is that both express a preference for simpler/smaller parameter vectors.

13

Ridge Objective

For least-squares regression, a common Ridge form is

\[ \boxed{ J_{\text{Ridge}}(w) = \|Xw-y\|_2^2 + \lambda\|w\|_2^2 } \]

or explicitly,

\[ \boxed{ J_{\text{Ridge}}(w) = \|Xw-y\|_2^2 + \lambda\sum_{j=1}^{d}w_j^2 } \]

where \(\lambda\ge0\).

This follows the supplied course progression:

least squares
   ↓
model flexibility
   ↓
overfitting risk
   ↓
regularization
14

Lasso Objective

The corresponding Lasso form is

\[ \boxed{ J_{\text{Lasso}}(w) = \|Xw-y\|_2^2 + \lambda\|w\|_1 } \]

or

\[ \boxed{ J_{\text{Lasso}}(w) = \|Xw-y\|_2^2 + \lambda\sum_{j=1}^{d}|w_j| } \]

The core mathematical difference is therefore:

\[ \boxed{ \text{Ridge}:\sum_jw_j^2 } \]

versus

\[ \boxed{ \text{Lasso}:\sum_j|w_j| } \]

18

Effect of \(\lambda\)

The regularization strength controls the trade-off.

\[ J(w) = L(w)+\lambda\Omega(w). \]

Case 1: \(\lambda=0\)

\[ J(w)=L(w). \]

No regularization.

The problem reduces to ordinary loss minimization.

Case 2: small positive \(\lambda\)

Regularization matters, but the data fit still strongly influences the solution.

Case 3: very large \(\lambda\)

The penalty becomes extremely important.

The optimization strongly prefers small coefficients.

This can overly constrain the model and increase underfitting.

Memory line

λ small → weak control
λ large → strong control
19

Derivative of the Squared L2 Penalty

Let

\[ \Omega(w)=\|w\|_2^2 = \sum_{j=1}^{d}w_j^2. \]

Differentiate with respect to \(w_j\):

\[ \frac{\partial\Omega}{\partial w_j} = 2w_j. \]

Therefore the gradient is

\[ \boxed{ \nabla_w\|w\|_2^2=2w } \]

This is one reason Ridge integrates naturally with gradient-based optimization.

20

Gradient Derivation Step by Step

Start with

\[ \|w\|_2^2 = w_1^2+w_2^2+\cdots+w_d^2. \]

Then:

\[ \frac{\partial}{\partial w_1} \|w\|_2^2 = 2w_1 \]
\[ \frac{\partial}{\partial w_2} \|w\|_2^2 = 2w_2 \]

and so on.

Stacking the partial derivatives:

\[ \nabla_w\|w\|_2^2 = \begin{bmatrix} 2w_1\\ 2w_2\\ \vdots\\ 2w_d \end{bmatrix} = \boxed{2w}. \]

Therefore for

\[ J_R(w) = L(w)+\lambda\|w\|_2^2, \]

we obtain

\[ \boxed{ \nabla J_R(w) = \nabla L(w)+2\lambda w } \]

under this objective convention.

Convention warning: Some textbooks define Ridge with a factor such as \(\frac{\lambda}{2}\|w\|_2^2\) or scale the data loss by \(1/n\). Then the exact coefficient multiplying \(w\) changes. The conceptual penalty remains L2.

21

Why L1 Is Different at Zero

For one scalar \(w\),

\[ |w| = \begin{cases} w,&w\gt 0\\ -w,&w\lt 0. \end{cases} \]

At \(w=0\), the ordinary derivative does not exist.

From the right:

\[ \frac{d}{dw}|w|=1. \]

From the left:

\[ \frac{d}{dw}|w|=-1. \]

So the one-sided slopes disagree at zero.

|w|
       ↑
       | \       /
       |  \     /
       |   \   /
       |    \ /
       +-----●--------→ w
             0
         slope changes

This sharp point is the calculus counterpart of the geometric corner.

22

Subgradient at Zero

Although \(|w|\) is not differentiable at \(w=0\), optimization can still handle it using a subgradient.

For the scalar absolute-value function,

\[ \partial |w| = \begin{cases} \{1\},&w\gt 0\\ [-1,1],&w=0\\ \{-1\},&w\lt 0. \end{cases} \]

So at zero, there is not one ordinary derivative. There is a whole interval of valid subgradients.

This mathematical fact is closely connected with Lasso's ability to produce exact zeros.

One-Dimensional Lasso Problem

Consider the simple objective

\[ \boxed{ J(w) = \frac12(z-w)^2+\lambda|w| } \]

where \(z\) is some data-driven quantity.

This tiny problem is extremely useful because it isolates the core L1 behaviour.

We can ask:

What value of \(w\) minimizes this objective?

24

Solve for \(w>0\)

When

\[ w\gt 0, \]

we have

\[ |w|=w. \]

Therefore

\[ J(w) = \frac12(z-w)^2+\lambda w. \]

Differentiate:

\[ \frac{dJ}{dw} = -(z-w)+\lambda. \]

Set derivative to zero:

\[ -(z-w)+\lambda=0. \]

Therefore

\[ w=z-\lambda. \]

This is valid only if

\[ z-\lambda\gt 0 \]

or

\[ z\gt \lambda. \]
25

Solve for \(w<0\)

When

\[ w\lt 0, \]

we have

\[ |w|=-w. \]

Thus

\[ J(w) = \frac12(z-w)^2-\lambda w. \]

Differentiate:

\[ \frac{dJ}{dw} = -(z-w)-\lambda. \]

Set to zero:

\[ -(z-w)-\lambda=0. \]

Hence

\[ w=z+\lambda. \]

This is valid only when

\[ z+\lambda\lt 0 \]

or

\[ z\lt -\lambda. \]
26

The Zero Case

Now consider

\[ |z|\le\lambda. \]

The optimum is

\[ \boxed{w=0}. \]

Combining the three cases gives the soft-thresholding operator:

\[ \boxed{ \hat w = \operatorname{sign}(z) \max(|z|-\lambda,0) } \]

This is a major mathematical insight into L1 regularization.

27

Soft Thresholding Intuition

The operation

\[ \operatorname{sign}(z) \max(|z|-\lambda,0) \]

means:

  1. keep the sign of \(z\);
  2. reduce its magnitude by \(\lambda\);
  3. if the magnitude is too small, make it exactly zero.

Visualize:

large positive z
      ↓ subtract λ
smaller positive w

small positive z
      ↓ λ is too large
w = 0

small negative z
      ↓
w = 0

large negative z
      ↓ add λ toward zero
less negative w

This is why L1 is associated with sparsity.

28

Soft-Thresholding Numerical

Take

\[ z=5,\qquad\lambda=2. \]

Then:

\[ \hat w = \operatorname{sign}(5) \max(5-2,0) \]
\[ =1(3) \]
\[ \boxed{\hat w=3}. \]

Now take

\[ z=1,\qquad\lambda=2. \]

Then:

\[ \hat w = \operatorname{sign}(1) \max(1-2,0) \]
\[ = 1\cdot0 \]
\[ \boxed{\hat w=0}. \]
29

What “Sparse” Means

A vector is sparse when many of its entries are exactly zero.

For example:

\[ w=(0,2.4,0,0,-1.3,0) \]

is sparse because most coordinates are zero.

Compare with:

\[ w=(0.2,2.4,-0.1,0.05,-1.3,0.07) \]

which is much less sparse.

Lasso connection

L1 regularization can produce exact zero coefficients.

Therefore it can create sparse models.

Important wording

Say:

Lasso can promote sparsity.

Do not claim:

“Lasso always produces a sparse model.”

The actual result depends on the data, regularization strength, model formulation, and optimization.

30

Why Ridge Usually Shrinks Rather Than Selects

Ridge uses

\[ \lambda\sum_jw_j^2. \]

Its penalty is smooth.

For scalar \(w_j\),

\[ \frac{d}{dw_j}w_j^2=2w_j. \]

The penalty gradient is zero exactly at \(w_j=0\), but there is no sharp L1-style kink.

As a result, Ridge is characteristically associated with continuous shrinkage rather than exact coefficient selection.

Exam-safe statement:

Ridge generally shrinks coefficients toward zero but does not use exact sparsity as its defining mechanism.

Critical idea

32

Regularization as a Complexity Preference

Suppose two parameter vectors fit the data equally well.

Model A

\[ w_A=(4,4). \]

Model B

\[ w_B=(2,2,2,2) \]

The comparison is not meaningful until the loss and parameterization are specified.

This is an important lesson:

Regularization does not mean “fewer numbers” by itself.

It means optimizing an explicit mathematical objective containing a complexity penalty.

33

Scaling Matters

Coefficient-based penalties operate on parameter values.

Suppose one feature is measured in meters and another in millimeters.

Changing units changes the numerical magnitude of the corresponding coefficients.

Therefore, without scaling, the penalty may interact differently with parameters simply because the input features use different units.

The supplied Lecture 09 specifically emphasizes:

feature scaling
      ↓
improved optimization behaviour
      ↓
faster / more stable convergence

and the Ridge/Lasso material emphasizes the additional reason:

consistent feature scales
      ↓
more comparable coefficient penalties

A common preprocessing approach is standardization:

\[ \boxed{ x_j' = \frac{x_j-\mu_j}{\sigma_j} } \]

where:

  • \(\mu_j\) = feature mean;
  • \(\sigma_j\) = feature standard deviation.
34

Why the Intercept Is Often Treated Separately

A common model is

\[ \hat y=Xw+b. \]

Here \(b\) is an intercept.

Many practical regularized formulations penalize \(w\) but leave \(b\) unpenalized:

\[ \boxed{ J(w,b)=L(w,b)+\lambda\Omega(w) } \]

rather than

\[ L(w,b)+\lambda\Omega(w,b). \]

The motivation is that the intercept mainly shifts the baseline prediction, while regularization is often intended to control feature-associated coefficients.

Important caveat

The exact treatment depends on the model and implementation convention.

Do not universalize this as a mathematical law.

35

Penalized vs Constrained Form — Deeper View

Consider L1 regularization.

Penalized form

\[ \min_w L(w)+\lambda\|w\|_1. \]

Constrained form

\[ \min_w L(w) \quad \text{s.t.} \quad \|w\|_1\le c. \]

The first says:

pay for parameter magnitude.

The second says:

stay inside an allowed parameter region.

For L2:

\[ \|w\|_2\le c \]

gives a circular/spherical region.

For L1:

\[ \|w\|_1\le c \]

gives a diamond in two dimensions and a cross-polytope in higher dimensions.

36

Higher-Dimensional Geometry

The two-dimensional pictures are not merely decorative.

They are slices of higher-dimensional geometry.

L2

\[ \|w\|_2\le c \]

forms a Euclidean ball.

  • 2D → circle
  • 3D → sphere
  • \(d\)D → hypersphere-like ball

L1

\[ \|w\|_1\le c \]

forms a cross-polytope.

  • 2D → diamond
  • 3D → octahedron
  • higher dimensions → higher-dimensional cross-polytopes

You do not normally need the word “cross-polytope” for a basic exam answer, but understanding it clarifies that the geometry scales beyond 2D.

37

Norm Balls and Coordinate Axes

For L1 in 2D:

\[ |w_1|+|w_2|\le c. \]

The boundary reaches the axes at:

\[ (c,0),\quad(0,c),\quad(-c,0),\quad(0,-c). \]

Those axis intersections are exactly the locations where one coordinate is zero.

For example:

\[ (0,c) \]

has \(w_1=0\).

This is the geometric seed of feature sparsity.

38

A Worked Regularization Objective

Suppose

\[ \|Xw-y\|_2^2=8, \]
\[ w=(3,-4), \]

and

\[ \lambda=0.5. \]

First calculate the L2 penalty:

\[ \|w\|_2^2 = 3^2+(-4)^2 = 25. \]

Then:

\[ \lambda\|w\|_2^2 = 0.5(25) = 12.5. \]

Therefore:

\[ J_R(w)=8+12.5 \]
\[ \boxed{J_R(w)=20.5}. \]

For Lasso:

\[ \|w\|_1=7. \]

Thus:

\[ \lambda\|w\|_1 = 0.5(7) = 3.5. \]

So:

\[ \boxed{J_L(w)=8+3.5=11.5}. \]

Interpretation

Do not conclude that Lasso is “better” because 11.5 is numerically smaller.

The objectives use different penalty definitions.

Numerical Protocol

Whenever a regularization numerical appears:

Step 1 — Given

Write:

\[ w,\quad X,\quad y,\quad\lambda,\quad\text{loss}. \]

Step 2 — Identify method

  • Ridge → L2 / squared L2;
  • Lasso → L1.

Step 3 — Write the penalty

Ridge:

\[ \lambda\sum_jw_j^2. \]

Lasso:

\[ \lambda\sum_j|w_j|. \]

Step 4 — Calculate the norm/penalty

Show intermediate arithmetic.

Step 5 — Add data loss

Step 6 — Interpret

Explain whether the penalty encourages smaller coefficients and what increasing \(\lambda\) would do conceptually.

40

Ridge Gradient-Descent Update

Suppose

\[ J_R(w)=L(w)+\lambda\|w\|_2^2. \]

Then:

\[ \nabla J_R(w) = \nabla L(w)+2\lambda w. \]

Gradient descent gives

\[ w_{t+1} = w_t-\eta\nabla J_R(w_t). \]

Therefore:

\[ \boxed{ w_{t+1} = w_t - \eta\left[ \nabla L(w_t)+2\lambda w_t \right] } \]

or

\[ \boxed{ w_{t+1} = (1-2\eta\lambda)w_t - \eta\nabla L(w_t) } \]

under this exact objective convention.

Important interpretation

The \(2\eta\lambda w_t\) term pulls the parameters toward zero.

This is the mathematical meaning of shrinkage.

41

Why Objective Conventions Matter

You may encounter:

\[ L(w)+\lambda\|w\|_2^2 \]

or

\[ L(w)+\frac{\lambda}{2}\|w\|_2^2 \]

or

\[ \frac1nL(w)+\lambda\|w\|_2^2. \]

These are not contradictory formulations.

The constants affect the numerical scale of the hyperparameter and gradient.

Exam-safe rule

When deriving a gradient:

Differentiate the exact objective written in the question.

Never blindly copy a gradient from memory without checking the factor multiplying the penalty.

42

L1 Gradient Away From Zero

For

\[ \Omega(w)=\|w\|_1 = \sum_j|w_j|, \]

when every \(w_j\ne0\),

\[ \frac{\partial}{\partial w_j}|w_j| = \operatorname{sign}(w_j). \]

Therefore, away from zero,

\[ \nabla\|w\|_1 = \begin{bmatrix} \operatorname{sign}(w_1)\\ \vdots\\ \operatorname{sign}(w_d) \end{bmatrix}. \]

At zero, ordinary differentiation fails and subgradients are used.

43

Why L1 Can Create Exact Zeros — Algebraic View

The one-dimensional solution

\[ \hat w = \operatorname{sign}(z)\max(|z|-\lambda,0) \]

shows the threshold directly.

If

\[ |z|\gt \lambda, \]

then the coefficient survives but is reduced.

If

\[ |z|\le\lambda, \]

then

\[ \boxed{\hat w=0}. \]

Thus L1 does not merely “make weights smaller.”

It can change the support of the vector:

\[ \operatorname{supp}(w) = \{j:w_j\ne0\}. \]

Reducing the support means fewer active coefficients.

44

Support of a Vector

For

\[ w=(0,2,0,-3,0), \]

the support is

\[ \operatorname{supp}(w)=\{2,4\}. \]

The vector has two active coordinates.

Sparse learning can therefore be understood as learning a small support.

AI/ML interpretation

A Lasso model with many zero coefficients effectively says:

“These coordinates are not needed by the fitted model at this chosen regularization level.”

That is a modelling statement, not automatically a causal or scientific statement.

45

Scaling + Sparsity + Interpretation

Suppose features \(x_1\) and \(x_2\) measure similar information but are on very different scales.

Then a coefficient comparison such as

\[ |w_1|\gt |w_2| \]

does not automatically mean feature 1 is more influential.

Coefficient magnitude depends on feature units.

Therefore:

coefficient size
       ≠
importance in a universal sense

This is especially important when interpreting regularized models.

Do Not Confuse These Three Ideas

Idea 1 — Small coefficients

A coefficient is numerically small:

\[ w_j=0.001. \]

Idea 2 — Exact zero

\[ w_j=0. \]

Idea 3 — Feature removed from the original dataset

The feature column is physically deleted from \(X\).

These are not equivalent.

Lasso can produce:

\[ w_j=0 \]

without changing the original data matrix.

So:

\[ \boxed{ \text{zero coefficient} \neq \text{deleted feature column} } \]

Regularization and Bias–Variance

The course material links model flexibility, overfitting, and the bias-variance trade-off.

A typical conceptual chain is:

\[ \text{stronger regularization} \]
\[ \downarrow \]
\[ \text{less flexible parameter space} \]
\[ \downarrow \]
\[ \text{variance tends to decrease} \]

while

\[ \text{bias tends to increase}. \]

Thus:

λ ↑
→ model more constrained
→ variance tends to ↓
→ bias tends to ↑

This is a conceptual tendency, not a guarantee that every numerical test error will behave monotonically.

49

Convexity Connection

For standard least-squares linear regression:

\[ L(w)=\|Xw-y\|_2^2 \]

is convex in \(w\).

The squared L2 penalty

\[ \|w\|_2^2 \]

is also convex.

Therefore their sum is convex:

\[ L(w)+\lambda\|w\|_2^2. \]

L1 norm is also convex:

\[ \|w\|_1. \]

Hence standard Lasso regression is also convex.

Why this matters

Convexity gives a very useful optimization property:

Every local minimum is a global minimum.

The challenge is not that the standard Ridge/Lasso objective is non-convex; the practical issue is finding the minimizer efficiently and handling the nonsmooth structure of L1.

50

Closed-Form Ridge Solution

For the objective

\[ J(w)=\|Xw-y\|_2^2+\lambda\|w\|_2^2, \]

differentiate:

\[ \nabla J(w) = 2X^T(Xw-y)+2\lambda w. \]

Set equal to zero:

\[ 2X^TXw-2X^Ty+2\lambda w=0. \]

Divide by 2:

\[ X^TXw-X^Ty+\lambda w=0. \]

Collect \(w\):

\[ (X^TX+\lambda I)w=X^Ty. \]

Therefore, when the inverse exists,

\[ \boxed{ w^*= (X^TX+\lambda I)^{-1}X^Ty } \]

under this standard convention.

This is the familiar Ridge closed form.

51

Why the Same Formula Is Not Lasso

Lasso uses

\[ \lambda\sum_j|w_j|. \]

The absolute value introduces a kink at zero.

Therefore the ordinary smooth derivative-based derivation used for Ridge does not directly produce

\[ (X^TX+\lambda I)^{-1}X^Ty. \]

So do not write the Ridge inverse formula for Lasso.

Exam trap

Wrong:

\[ \boxed{ \hat w_{\text{Lasso}} = (X^TX+\lambda I)^{-1}X^Ty } \]

Correct idea:

Lasso uses an L1 penalty and generally requires an optimization method suited to the nonsmooth objective.

52

Regularization and Feature Selection

Lasso is often associated with feature selection because exact zero coefficients are possible.

For example:

\[ w=(2.7,0,0,-1.2,0.4,0). \]

The nonzero support is:

\[ \{1,4,5\}. \]

A model can therefore become more interpretable in terms of which coordinates are active.

But beware:

  • correlated predictors can complicate which feature receives a nonzero coefficient;
  • sparsity does not guarantee superior predictive accuracy;
  • selected features are not automatically causal variables;
  • changing \(\lambda\) can change the selected set.
53

Why Correlated Predictors Need Care

Suppose two features are strongly correlated.

The prediction problem may have several ways to distribute explanatory weight between them.

Regularization can therefore affect which coefficients remain large or become small/zero.

This means:

\[ \text{“Lasso selected feature A”} \]

does not necessarily mean:

\[ \text{“feature A is intrinsically the only important cause.”} \]

The selection is a property of the fitted optimization problem.

54

Advanced Connection — Elastic Net

A useful extension combines L1 and L2 penalties:

\[ \boxed{ J(w) = L(w) + \lambda_1\|w\|_1 + \lambda_2\|w\|_2^2 } \]

This is commonly called Elastic Net under a particular parameterization.

The idea is:

L1 contribution
→ sparsity

L2 contribution
→ smooth shrinkage

This is beyond the minimum mathematical core for the present course, but it is useful because it shows that regularization is a design space rather than a two-method binary.

Norms and Other AI/ML Uses

The importance of norms extends beyond Ridge/Lasso.

Distance

L2:

\[ d(x,y)=\|x-y\|_2. \]

Used heavily in geometric reasoning and algorithms such as KNN.

Absolute deviation

L1:

\[ \|x-y\|_1. \]

Useful when absolute coordinate differences are relevant.

Weight regularization

\[ \|w\|_1,\quad\|w\|_2^2. \]

Error measurement

Many losses are built from squared or absolute differences.

So a basic understanding of norms becomes a recurring mathematical tool throughout ML.

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Analytical Solution Trap (Ridge vs Lasso):** - **Ridge ($L_2$):** Always has an analytical closed-form formula because $\|w\|_2^2$ is smooth and strictly convex everywhere:
$$w^* = (X^T X + \lambda I)^{-1} X^T y$$
Even if $X^T X$ is singular (collinear features), $(X^T X + \lambda I)$ is ALWAYS strictly positive definite and invertible! - **Lasso ($L_1$):** Does **NOT** have a closed-form formula in matrix form because $|w|$ is non-differentiable at $w=0$. It requires iterative optimization like **Coordinate Descent** with the soft-thresholding operator:
$$S(z, \gamma) = \text{sign}(z) \max(|z| - \gamma, 0)$$
In theory questions, never write an inverse formula for Lasso!

Mistake 1

Writing:

\[ \|w\|_1=\sqrt{\sum_jw_j^2}. \]

That is L2, not L1.

Mistake 2

Forgetting the square root in the L2 norm.

\[ \|w\|_2 = \sqrt{\sum_jw_j^2}. \]

Mistake 3

Confusing \(\|w\|_2\) and \(\|w\|_2^2\).

Mistake 4

Saying “Lasso always sets weights to zero.”

It can, but it does not necessarily make every model sparse.

Mistake 5

Calling Ridge a feature-selection method.

Its characteristic action is shrinkage, not exact sparse selection.

Mistake 6

Using the Ridge inverse formula for Lasso.

Mistake 7

Saying a larger \(\lambda\) always improves test accuracy.

It can over-regularize.

Mistake 8

Ignoring feature scaling.

Mistake 9

Treating coefficient magnitude as universally comparable across unscaled features.

Mistake 10

Assuming a zero Lasso coefficient proves the feature is causally irrelevant.

\[ \boxed{ J_L(w)=L(w)+\lambda\|w\|_1 } \]

\[ \boxed{ \nabla\|w\|_2^2=2w } \]

Ridge gradient

\[ \boxed{ \nabla J_R = \nabla L+2\lambda w } \]

under the stated standard objective convention.

Final Memory Compression

Memorize this:

\[ \boxed{ L_1=\sum|w_j| \quad\Longrightarrow\quad \text{diamond} \quad\Longrightarrow\quad \text{corners} \quad\Longrightarrow\quad \text{zeros possible} } \]
\[ \boxed{ L_2^2=\sum w_j^2 \quad\Longrightarrow\quad \text{circle/sphere} \quad\Longrightarrow\quad \text{smoothness} \quad\Longrightarrow\quad \text{shrinkage} } \]

and:

\[ \boxed{ \text{regularized objective} = \text{data loss} + \lambda\times\text{complexity penalty} } \]

That is the mathematical backbone of Ridge/Lasso.
