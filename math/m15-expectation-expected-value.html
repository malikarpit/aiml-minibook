01

Why This Lesson Exists

A probability distribution can describe many possible outcomes.

But sometimes we need one summary quantity:

What value should we expect on average?

That is the expected value.

Expectation appears everywhere in AI/ML:

expected loss
expected reward
expected prediction
expected value of a policy
expected error
expected feature value

It is one of the most important bridges from probability to learning theory and reinforcement learning.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Expectation sample average ka theoretical version hai. Agar hum ek experiment ko croro (millions) baar repeat karein, toh average value kis point par aakar rukegi? Wahi expected value $E[X]$ hai. Physics mein ye seesaw ya lever ka **Center of Mass** hota hai. Aur sabse magical rule hai **Linearity of Expectation**: $E[X + Y] = E[X] + E[Y]$—ye rule HAMESHA sach hota hai, chahe $X$ aur $Y$ kitne bhi dependent kyun na hon!

Suppose a game pays:

₹10 with probability 0.5
₹0  with probability 0.5

You do not receive ₹5 on every game.

But over many repeated games, the average payoff approaches:

\[ 0.5(10)+0.5(0)=5. \]

So:

\[ \boxed{ E[X]=5. } \]

Expectation is therefore a probability-weighted average.

03

Random Variable Setup

Let:

\[ X \]

be a random variable.

If \(X\) is discrete, it takes values:

\[ x_1,x_2,\ldots \]

with probabilities:

\[ p_X(x_i). \]

Expectation combines:

possible value
×
probability of that value

and adds the results.

04

Discrete Expectation

For a discrete random variable:

\[ \boxed{ E[X] = \sum_xx\,p_X(x). } \]

The supplied Lecture02 gives exactly this formula. fileciteturn64file7

Read it as:

multiply each possible value by its probability, then add.

05

Worked Example — Fair Die

graph LR
    A["Random Variable Outcomes: x1, x2, ..., xk"] --> C["Expectation E[X] = Σ x_i · P(X = x_i)"]
    B["Probability Weights: p1, p2, ..., pk"] --> C
    C --> D["Physical Meaning: Center of Mass (Balance Point of Lever)"]
    C --> E["Linearity: E[aX + bY] = aE[X] + bE[Y] (ALWAYS Holds!)"]
    style C fill:#0f172a,stroke:#fbbf24,color:#fbbf24,stroke-width:2px

Let:

\[ X=\text{outcome of a fair six-sided die}. \]

Then:

\[ P(X=x)=\frac16 \]

for:

\[ x=1,\ldots,6. \]

Therefore:

\[ E[X] = 1\frac16+ 2\frac16+ 3\frac16+ 4\frac16+ 5\frac16+ 6\frac16. \]

So:

\[ E[X] = \frac{1+2+3+4+5+6}{6} = \frac{21}{6} = \boxed{3.5}. \]

Important:

The expected value does not need to be an outcome that can actually occur.

A die never shows 3.5, but its expected value is 3.5.

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

x_outcomes = np.array([1, 2, 3, 4])
p_weights = np.array([0.1, 0.2, 0.4, 0.3])

expected_value = np.sum(x_outcomes * p_weights)
samples = np.random.choice(x_outcomes, size=100000, p=p_weights)
empirical_mean = np.mean(samples)

print("Theoretical Expectation E[X]:", expected_value)
print("Empirical Mean (100k samples):", np.round(empirical_mean, 4))
06

Continuous Expectation

For a continuous random variable with density \(f_X(x)\):

\[ \boxed{ E[X] = \int_{-\infty}^{\infty} x f_X(x)\,dx. } \]

The supplied Lecture02 gives this continuous analogue. fileciteturn64file7

Memory:

discrete
→ sum

continuous
→ integral
07

Expectation as a Weighted Average

Compare with an ordinary average:

\[ \bar x=\frac1n\sum_ix_i. \]

Expectation replaces equal weights with probability weights:

\[ E[X]=\sum_xx\,P(X=x). \]

So:

ordinary average
→ equal/sample weights

expectation
→ probability weights
08

Expected Value Is Not “Most Likely Value”

Do not confuse:

expectation
mode
median
most probable outcome

They are different concepts.

Example:

0 with probability .99
100 with probability .01

Then:

\[ E[X]=1, \]

but the most likely outcome is:

\[ 0. \]
09

Expectation of a Function

Suppose:

\[ Y=g(X). \]

We may want:

\[ E[Y]=E[g(X)]. \]

For a discrete \(X\):

\[ \boxed{ E[g(X)] = \sum_xg(x)p_X(x). } \]

The supplied Lecture02 explicitly gives this direct approach and notes that it can be easier than first deriving the distribution of \(Y\). fileciteturn64file7

10

Why This Is Powerful

Suppose:

\[ Y=X^2. \]

You do not necessarily need to construct the PMF of \(Y\).

Instead:

\[ \boxed{ E[Y]=E[X^2] = \sum_xx^2p_X(x). } \]

This direct expectation-of-a-function rule becomes very useful for variance.

11

Worked Example — Function of a Random Variable

⚠️ University Exam Trap & Common Misconception
**Non-Linear Functions do NOT Distribute:** $E[g(X)] \neq g(E[X])$ in general! For example, $E[X^2] \neq (E[X])^2$ (their difference is precisely the variance!). Similarly, $E[\log(X)] \neq \log(E[X])$. Assuming expectation slips inside non-linear functions is a fatal university exam mistake.

Suppose:

\[ X= \begin{cases} 0,&P=0.5\\ 2,&P=0.5. \end{cases} \]

Let:

\[ Y=X^2. \]

Then:

\[ E[Y] = 0^2(0.5)+2^2(0.5) \]
\[ =0+2 = \boxed2. \]

Notice:

\[ (E[X])^2 \]

is not generally the same as:

\[ E[X^2]. \]

Indeed:

\[ E[X]=0(0.5)+2(0.5)=1 \]

so:

\[ (E[X])^2=1, \]

while:

\[ E[X^2]=2. \]

12

Expectation of a Constant

⚠️ University Exam Trap & Common Misconception
**Non-Linear Functions do NOT Distribute:** $E[g(X)] \neq g(E[X])$ in general! For example, $E[X^2] \neq (E[X])^2$ (their difference is precisely the variance!). Similarly, $E[\log(X)] \neq \log(E[X])$. Assuming expectation slips inside non-linear functions is a fatal university exam mistake.

For constant \(c\):

\[ \boxed{ E[c]=c. } \]

Because the total probability is 1.

Formally:

\[ E[c] = \sum_xc\,p_X(x) = c\sum_xp_X(x) = c. \]
13

Pulling Out a Constant

For real \(a,b\):

\[ \boxed{ E[aX+b] = aE[X]+b. } \]

The supplied Lecture02 explicitly states this property. fileciteturn64file7

This is called linearity of expectation.

14

Linearity of Expectation

For random variables \(X_1,\ldots,X_n\):

\[ \boxed{ E[X_1+\cdots+X_n] = E[X_1]+\cdots+E[X_n]. } \]

Crucially:

\[ \boxed{ \text{independence is not required.} } \]

The supplied Lecture02 explicitly emphasizes this. fileciteturn64file7

15

Worked Example — Linearity

Suppose:

\[ E[X]=4 \]

and:

\[ E[Y]=7. \]

Then:

\[ E[X+Y] = 4+7 = \boxed{11}. \]

No independence assumption is needed.

16

Scaling and Shifting

Suppose:

\[ Y=3X+5. \]

Then:

\[ E[Y] = 3E[X]+5. \]

If:

\[ E[X]=4, \]

then:

\[ E[Y]=3(4)+5 = \boxed{17}. \]

This is often faster than deriving the full distribution of \(Y\).

17

Expected Value of a Sum of Indicators

An indicator variable for event \(A\) is:

\[ \boxed{ I_A= \begin{cases} 1,&A\text{ occurs}\\ 0,&A\text{ does not occur}. \end{cases} } \]

Then:

\[ \boxed{ E[I_A]=P(A). } \]

Why?

\[ E[I_A] = 1P(A)+0P(A^c) = P(A). \]

This is a useful bridge to counting and expected counts.

18

Expected Number of Occurrences

If:

\[ X=I_1+\cdots+I_n, \]

then:

\[ E[X] = E[I_1]+\cdots+E[I_n]. \]

Since:

\[ E[I_i]=P(I_i=1), \]

we get:

\[ \boxed{ E[X]=\sum_iP(I_i=1). } \]

This is called the indicator-variable technique.

The supplied Lecture02 uses a related indicator decomposition for the expected number of heads in repeated coin tosses. fileciteturn64file7

19

Binomial Expectation

Suppose:

\[ X\sim Binomial(n,p). \]

Interpret:

\(X\) is the number of successes in \(n\) independent trials with success probability \(p\).

Then:

\[ \boxed{ E[X]=np. } \]

The supplied Lecture02 derives this using linearity of expectation rather than directly summing the binomial PMF. fileciteturn64file7

20

Derivation of Binomial Expectation

Let:

\[ X_i= \begin{cases} 1,&\text{trial }i\text{ succeeds}\\ 0,&\text{otherwise}. \end{cases} \]

Then:

\[ X=X_1+\cdots+X_n. \]

Therefore:

\[ E[X] = E[X_1]+\cdots+E[X_n]. \]

Each:

\[ E[X_i]=p. \]

Hence:

\[ \boxed{ E[X]=np. } \]

Notice that linearity gets the result without needing to expand the full binomial PMF sum.

21

Expectation of Two Random Variables

For functions \(g(X,Y)\):

\[ \boxed{ E[g(X,Y)] = \sum_x\sum_y g(x,y)p_{X,Y}(x,y) } \]

for discrete variables.

The supplied Lecture02 states this formula. fileciteturn64file7

For example:

\[ E[XY] = \sum_x\sum_yxy\,p_{X,Y}(x,y). \]
22

Independent Variables and Product Expectation

If \(X,Y\) are independent:

\[ \boxed{ E[XY]=E[X]E[Y]. } \]

Why?

Start:

\[ E[XY] = \sum_x\sum_y xy\,p_X(x)p_Y(y). \]

Rearrange:

\[ = \left(\sum_xxp_X(x)\right) \left(\sum_yyp_Y(y)\right). \]

Therefore:

\[ \boxed{ E[XY]=E[X]E[Y]. } \]

The supplied Lecture02 gives this useful identity. fileciteturn64file7

23

Important Contrast: Sum vs Product

Sum

\[ E[X+Y]=E[X]+E[Y] \]

always under the usual existence conditions.

Product

\[ E[XY]=E[X]E[Y] \]

requires an additional condition such as independence.

Memory:

E of sum
→ always separates

E of product
→ generally does not separate
24

Conditional Expectation

Suppose you know:

\[ X=x. \]

Then the conditional expectation of \(Y\) is:

\[ \boxed{ E[Y|X=x] = \sum_y y\,p_{Y|X}(y|x) } \]

for discrete \(Y\).

This means:

average \(Y\) after restricting attention to cases where \(X=x\).

The supplied Lecture02 gives this exact formula and a table-based numerical example. fileciteturn64file7

25

Conditional Expectation as a Function

Instead of one fixed \(x\), we can write:

\[ \boxed{ E[Y|X] } \]

as a quantity that depends on \(X\).

Conceptually:

\[ x \rightarrow E[Y|X=x]. \]

This becomes extremely important in regression and reinforcement learning.

26

Regression Connection

A regression model estimates a conditional relationship between target and input.

Conceptually:

\[ \boxed{ f(x)\approx E[Y|X=x]. } \]

The exact relationship depends on the modeling assumptions and loss.

This is a deep reason conditional expectation matters in supervised learning.

27

Reinforcement-Learning Connection

A value function has the structure:

\[ \boxed{ V^\pi(s) = E_\pi[G_t|S_t=s]. } \]

Interpret:

expected future return given that the current state is \(s\), following policy \(\pi\).

Therefore RL value functions are naturally conditional expectations.

This creates the bridge:

probability
→ random variable
→ expectation
→ conditional expectation
→ value function
28

Expected Loss

Suppose:

\[ L(Y,\hat Y) \]

is a random loss across randomly drawn data.

Then:

\[ \boxed{ E[L(Y,\hat Y)] } \]

is expected loss.

Training often uses empirical averages as estimates of population expectations:

\[ \frac1n\sum_{i=1}^{n}L(y_i,\hat y_i) \]

which is the sample analogue of an expected loss under the data distribution.

This is the mathematical bridge between probability and empirical machine learning.

29

Why Expectation Does Not Mean Guaranteed Outcome

Suppose:

\[ X= \begin{cases} 0,&0.5\\ 10,&0.5. \end{cases} \]

Then:

\[ E[X]=5. \]

But \(X\) is never actually 5.

Therefore:

\[ \boxed{ \text{expected value is an average, not a guaranteed result.} } \]

This is one of the most important conceptual points.

30

Existence of Expectation

For an expectation to be well-defined, the relevant absolute-value sum/integral should be finite under the standard conditions.

The supplied Lecture02 notes:

expectation exists only when the absolute-value sums/integrals are finite. fileciteturn64file7

For ordinary DSC-14 numericals, most distributions encountered will satisfy the required conditions.

Still, remember:

an expectation is not automatically finite for every conceivable random variable.

Worked Example B — Expectation of \(X^2\)

Using the same PMF:

\[ E[X^2] = 0^2(0.2) + 1^2(0.5) + 2^2(0.3). \]
\[ =0+0.5+1.2 = \boxed{1.7}. \]

Therefore:

\[ (E[X])^2=(1.1)^2=1.21. \]

So:

\[ \boxed{ E[X^2]\ne(E[X])^2. } \]

This difference becomes the key ingredient in variance.

Let:

Worked Example F — Independent Product

Suppose:

\[ E[X]=2, \quad E[Y]=5 \]

and \(X,Y\) are independent.

Then:

\[ E[XY] = E[X]E[Y] = 10. \]
\[ \boxed{E[XY]=10}. \]

Without independence, knowing only the two means is insufficient in general.

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Non-Linear Functions do NOT Distribute:** $E[g(X)] \neq g(E[X])$ in general! For example, $E[X^2] \neq (E[X])^2$ (their difference is precisely the variance!). Similarly, $E[\log(X)] \neq \log(E[X])$. Assuming expectation slips inside non-linear functions is a fatal university exam mistake.

Mistake 1 — Expectation = most likely value

False.

Mistake 2 — Expectation must be an attainable outcome

False.

Mistake 3 — Confusing:

\[ E[X^2] \]

with:

\[ (E[X])^2. \]

They are generally different.

Mistake 4 — Assuming linearity requires independence

It does not.

Mistake 5 — Separating product without justification

\[ E[XY]\ne E[X]E[Y] \]

in general.

Mistake 6 — Forgetting probabilities

Expectation is not:

\[ \sum_xx. \]

It is:

\[ \sum_xxp_X(x). \]

Mistake 7 — Conditional expectation without conditioning distribution

For:

\[ E[Y|X=x], \]

you need the conditional distribution of \(Y\) given \(X=x\).
