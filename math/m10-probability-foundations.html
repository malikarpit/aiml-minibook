01

Why This Lesson Exists

Machine learning works with data, but many real-world processes are uncertain.

Examples:

Will a transaction be fraudulent?
Will a patient have a condition?
Will a user click an advertisement?
Which word comes next?
Which action will produce a reward?

Probability gives us a mathematical language for uncertainty.

The foundation is:

random experiment
↓
possible outcomes
↓
sample space
↓
events
↓
probability

Once that foundation is clear, conditional probability, Bayes, random variables and expectation become much easier.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Probability duniya ki uncertainty ko measure karne ka scale hai: 0 matlab impossible, 1 matlab absolutely guaranteed. AI mein hum deterministic algorithms se hatkar probabilistic models banate hain kyunki real-world data mein noise hota hai. Jab ek classifier kehta hai `p = 0.92`, woh keh raha hai ki 92% confidence hai ki patient ko disease hai. Kolmogorov ke teen axioms is poori theory ki neev hain!

Think of probability as a system for assigning numerical measures of uncertainty.

A random experiment has many possible outcomes.

Example:

experiment → toss a coin
outcomes   → H, T

The complete set of possibilities is:

\[ \Omega=\{H,T\}. \]

The event:

“A head occurs”

is:

\[ A=\{H\}. \]

Probability then assigns:

\[ P(A)=0.5 \]

for a fair coin.

03

Random Experiment

A random experiment is an experiment with an uncertain outcome.

Examples:

toss a coin
roll a die
select a student
measure a dart's distance from center
observe tomorrow's rainfall

The experiment itself defines what counts as an outcome.

04

Sample Space

The sample space is the set of all possible outcomes.

\[ \boxed{ \Omega=\text{set of all outcomes} } \]

An individual outcome is often written:

\[ \omega\in\Omega. \]

The supplied Lecture01 uses this exact notation.

Coin toss

\[ \boxed{ \Omega=\{H,T\} } \]

Six-sided die

\[ \boxed{ \Omega=\{1,2,3,4,5,6\} } \]

Toss until first head

Suppose the outcome is the number of tosses until the first head.

Possible outcomes:

\[ \boxed{ \Omega=\{1,2,3,\ldots\} } \]

because the first head could occur on toss 1, 2, 3, and so on.

The supplied lecture uses this example to show an infinite countable sample space.

Dart experiment

If the observed outcome is distance \(r\) from the center of a board of radius \(R\):

\[ \boxed{ \Omega=[0,R]. } \]

This is an uncountable sample space.

06

Finite, Countable and Uncountable

Finite

A finite number of outcomes.

Example:

\[ \{H,T\}. \]

Countably infinite

The outcomes can be listed:

\[ \omega_1,\omega_2,\omega_3,\ldots \]

Example:

\[ \{1,2,3,\ldots\}. \]

Uncountable

Cannot be put into a one-to-one list indexed by positive integers.

Example:

\[ [0,1]. \]

Why this distinction matters

It affects how probabilities are represented and computed.

finite/countable
→ individual outcomes can have probability masses

continuous/unccountable
→ individual points may have probability 0
→ intervals/regions carry probability
07

Event

An event is a subset of the sample space:

\[ \boxed{ A\subseteq\Omega. } \]

It represents a condition or collection of outcomes we care about.

Example:

Die:

\[ \Omega=\{1,2,3,4,5,6\}. \]

Event “even number”:

\[ \boxed{ E=\{2,4,6\}. } \]

Event “at least 4”:

\[ \boxed{ H=\{4,5,6\}. } \]

These examples follow the supplied Lecture01 framing.

08

Event vs Outcome

Do not confuse these.

Outcome

One particular possibility:

\[ \omega=4. \]

Event

A collection of outcomes:

\[ E=\{2,4,6\}. \]

So:

outcome → one element
event   → subset
09

Empty Event and Certain Event

The empty set:

\[ \boxed{ \varnothing } \]

means an impossible event.

The entire sample space:

\[ \boxed{ \Omega } \]

represents the certain event.

Therefore:

\[ P(\varnothing)=0 \]

and:

\[ P(\Omega)=1. \]
10

Complement of an Event

The complement of \(A\) contains all outcomes that are not in \(A\):

\[ \boxed{ A^c=\Omega\setminus A. } \]

Therefore:

\[ \boxed{ P(A^c)=1-P(A). } \]

Example:

If:

\[ P(A)=0.7, \]

then:

\[ P(A^c)=0.3. \]

11

Union of Events

⚠️ University Exam Trap & Common Misconception
**Inclusion-Exclusion Forgotten Term:** If events $A$ and $B$ are not mutually exclusive, $P(A \cup B) = P(A) + P(B) - P(A \cap B)$. Writing $P(A \cup B) = P(A) + P(B)$ without checking if $A \cap B = \emptyset$ is the most frequent beginner error!
\[ \boxed{ A\cup B } \]

means:

\(A\) occurs or \(B\) occurs or both occur.

Example:

\[ A=\{1,2,3\}, \quad B=\{3,4,5\}. \]

Then:

\[ A\cup B= \{1,2,3,4,5\}. \]
12

Intersection of Events

⚠️ University Exam Trap & Common Misconception
**Inclusion-Exclusion Forgotten Term:** If events $A$ and $B$ are not mutually exclusive, $P(A \cup B) = P(A) + P(B) - P(A \cap B)$. Writing $P(A \cup B) = P(A) + P(B)$ without checking if $A \cap B = \emptyset$ is the most frequent beginner error!
\[ \boxed{ A\cap B } \]

means:

Both \(A\) and \(B\) occur.

For the previous example:

\[ A\cap B=\{3\}. \]
13

Disjoint Events

Events are disjoint if they cannot happen together:

\[ \boxed{ A\cap B=\varnothing. } \]

Example:

For one die roll:

\[ A=\{1\}, \quad B=\{2\}. \]

They cannot both occur.

Therefore:

\[ P(A\cap B)=0. \]
14

Mutually Exclusive vs Independent

These ideas are different.

Mutually exclusive

\[ A\cap B=\varnothing. \]

They cannot occur together.

Independent

Knowing one occurred does not change the probability of the other.

For positive-probability events:

\[ P(A|B)=P(A). \]

Do not use these terms interchangeably.

15

Collection of Events

Probability theory considers a collection of events, often represented by:

\[ \mathcal F. \]

For a rigorous treatment, \(\mathcal F\) is a \(\sigma\)-algebra.

The supplied Lecture01 notes this explicitly but defer measure-theoretic details.

For DSC-14 mathematical learning, the most important practical idea is:

\(\mathcal F\) is the collection of events for which probability is defined.

16

Probability Measure

A probability measure assigns a number to each event:

\[ \boxed{ P:\mathcal F\rightarrow[0,1]. } \]

Interpretation:

event
↓
probability between 0 and 1
17

Probability Axioms

The supplied Lecture01 gives the two displayed axioms in its formulation:

Normalization

\[ \boxed{ P(\Omega)=1. } \]

The entire sample space has probability 1.

Countable additivity

For disjoint events:

\[ A_1,A_2,\ldots \]

with:

\[ A_i\cap A_j=\varnothing \quad (i\ne j), \]

we have:

\[ \boxed{ P\left(\bigcup_iA_i\right) = \sum_iP(A_i). } \]

These are the course-source foundations for the probability measure.

18

Why Countable Additivity Matters

Suppose:

\[ A=\{2,4\} \]

for a fair die.

The individual probabilities are:

\[ P(2)=\frac16, \quad P(4)=\frac16. \]

Because they are disjoint:

\[ P(A) = P(2)+P(4) = \frac26 = \frac13. \]

This is the discrete event-calculation idea emphasized in Lecture01.

19

Derived Property: Empty Event

Because:

\[ \Omega=A\cup A^c \]

and:

\[ A\cap A^c=\varnothing, \]

we get:

\[ P(\Omega)=P(A)+P(A^c)=1. \]

Therefore:

\[ \boxed{ P(A^c)=1-P(A). } \]

The supplied lecture lists this as a derived property.

20

Monotonicity

If:

\[ A\subseteq B, \]

then:

\[ \boxed{ P(A)\le P(B). } \]

Intuition:

If every outcome in \(A\) is also in \(B\), \(A\) cannot be more probable than \(B\).

This is another derived property listed in Lecture01.

21

Inclusion-Exclusion

For two events:

\[ \boxed{ P(A\cup B) = P(A)+P(B)-P(A\cap B). } \]

Why subtract the intersection?

Because:

P(A)
+
P(B)

counts the overlap twice.

Subtract one copy:

\[ P(A\cap B). \]
22

Disjoint Special Case

If:

\[ A\cap B=\varnothing, \]

then:

\[ P(A\cap B)=0. \]

So:

\[ \boxed{ P(A\cup B)=P(A)+P(B). } \]

This is the familiar addition rule for mutually exclusive events.

23

Three-Event Inclusion-Exclusion

\[ \boxed{ \begin{aligned} P(A\cup B\cup C) ={}&P(A)+P(B)+P(C)\\ &-P(A\cap B)-P(B\cap C)-P(C\cap A)\\ &+P(A\cap B\cap C). \end{aligned} } \]

The pattern is:

add singles
→ subtract pairwise overlaps
→ add triple overlap

The supplied Lecture01 explicitly includes this form.

24

Union Bound

For two events:

\[ \boxed{ P(A\cup B)\le P(A)+P(B). } \]

This remains true because:

\[ P(A\cap B)\ge0. \]

For many events:

\[ \boxed{ P\left(\bigcup_iA_i\right) \le \sum_iP(A_i). } \]

The supplied course notes introduce the union bound alongside inclusion-exclusion.

25

Equally Likely Finite Outcomes

If a finite sample space has \(N\) equally likely outcomes and event \(A\) contains \(k\) outcomes:

\[ \boxed{ P(A)=\frac{k}{N}. } \]

Example:

Fair die:

\[ N=6. \]

Even event:

\[ k=3. \]

Therefore:

\[ P(E)=\frac36=\frac12. \]
26

Discrete Probability

For a countable sample space, probabilities of individual outcomes can determine event probabilities through countable additivity.

Example:

\[ \Omega=\{1,2,3,4,5,6\} \]

with:

\[ P(i)=\frac16. \]

Then:

\[ P(\{2,5\}) = P(2)+P(5) = \frac26 = \frac13. \]

This is directly aligned with Lecture01's discrete-probability discussion.

27

Continuous Probability

For a continuous sample space, a particular point can have probability zero.

For a uniform distribution on \([0,1]\):

\[ P(X=0.34786)=0. \]

But:

\[ P(0.2\le X\le0.5)=0.3. \]

The supplied Lecture01 uses exactly this example to emphasize that intervals/regions carry probability in the continuous setting.

28

Important Continuous-Probability Lesson

Do not interpret:

\[ P(X=x)=0 \]

as:

“the value \(x\) cannot occur.”

In a continuous model, individual points can have probability zero while intervals have positive probability.

The crucial object is the probability assigned to regions/intervals.

Worked Example F — Continuous Interval

Suppose \(X\) is uniformly distributed on:

\[ [0,10]. \]

Under the uniform model, an interval's probability is proportional to its length.

Find:

\[ P(2\le X\le5). \]

Interval length:

\[ 5-2=3. \]

Total length:

\[ 10. \]

Thus:

\[ \boxed{ P(2\le X\le5)=\frac3{10}=0.3. } \]

The interpretation mirrors the continuous-probability treatment in Lecture01.

Hinglish Teacher Explanation

Probability ko simple language mein:

“Kisi event ke hone ki mathematical likelihood.”

Sabse pehle sample space samjho.

Coin toss:

\[ \Omega=\{H,T\}. \]

Matlab possible outcomes sirf H aur T hain.

Agar event:

\[ A=\{H\} \]

hai, toh hum pooch rahe hain:

“Head aane ki probability kya hai?”

Fair coin ke liye:

\[ P(A)=\frac12. \]

Die ke liye:

\[ \Omega=\{1,2,3,4,5,6\}. \]

Even event:

\[ A=\{2,4,6\}. \]

Toh:

\[ P(A)=\frac36=\frac12. \]

Event ko “outcome” mat samajhna.

Outcome = ek possibility.
Event = possibilities ka set jiske baare mein question pooch rahe ho.

Continuous case mein aur interesting hai:

\[ P(X=x)=0 \]

ho sakta hai, phir bhi \(x\) possible hai.

Matlab continuous probability mein point se zyada interval/region important hota hai.

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Inclusion-Exclusion Forgotten Term:** If events $A$ and $B$ are not mutually exclusive, $P(A \cup B) = P(A) + P(B) - P(A \cap B)$. Writing $P(A \cup B) = P(A) + P(B)$ without checking if $A \cap B = \emptyset$ is the most frequent beginner error!

Mistake 1 — Confusing outcome and event

\[ 4 \]

is an outcome.

\[ \{2,4,6\} \]

is an event.

Mistake 2 — Adding overlapping probabilities without correction

Wrong:

\[ P(A\cup B)=P(A)+P(B) \]

unless \(A,B\) are disjoint.

Correct:

\[ P(A\cup B)=P(A)+P(B)-P(A\cap B). \]

Mistake 3 — Treating probability as allowed outside \([0,1]\)

A probability must satisfy:

\[ 0\le P(A)\le1. \]

Mistake 4 — Thinking probability zero means impossible in every setting

This is false for continuous random variables.

Mistake 5 — Confusing independent and disjoint

They are different concepts.

For nontrivial positive-probability events, disjointness and independence are generally incompatible.
