01

Why This Lesson Exists

Machine-learning models are functions.

A model takes some input and produces an output:

\[ x\longrightarrow f(x)\longrightarrow \hat y. \]

Many important AI/ML functions are nonlinear:

sigmoid
tanh
ReLU
softmax
exponential
logarithm
loss functions

To understand them, you need to understand:

what a function is
→ domain/range
→ graph
→ slope
→ composition
→ inverse
→ exponential behaviour
→ logarithmic behaviour

This chapter builds that foundation.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Logarithm AI ka sabse bada friend hai! Do reasons hain: 1. **Numerical Stability:** Jab 1000 probabilities ko multiply karoge ($0.01 \times 0.05 \times \dots$), toh computer mein underflow (zero) ho jayega. Log lene par multiplication addition ban jata hai: $\log(a \cdot b) = \log a + \log b$. 2. **Extreme Penalty:** Jab model confident hokar galat prediction karta hai ($p \to 0$), toh $-\log(p) \to \infty$ ban jata hai—jo gradient descent ko zor se jhatka deta hai taaki parameters turant correct hon!

A function is a rule:

Give me an input, and I give you an output according to a defined relationship.

Think of a machine:

INPUT
  ↓
FUNCTION
  ↓
OUTPUT

Example:

\[ f(x)=2x+1. \]

Input:

\[ x=3. \]

Output:

\[ f(3)=7. \]

In ML:

features
  ↓
model
  ↓
prediction
03

Function Definition

A function \(f\) maps each allowed input in its domain to exactly one output.

Notation:

\[ \boxed{ f:X\rightarrow Y } \]

where:

  • \(X\) = domain;
  • \(Y\) = codomain.

For a numerical function:

\[ f(x)=x^2. \]

Every real \(x\) has exactly one output \(x^2\).

04

Domain and Range

Domain

The set of inputs that are allowed.

For:

\[ f(x)=\frac1x, \]

we cannot use:

\[ x=0. \]

So the domain excludes zero.

Range

The set of outputs actually produced.

For:

\[ f(x)=x^2 \]

with real \(x\):

\[ f(x)\ge0. \]

Therefore the range is:

\[ [0,\infty). \]

A mathematical formula may have restrictions.

Example:

\[ \log x \]

over the real numbers requires:

\[ x\gt 0. \]

Likewise:

\[ \frac1x \]

requires:

\[ x\ne0. \]

In ML, numerical implementations may also need protection from problematic values such as:

log(0)
division by zero
overflow in exp

Mathematics tells you where the expressions are valid.

06

Independent and Dependent Variables

In:

\[ y=f(x) \]

\(x\) is conventionally the input and \(y\) the resulting output.

We can visualize:

x changes
  ↓
f(x) changes

For:

\[ y=2x+1, \]

a change in \(x\) causes a corresponding change in \(y\).

07

Function Graph

A graph of:

\[ y=f(x) \]

plots input against output.

Horizontal axis:

\[ x \]

Vertical axis:

\[ y. \]

For:

\[ f(x)=x^2, \]

the graph is a parabola.

For:

\[ f(x)=2x+1, \]

the graph is a straight line.

08

Reading a Graph

From a graph, ask:

What is the input?
What is the output?
Is the function increasing?
Is it decreasing?
Where is the minimum?
Where is the maximum?
Does it cross an axis?
What is its slope?
Does it have a boundary/asymptote?

This visual reasoning becomes useful when interpreting:

loss curves
activation functions
optimization landscapes
decision boundaries
probability curves
09

Slope of a Straight Line

For:

\[ y=mx+c, \]

the slope is:

\[ \boxed{m}. \]

Using two points:

\[ \boxed{ m=\frac{y_2-y_1}{x_2-x_1} } \]

when \(x_2\ne x_1\).

Interpretation:

How much \(y\) changes for a unit change in \(x\).

10

Positive and Negative Slope

If:

\[ m\gt 0, \]

the line rises as \(x\) increases.

If:

\[ m\lt 0, \]

the line falls as \(x\) increases.

If:

\[ m=0, \]

the line is horizontal.

AI/ML connection

A derivative generalizes this idea to curved functions.

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

def sigmoid(z):
    return np.where(z >= 0, 1 / (1 + np.exp(-z)), np.exp(z) / (1 + np.exp(z)))

def binary_cross_entropy(y_true, y_prob):
    eps = 1e-15
    y_prob = np.clip(y_prob, eps, 1 - eps)
    return - (y_true * np.log(y_prob) + (1 - y_true) * np.log(1 - y_prob))

z_values = np.array([-5.0, 0.0, 2.5, 5.0])
probs = sigmoid(z_values)
print("Logits z:", z_values)
print("Sigmoid Probabilities σ(z):", np.round(probs, 4))
print("Loss if target=1:", np.round(binary_cross_entropy(1, probs), 4))
11

Function Composition

⚠️ University Exam Trap & Common Misconception
**Logarithm Domain & Identity Trap:** $\ln(x)$ is defined ONLY for $x \gt 0$. Never compute $\log(0)$. Furthermore, $\log(a + b) \neq \log a + \log b$! Only products split into sums: $\log(a \cdot b) = \log a + \log b$ and $\log(a / b) = \log a - \log b$.
\[ \boxed{ (f\circ g)(x)=f(g(x)) } \]

Functions can be chained.

Example:

\[ x \rightarrow g(x) \rightarrow f(g(x)). \]

This is the mathematical structure behind a multi-layer neural network:

input
→ layer 1
→ activation
→ layer 2
→ activation
→ output

The total model is a composition of functions.

12

Identity Function

⚠️ University Exam Trap & Common Misconception
**Logarithm Domain & Identity Trap:** $\ln(x)$ is defined ONLY for $x \gt 0$. Never compute $\log(0)$. Furthermore, $\log(a + b) \neq \log a + \log b$! Only products split into sums: $\log(a \cdot b) = \log a + \log b$ and $\log(a / b) = \log a - \log b$.
\[ \boxed{ f(x)=x } \]

The output equals the input.

It is the neutral mapping under composition:

\[ f(g(x))=g(x) \]

when \(f\) is identity.

13

Inverse Function

An inverse reverses a function's mapping when an appropriate inverse exists.

If:

\[ f(x)=2x+3, \]

then:

\[ y=2x+3. \]

Solve for \(x\):

\[ x=\frac{y-3}{2}. \]

Therefore:

\[ \boxed{ f^{-1}(y)=\frac{y-3}{2} } \]

or equivalently:

\[ \boxed{ f^{-1}(x)=\frac{x-3}{2}. } \]
14

Why Inverses Matter

Logarithms are the inverse of exponentiation.

If:

\[ y=e^x, \]

then:

\[ x=\ln y. \]

This relationship becomes fundamental when understanding likelihoods, cross-entropy and numerical stability.

15

Even and Odd Functions

Even

\[ \boxed{ f(-x)=f(x) } \]

Graph is symmetric about the \(y\)-axis.

Example:

\[ f(x)=x^2. \]

Odd

\[ \boxed{ f(-x)=-f(x) } \]

Graph is symmetric about the origin.

Example:

\[ f(x)=x^3. \]

This is not a central exam target, but it develops graph intuition.

16

Exponential Function

General form:

\[ \boxed{ f(x)=a^x } \]

for \(a\gt 0\), \(a\ne1\).

Special case:

\[ \boxed{ f(x)=e^x } \]

where:

\[ e\approx2.71828. \]
17

Exponential Behaviour

For \(a\gt 1\):

\[ a^x \]

grows as \(x\) increases.

For:

\[ 0\lt a\lt 1, \]

it decreases as \(x\) increases.

Example:

\[ 2^x \]

grows rapidly.

\[ \left(\frac12\right)^x \]

decays.

ML connections

Exponentials appear in:

sigmoid
softmax
probability models
log-likelihood
gradient calculations
18

The Special Property of \(e^x\)

The natural exponential is special because:

\[ \boxed{ \frac{d}{dx}e^x=e^x } \]

Its rate of change equals its own value.

This makes exponential functions especially convenient in calculus and optimization.

19

Exponential Rules

\[ \boxed{ a^xa^y=a^{x+y} } \]
\[ \boxed{ \frac{a^x}{a^y}=a^{x-y} } \]
\[ \boxed{ (a^x)^y=a^{xy} } \]
\[ \boxed{ a^{-x}=\frac1{a^x} } \]
20

Natural Logarithm

The natural logarithm is:

\[ \boxed{\ln x} \]

and is the inverse of \(e^x\).

Therefore:

\[ \ln(e^x)=x \]

and for \(x\gt 0\):

\[ e^{\ln x}=x. \]
21

Logarithm as an Exponent Question

\[ \log_b x=y \]

asks:

What power of \(b\) gives \(x\)?

Example:

\[ \log_2 32=5 \]

because:

\[ 2^5=32. \]
22

Log Rules

Product

\[ \boxed{ \ln(ab)=\ln a+\ln b } \]

Quotient

\[ \boxed{ \ln\left(\frac ab\right)=\ln a-\ln b } \]

Power

\[ \boxed{ \ln(a^r)=r\ln a } \]

for the appropriate real-domain conditions.

These rules are extremely important when manipulating likelihoods and objectives.

23

Why Logs Are Useful in ML

Suppose we multiply many probabilities:

\[ p_1p_2p_3\cdots p_n. \]

The product can become very small.

Taking logarithms changes multiplication into addition:

\[ \ln(p_1p_2\cdots p_n) = \ln p_1+\ln p_2+\cdots+\ln p_n. \]

This is mathematically convenient.

In probability-based ML:

likelihood
→ log-likelihood
→ easier algebra
→ easier optimization
24

Change of Base

\[ \boxed{ \log_b x= \frac{\log_k x}{\log_k b} } \]

Commonly:

\[ \boxed{ \log_b x= \frac{\ln x}{\ln b} } \]

Example:

\[ \log_2 8 = \frac{\ln8}{\ln2} = 3. \]
25

Exponential and Logarithm Connection

These operations reverse each other.

exponential
x → eˣ

logarithm
y → ln(y)

So:

\[ e^{\ln x}=x \]

and:

\[ \ln(e^x)=x. \]

This inverse relationship should become automatic.

26

Sigmoid Function

One of the most important functions in this course:

\[ \boxed{ \sigma(z)=\frac1{1+e^{-z}} } \]

It maps real inputs to:

\[ (0,1). \]

Behaviour

very negative z
→ sigmoid close to 0

z = 0
→ sigmoid = 0.5

very positive z
→ sigmoid close to 1
27

Sigmoid Symmetry

The sigmoid satisfies:

\[ \boxed{ \sigma(-z)=1-\sigma(z) } \]

At zero:

\[ \sigma(0)=\frac12. \]

This property is useful for quickly checking calculations.

28

Sigmoid Derivative

\[ \boxed{ \sigma'(z)=\sigma(z)(1-\sigma(z)) } \]

The derivative is largest around the middle and becomes small toward the extremes.

This helps explain why sigmoid activations can contribute to vanishing-gradient behaviour in deep networks.

29

Hyperbolic Tangent

\[ \boxed{ \tanh(z)= \frac{e^z-e^{-z}} {e^z+e^{-z}} } \]

Its output lies in:

\[ (-1,1). \]

Derivative:

\[ \boxed{ \tanh'(z)=1-\tanh^2(z) } \]

Comparison

sigmoid → (0,1)
tanh    → (-1,1)
30

ReLU

\[ \boxed{ ReLU(x)=\max(0,x) } \]

Piecewise:

\[ ReLU(x)= \begin{cases} 0,&x\lt 0\\ x,&x\ge0 \end{cases} \]

Derivative is:

\[ ReLU'(x)= \begin{cases} 0,&x\lt 0\\ 1,&x\gt 0 \end{cases} \]

At \(x=0\), a derivative convention/subgradient choice is needed.

31

Softmax

For a vector of scores \(z_1,\ldots,z_K\):

\[ \boxed{ softmax(z_k) = \frac{e^{z_k}} {\sum_{j=1}^{K}e^{z_j}} } \]

Each output is positive and the outputs sum to 1:

\[ \sum_{k=1}^{K}softmax(z_k)=1. \]

This makes softmax useful for multi-class probability-style outputs.

32

Softmax Intuition

Suppose:

\[ z=[2,1,0]. \]

The larger score receives a larger softmax value.

Softmax does two things:

1. exponentiate scores
2. normalize them by total exponential mass

The outputs become comparable across classes.

33

Numerical Stability Note

Directly computing:

\[ e^{z_k} \]

can overflow for very large \(z_k\).

Because adding the same constant to every score does not change softmax:

\[ softmax(z)=softmax(z-c) \]

for a common scalar \(c\).

Choose:

\[ c=\max_jz_j. \]

Then:

\[ \boxed{ softmax(z_k)= \frac{e^{z_k-\max z}} {\sum_j e^{z_j-\max z}} } \]

This is the standard numerical-stability transformation.

34

Loss as a Function

A loss function tells us how undesirable a prediction is.

Example:

\[ L(y,\hat y)=(y-\hat y)^2. \]

For fixed \(y\), this becomes a function of \(\hat y\).

At:

\[ \hat y=y, \]

the loss is:

\[ 0. \]

As prediction moves away from the target, squared loss increases.

35

Loss Curves and Optimization

Imagine:

Loss
 ↑
 |       \     /
 |        \___/
 |
 +----------------→ parameter

The goal of optimization is generally to find parameter values where the objective is sufficiently small.

This motivates:

loss
→ derivative
→ gradient
→ gradient descent

covered in M18–M23.

36

Convex vs Non-Convex Intuition

A convex objective has no “bad local valleys” below the global minimum in the usual single-objective sense.

Simple quadratic:

\[ f(x)=x^2 \]

is convex.

A complex neural-network loss surface can be non-convex.

Why this matters

convex
→ optimization has stronger global structure

non-convex
→ optimization is harder

A full optimization treatment comes later.

37

Monotonicity

A function is increasing over an interval when larger input produces larger output.

A function is decreasing when larger input produces smaller output.

Examples:

\[ e^x \]

is increasing.

\[ e^{-x} \]

is decreasing.

\[ \ln x \]

is increasing over \(x\gt 0\).

This helps with reasoning about equations without computing every value.

38

Asymptotes and Limits — Intuition

An asymptote is a line or curve that a function approaches.

For sigmoid:

\[ x\to-\infty \Rightarrow \sigma(x)\to0 \]

and:

\[ x\to\infty \Rightarrow \sigma(x)\to1. \]

Thus:

\[ y=0 \]

and:

\[ y=1 \]

act as horizontal asymptotes.

This explains the saturation behaviour of sigmoid.

39

Limit Notation Preview

\[ \boxed{ \lim_{x\to a}f(x) } \]

means:

What value does \(f(x)\) approach as \(x\) gets arbitrarily close to \(a\)?

Example:

\[ \lim_{x\to0}x^2=0. \]

Limits support the formal definition of derivatives, developed in M18.

40

Derivative as Local Slope

For a function \(f(x)\), the derivative:

\[ f'(x) \]

measures local rate of change.

Geometrically:

slope of the tangent line.

This is the bridge:

graph
→ slope
→ derivative
→ gradient
→ optimization

\[ \ln(ab)=\ln a+\ln b \]

and:

\[ \ln(a^r)=r\ln a. \]

Therefore:

\[ \boxed{ 3\ln x+\ln y } \]

under the relevant positive-domain assumptions.

Worked Example I — Stable Softmax

Suppose:

\[ z=[1001,1000]. \]

Direct exponentiation can be numerically problematic.

Take:

\[ c=\max(z)=1001. \]

Then:

\[ z-c=[0,-1]. \]

So:

\[ softmax(z) = softmax([0,-1]). \]

Thus:

\[ p_1= \frac1{1+e^{-1}} \]

and:

\[ p_2= \frac{e^{-1}}{1+e^{-1}}. \]

The probabilities are unchanged, while the exponentials are safe to compute.

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Logarithm Domain & Identity Trap:** $\ln(x)$ is defined ONLY for $x \gt 0$. Never compute $\log(0)$. Furthermore, $\log(a + b) \neq \log a + \log b$! Only products split into sums: $\log(a \cdot b) = \log a + \log b$ and $\log(a / b) = \log a - \log b$.

Mistake 1 — Log of zero

Over real numbers:

\[ \ln0 \]

is undefined.

Mistake 2 — Log of a negative real number

\[ \ln(-1) \]

is not a real-valued expression.

Mistake 3 — Confusing \(\ln\) and \(\log_2\)

Their values differ unless the base is accounted for.

Mistake 4 — Forgetting the sigmoid denominator

\[ \sigma(z)\ne\frac1{1+e^z}. \]

Correct:

\[ \boxed{ \sigma(z)=\frac1{1+e^{-z}} } \]

Mistake 5 — Softmax does not simply divide raw scores by their sum

It exponentiates first.

Mistake 6 — ReLU has no positive output for negative input

\[ ReLU(-5)=0. \]

Final Concept Anchor

The most useful function-level mental model for AI/ML is:

\[ \boxed{ \text{input} \rightarrow \text{transformation} \rightarrow \text{output} } \]

A machine-learning model simply makes the transformation learnable.

For example:

\[ x \rightarrow wx+b \rightarrow \sigma(wx+b) \rightarrow \hat y. \]

That single chain already contains:

algebra
→ function
→ affine transformation
→ nonlinear function
→ prediction

The upcoming vector and matrix chapters replace the simple scalar \(wx+b\) with the much more powerful:

\[ \boxed{ w^Tx+b. } \]

That is the gateway into the mathematical core of modern AI/ML.
