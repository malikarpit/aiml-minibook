01

Why This Lesson Exists

M18 taught:

\[ y=f(x) \]

and how to calculate:

\[ \frac{dy}{dx}. \]

M19 extended this to several variables:

\[ z=f(x,y) \]

and introduced partial derivatives.

But modern models are often built as compositions.

For example:

\[ x \rightarrow z \rightarrow a \rightarrow L. \]

The final quantity \(L\) depends on \(x\) through several intermediate variables.

The central question becomes:

How does a change at the beginning of the chain affect the final output?

The answer is the chain rule.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Chain Rule deep learning ka heart engine hai! Socho ek line of dominoes: Agar $w$ ko hilane se $z$ hile, $z$ ke hilne se activation $a$ hile, aur $a$ ke hilne se loss $L$ hile, toh $w$ ka $L$ par final effect sabhi beech ke multipliers ka product hota hai: $\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w}$. Is process ko computer mein execute karna hi **Backpropagation** kehlata hai!

Imagine a sequence:

x
↓
z
↓
a
↓
L

Suppose:

x increases slightly
→ z changes
→ a changes
→ L changes

The total effect is obtained by multiplying the local effects along the chain.

Conceptually:

local effect
×
local effect
×
local effect
=
total effect

That is the chain rule.

03

Simple Two-Function Chain

Suppose:

\[ y=f(u) \]

and:

\[ u=g(x). \]

Then \(y\) is ultimately a function of \(x\):

\[ y=f(g(x)). \]

The chain rule states:

\[ \boxed{ \frac{dy}{dx} = \frac{dy}{du} \frac{du}{dx}. } \]

Equivalently:

\[ \boxed{ \frac{d}{dx}f(g(x)) = f'(g(x))g'(x). } \]
04

Why Multiplication Appears

Suppose:

\[ x\rightarrow u\rightarrow y. \]

A small change in \(x\) produces approximately:

\[ \Delta u\approx\frac{du}{dx}\Delta x. \]

Then that change in \(u\) produces:

\[ \Delta y \approx \frac{dy}{du}\Delta u. \]

Substitute the first relation:

\[ \Delta y \approx \frac{dy}{du} \frac{du}{dx} \Delta x. \]

Therefore:

\[ \frac{\Delta y}{\Delta x} \approx \frac{dy}{du} \frac{du}{dx}. \]

Taking the local limit leads to:

\[ \boxed{ \frac{dy}{dx} = \frac{dy}{du}\frac{du}{dx}. } \]
05

Worked Example — \(y=(3x+1)^2\)

Let:

\[ u=3x+1 \]

and:

\[ y=u^2. \]

First:

\[ \frac{dy}{du}=2u. \]

Second:

\[ \frac{du}{dx}=3. \]

Therefore:

\[ \frac{dy}{dx} = 2u\cdot3. \]

Substitute:

\[ u=3x+1. \]

Thus:

\[ \boxed{ \frac{dy}{dx}=6(3x+1). } \]

Expanding:

\[ \boxed{ \frac{dy}{dx}=18x+6. } \]

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

x = 2.0
w = 0.5
b = 0.1
y = 1.0

# 1. Forward Pass
z = w * x + b
a = 1.0 / (1.0 + np.exp(-z))
loss = 0.5 * (y - a)**2

# 2. Backward Pass via Chain Rule
dL_da = -(y - a)
da_dz = a * (1.0 - a)
dL_dz = dL_da * da_dz
dL_dw = dL_dz * x
dL_db = dL_dz * 1.0

print("Forward: z =", round(z, 3), "a =", round(a, 3), "loss =", round(loss, 4))
print("Backward gradients: dL/dw =", round(dL_dw, 5), "dL/db =", round(dL_db, 5))
06

Direct Method vs Chain-Rule Method

For:

\[ y=(3x+1)^2, \]

the direct method gives:

\[ y'=2(3x+1)(3) = 6(3x+1). \]

The chain-rule method gives the same result:

\[ \boxed{ \frac{dy}{dx} = \frac{dy}{du} \frac{du}{dx}. } \]

The point is not that direct differentiation is impossible.

The point is that the chain rule becomes essential when the composition is deep and nested.

07

Deeper Chain

Suppose:

\[ x\rightarrow u\rightarrow v\rightarrow y. \]

Then:

\[ u=g(x), \]
\[ v=h(u), \]
\[ y=f(v). \]

The derivative becomes:

\[ \boxed{ \frac{dy}{dx} = \frac{dy}{dv} \frac{dv}{du} \frac{du}{dx}. } \]

Every intermediate dependency contributes a local derivative.

08

Worked Example — Three-Level Chain

Let:

\[ u=x^2, \]
\[ v=3u+1, \]
\[ y=v^2. \]

Then:

\[ \frac{du}{dx}=2x, \]
\[ \frac{dv}{du}=3, \]
\[ \frac{dy}{dv}=2v. \]

Therefore:

\[ \frac{dy}{dx} = 2v\cdot3\cdot2x. \]

Substitute:

\[ v=3x^2+1. \]

So:

\[ \boxed{ \frac{dy}{dx} = 12x(3x^2+1). } \]

09

The Dependency-Path Mental Model

A very useful way to think about the chain rule:

start variable
     ↓
intermediate quantity
     ↓
intermediate quantity
     ↓
final quantity

Ask:

“Which path connects my variable to the final output?”

Then:

multiply local derivatives along that path

This becomes the basis of computational graphs.

10

Computational Graphs

A computational graph represents a function as a sequence of elementary operations.

Example:

\[ z=xy \]
\[ a=z+3 \]
\[ L=a^2. \]

Graph:

x ───┐
     × → z → (+3) → a → square → L
y ───┘

The forward direction computes the value.

The backward direction applies the chain rule to compute derivatives.

11

Forward Pass

⚠️ University Exam Trap & Common Misconception
**Branching Path Summation Trap:** If a variable $z$ branches into multiple paths (e.g. affects both $h_1$ and $h_2$, which both affect loss $L$), the total chain rule MUST sum over all paths: $\frac{\partial L}{\partial z} = \frac{\partial L}{\partial h_1}\frac{\partial h_1}{\partial z} + \frac{\partial L}{\partial h_2}\frac{\partial h_2}{\partial z}$. Missing the sum across branches is the #1 mistake in neural net backpropagation exam proofs!

Using:

\[ x=2,\qquad y=4, \]

calculate:

\[ z=xy=8. \]

Then:

\[ a=z+3=11. \]

Then:

\[ L=a^2=121. \]

So:

x=2
y=4
↓
z=8
↓
a=11
↓
L=121

This is the forward pass.

12

Local Derivatives in the Graph

⚠️ University Exam Trap & Common Misconception
**Branching Path Summation Trap:** If a variable $z$ branches into multiple paths (e.g. affects both $h_1$ and $h_2$, which both affect loss $L$), the total chain rule MUST sum over all paths: $\frac{\partial L}{\partial z} = \frac{\partial L}{\partial h_1}\frac{\partial h_1}{\partial z} + \frac{\partial L}{\partial h_2}\frac{\partial h_2}{\partial z}$. Missing the sum across branches is the #1 mistake in neural net backpropagation exam proofs!

For:

\[ z=xy, \]

we have:

\[ \frac{\partial z}{\partial x}=y, \qquad \frac{\partial z}{\partial y}=x. \]

For:

\[ a=z+3, \]
\[ \frac{\partial a}{\partial z}=1. \]

For:

\[ L=a^2, \]
\[ \frac{\partial L}{\partial a}=2a. \]

These are local derivatives.

13

Reverse-Mode Calculation

Suppose we want:

\[ \frac{\partial L}{\partial x}. \]

Follow the path:

\[ x\rightarrow z\rightarrow a\rightarrow L. \]

Then:

\[ \boxed{ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial a} \frac{\partial a}{\partial z} \frac{\partial z}{\partial x}. } \]

At the numerical point:

\[ \frac{\partial L}{\partial a}=2a=22, \]
\[ \frac{\partial a}{\partial z}=1, \]
\[ \frac{\partial z}{\partial x}=y=4. \]

Therefore:

\[ \boxed{ \frac{\partial L}{\partial x}=22\cdot1\cdot4=88. } \]

Similarly:

\[ \boxed{ \frac{\partial L}{\partial y}=22\cdot1\cdot2=44. } \]

14

Why the Backward Pass Is Powerful

Suppose a model has:

millions of parameters

and one scalar loss:

\[ L. \]

We want:

\[ \frac{\partial L}{\partial w_i} \]

for many parameters.

A computational graph lets us reuse intermediate derivative information instead of independently rebuilding the entire derivative expression for every parameter.

This is the core computational idea behind reverse-mode differentiation.

For neural networks, this is commonly referred to as backpropagation.

15

Chain Rule in Parameter Learning

Suppose:

\[ w\rightarrow z\rightarrow L. \]

Then:

\[ \boxed{ \frac{dL}{dw} = \frac{dL}{dz} \frac{dz}{dw}. } \]

Interpretation:

How sensitive is L to z?
×
How sensitive is z to w?
=
How sensitive is L to w?

This interpretation is extremely important in ML.

16

A Local Sensitivity Interpretation

A derivative can be viewed as a local sensitivity factor.

For example:

\[ \frac{dL}{dz}=5 \]

means a small change in \(z\) produces roughly:

\[ \Delta L\approx5\Delta z. \]

If:

\[ \frac{dz}{dw}=3, \]

then:

\[ \frac{dL}{dw}=5\cdot3=15. \]

So:

\[ \Delta L\approx15\Delta w. \]

The chain rule composes sensitivities.

17

Chain Rule with Partial Derivatives

Now consider:

\[ z=f(x,y) \]

and:

\[ L=g(z). \]

Then:

\[ L \]

depends on both \(x\) and \(y\) through \(z\).

The chain rule gives:

\[ \boxed{ \frac{\partial L}{\partial x} = \frac{dL}{dz} \frac{\partial z}{\partial x} } \]

and:

\[ \boxed{ \frac{\partial L}{\partial y} = \frac{dL}{dz} \frac{\partial z}{\partial y}. } \]
18

Multiple Paths

This is a crucial extension.

Suppose:

\[ x\rightarrow z_1\rightarrow L \]

and:

\[ x\rightarrow z_2\rightarrow L. \]

Then \(L\) depends on \(x\) through two paths.

The total derivative is the sum of the path contributions:

\[ \boxed{ \frac{dL}{dx} = \frac{\partial L}{\partial z_1} \frac{dz_1}{dx} + \frac{\partial L}{\partial z_2} \frac{dz_2}{dx}. } \]

Mental rule:

one dependency path
→ multiply

multiple dependency paths
→ multiply along each path
→ add path contributions

This “multiply along paths, add across paths” idea is a powerful way to understand reverse-mode differentiation.

19

Worked Example — Two Paths

Let:

\[ z_1=2x, \]
\[ z_2=x^2, \]

and:

\[ L=z_1+3z_2. \]

Then:

\[ \frac{\partial L}{\partial z_1}=1, \]
\[ \frac{\partial L}{\partial z_2}=3. \]

Also:

\[ \frac{dz_1}{dx}=2, \]
\[ \frac{dz_2}{dx}=2x. \]

Therefore:

\[ \frac{dL}{dx} = (1)(2)+(3)(2x). \]

Hence:

\[ \boxed{ \frac{dL}{dx}=2+6x. } \]

Directly:

\[ L=2x+3x^2, \]

so:

\[ L'=2+6x. \]

Both methods agree.

20

Why Order Matters

Suppose:

\[ x\rightarrow u\rightarrow v\rightarrow L. \]

The chain must respect dependency:

\[ \frac{dL}{dx} = \frac{dL}{dv} \frac{dv}{du} \frac{du}{dx}. \]

You cannot randomly multiply derivatives from unrelated nodes.

The chain rule follows the actual dependency path.

21

Product of Local Effects

For:

\[ x\rightarrow u\rightarrow v\rightarrow y, \]

think:

effect of x on u
×
effect of u on v
×
effect of v on y

Thus:

\[ \boxed{ \text{total local sensitivity} = \prod \text{(local sensitivities along path)}. } \]

This viewpoint will later help explain vanishing and exploding gradients in deep networks.

22

Chain Rule and Composition

For:

\[ y=f(g(x)), \]

the outer derivative must be evaluated at the inner output:

\[ \boxed{ \frac{dy}{dx} = f'(g(x))g'(x). } \]

This is a frequent exam trap.

Do not accidentally write:

\[ f'(x)g'(x). \]

The correct expression is:

\[ f'(g(x))g'(x). \]
23

Worked Example — Exponential Composition

Let:

\[ y=e^{x^2}. \]

Define:

\[ u=x^2. \]

Then:

\[ y=e^u. \]

Therefore:

\[ \frac{dy}{du}=e^u, \]
\[ \frac{du}{dx}=2x. \]

Hence:

\[ \boxed{ \frac{dy}{dx} = 2xe^{x^2}. } \]

Worked Example — Log Composition

Let:

\[ y=\ln(x^2+1). \]

Set:

\[ u=x^2+1. \]

Then:

\[ \frac{dy}{du}=\frac1u, \]

and:

\[ \frac{du}{dx}=2x. \]

Therefore:

\[ \boxed{ \frac{dy}{dx} = \frac{2x}{x^2+1}. } \]

25

Computational Graph for a Neural-Like Expression

Consider:

\[ z=w x+b, \]
\[ a=\sigma(z), \]
\[ L=(a-y)^2. \]

Graph:

x ─────┐
       × ──→ wx ──┐
w ─────┘          + ──→ z ──→ σ ──→ a ──→ (a−y)² ──→ L
                  ↑
b ─────────────────┘

The exact activation function \(\sigma\) is not the focus here.

The chain structure is:

\[ w\rightarrow z\rightarrow a\rightarrow L. \]

Thus:

\[ \boxed{ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \frac{\partial a}{\partial z} \frac{\partial z}{\partial w}. } \]

Because:

\[ \frac{\partial z}{\partial w}=x, \]

we obtain:

\[ \boxed{ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \frac{\partial a}{\partial z} x. } \]

This is the structural idea used repeatedly in backpropagation.

26

Backpropagation as Repeated Chain Rule

At its mathematical core:

\[ \boxed{ \text{backpropagation} = \text{efficient application of the chain rule through a computational graph}. } \]

It is therefore not a completely separate calculus trick.

It is the chain rule organized computationally.

27

Forward Mode vs Reverse Mode

There are two broad ways to propagate derivative information.

Forward mode

Start from an input change and propagate its effect forward.

input sensitivity
→ intermediate sensitivity
→ output sensitivity

Useful when:

few inputs
many outputs

Reverse mode

Start from an output quantity, such as a scalar loss, and propagate sensitivity backward.

output sensitivity
→ intermediate sensitivity
→ parameter sensitivity

This is especially useful when:

many parameters
one scalar output

That situation is common in machine learning.

28

Why Reverse Mode Fits ML

A neural network may have:

millions or billions of parameters

but training usually produces one scalar objective for one example/batch:

\[ L. \]

We want the derivative with respect to many parameters:

\[ \nabla_{\theta}L. \]

Reverse-mode differentiation works from the scalar output backward and can efficiently accumulate parameter sensitivities.

This is the mathematical reason backpropagation is so important for neural networks.

29

Jacobian Preview

For a scalar function:

\[ f:\mathbb R^d\to\mathbb R, \]

the gradient collects partial derivatives.

For a vector-valued function:

\[ \mathbf y:\mathbb R^n\to\mathbb R^m, \]

we need the derivatives of every output with respect to every input.

These derivatives form the Jacobian.

M21 develops this systematically.

Hinglish Teacher Explanation

Chain rule ko ek pipeline samjho:

x
↓
z
↓
a
↓
loss

Agar \(x\) thoda change hua, toh directly loss nahi badalta.

Pehle:

x changes
→ z changes
→ a changes
→ loss changes

Har stage ka apna sensitivity factor hai.

For example:

\[ \frac{dz}{dx}=3, \]
\[ \frac{da}{dz}=5, \]
\[ \frac{dL}{da}=2. \]

Toh:

\[ \frac{dL}{dx} = 2\times5\times3 = 30. \]

Meaning:

\(x\) mein tiny change ka loss par local effect 30 times ke scale par hai.

Agar graph mein do different paths hain, har path ka contribution calculate karke add karte hain.

Yahi idea neural-network backpropagation ka mathematical heart hai.

Numerical-Solving Protocol

For a nested function:

1. Identify inner and outer functions
2. Define intermediate variables if helpful
3. Differentiate each local stage
4. Multiply derivatives in dependency order
5. Substitute back
6. Simplify

For a computational graph:

1. Draw nodes
2. Compute forward values
3. Compute local derivatives
4. Start at the final output
5. Propagate sensitivity backward
6. Multiply along each path
7. Add contributions from multiple paths

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Branching Path Summation Trap:** If a variable $z$ branches into multiple paths (e.g. affects both $h_1$ and $h_2$, which both affect loss $L$), the total chain rule MUST sum over all paths: $\frac{\partial L}{\partial z} = \frac{\partial L}{\partial h_1}\frac{\partial h_1}{\partial z} + \frac{\partial L}{\partial h_2}\frac{\partial h_2}{\partial z}$. Missing the sum across branches is the #1 mistake in neural net backpropagation exam proofs!

Mistake 1

For:

\[ f(g(x)), \]

forgetting \(g'(x)\).

Mistake 2

Evaluating the outer derivative at \(x\) instead of \(g(x)\).

Mistake 3

Multiplying derivatives from unrelated paths.

Mistake 4

Forgetting to add contributions when two paths connect the same input to the output.

Mistake 5

Confusing:

local derivative

with:

total derivative through the full graph.

Mistake 6

Trying to differentiate a large composite expression in one giant step when a computational graph would make the dependency structure clearer.
