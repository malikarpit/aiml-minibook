One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Random Variable koi normal variable nahi hai—ye asal mein ek **Function** hai jo outcome ko ek real number par map karta hai! Discrete distribution mein har point par probability mass hota hai ($P(X = 3) = 0.2$). Continuous distribution mein kisi EXACT point ki probability ZERO hoti hai ($P(X = 1.73205) = 0$)! Probability sirf kisi range ke andar area under curve se aati hai: $\int_a^b f(x) dx$.

A random variable is like a translator:

random experiment
      ↓
outcome ω
      ↓
random variable X
      ↓
number X(ω)

For example, toss a coin twice.

Outcomes:

\[ HH,HT,TH,TT. \]

Let:

\[ X=\text{number of heads}. \]

Then:

HH → 2
HT → 1
TH → 1
TT → 0

The supplied Lecture02 uses this exact example.

03

Formal Definition

A random variable is a function:

\[ \boxed{ X:\Omega\rightarrow\mathbb R. } \]

It maps each outcome:

\[ \omega\in\Omega \]

to a real number:

\[ X(\omega). \]

The supplied Lecture02 explicitly gives this definition and notation.

04

Important Idea: A Random Variable Is a Function

The word “variable” can be misleading.

Mathematically:

\[ X \]

is a function.

It is random because its input outcome is random.

Example:

\[ X(H)=1, \quad X(T)=0. \]

So:

outcome
→ function
→ numerical value

Random Variable Example — One Coin

graph TD
    A["Sample Space Ω (e.g. Outcomes of Experiment)"] -->|Mapping X: Ω → ℝ| B["Random Variable X"]

Experiment:

Toss a fair coin once.

Sample space:

\[ \Omega=\{H,T\}. \]

Define:

\[ X= \begin{cases} 1,&H\\ 0,&T \end{cases} \]

Then:

\[ X(H)=1, \qquad X(T)=0. \]

This random variable is discrete.

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

def normal_pdf(x, mu=0.0, sigma=1.0):
    return (1.0 / (sigma * np.sqrt(2 * np.pi))) * np.exp(-0.5 * ((x - mu) / sigma)**2)

x_vals = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])
densities = normal_pdf(x_vals, mu=0.0, sigma=1.0)

print("Standard Normal PDF values at", x_vals)
print("Densities f(x):", np.round(densities, 4))
print("Peak density at mu=0 is ~0.3989")

Range / Support

The range of \(X\) is the set of values it can take:

\[ \boxed{ \mathcal X=\{X(\omega):\omega\in\Omega\}. } \]

For a discrete random variable, the range is finite or countably infinite.

For the two-coin example:

\[ \mathcal X=\{0,1,2\}. \]
08

Discrete vs Continuous

Discrete random variable

Takes values in a finite or countably infinite set.

Examples:

number of heads
number of customers
number of errors
number of clicks

Continuous random variable

Can take values over intervals of real numbers.

Examples:

height
temperature
time
distance

The supplied Lecture02 explicitly separates discrete and continuous random variables.

09

PMF

For a discrete random variable \(X\), the probability mass function is:

\[ \boxed{ p_X(x)=P(X=x). } \]

It tells us the probability assigned to each possible value.

The supplied Lecture02 gives this definition.

10

PMF Properties

For every valid \(x\):

\[ \boxed{ p_X(x)\ge0 } \]

and:

\[ \boxed{ \sum_{x\in\mathcal X}p_X(x)=1. } \]

For a set \(A\subseteq\mathcal X\):

\[ \boxed{ P(X\in A) = \sum_{x\in A}p_X(x). } \]

Two-Coin PMF

⚠️ University Exam Trap & Common Misconception
**PDF Value is NOT a Probability:** For continuous variables, $f(x)$ is a probability DENSITY, not a probability! $f(x)$ can easily exceed 1.0 (for instance, a uniform distribution on $[0, 0.5]$ has $f(x) = 2.0$). Only the integral (area) over an interval represents probability and cannot exceed 1.0.

For:

\[ X=\text{number of heads in two fair tosses}, \]

possible values:

\[ 0,1,2. \]

\(X=0\)

Only:

\[ TT. \]

Therefore:

\[ p_X(0)=\frac14. \]

\(X=1\)

Outcomes:

\[ HT,TH. \]

Therefore:

\[ p_X(1)=\frac24=\frac12. \]

\(X=2\)

Only:

\[ HH. \]

Therefore:

\[ p_X(2)=\frac14. \]

So:

\[ \boxed{ p_X(0)=\frac14,\quad p_X(1)=\frac12,\quad p_X(2)=\frac14. } \]

The supplied Lecture02 gives these exact values and verifies that the total mass is 1.

Calculating an Event from a PMF

Suppose:

\[ p_X(0)=0.2,\quad p_X(1)=0.5,\quad p_X(2)=0.3. \]

Find:

\[ P(X\in\{1,2\}). \]

Add the relevant masses:

14

CDF

The cumulative distribution function exists for any random variable.

Definition:

\[ \boxed{ F_X(x)=P(X\le x). } \]

The supplied Lecture02 explicitly states this definition.

It accumulates probability from the left.

15

CDF Interpretation

Think:

move from −∞ toward x
↓
keep collecting probability
↓
F_X(x)

Therefore \(F_X(x)\) can never decrease.

\[ \boxed{ F_X(x)\text{ is non-decreasing}. } \]

Also:

\[ \boxed{ \lim_{x\to-\infty}F_X(x)=0 } \]

and:

\[ \boxed{ \lim_{x\to+\infty}F_X(x)=1. } \]

These properties are given in Lecture02.

16

CDF of the Two-Coin Variable

Recall:

\[ P(X=0)=\frac14 \]
\[ P(X=1)=\frac12 \]
\[ P(X=2)=\frac14. \]

Then:

At \(x\lt 0\)

\[ F_X(x)=0. \]

At \(0\le x\lt 1\)

\[ F_X(x)=\frac14. \]

At \(1\le x\lt 2\)

\[ F_X(x)=\frac14+\frac12 = \frac34. \]

At \(x\ge2\)

\[ F_X(x)=1. \]

So the discrete CDF is a step function.

17

PMF vs CDF

PMF

\[ p_X(x)=P(X=x). \]

Question:

Probability at this specific discrete value?

CDF

\[ F_X(x)=P(X\le x). \]

Question:

Probability accumulated up to this value?

Memory:

PMF = point mass
CDF = cumulative mass
18

CDF Intervals

For any random variable and \(a\lt b\):

\[ \boxed{ P(a\lt X\le b) = F_X(b)-F_X(a). } \]

The supplied Lecture02 states this identity explicitly.

This formula is extremely useful because it works for both discrete and continuous distributions, with the endpoint convention shown.

19

Discrete CDF as Sum of PMF

For discrete \(X\):

\[ \boxed{ F_X(x) = \sum_{y\le x}p_X(y). } \]

So:

PMF
↓ cumulative sum
CDF

This is exactly the relationship shown in the supplied Lecture02.

20

Continuous Random Variable

A continuous random variable can take values over an interval.

Example:

\[ X\sim Uniform[2,2.5]. \]

There are infinitely many possible values.

For a particular point such as:

\[ x=2.25, \]

we have:

\[ \boxed{ P(X=2.25)=0. } \]

This does not mean 2.25 is impossible.

It means a single point has zero probability under the continuous model.

The supplied Lecture02 highlights this distinction.

21

PDF

For a continuous random variable, the probability density function is:

\[ \boxed{ f_X(x)=\frac{dF_X(x)}{dx} } \]

where the derivative exists.

The supplied Lecture02 states that the PDF is the derivative of the CDF.

22

PDF Is Not a Probability

This is one of the most important traps.

A PDF satisfies:

\[ f_X(x)\ge0. \]

But:

\[ \boxed{ f_X(x)\text{ itself is not generally a probability}. } \]

It can even be greater than 1.

The probability of an interval is the area under the PDF:

\[ \boxed{ P(a\le X\le b) = \int_a^b f_X(t)\,dt. } \]

This distinction is explicitly emphasized in Lecture02.

23

Total Area Under a PDF

Because total probability is 1:

\[ \boxed{ \int_{-\infty}^{\infty} f_X(t)\,dt=1. } \]

Therefore a valid PDF must have total area exactly 1.

24

CDF from PDF

For a continuous random variable:

\[ \boxed{ F_X(x) = \int_{-\infty}^{x} f_X(t)\,dt. } \]

So:

PDF
→ integrate
→ CDF

CDF
→ differentiate
→ PDF

when the required regularity conditions hold.

The supplied Lecture02 gives both relationships.

25

Worked Example — Uniform PDF

Let:

\[ X\sim Uniform[2,2.5]. \]

The interval width is:

\[ 2.5-2=0.5. \]

For a uniform density:

\[ f_X(x)=c \]

inside the interval.

Total area must be 1:

\[ \int_2^{2.5}c\,dx=1. \]

Therefore:

\[ 0.5c=1 \]

so:

\[ \boxed{ c=2. } \]

Thus:

\[ f_X(x)= \begin{cases} 2,&2\le x\le2.5\\ 0,&\text{otherwise}. \end{cases} \]

This is the exact normalization calculation from Lecture02.

Worked Example — CDF of Uniform Distribution

For:

\[ X\sim Uniform[a,b], \]

the CDF is:

\[ F_X(x)= \begin{cases} 0,&x\lt a\\ \frac{x-a}{b-a},&a\le x\le b\\ 1,&x\gt b. \end{cases} \]

For:

\[ Uniform[2,2.5], \]

this becomes:

\[ \boxed{ F_X(x)= \begin{cases} 0,&x\lt 2\\ \dfrac{x-2}{0.5},&2\le x\le2.5\\ 1,&x\gt 2.5. \end{cases} } \]

At:

\[ x=2.25, \]
\[ F_X(2.25) = \frac{0.25}{0.5} = \boxed{0.5}. \]

A Common Trap: PDF > 1

Suppose:

\[ f_X(x)=2 \]

over an interval of length \(0.5\).

That is completely valid because:

\[ 2(0.5)=1. \]

So:

\[ \boxed{ f_X(x)\gt 1 } \]

is possible.

What must remain true is:

PDF ≥ 0
total area = 1

Reinforcement-Learning Connection

In RL:

state
→ action
→ reward
→ next state

can be stochastic.

A reward \(R_t\) is therefore naturally treated as a random variable.

The return:

\[ G_t \]

is also a random quantity.

Expectation later gives:

\[ V^\pi(s)=E[G_t|S_t=s]. \]

Thus random-variable mathematics eventually becomes the foundation for value functions.

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**PDF Value is NOT a Probability:** For continuous variables, $f(x)$ is a probability DENSITY, not a probability! $f(x)$ can easily exceed 1.0 (for instance, a uniform distribution on $[0, 0.5]$ has $f(x) = 2.0$). Only the integral (area) over an interval represents probability and cannot exceed 1.0.

Mistake 1 — PMF for a continuous variable

Continuous variables use a PDF, not a PMF.

Mistake 2 — PDF is probability

Wrong.

\[ f_X(x) \]

is density.

Mistake 3 — PDF must be ≤1

False.

Only total area must equal 1.

Mistake 4 — CDF can decrease

False.

\[ F_X(x) \]

is non-decreasing.

Mistake 5 — \(P(X=x)=0\) means impossible

Not in continuous models.

Mistake 6 — CDF is only for continuous variables

False.

CDF exists for every random variable.

Mistake 7 — PMF values need not sum to 1

They must:

\[ \sum_xp_X(x)=1. \]

F-M13-PMF-01 — PMF

\[ \boxed{ p_X(x)=P(X=x) } \]

for discrete \(X\).

F-M13-PMF-02 — PMF Normalization

\[ \boxed{ \sum_xp_X(x)=1 } \]

F-M13-EVENT-01 — Event from PMF

\[ \boxed{ P(X\in A)=\sum_{x\in A}p_X(x) } \]

F-M13-CDF-01 — CDF

\[ \boxed{ F_X(x)=P(X\le x) } \]

F-M13-CDF-02 — Interval Probability

\[ \boxed{ P(a\lt X\le b)=F_X(b)-F_X(a) } \]

F-M13-PDF-01 — PDF from CDF

\[ \boxed{ f_X(x)=\frac{dF_X(x)}{dx} } \]

where differentiable.

F-M13-PDF-02 — Probability from PDF

\[ \boxed{ P(a\le X\le b) = \int_a^b f_X(t)\,dt } \]

F-M13-PDF-03 — PDF Normalization

\[ \boxed{ \int_{-\infty}^{\infty}f_X(t)\,dt=1 } \]

Discrete ↔ Continuous Translation

A powerful memory map:

DISCRETE                    CONTINUOUS

PMF                         PDF
pX(x)                       fX(x)

sum                         integral

Σ pX(x)=1                   ∫fX(x)dx=1

point mass                  density/area

CDF = cumulative sum        CDF = cumulative integral

If given a PMF

Identify possible x values
↓

↓
add the relevant probabilities

If given a CDF

write F(b)
− F(a)

with the exact endpoint convention required.

If given a PDF

identify interval
↓
integrate PDF over interval
↓
check result lies in [0,1]

If given a discrete RV

build support
↓
map outcomes → numbers
↓
calculate PMF
