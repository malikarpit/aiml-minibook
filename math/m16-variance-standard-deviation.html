01

Why This Lesson Exists

Expectation tells us the center of a random variable.

But two random variables can have the same expectation and behave very differently.

Example:

A: values usually close to 5
B: values sometimes near 0 and sometimes near 10

Both may have:

\[ E[X]=5. \]

But B is much more spread out.

We therefore need a second summary:

\[ \boxed{\text{How far does }X\text{ tend to move away from its mean?}} \]

That is the purpose of variance.

Its square root is the standard deviation.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Mean batata hai distribution kahan center hai; Variance batata hai distribution kitna bikhra hua hai (spread)! Agar do models ka average accuracy 80% hai, lekin ek model har test par 79-81% deta hai (low variance) aur doosra model kabhi 40% kabhi 100% deta hai (high variance), toh low variance model production ke liye 100 times better hai!

Suppose:

\[ E[X]=10. \]

An outcome:

\[ X=11 \]

is only 1 unit away from the mean.

An outcome:

\[ X=20 \]

is 10 units away.

Variance measures these deviations while making them nonnegative and emphasizing large deviations.

Conceptually:

value
 ↓
distance from mean
 ↓
square distance
 ↓
probability-weighted average
 ↓
variance
03

Definition of Variance

The variance of \(X\) is:

\[ \boxed{ Var(X) = E\left[(X-E[X])^2\right]. } \]

The supplied Lecture02 gives this definition directly. fileciteturn67file4

Let:

\[ \mu=E[X]. \]

Then the same formula becomes:

\[ \boxed{ Var(X)=E[(X-\mu)^2]. } \]
04

Why Do We Subtract the Mean?

The mean represents the center.

Therefore:

\[ X-\mu \]

measures the deviation from the center.

Example:

\[ \mu=10. \]

If:

\[ X=12, \]

then:

\[ X-\mu=2. \]

If:

\[ X=8, \]

then:

\[ X-\mu=-2. \]

Without squaring, positive and negative deviations could cancel.

05

Why Square the Deviation?

graph TD
    A["Expected Mean: μ = E[X]"] --> B["Deviations from Mean: (X - μ)"]
    B --> C["Square Deviations: (X - μ)² (Guarantees Positive Penalties)"]
    C --> D["Variance: Var(X) = E[(X - μ)²] = E[X²] - (E[X])²"]
    D --> E["Standard Deviation: σ = √Var(X) (Original Feature Units)"]
    style D fill:#0f172a,stroke:#fbbf24,color:#fbbf24,stroke-width:2px

Consider:

\[ +2,\quad -2. \]

Their ordinary average is:

\[ \frac{2+(-2)}2=0. \]

That would incorrectly suggest no spread.

Square them:

\[ 2^2=4, \]
\[ (-2)^2=4. \]

Now both contribute positively.

So:

\[ (X-\mu)^2 \]

turns distance into a nonnegative quantity.

Large deviations are also penalized more strongly.

06

Discrete Variance

For a discrete random variable:

\[ \boxed{ Var(X) = \sum_x (x-\mu)^2p_X(x) } \]

where:

\[ \mu=E[X]. \]

Read it as:

deviation² × probability, summed over every possible value.

07

Continuous Variance

For a continuous random variable:

\[ \boxed{ Var(X) = \int_{-\infty}^{\infty} (x-\mu)^2f_X(x)\,dx. } \]

So the familiar probability pattern continues:

discrete
→ summation

continuous
→ integration
08

The Computational Formula

Directly calculating:

\[ E[(X-\mu)^2] \]

can be inconvenient.

A highly useful identity is:

\[ \boxed{ Var(X) = E[X^2]-E[X]^2. } \]

The supplied Lecture02 explicitly gives this identity. fileciteturn67file4

In terms of \(\mu\):

\[ \boxed{ Var(X)=E[X^2]-\mu^2. } \]

This is often the fastest route in numerical problems.

09

Derivation of the Computational Formula

Start with:

\[ Var(X)=E[(X-\mu)^2]. \]

Expand:

\[ (X-\mu)^2=X^2-2\mu X+\mu^2. \]

Therefore:

\[ Var(X) = E[X^2-2\mu X+\mu^2]. \]

Using linearity:

\[ = E[X^2]-2\mu E[X]+E[\mu^2]. \]

Because \(\mu\) is a constant:

\[ E[\mu^2]=\mu^2. \]

And:

\[ E[X]=\mu. \]

So:

\[ Var(X) = E[X^2]-2\mu^2+\mu^2. \]

Hence:

\[ \boxed{ Var(X)=E[X^2]-\mu^2 = E[X^2]-E[X]^2. } \]

This identity should be understood, not merely memorized.

10

Two Variance Routes

Route A — Definition

\[ \boxed{ Var(X)=E[(X-\mu)^2] } \]

Use when deviation-from-mean intuition is important.

Route B — Shortcut

\[ \boxed{ Var(X)=E[X^2]-E[X]^2 } \]

Use when \(E[X]\) and \(E[X^2]\) are easy to obtain.

Memory:

variance
=
mean of squared deviations

or

second moment
−
square of first moment

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

data = np.array([2.0, 4.0, 4.0, 4.0, 5.0, 5.0, 7.0, 9.0])
mean = np.mean(data)
var_sample = np.var(data, ddof=1)
std_dev = np.std(data, ddof=1)

print("Data:", data)
print("Mean μ:", mean)
print("Sample Variance s²:", var_sample)
print("Sample Std Dev s:", np.round(std_dev, 4))
11

Variance Is Never Negative

⚠️ University Exam Trap & Common Misconception
**Variance Linear Scaling Rule:** $\text{Var}(aX + b) = a^2 \text{Var}(X)$! The additive constant $b$ shifts every point equally without stretching the spread, so its contribution to variance is EXACTLY ZERO! The multiplier $a$ is squared ($a^2$). Writing $\text{Var}(aX+b) = a\text{Var}(X) + b$ is an automatic zero in exams!

Because:

\[ (X-\mu)^2\ge0 \]

for every outcome:

\[ E[(X-\mu)^2]\ge0. \]

Therefore:

\[ \boxed{ Var(X)\ge0. } \]

A negative variance is mathematically impossible and indicates an error.

12

When Is Variance Zero?

⚠️ University Exam Trap & Common Misconception
**Variance Linear Scaling Rule:** $\text{Var}(aX + b) = a^2 \text{Var}(X)$! The additive constant $b$ shifts every point equally without stretching the spread, so its contribution to variance is EXACTLY ZERO! The multiplier $a$ is squared ($a^2$). Writing $\text{Var}(aX+b) = a\text{Var}(X) + b$ is an automatic zero in exams!

If:

\[ Var(X)=0, \]

then the squared deviation is zero with probability 1.

Hence:

\[ X=\mu \]

almost surely.

Informally:

there is no randomness left; the value is effectively constant.

Example:

\[ X=7 \]

always gives:

\[ E[X]=7, \]
\[ Var(X)=0. \]
13

Worked Example — Simple Discrete PMF

Suppose:

\(x\) \(p_X(x)\)
0 0.2
1 0.5
2 0.3

From M15:

\[ E[X]=1.1. \]

Now:

\[ E[X^2] = 0^2(0.2)+1^2(0.5)+2^2(0.3) = 1.7. \]

Therefore:

\[ Var(X) = 1.7-(1.1)^2 \]
\[ = 1.7-1.21 = \boxed{0.49}. \]

15

Standard Deviation

Variance is measured in squared units.

If \(X\) is measured in:

metres

then variance is measured in:

metres²

That is sometimes inconvenient for interpretation.

The standard deviation returns to the original unit:

\[ \boxed{ \sigma_X = \sqrt{Var(X)}. } \]

The supplied Lecture02 defines standard deviation as the square root of variance. fileciteturn67file4

16

Worked Example — Standard Deviation

From the previous example:

\[ Var(X)=0.49. \]

Therefore:

\[ \sigma_X = \sqrt{0.49} = \boxed{0.7}. \]

So:

Mean = 1.1
Variance = 0.49
Standard deviation = 0.7

17

Variance vs Standard Deviation

Quantity Formula Unit
Variance \(E[(X-\mu)^2]\) squared unit
Standard deviation \(\sqrt{Var(X)}\) original unit

Memory:

Variance squares. Standard deviation unsquares.

18

Scaling Property

Suppose:

\[ Y=aX. \]

Then:

\[ \boxed{ Var(aX)=a^2Var(X). } \]

Why the square?

Because:

\[ aX-E[aX] = a(X-E[X]), \]

and squaring gives:

\[ a^2(X-E[X])^2. \]

Therefore:

\[ \boxed{ Std(aX)=|a|Std(X). } \]
19

Shift Property

Suppose:

\[ Y=X+b. \]

Then:

\[ \boxed{ Var(X+b)=Var(X). } \]

Adding a constant moves the entire distribution without changing its spread.

Conceptually:

shift center
→ spread unchanged
20

Combined Affine Transformation

For:

\[ Y=aX+b, \]

the mean is:

\[ E[Y]=aE[X]+b \]

and the variance is:

\[ \boxed{ Var(Y)=a^2Var(X). } \]

The shift \(b\) does not affect variance.

21

Why the Mean Shift Does Not Matter

Suppose two datasets are:

1, 2, 3

and:

101, 102, 103

Their centers differ by 100, but their spread is identical.

Adding a constant changes location:

\[ X\rightarrow X+b \]

but not dispersion.

22

Uniform Distribution Example

The supplied Lecture02 works with:

\[ X\sim Uniform(0,1). \]

For this distribution:

\[ E[X]=\frac12 \]

and:

\[ \boxed{ Var(X)=\frac1{12}. } \]

The lecture derives the second moment:

\[ E[X^2] = \int_0^1x^2dx = \frac13 \]

and therefore:

\[ Var(X) = \frac13-\frac14 = \frac1{12}. \]

Variance as a Measure of Uncertainty

Two distributions can share the same mean but have different variance.

small variance
→ tightly concentrated around mean

large variance
→ more dispersed around mean

This is why variance is often used as a simple measure of uncertainty.

But remember:

variance is sensitive to squared deviations, so unusually large deviations can have strong influence.

25

Expectation and Variance Work Together

A useful mental pair is:

\[ \boxed{ E[X]\rightarrow \text{center} } \]
\[ \boxed{ Var(X)\rightarrow \text{spread} } \]

and:

\[ \boxed{ Std(X)\rightarrow \text{spread in original units}. } \]

Think:

mean
  ↓
where is the distribution centered?

variance/std
  ↓
how dispersed is it?
26

AI/ML Connection — Feature Scaling

Suppose a feature \(X\) has:

\[ E[X]=50, \qquad Std(X)=10. \]

Standardization uses:

\[ \boxed{ Z=\frac{X-\mu}{\sigma}. } \]

Then:

\[ E[Z]=0 \]

and:

\[ Var(Z)=1 \]

when \(\mu,\sigma\) are the true mean and standard deviation with \(\sigma\gt 0\).

This makes variance directly relevant to preprocessing and optimization.

27

AI/ML Connection — Bias–Variance

The supplied Lecture08.pdf uses variance as one component of expected test error:

\[ \boxed{ Expected\ Test\ Error = Bias^2+Variance+Irreducible\ Error. } \]

It describes variance as error due to sensitivity of the learned model to the training data. fileciteturn67file5

Important distinction:

M16 variance of a random variable

and:

model variance in bias–variance analysis

are related mathematically through expected squared deviations, but they refer to different random quantities.

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Variance Linear Scaling Rule:** $\text{Var}(aX + b) = a^2 \text{Var}(X)$! The additive constant $b$ shifts every point equally without stretching the spread, so its contribution to variance is EXACTLY ZERO! The multiplier $a$ is squared ($a^2$). Writing $\text{Var}(aX+b) = a\text{Var}(X) + b$ is an automatic zero in exams!

Mistake 1

Writing:

\[ Var(X)=E[X]^2-E[X^2]. \]

Wrong sign.

Correct:

\[ \boxed{ Var(X)=E[X^2]-E[X]^2. } \]

Mistake 2

Forgetting the square:

\[ E[X-\mu] \]

is zero, not variance.

Mistake 3

Taking square root too early.

First compute variance, then:

\[ \sigma=\sqrt{Var(X)}. \]

Mistake 4

Thinking adding a constant changes variance.

It does not.

Mistake 5

Thinking multiplying by \(a\) multiplies variance by \(a\).

It multiplies variance by:

\[ a^2. \]

Mistake 6

Using standard deviation and variance interchangeably.

They have different units and different formulas.

30

Numerical-Solving Protocol

When asked for variance:

1. Find E[X]
2. Find E[X²]
3. Use Var(X)=E[X²]−E[X]²
4. If needed, take sqrt for SD
5. Check Var(X) ≥ 0
6. Check units

Alternative:

1. Find μ
2. Compute (x−μ)²
3. Weight by probability
4. Sum/integrate

Choose the simpler route.
