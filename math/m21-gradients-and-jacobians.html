01

Why This Lesson Exists

M19 gave us:

\[ \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_d}. \]

M20 taught us how derivatives flow through compositions.

Now we need a clean mathematical object that gathers this information.

For a scalar-valued function:

\[ f:\mathbb R^d\to\mathbb R, \]

that object is the gradient.

For a vector-valued function:

\[ \mathbf f:\mathbb R^n\to\mathbb R^m, \]

the corresponding general object is the Jacobian matrix.

These objects connect calculus to linear algebra.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Gradient vector $\nabla f$ sabhi partial derivatives ko ek single vector mein pack kar deta hai. Iski do sabse important geometric properties hain: 1. **Contour Lines se Perpendicular:** Gradient hamesha loss ke contour rings se $90^\circ$ par hota hai. 2. **Steepest Direction:** Ye us raste ki taraf point karta hai jahan chalne par function sabse tezi se badhega! Isiliye Gradient Descent ka rule itna simple aur elegant hai: $\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla L$. Minus sign ka matlab hai: "Upar chadhne ke bajaye ghaati (valley) mein utro!"

Suppose:

\[ f(x,y) \]

is the height of a hill.

At one point, we want to know:

How steep in x?
How steep in y?
What happens in an arbitrary direction?
Which direction climbs fastest?
Which direction descends fastest?

The gradient packages these local slopes into one vector.

partial derivatives
       ↓
    gradient
       ↓
directional change
       ↓
steepest ascent / descent
       ↓
optimization
03

Gradient Definition

For:

\[ f:\mathbb R^d\to\mathbb R, \]

the gradient with respect to:

\[ \mathbf x= \begin{bmatrix} x_1\\ \vdots\\ x_d \end{bmatrix} \]

is:

\[ \boxed{ \nabla_{\mathbf x}f(\mathbf x) = \begin{bmatrix} \frac{\partial f}{\partial x_1}\\ \frac{\partial f}{\partial x_2}\\ \vdots\\ \frac{\partial f}{\partial x_d} \end{bmatrix}. } \]

The supplied Lecture09 states this exact structural idea: the gradient extends the derivative to vector inputs and is obtained by stacking the partial derivatives with respect to each component. fileciteturn69file0

04

Why the Gradient Is a Vector

A scalar function with \(d\) inputs has \(d\) coordinate-wise rates of change:

\[ \frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_d}. \]

Therefore they naturally form:

\[ d \]

components.

So:

input dimension = d
scalar output
↓
gradient dimension = d

For:

\[ f:\mathbb R^3\to\mathbb R, \]

the gradient has three components.

Let:

\[ f(x,y)=x^2+3xy+y^2. \]

From M19:

\[ \frac{\partial f}{\partial x}=2x+3y, \]
\[ \frac{\partial f}{\partial y}=3x+2y. \]

Therefore:

\[ \boxed{ \nabla f(x,y) = \begin{bmatrix} 2x+3y\\ 3x+2y \end{bmatrix}. } \]

At:

\[ (x,y)=(1,2), \]
\[ \nabla f(1,2) = \begin{bmatrix} 8\\ 7 \end{bmatrix}. \]

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

def grad_f(x, y):
    return np.array([2*x, 6*y])

point = np.array([2.0, 1.0])
gradient = grad_f(point[0], point[1])
norm_grad = np.linalg.norm(gradient)
unit_ascent_dir = gradient / norm_grad
unit_descent_dir = -unit_ascent_dir

print("At point (x=2, y=1):")
print("Gradient vector ∇f:", gradient)
print("Magnitude of gradient:", round(norm_grad, 4))
print("Unit steepest descent direction -∇f/||∇f||:", np.round(unit_descent_dir, 4))
06

Gradient as a Collection of Coordinate Slopes

At \((1,2)\):

\[ \nabla f= \begin{bmatrix} 8\\ 7 \end{bmatrix}. \]

Interpretation:

\[ f_x=8 \]

means a local increase in \(x\) increases \(f\) at approximately 8 units per unit of \(x\).

Similarly:

\[ f_y=7. \]

The gradient therefore summarizes local coordinate sensitivity.

07

Direction Is the Missing Piece

Partial derivatives only inspect coordinate directions.

But suppose we move along:

\[ \mathbf u= \begin{bmatrix} u_1\\ u_2 \end{bmatrix}. \]

That can be any direction.

We want:

“How fast does \(f\) change if I move in direction \(\mathbf u\)?”

That is the directional derivative.

08

Unit Direction Vector

Usually, direction is represented by a unit vector:

\[ \boxed{ \|\mathbf u\|_2=1. } \]

For:

\[ \mathbf u= \begin{bmatrix} u_1\\ u_2 \end{bmatrix}, \]

this means:

\[ u_1^2+u_2^2=1. \]

Using a unit vector separates:

direction

from:

step size
09

Directional Derivative

For differentiable \(f\), the directional derivative along unit vector \(\mathbf u\) is:

\[ \boxed{ D_{\mathbf u}f(\mathbf x) = \nabla f(\mathbf x)^\top\mathbf u. } \]

Equivalently:

\[ \boxed{ D_{\mathbf u}f = \nabla f\cdot\mathbf u. } \]

Expanded:

\[ D_{\mathbf u}f = \sum_{i=1}^d \frac{\partial f}{\partial x_i}u_i. \]
10

Why the Dot Product Appears

Recall from M06:

\[ \mathbf a^\top\mathbf b = \|\mathbf a\| \|\mathbf b\| \cos\theta. \]

For unit \(\mathbf u\):

\[ \|\mathbf u\|=1. \]

Therefore:

\[ D_{\mathbf u}f = \|\nabla f\|\cos\theta. \]

This immediately gives a geometric interpretation.

11

Directional Derivative Interpretation

⚠️ University Exam Trap & Common Misconception
**Gradient is a Vector, Jacobian is a Matrix:** Never call $\nabla f$ a scalar! For a scalar loss $f: \mathbb{R}^d \to \mathbb{R}$, $\nabla f$ is a $d \times 1$ vector. For a vector-valued function $F: \mathbb{R}^n \to \mathbb{R}^m$ (like a multi-output neural layer), the derivative is the $m \times n$ **Jacobian matrix** $J_{ij} = \frac{\partial F_i}{\partial x_j}$!

Let \(\theta\) be the angle between:

\[ \nabla f \]

and:

\[ \mathbf u. \]

Then:

\[ \boxed{ D_{\mathbf u}f = \|\nabla f\|\cos\theta. } \]

Therefore:

Same direction

\[ \theta=0 \]

gives:

\[ D_{\mathbf u}f=\|\nabla f\|. \]

Maximum increase.

Opposite direction

\[ \theta=\pi \]

gives:

\[ D_{\mathbf u}f=-\|\nabla f\|. \]

Maximum decrease.

Perpendicular

\[ \theta=\frac{\pi}{2} \]

gives:

\[ D_{\mathbf u}f=0. \]

No first-order change.

12

The Gradient Points Toward Steepest Ascent

⚠️ University Exam Trap & Common Misconception
**Gradient is a Vector, Jacobian is a Matrix:** Never call $\nabla f$ a scalar! For a scalar loss $f: \mathbb{R}^d \to \mathbb{R}$, $\nabla f$ is a $d \times 1$ vector. For a vector-valued function $F: \mathbb{R}^n \to \mathbb{R}^m$ (like a multi-output neural layer), the derivative is the $m \times n$ **Jacobian matrix** $J_{ij} = \frac{\partial F_i}{\partial x_j}$!

Because:

\[ \cos\theta\le1, \]

the maximum possible directional derivative is:

\[ \boxed{ \max_{\|\mathbf u\|=1} D_{\mathbf u}f = \|\nabla f\|. } \]

This occurs when:

\[ \boxed{ \mathbf u = \frac{\nabla f}{\|\nabla f\|} } \]

provided the gradient is nonzero.

Thus:

\[ \boxed{ \nabla f \text{ points in the direction of steepest local increase.} } \]
13

Steepest Descent

To reduce the function fastest locally, move in the opposite direction:

\[ \boxed{ -\nabla f. } \]

This is the geometric foundation of gradient descent.

The dedicated optimization file M22 develops the update rule in detail.

14

Worked Example — Directional Derivative

Let:

\[ f(x,y)=x^2+y^2. \]

Then:

\[ \nabla f= \begin{bmatrix} 2x\\ 2y \end{bmatrix}. \]

At:

\[ (1,2), \]
\[ \nabla f(1,2) = \begin{bmatrix} 2\\ 4 \end{bmatrix}. \]

Suppose:

\[ \mathbf u= \frac1{\sqrt2} \begin{bmatrix} 1\\ 1 \end{bmatrix}. \]

Then:

\[ D_{\mathbf u}f = \begin{bmatrix} 2&4 \end{bmatrix} \frac1{\sqrt2} \begin{bmatrix} 1\\ 1 \end{bmatrix}. \]

Therefore:

\[ D_{\mathbf u}f = \frac{6}{\sqrt2} = \boxed{3\sqrt2}. \]

15

Compare with the Steepest Direction

At \((1,2)\):

\[ \nabla f= \begin{bmatrix} 2\\ 4 \end{bmatrix}. \]

Its norm is:

\[ \|\nabla f\|_2 = \sqrt{2^2+4^2} = \sqrt{20} = 2\sqrt5. \]

The maximum directional derivative is therefore:

\[ \boxed{ 2\sqrt5. } \]

The chosen direction produced:

\[ 3\sqrt2. \]

Since:

\[ 3\sqrt2\lt 2\sqrt5, \]

it is not the steepest direction.

16

A Useful Bound

By Cauchy–Schwarz:

\[ |\mathbf a^\top\mathbf b| \le \|\mathbf a\|_2\|\mathbf b\|_2. \]

For unit \(\mathbf u\):

\[ |D_{\mathbf u}f| = |\nabla f^\top\mathbf u| \le \|\nabla f\|. \]

Therefore:

\[ \boxed{ |D_{\mathbf u}f| \le \|\nabla f\|. } \]

The gradient norm is the maximum magnitude of first-order directional change.

17

Level Sets and Gradient Geometry

A level set is a set of points where:

\[ f(\mathbf x)=c \]

for a constant \(c\).

Example for:

\[ f(x,y)=x^2+y^2: \]
\[ x^2+y^2=c \]

produces circles.

Moving along a level set leaves \(f\) unchanged.

Therefore the directional derivative along a tangent direction is:

\[ 0. \]

Since:

\[ D_{\mathbf u}f = \nabla f^\top\mathbf u, \]

the gradient is perpendicular to the level-set tangent.

Thus:

\[ \boxed{ \nabla f \perp \text{level-set direction}. } \]

19

Local Linear Approximation in Vector Form

The one-variable approximation was:

\[ f(x+\Delta x) \approx f(x)+f'(x)\Delta x. \]

In multiple variables:

\[ \boxed{ f(\mathbf x+\Delta\mathbf x) \approx f(\mathbf x) + \nabla f(\mathbf x)^\top \Delta\mathbf x. } \]

This formula is fundamental.

It says:

near \(\mathbf x\), the function behaves approximately like an affine plane.

20

Worked Local Approximation

Let:

\[ f(x,y)=x^2+y^2. \]

At:

\[ (1,2), \]

we have:

\[ f(1,2)=5. \]

And:

\[ \nabla f(1,2)= \begin{bmatrix} 2\\ 4 \end{bmatrix}. \]

Suppose:

\[ \Delta\mathbf x= \begin{bmatrix} 0.01\\ -0.02 \end{bmatrix}. \]

Then:

\[ f(\mathbf x+\Delta\mathbf x) \approx 5+ \begin{bmatrix} 2&4 \end{bmatrix} \begin{bmatrix} 0.01\\ -0.02 \end{bmatrix}. \]

Calculate:

\[ 5+(0.02-0.08) = \boxed{4.94}. \]

The actual function value at:

\[ (1.01,1.98) \]

is close to this approximation.

21

Gradient Dimension

If:

\[ f:\mathbb R^d\to\mathbb R, \]

then:

\[ \boxed{ \nabla f\in\mathbb R^d. } \]

This dimension check is useful.

Example:

\[ f(w_1,w_2,w_3,w_4,w_5) \]

has a gradient with:

\[ \boxed5 \]

components.

22

Jacobian — Why We Need a Matrix

Now consider a vector-valued function:

\[ \mathbf f: \mathbb R^n\to\mathbb R^m. \]

Write:

\[ \mathbf f(\mathbf x) = \begin{bmatrix} f_1(\mathbf x)\\ f_2(\mathbf x)\\ \vdots\\ f_m(\mathbf x) \end{bmatrix}. \]

Each output has derivatives with respect to every input.

We therefore need:

m outputs
×
n inputs

partial derivatives.

These are arranged into the Jacobian matrix.

23

Jacobian Definition

The Jacobian is:

\[ \boxed{ J_{\mathbf f}(\mathbf x) = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2} & \cdots & \frac{\partial f_2}{\partial x_n} \\ \vdots & \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \frac{\partial f_m}{\partial x_2} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}. } \]

Thus:

\[ \boxed{ J_{\mathbf f}\in\mathbb R^{m\times n}. } \]
24

Row Meaning

Row \(i\) contains:

\[ \nabla f_i^\top \]

under the common row-Jacobian convention.

So:

row i
→ derivatives of output fᵢ
  with respect to every input

This makes the Jacobian a stack of output gradients.

25

Worked Example — Jacobian of a Vector Function

Let:

\[ f_1(x,y)=x^2+y, \]
\[ f_2(x,y)=xy. \]

Then:

\[ \frac{\partial f_1}{\partial x}=2x, \qquad \frac{\partial f_1}{\partial y}=1. \]

And:

\[ \frac{\partial f_2}{\partial x}=y, \qquad \frac{\partial f_2}{\partial y}=x. \]

Therefore:

\[ \boxed{ J_{\mathbf f}(x,y) = \begin{bmatrix} 2x&1\\ y&x \end{bmatrix}. } \]

At:

\[ (x,y)=(1,2), \]
\[ \boxed{ J_{\mathbf f}(1,2) = \begin{bmatrix} 2&1\\ 2&1 \end{bmatrix}. } \]

26

Jacobian Dimensions — Exam Habit

Always write:

\[ \boxed{ \text{Jacobian dimensions} = (\text{output dimension}) \times (\text{input dimension}). } \]

So for:

\[ \mathbf f:\mathbb R^5\to\mathbb R^3, \]

the Jacobian is:

\[ \boxed{ 3\times5. } \]

This quick dimension check catches many errors.

27

Gradient vs Jacobian

Object Function type Shape
Derivative \(\mathbb R\to\mathbb R\) scalar
Gradient \(\mathbb R^d\to\mathbb R\) \(d\)-vector
Jacobian \(\mathbb R^n\to\mathbb R^m\) \(m\times n\)

Conceptual hierarchy:

scalar → scalar
      → derivative

vector → scalar
      → gradient

vector → vector
      → Jacobian
28

Scalar Function as a Special Jacobian Case

If:

\[ m=1, \]

then:

\[ J_f \]

is a:

\[ 1\times n \]

row matrix containing the partial derivatives.

Depending on convention, the gradient is commonly represented as the corresponding column vector.

So:

Jacobian of scalar output
↔ gradient with a transpose convention

The important thing is to stay consistent about row vs column orientation.

29

Differential View

For a small input change:

\[ \Delta\mathbf x, \]

a differentiable vector-valued function satisfies approximately:

\[ \boxed{ \Delta\mathbf f \approx J_{\mathbf f}(\mathbf x)\Delta\mathbf x. } \]

This is the multivariable analogue of:

\[ \Delta y\approx f'(x)\Delta x. \]

So the Jacobian is the local linear transformation that maps small input changes to approximate output changes.

30

Worked Differential Example

Using:

\[ \mathbf f(x,y) = \begin{bmatrix} x^2+y\\ xy \end{bmatrix}, \]

at:

\[ (1,2), \]

the Jacobian is:

\[ J= \begin{bmatrix} 2&1\\ 2&1 \end{bmatrix}. \]

Take:

\[ \Delta\mathbf x= \begin{bmatrix} 0.1\\ 0.2 \end{bmatrix}. \]

Then:

\[ \Delta\mathbf f \approx J\Delta\mathbf x \]
\[ = \begin{bmatrix} 2&1\\ 2&1 \end{bmatrix} \begin{bmatrix} 0.1\\ 0.2 \end{bmatrix} = \begin{bmatrix} 0.4\\ 0.4 \end{bmatrix}. \]

Thus the Jacobian predicts the first-order output change.

print("Magnitude of gradient:", round(norm_grad, 4))
print("Unit steepest descent direction -∇f/||∇f||:", np.round(unit_descent_dir, 4))
31

Chain Rule with Jacobians

For composition:

\[ \mathbf z=\mathbf g(\mathbf x), \]
\[ \mathbf y=\mathbf f(\mathbf z), \]

the Jacobians compose through matrix multiplication:

\[ \boxed{ J_{\mathbf f\circ\mathbf g}(\mathbf x) = J_{\mathbf f}(\mathbf g(\mathbf x)) J_{\mathbf g}(\mathbf x). } \]

This is the multivariable chain rule.

Notice the transition:

scalar chain rule
→ multiply derivatives

vector chain rule
→ multiply Jacobian matrices

This is a major conceptual bridge from calculus to ML linear algebra.

32

Why Matrix Multiplication Appears

Suppose:

\[ \Delta\mathbf z \approx J_{\mathbf g}\Delta\mathbf x \]

and:

\[ \Delta\mathbf y \approx J_{\mathbf f}\Delta\mathbf z. \]

Substitute:

\[ \Delta\mathbf y \approx J_{\mathbf f} J_{\mathbf g} \Delta\mathbf x. \]

Therefore:

\[ \boxed{ J_{\mathbf f\circ\mathbf g} = J_{\mathbf f}J_{\mathbf g}. } \]

The chain rule becomes matrix multiplication because intermediate vector changes are transformed successively.

33

Worked Jacobian Chain Example

Let:

\[ \mathbf g(x,y) = \begin{bmatrix} x+y\\ xy \end{bmatrix} \]

and:

\[ \mathbf f(u,v) = \begin{bmatrix} u^2\\ u+v \end{bmatrix}. \]

Then:

\[ J_{\mathbf g} = \begin{bmatrix} 1&1\\ y&x \end{bmatrix}. \]

Also:

\[ J_{\mathbf f} = \begin{bmatrix} 2u&0\\ 1&1 \end{bmatrix}. \]

Because:

\[ u=x+y,\qquad v=xy, \]

the composed Jacobian is:

\[ \boxed{ J_{\mathbf f\circ\mathbf g} = J_{\mathbf f} J_{\mathbf g}. } \]

The key lesson is structural: calculate local Jacobians and compose them by multiplication.

Gradient and Linear Approximation

For scalar:

\[ f(\mathbf x), \]

the Jacobian is effectively the collection of first derivatives.

The local approximation becomes:

\[ \boxed{ f(\mathbf x+\Delta\mathbf x) \approx f(\mathbf x) + \nabla f(\mathbf x)^\top\Delta\mathbf x. } \]

Thus:

gradient
+
small input displacement
→
predicted scalar change
35

Optimization Connection

Suppose:

\[ L(\mathbf w) \]

is a scalar loss.

Then:

\[ \nabla L(\mathbf w) \]

contains all parameter derivatives.

The local approximation is:

\[ L(\mathbf w+\Delta\mathbf w) \approx L(\mathbf w) + \nabla L(\mathbf w)^\top \Delta\mathbf w. \]

Choose:

\[ \Delta\mathbf w = -\eta\nabla L. \]

Then:

\[ L(\mathbf w+\Delta\mathbf w) \approx L(\mathbf w) - \eta \|\nabla L\|^2. \]

Since:

\[ \|\nabla L\|^2\ge0, \]

the first-order predicted change is non-positive for \(\eta\gt 0\).

This is the mathematical intuition for gradient descent.

Detailed step-size and convergence analysis belongs to M22.

36

Why the Gradient Has a Direction

A gradient is not simply:

a list of numbers

It also defines a vector direction in parameter space.

For example:

\[ \nabla L= \begin{bmatrix} 3\\ -4 \end{bmatrix}. \]

Interpretation:

increase w₁ → locally increases loss
increase w₂ → locally decreases loss

To decrease the loss using first-order information, move approximately in:

\[ -\nabla L = \begin{bmatrix} -3\\ 4 \end{bmatrix}. \]
37

Gradient Norm as Sensitivity Magnitude

The vector:

\[ \nabla f \]

has both:

direction
magnitude

Magnitude:

\[ \boxed{ \|\nabla f\|_2 = \sqrt{ \sum_{i=1}^d \left( \frac{\partial f}{\partial x_i} \right)^2 }. } \]

This is the largest first-order rate of change over unit directions.

38

Zero Gradient

If:

\[ \boxed{ \nabla f(\mathbf x)=\mathbf0, } \]

then every first partial derivative is zero.

The first-order directional derivative in every direction is therefore zero:

\[ D_{\mathbf u}f=0. \]

Such a point is a stationary point.

As with one-variable calculus, stationary does not by itself prove minimum.

39

Gradient vs Direction of Actual Motion

Important distinction:

gradient
→ direction of maximum increase

negative gradient
→ direction of maximum decrease

But an optimization algorithm may use:

learning rate
constraints
momentum
normalization
adaptive scaling

so its actual step need not have exactly the same magnitude as the gradient.

Dimension-Checking Protocol

Gradient

If:

\[ f:\mathbb R^d\to\mathbb R, \]

then:

\[ \nabla f \]

has \(d\) components.

Jacobian

If:

\[ f:\mathbb R^n\to\mathbb R^m, \]

then:

\[ J_f \]

must be:

\[ m\times n. \]

Matrix-chain check

If:

\[ J_f \]

is:

\[ m\times k \]

and:

\[ J_g \]

is:

\[ k\times n, \]

then:

\[ J_fJ_g \]

is:

\[ m\times n. \]

If dimensions do not multiply correctly, revisit the derivative orientation.

43

Numerical-Solving Protocol

For a gradient:

1. Identify every input variable
2. Compute one partial derivative per input
3. Stack them consistently
4. Substitute the point
5. Check the vector dimension

For a directional derivative:

1. Find the gradient
2. Verify the direction is a unit vector
3. Compute gradientᵀ × direction
4. Interpret the sign

For a Jacobian:

1. List all output components
2. List all input variables
3. Differentiate every output wrt every input
4. Arrange derivatives in output-row/input-column order
5. Check dimensions

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Gradient is a Vector, Jacobian is a Matrix:** Never call $\nabla f$ a scalar! For a scalar loss $f: \mathbb{R}^d \to \mathbb{R}$, $\nabla f$ is a $d \times 1$ vector. For a vector-valued function $F: \mathbb{R}^n \to \mathbb{R}^m$ (like a multi-output neural layer), the derivative is the $m \times n$ **Jacobian matrix** $J_{ij} = \frac{\partial F_i}{\partial x_j}$!

Mistake 1

Treating a gradient as a scalar.

For:

\[ f:\mathbb R^d\to\mathbb R, \]

the gradient generally has \(d\) components.

Mistake 2

Forgetting to normalize the direction vector when the question asks for a directional derivative along a unit direction.

Mistake 3

Confusing steepest ascent with steepest descent.

\[ +\nabla f \rightarrow \text{increase} \]
\[ -\nabla f \rightarrow \text{decrease} \]

Mistake 4

Getting the Jacobian dimensions backwards.

For:

\[ \mathbb R^n\to\mathbb R^m, \]

the common Jacobian convention is:

\[ m\times n. \]

Mistake 5

Mixing row-gradient and column-gradient conventions without accounting for transposes.

Mistake 6

Thinking a zero gradient proves a minimum.

It only establishes zero first-order change.

Mistake 7

Assuming the gradient gives the full nonlinear behavior.

It gives local first-order information.
