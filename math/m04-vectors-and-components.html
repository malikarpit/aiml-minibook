01

Why This Lesson Exists

Machine-learning data is rarely a single number.

A student might be described by:

age
hours studied
attendance
previous score

Instead of writing four separate numbers, mathematics groups them into one object:

\[ \boxed{ x= \begin{bmatrix} age\\ hours\\ attendance\\ score \end{bmatrix} } \]

That object is a vector.

Vectors let us represent:

  • data points;
  • feature sets;
  • model parameters;
  • directions;
  • states;
  • embeddings;
  • gradients.

They are one of the most important mathematical objects in AI/ML.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Vector ko do alag nazron se dekho: 1. **Computer Scientist ka Lens:** Vector ek ordered list of numbers hai (`[age, income, credit_score]`). 2. **Mathematician ka Lens:** Vector multi-dimensional space mein origin $(0,0,\dots,0)$ se nikli hui ek directed arrow hai jiski ek length aur ek direction hoti hai. AI in dono nazron ko joodta hai: jab hum do vectors ko add ya multiply karte hain, toh data aur geometry sath-sath transform hote hain!

Think of a vector as an ordered collection of numbers.

For example:

\[ x= \begin{bmatrix} 3\\ 5\\ 2 \end{bmatrix} \]

can be read as:

first component = 3
second component = 5
third component = 2

But there is a second interpretation:

In geometry, the same vector can represent an arrow with a direction and length.

So:

vector
=
ordered numerical representation
+
geometric object
03

Real-World Analogy

Imagine describing a house using:

area = 1200
bedrooms = 3
age = 8
distance from metro = 1.5

Write:

\[ x= \begin{bmatrix} 1200\\ 3\\ 8\\ 1.5 \end{bmatrix}. \]

That is a feature vector.

A machine-learning model can take this vector and transform it into a prediction.

04

Scalar vs Vector

Scalar

One number:

\[ 5 \]

Vector

Multiple ordered components:

\[ \begin{bmatrix} 5\\ 2\\ 7 \end{bmatrix}. \]

Memory:

scalar → one value
vector → ordered values

For:

\[ x= \begin{bmatrix} x_1\\ x_2\\ x_3 \end{bmatrix} \]

the components are:

\[ x_1,\quad x_2,\quad x_3. \]

General \(d\)-dimensional vector:

\[ \boxed{ x= \begin{bmatrix} x_1\\ x_2\\ \vdots\\ x_d \end{bmatrix} } \]

and:

\[ x\in\mathbb R^d. \]

Read:

\(x\) is a vector with \(d\) real-valued components.

06

Row Vector vs Column Vector

A column vector:

\[ x= \begin{bmatrix} 1\\ 2\\ 3 \end{bmatrix} \]

has shape:

\[ 3\times1. \]

Its transpose:

\[ x^T= \begin{bmatrix} 1&2&3 \end{bmatrix} \]

has shape:

\[ 1\times3. \]

Both contain the same components but have different orientations.

This distinction becomes critical in matrix multiplication.

07

Dimension vs Shape

For:

\[ x= \begin{bmatrix} 2\\ 4\\ 6 \end{bmatrix} \]

we say:

dimension = 3
shape = 3 × 1

Do not automatically treat these words as interchangeable.

A vector's dimension refers to the number of components.

Its matrix representation also has a shape.

08

Vector Equality

Two vectors are equal when corresponding components are equal.

\[ \boxed{ x=y \iff x_i=y_i \text{ for all }i } \]

Example:

\[ \begin{bmatrix} 1\\ 2\\ 3 \end{bmatrix} = \begin{bmatrix} 1\\ 2\\ 3 \end{bmatrix}. \]

But:

\[ \begin{bmatrix} 1\\ 2 \end{bmatrix} \ne \begin{bmatrix} 1\\ 2\\ 3 \end{bmatrix}. \]

They have different dimensions.

09

Vector Addition

Two vectors of the same dimension can be added component-wise.

\[ \boxed{ x+y= \begin{bmatrix} x_1+y_1\\ x_2+y_2\\ \vdots\\ x_d+y_d \end{bmatrix} } \]

Example:

\[ x= \begin{bmatrix} 1\\ 2\\ 3 \end{bmatrix}, \quad y= \begin{bmatrix} 4\\ 5\\ 6 \end{bmatrix} \]

then:

\[ x+y= \begin{bmatrix} 5\\ 7\\ 9 \end{bmatrix}. \]
10

Vector Subtraction

\[ \boxed{ x-y= \begin{bmatrix} x_1-y_1\\ \vdots\\ x_d-y_d \end{bmatrix} } \]

Example:

\[ \begin{bmatrix} 7\\ 5\\ 2 \end{bmatrix} - \begin{bmatrix} 3\\ 1\\ 4 \end{bmatrix} = \begin{bmatrix} 4\\ 4\\ -2 \end{bmatrix}. \]

Geometric meaning

\[ x-y \]

can represent the displacement from \(y\) to \(x\).

11

Scalar Multiplication

⚠️ University Exam Trap & Common Misconception
**Row Vector vs Column Vector Mismatch:** Standard mathematical convention mein bina transpose wala vector hamesha **COLUMN vector** ($d \times 1$) hota hai. Agar aap row vector ($1 \times d$) ko standard linear model mein bina transpose likhte ho, toh dimension multiplication $w x$ invalid ho jata hai; correct notation hamesha $w^T x$ hota hai!

A scalar can multiply every component.

\[ \boxed{ cx= \begin{bmatrix} cx_1\\ cx_2\\ \vdots\\ cx_d \end{bmatrix} } \]

Example:

\[ 3 \begin{bmatrix} 1\\ -2 \end{bmatrix} = \begin{bmatrix} 3\\ -6 \end{bmatrix}. \]

Geometry

  • positive \(c\): stretches if \(c\gt 1\), shrinks if \(0\lt c\lt 1\);
  • negative \(c\): reverses direction as well.
12

Zero Vector

⚠️ University Exam Trap & Common Misconception
**Row Vector vs Column Vector Mismatch:** Standard mathematical convention mein bina transpose wala vector hamesha **COLUMN vector** ($d \times 1$) hota hai. Agar aap row vector ($1 \times d$) ko standard linear model mein bina transpose likhte ho, toh dimension multiplication $w x$ invalid ho jata hai; correct notation hamesha $w^T x$ hota hai!

The zero vector is:

\[ \boxed{ 0= \begin{bmatrix} 0\\ 0\\ \vdots\\ 0 \end{bmatrix} } \]

of the required dimension.

Property:

\[ x+0=x. \]

This is the vector analogue of the scalar number zero.

13

Negative Vector

\[ -x=(-1)x. \]

If:

\[ x= \begin{bmatrix} 2\\ -3 \end{bmatrix}, \]

then:

\[ -x= \begin{bmatrix} -2\\ 3 \end{bmatrix}. \]

And:

\[ x+(-x)=0. \]

In two dimensions:

\[ x= \begin{bmatrix} 3\\ 2 \end{bmatrix} \]

can be drawn as an arrow from:

\[ (0,0) \]

to:

\[ (3,2). \]

The vector is not tied to one physical location.

An arrow translated without changing its length or direction represents the same free vector.

15

Position Vector

A point:

\[ P=(3,2) \]

can be represented by its position vector:

\[ \vec{OP}= \begin{bmatrix} 3\\ 2 \end{bmatrix}. \]

This lets coordinate geometry and vector algebra use the same numerical representation.

16

Magnitude Preview

Every vector has a length/magnitude.

For:

\[ x= \begin{bmatrix} 3\\ 4 \end{bmatrix} \]

the Euclidean length is:

\[ \sqrt{3^2+4^2}=5. \]

Formal norm treatment is in M05.

For now remember:

vector
→ components
→ geometry
→ magnitude
→ direction
17

Direction

In 2D:

\[ x= \begin{bmatrix} x_1\\ x_2 \end{bmatrix}. \]

Its direction relative to the positive \(x\)-axis can be represented by:

\[ \boxed{ \theta=\operatorname{atan2}(x_2,x_1) } \]

where \(\operatorname{atan2}\) handles the quadrant correctly.

This is useful for geometric intuition, although angle calculations are not a central DSC-14 exam requirement.

18

Unit Vector

A unit vector has magnitude 1.

For a nonzero vector \(x\):

\[ \boxed{ \hat x=\frac{x}{\|x\|_2} } \]

This operation is called normalization.

Example:

\[ x= \begin{bmatrix} 3\\ 4 \end{bmatrix}, \quad \|x\|_2=5. \]

Then:

\[ \hat x= \begin{bmatrix} 3/5\\ 4/5 \end{bmatrix}. \]

Its length is 1.

19

Why Normalization Matters in ML

Feature magnitudes can differ greatly.

Suppose:

age       = 21
income    = 800000

A model based on distances or dot products can become dominated by scale.

Normalization/scaling may reduce this issue.

However:

Vector normalization and feature standardization are related but not identical operations.

Do not treat every kind of “normalization” as the same procedure.

Vector as a Feature Representation

Suppose:

\[ x= \begin{bmatrix} 2\\ 5\\ 1 \end{bmatrix} \]

represents:

hours studied = 2
attendance = 5
previous score = 1

A linear model can calculate:

\[ w^Tx+b. \]

So the vector becomes the bridge:

real-world object
→ numerical features
→ vector
→ mathematical model
→ prediction
21

Vector as Parameter Representation

A model may have multiple weights:

\[ w_1,w_2,\ldots,w_d. \]

Group them:

\[ \boxed{ w= \begin{bmatrix} w_1\\ w_2\\ \vdots\\ w_d \end{bmatrix} } \]

Now model training can update the entire parameter vector:

\[ w\leftarrow w-\eta\nabla_wJ. \]

Vectors therefore represent both:

input
and
learned parameters.
22

Linear Combination

A vector can be built from other vectors using weighted sums.

Example:

\[ v=2u_1-3u_2. \]

This is a linear combination of \(u_1,u_2\).

More generally:

\[ \boxed{ v=\sum_{i=1}^{k}c_i u_i } \]

where \(c_i\) are scalars.

This idea becomes important for:

  • span;
  • basis;
  • linear independence;
  • matrix transformations.

Those are developed in later lessons.

23

Standard Basis Vectors

In \(\mathbb R^2\):

\[ e_1= \begin{bmatrix} 1\\ 0 \end{bmatrix}, \qquad e_2= \begin{bmatrix} 0\\ 1 \end{bmatrix}. \]

Every 2D vector can be written:

\[ \boxed{ x_1e_1+x_2e_2 } \]

because:

\[ x_1 \begin{bmatrix} 1\\0 \end{bmatrix} + x_2 \begin{bmatrix} 0\\1 \end{bmatrix} = \begin{bmatrix} x_1\\x_2 \end{bmatrix}. \]

In \(\mathbb R^3\):

\[ e_1= \begin{bmatrix} 1\\0\\0 \end{bmatrix}, \quad e_2= \begin{bmatrix} 0\\1\\0 \end{bmatrix}, \quad e_3= \begin{bmatrix} 0\\0\\1 \end{bmatrix}. \]
24

Vector Data Matrix Preview

Suppose we have three examples, each with two features:

\[ x^{(1)}= \begin{bmatrix} 1\\ 2 \end{bmatrix}, \quad x^{(2)}= \begin{bmatrix} 3\\ 4 \end{bmatrix}, \quad x^{(3)}= \begin{bmatrix} 5\\ 6 \end{bmatrix}. \]

We can arrange them as rows:

\[ X= \begin{bmatrix} 1&2\\ 3&4\\ 5&6 \end{bmatrix}. \]

Then:

\[ X\in\mathbb R^{3\times2}. \]

Interpretation:

3 examples
2 features

This is the basic bridge from vectors to matrices.

25

Vector vs Matrix

A useful mental separation:

vector
→ one ordered list / one point / one direction

matrix
→ organized collection / transformation / table of values

But a vector can also be represented mathematically as a \(d\times1\) matrix.

Context determines which viewpoint is most useful.

\[ x-y \]

For:

\[ x= \begin{bmatrix} 5\\ 4 \end{bmatrix}, \quad y= \begin{bmatrix} 2\\ 1 \end{bmatrix}, \]

So moving from \(y\) to \(x\) is the displacement \((3,3)\).

This will matter in distance calculations.

Worked Example C — Linear Combination

Let:

\[ u= \begin{bmatrix} 1\\ 2 \end{bmatrix}, \quad v= \begin{bmatrix} 3\\ 1 \end{bmatrix}. \]

Find:

\[ 2u-v. \]

First:

\[ 2u= \begin{bmatrix} 2\\ 4 \end{bmatrix}. \]

Then:

\[ 2u-v= \begin{bmatrix} 2\\ 4 \end{bmatrix} - \begin{bmatrix} 3\\ 1 \end{bmatrix} = \boxed{ \begin{bmatrix} -1\\ 3 \end{bmatrix} }. \]

Worked Example E — Feature Vector

Suppose:

\[ x= \begin{bmatrix} 21\\ 7\\ 85 \end{bmatrix} \]

represents:

age = 21
study hours = 7
previous score = 85

and:

\[ w= \begin{bmatrix} 0.1\\ 0.5\\ 0.2 \end{bmatrix}, \qquad b=2. \]

The model's weighted score is:

\[ w^Tx+b. \]

The dot product is developed fully in M06; for now:

\[ w^Tx = 0.1(21)+0.5(7)+0.2(85) \]
\[ =2.1+3.5+17 = 22.6. \]

Thus:

\[ \hat y=22.6+2=\boxed{24.6}. \]

This example shows why vectors matter: many features can be combined systematically.

Worked Example F — Dimension Check

Suppose:

\[ x\in\mathbb R^3 \]

and:

\[ w\in\mathbb R^2. \]

Can \(w^Tx\) be computed as a standard dot product?

No.

The dimensions do not match:

\[ 2\ne3. \]

Therefore:

\[ \boxed{\text{dimension mismatch}} \]

This is one of the most common mathematical implementation errors in ML.

Vector Arithmetic Rules

For compatible vectors:

Commutativity of addition

\[ \boxed{ x+y=y+x } \]

Associativity

\[ \boxed{ (x+y)+z=x+(y+z) } \]

Scalar distribution

\[ \boxed{ c(x+y)=cx+cy } \]

Scalar addition distribution

\[ \boxed{ (c+d)x=cx+dx } \]

These rules make vector algebra behave like familiar algebra.

⚠️ University Exam Trap & Common Misconception
**Row Vector vs Column Vector Mismatch:** Standard mathematical convention mein bina transpose wala vector hamesha **COLUMN vector** ($d \times 1$) hota hai. Agar aap row vector ($1 \times d$) ko standard linear model mein bina transpose likhte ho, toh dimension multiplication $w x$ invalid ho jata hai; correct notation hamesha $w^T x$ hota hai!

Mistake 1 — Adding different dimensions

You cannot directly add:

\[ \begin{bmatrix}1\\2\end{bmatrix} + \begin{bmatrix}3\\4\\5\end{bmatrix}. \]

Mistake 2 — Treating a vector like a scalar

\[ x+y \]

means component-wise addition, not an arbitrary operation on two objects.

Mistake 3 — Confusing dimension and shape

A 3-component column vector has dimension 3 and shape \(3\times1\).

Mistake 4 — Forgetting transpose

\[ w^Tx \]

and:

\[ wx \]

are not the same notation once \(w,x\) are vectors.

Mistake 5 — Normalization confusion

Unit-vector normalization:

\[ x/\|x\| \]

is not the same as standardizing a feature using mean and standard deviation.

Mistake 6 — Thinking a vector has a fixed location

A free vector represents displacement/direction/magnitude independent of where its arrow is drawn.
