01

Why Optimization Exists

Machine learning ultimately needs good parameter values.

Let a model be:

\[ \hat y=f_{\mathbf w}(x) \]

and let its training objective be:

\[ \boxed{\min_{\mathbf w}J(\mathbf w)} \]

The pipeline is:

parameters → predictions → loss → gradient → parameter update → repeat

The supplied course material explicitly formulates supervised learning as minimizing average squared error and presents least squares as an optimization problem.

02

Loss and Objective

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Optimization ka basic matlab hai: "Model ke parameters ko aisi direction mein twist karna jisse error (loss) sabse kam ho jaye." Agar tum ek andheri pahadi par ho aur niche ghaati tak pahunchna hai, toh sabse simple tariqa kya hai? Apne pairon ke niche ki dhalan (slope) check karo. Jis taraf dhalan sabse tezi se niche ja rahi ho (`-\nabla J`), usi direction mein ek chhota kadam (`\eta`) badhao. Yehi **Gradient Descent** hai! Lekin step size $\eta$ par dhyan dena zaroori hai: - $\eta$ bohot chhota hua $\to$ subah ho jayegi pahadi par (slow convergence). - $\eta$ bohot bada hua $\to$ samne wali pahadi par jump karke gir jaoge (divergence / oscillation)!

For one example:

\[ L_i(\mathbf w) \]

is its loss.

For (n) examples, the empirical average objective is:

\[ \boxed{ J(\mathbf w)=\frac1n\sum_{i=1}^{n}L_i(\mathbf w) } \]

For squared error:

\[ \boxed{ J(\mathbf w)= \frac1n\sum_{i=1}^{n} (f_{\mathbf w}(\mathbf x_i)-y_i)^2 } \]

Argmin

\[ \boxed{\arg\min_{\mathbf w}J(\mathbf w)} \]

returns the parameter value(s) achieving the minimum.

Example:

\[ J(w)=(w-3)^2 \]

gives:

\[ \arg\min_wJ(w)=3,\qquad \min_wJ(w)=0. \]

Trap: argmin is a parameter/value of the variable; min is the minimum objective value.

03

Optimization Landscape

For one parameter:

Loss
 ↑
 |       \       /
 |        \_____/
 |           *
 +----------------→ w

At a smooth interior stationary point:

\[ \boxed{J'(w^*)=0} \]

For multiple parameters:

\[ \boxed{\nabla J(\mathbf w^*)=\mathbf0} \]

But zero gradient does not prove a global minimum.

A stationary point can be a:

  • local minimum,
  • local maximum,
  • saddle point,
  • flat stationary point.
04

Local vs Global Minimum

A local minimum is no larger than sufficiently nearby values.

A global minimum is no larger than every feasible value.

This distinction matters especially for non-convex objectives.

Convex intuition

       \     /
        \___/
          *

Non-convex intuition

   \_/ \____/ \_/
      *      *

For a differentiable convex objective in the standard unconstrained setting, every local minimum is global.

Gradient as a Descent Signal

From M21:

\[ \nabla J(\mathbf w) \]

points toward steepest local increase.

Therefore:

\[ \boxed{-\nabla J(\mathbf w)} \]

points toward steepest local decrease.

The basic gradient-descent update is:

\[ \boxed{ \mathbf w_{t+1} = \mathbf w_t-\eta\nabla J(\mathbf w_t) } \]

where:

\[ \eta\\gt 0 \]

is the learning rate.

Meaning

gradient
→ direction + local sensitivity

η
→ how far to move

−gradient
→ descent direction
06

One-Dimensional Derivation

For:

\[ J(w), \]

the first-order approximation from M18 is:

\[ J(w+\Delta w) \approx J(w)+J'(w)\Delta w. \]

Choose:

\[ \Delta w=-\eta J'(w). \]

Then:

\[ J(w-\eta J'(w)) \approx J(w)-\eta[J'(w)]^2. \]

For (\eta>0), the first-order predicted change is non-positive.

Thus:

\[ \boxed{ w_{\text{new}}=w-\eta J'(w) } \]

is locally sensible for minimization.

This is a local first-order argument, not a guarantee that every finite step lowers the objective.

07

Multivariable Derivation

From M21:

\[ J(\mathbf w+\Delta\mathbf w) \approx J(\mathbf w)+ \nabla J(\mathbf w)^\top\Delta\mathbf w. \]

Choose:

\[ \Delta\mathbf w=-\eta\nabla J(\mathbf w). \]

Then:

\[ J(\mathbf w+\Delta\mathbf w) \approx J(\mathbf w) -\eta \|\nabla J(\mathbf w)\|_2^2. \]

Therefore the first-order predicted change is:

\[ \boxed{ -\eta\|\nabla J\|_2^2\le0. } \]
08

Coordinate Update

If:

\[ \mathbf w= \[w_1,\ldots,w_d\]

\^\top, ]

then:

\[ \boxed{ w_{j,t+1} = w_{j,t} - \eta \frac{\partial J}{\partial w_j} } \]

for each parameter.

This makes the connection between partial derivatives and learning explicit.

09

Worked Example

Let:

\[ J(w)=(w-4)^2. \]

Then:

\[ J'(w)=2(w-4). \]

Take:

\[ \eta=0.25,\qquad w_0=0. \]

Step 1

\[ J'(0)=-8 \]
\[ w_1=0-0.25(-8)=2 \]

Step 2

\[ J'(2)=-4 \]
\[ w_2=2-0.25(-4)=3 \]

Step 3

\[ J'(3)=-2 \]
\[ w_3=3-0.25(-2)=3.5 \]

So:

\[ 0\rightarrow2\rightarrow3\rightarrow3.5\rightarrow\cdots \]

approaches:

\[ \boxed{w^*=4}. \]

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

# 1. Quadratic Loss Landscape: J(w1, w2) = 0.5 * (w1^2 + 4 * w2^2)
def loss(w):
    return 0.5 * (w[0]**2 + 4.0 * w[1]**2)

def grad(w):
    return np.array([w[0], 4.0 * w[1]])

# 2. Gradient Descent Simulation
w = np.array([4.0, 3.0])  # Initial point
lr = 0.2                  # Learning rate eta
trajectory = [w.copy()]

for step in range(25):
    g = grad(w)
    w = w - lr * g
    trajectory.append(w.copy())
    if np.linalg.norm(g) < 1e-4:
        break

print(f"Initial weights: [4.0, 3.0], Initial loss: {loss(np.array([4.0, 3.0])):.4f}")
print(f"Converged weights after {step+1} steps: {np.round(w, 5)}")
print(f"Final loss at minimum: {loss(w):.6e}")
10

Learning Rate

The learning rate controls step size.

Too small

tiny steps
→ slow convergence

Reasonable

progressive movement
→ efficient convergence

Too large

overshoot
→ oscillation
→ possible divergence

For:

\[ J(w)=w^2, \]

gradient descent gives:

\[ w_{t+1} = w_t-2\eta w_t = (1-2\eta)w_t. \]

For this particular quadratic, convergence requires:

\[ \|1-2\eta\|\\lt 1 \]

so:

\[ \boxed{0\lt \eta\lt 1}. \]

This is an example-specific result, not a universal learning-rate rule.

Feature Scaling and Optimization

⚠️ University Exam Trap & Common Misconception
**Stationary Point Ambiguity Trap:** When you set the gradient $\nabla J(w) = 0$, you have found a *stationary point*—NOT necessarily a minimum! In multivariable calculus: - If Hessian $H = \nabla^2 J(w)$ is positive definite ($H \succ 0$), it is a **local minimum**. - If $H$ is negative definite ($H \prec 0$), it is a **local maximum**. - If $H$ has both positive and negative eigenvalues, it is a **saddle point**! Always check the second derivative matrix (Hessian) or convexity condition in written university proofs!

The supplied Lecture09 explicitly states that feature scaling can improve gradient-descent convergence speed and stability.

If one feature is around (0!-!1) and another around (0!-!1{,}000{,}000), the optimization geometry can become badly stretched.

Conceptually:

poor scaling       better scaling

  ______              ___
 /      \            /   \
|        |          |     |
 \______/            \___/

Gradient-based methods may then take inefficient zig-zag paths.

Standardization

The supplied lecture gives:

\[ \boxed{ x_j\leftarrow\frac{x_j-\mu_j}{\sigma_j} } \]

producing zero mean and unit variance under the stated convention.

Min-max scaling

\[ \boxed{ x_j\leftarrow \frac{x_j-\min(x_j)} {\max(x_j)-\min(x_j)} } \]

maps values to (

\[0,1\]

) when the denominator is nonzero.

Least Squares Connection

⚠️ University Exam Trap & Common Misconception
**Stationary Point Ambiguity Trap:** When you set the gradient $\nabla J(w) = 0$, you have found a *stationary point*—NOT necessarily a minimum! In multivariable calculus: - If Hessian $H = \nabla^2 J(w)$ is positive definite ($H \succ 0$), it is a **local minimum**. - If $H$ is negative definite ($H \prec 0$), it is a **local maximum**. - If $H$ has both positive and negative eigenvalues, it is a **saddle point**! Always check the second derivative matrix (Hessian) or convexity condition in written university proofs!

For linear regression:

\[ \hat y_i=\mathbf x_i^\top\mathbf w \]

and residual:

\[ \mathbf x_i^\top\mathbf w-y_i. \]

The supplied Lecture09 gives:

\[ \boxed{ \sum_{i=1}^{n} (\mathbf x_i^\top\mathbf w-y_i)^2 = \|\mathbf X\mathbf w-\mathbf y\|_2^2 } \]

and therefore:

\[ \boxed{ \min_{\mathbf w} \|\mathbf X\mathbf w-\mathbf y\|_2^2. } \]

If:

\[ \mathbf X^\top\mathbf X \]

is invertible, the same lecture gives the closed-form solution:

\[ \boxed{ \mathbf w^* = (\mathbf X^\top\mathbf X)^{-1} \mathbf X^\top\mathbf y. } \]

So:

closed form
→ solve directly

gradient descent
→ iteratively approach solution
13

Why Gradient Descent Matters

Gradient descent is useful when:

  • the objective is differentiable,
  • parameters are numerous,
  • a closed-form solution is unavailable or inconvenient,
  • the model is a composition of many operations.

For neural networks, M20's computational-graph chain rule provides the derivatives needed to calculate:

\[ \nabla J. \]

The supplied Lecture09 also describes gradient descent as a backbone of many deep-learning algorithms.

14

Stopping Conditions

Possible conditions:

\[ \boxed{ \|\nabla J(\mathbf w)\|\lt \epsilon } \]

or:

\[ \boxed{ \|\mathbf w_{t+1}-\mathbf w_t\|\lt \epsilon } \]

or:

\[ \boxed{ |J_{t+1}-J_t|\lt \epsilon. } \]

Another practical limit is a maximum number of iterations.

15

Gradient Descent vs Hill Climbing

The supplied AI search lecture describes hill climbing as iterative improvement: start from a current state, inspect neighbouring states, and move to a better state; it also lists gradient ascent/descent as a form of iterative improvement.

The mathematical distinction is:

generic hill climbing
→ neighbourhood-based improvement

gradient descent
→ differentiable continuous objective
→ gradient gives local descent direction

They share an iterative-improvement idea but are not identical algorithms.

Hinglish Teacher Explanation

Optimization ka simple meaning:

"Aise parameters dhoondo jahan model ka loss minimum ho."

Agar:

\[ L(w) \]

loss hai, derivative:

\[ L'(w) \]

batata hai ki abhi loss kis direction mein badh raha hai.

Isliye loss kam karne ke liye:

\[ w_{\text{new}} = w-\eta L'(w). \]

Multiple parameters mein:

\[ \mathbf w_{\text{new}} = \mathbf w-\eta\nabla L. \]

Yaad rakho:

gradient
→ direction

learning rate
→ step size

(\eta) bahut chhota hua toh training slow ho sakti hai. Bahut bada hua toh minimum ko repeatedly cross karke unstable behaviour ho sakta hai.

Feature scaling bhi important hai because supplied lecture ke according scaling convergence speed aur stability improve kar sakti hai.

18

Numerical Protocol

1. Write J(w)
2. Calculate ∇J(w)
3. Write η
4. Write initial parameters
5. Evaluate gradient
6. Apply w_new = w − η∇J
7. Repeat
8. Track J if requested
19

Common Traps

  • Using (+\eta\nabla J) when minimizing.
  • Confusing argmin with min.
  • Treating learning rate as part of the gradient.
  • Assuming zero gradient proves global minimum.
  • Assuming a larger learning rate is always faster.
  • Ignoring feature scaling.
  • Confusing closed-form least squares with iterative gradient descent.
