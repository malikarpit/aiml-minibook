01

Why This Lesson Exists

Machine learning repeatedly asks:

“If I change an input or parameter slightly, how much does the output change?”

That is a question about rate of change.

For a function:

\[ y=f(x), \]

we want to know:

  • Is \(y\) increasing or decreasing?
  • How quickly is it changing?
  • Is the function becoming steeper?
  • Where is it flat?
  • Where might a minimum or maximum occur?

The mathematical object that answers the local rate-of-change question is the derivative.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Derivative ka simple matlab hai: **Sensitivity**. Agar main input $x$ ko zara sa ($0.0001$) hilaoon, toh output $y$ kitna hilega aur kis direction mein? Agar derivative positive hai, input badhane se output badhega; agar negative hai, input badhane se output ghatega. Isiliye agar hum kisi loss ko minimize karna chahte hain, hum hamesha derivative ke OPPOSITE direction mein chalte hain!

Imagine walking along a road.

At every location, you can ask:

How steep is the road here?

The derivative gives that local steepness.

positive derivative
→ climbing

negative derivative
→ descending

zero derivative
→ locally flat

In machine learning, replace:

road height

with:

loss

and replace:

location

with:

model parameter

Then the derivative tells us how the loss changes when the parameter changes.

That idea becomes the foundation of gradient descent.

03

Average Rate of Change

Before the derivative, start with the average.

Suppose:

\[ y=f(x). \]

Between:

\[ x=a \]

and:

\[ x=b, \]

the change in output is:

\[ \Delta y=f(b)-f(a). \]

The change in input is:

\[ \Delta x=b-a. \]

Therefore:

\[ \boxed{ \text{Average rate of change} = \frac{f(b)-f(a)}{b-a} } \]

provided \(a\ne b\).

Geometrically, this is the slope of the secant line joining the two points.

04

Example — Average Rate of Change

Let:

\[ f(x)=x^2. \]

Between:

\[ x=2 \]

and:

\[ x=5, \]

we have:

\[ f(2)=4, \]
\[ f(5)=25. \]

Therefore:

\[ \frac{25-4}{5-2} = \frac{21}{3} = \boxed7. \]

The function changes by an average of 7 units of output per unit of input over that interval.

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: x**2 - 4*x + 3
x_test = 3.0

num_deriv = numerical_derivative(f, x_test)
analytical_deriv = 2 * x_test - 4

print("Testing f(x) = x^2 - 4x + 3 at x = 3.0")
print("Analytical Derivative f'(3):", analytical_deriv)
print("Numerical Central Difference:", round(num_deriv, 5))

Average rate of change looks across an interval.

But what if we want the rate of change at one point?

Suppose we want the slope at \(x\).

Take a second point:

\[ x+h. \]

The average slope between \(x\) and \(x+h\) is:

\[ \frac{f(x+h)-f(x)}{h}. \]

Now make \(h\) smaller and smaller.

Conceptually:

two points
↓
bring them closer
↓
closer
↓
closer
↓

↓
tangent slope
06

Derivative Definition

The derivative of \(f\) at \(x\) is:

\[ \boxed{ f'(x) = \lim_{h\to0} \frac{f(x+h)-f(x)}{h} } \]

provided the limit exists.

Other common notation:

\[ \boxed{ \frac{dy}{dx} } \]

and:

\[ \boxed{ \frac{df}{dx}. } \]

Read \(f'(x)\) as:

“the derivative of \(f\) at \(x\).”

07

Why the Limit Is Needed

At exactly the same point:

\[ h=0, \]

the expression:

\[ \frac{f(x+h)-f(x)}{h} \]

would divide by zero.

So we do not directly substitute \(h=0\).

Instead we study what the expression approaches as:

\[ h\to0. \]

This is the role of the limit.

08

Worked Derivation — Derivative of \(x^2\)

Let:

\[ f(x)=x^2. \]

Start from the definition:

\[ f'(x) = \lim_{h\to0} \frac{(x+h)^2-x^2}{h}. \]

Expand:

\[ (x+h)^2=x^2+2xh+h^2. \]

Therefore:

\[ f'(x) = \lim_{h\to0} \frac{x^2+2xh+h^2-x^2}{h}. \]

Cancel:

\[ = \lim_{h\to0} \frac{2xh+h^2}{h}. \]

Factor:

\[ = \lim_{h\to0}(2x+h). \]

Now take the limit:

\[ \boxed{ f'(x)=2x. } \]

This is not merely a formula to memorize. It shows how local slope arises from the definition.

09

Tangent-Line Interpretation

At \(x=a\), the derivative:

\[ f'(a) \]

is the slope of the tangent line to the curve.

The tangent line is:

\[ \boxed{ y-f(a)=f'(a)(x-a). } \]

Equivalently:

\[ \boxed{ y=f(a)+f'(a)(x-a). } \]

This becomes important later for local approximation.

11

Sign of the Derivative

⚠️ University Exam Trap & Common Misconception
**Constant Derivative & Power Rule Trap:** $\frac{d}{dx}[c] = 0$. Many students forget that constants vanish under differentiation! Also, for exponentials $\frac{d}{dx}[e^x] = e^x$, do NOT apply power rule like $x e^{x-1}$.

Positive

If:

\[ f'(x)\gt 0, \]

the function is locally increasing.

Negative

If:

\[ f'(x)\lt 0, \]

the function is locally decreasing.

Zero

If:

\[ f'(x)=0, \]

the tangent is horizontal.

A zero derivative can occur at:

local minimum
local maximum
flat point

So:

\[ f'(x)=0 \]

does not automatically mean minimum.

12

First Derivative as a Direction Signal

⚠️ University Exam Trap & Common Misconception
**Constant Derivative & Power Rule Trap:** $\frac{d}{dx}[c] = 0$. Many students forget that constants vanish under differentiation! Also, for exponentials $\frac{d}{dx}[e^x] = e^x$, do NOT apply power rule like $x e^{x-1}$.

Think:

f'(x) > 0
→ moving right tends to increase f

f'(x) < 0
→ moving right tends to decrease f

f'(x) = 0
→ first-order change is locally zero

This is the intuition behind choosing a direction for optimization.

13

Basic Derivative Rules

These rules are foundational calculus tools.

Constant

If:

\[ f(x)=c, \]

then:

\[ \boxed{ f'(x)=0. } \]

A constant does not change.

Identity

If:

\[ f(x)=x, \]

then:

\[ \boxed{ f'(x)=1. } \]

Power Rule

For:

\[ f(x)=x^n, \]

the derivative is:

\[ \boxed{ f'(x)=nx^{n-1}. } \]

Constant Multiple Rule

If:

\[ f(x)=c\,g(x), \]

then:

\[ \boxed{ f'(x)=c\,g'(x). } \]

Sum Rule

If:

\[ f(x)=g(x)+h(x), \]

then:

\[ \boxed{ f'(x)=g'(x)+h'(x). } \]
14

Worked Example — Polynomial

Let:

\[ f(x)=3x^4-5x^2+7x-9. \]

Differentiate term by term:

\[ \frac{d}{dx}(3x^4)=12x^3, \]
\[ \frac{d}{dx}(-5x^2)=-10x, \]
\[ \frac{d}{dx}(7x)=7, \]
\[ \frac{d}{dx}(-9)=0. \]

Therefore:

\[ \boxed{ f'(x)=12x^3-10x+7. } \]

15

Product Rule

If:

\[ f(x)=u(x)v(x), \]

then:

\[ \boxed{ f'(x) = u'(x)v(x)+u(x)v'(x). } \]

Memory:

first derivative × second + first × second derivative

16

Worked Example — Product Rule

Let:

\[ f(x)=x^2e^x. \]

Take:

\[ u=x^2, \qquad v=e^x. \]

Then:

\[ u'=2x, \qquad v'=e^x. \]

Therefore:

\[ f'(x) = 2xe^x+x^2e^x. \]

Factor:

\[ \boxed{ f'(x)=e^x(x^2+2x). } \]

17

Quotient Rule

If:

\[ f(x)=\frac{u(x)}{v(x)}, \qquad v(x)\ne0, \]

then:

\[ \boxed{ f'(x) = \frac{u'v-uv'}{v^2}. } \]

Memory:

bottom × derivative(top)
− top × derivative(bottom)
--------------------------------
bottom²
18

Exponential and Logarithmic Derivatives

Important standard results:

\[ \boxed{ \frac{d}{dx}e^x=e^x } \]

and:

\[ \boxed{ \frac{d}{dx}\ln x=\frac1x, \qquad x\gt 0. } \]

For:

\[ a^x, \]
\[ \boxed{ \frac{d}{dx}a^x = a^x\ln a } \]

for \(a\gt 0\).

These are particularly useful in probability, logistic models, and neural-network mathematics.

19

Trigonometric Derivatives

Useful foundation:

\[ \boxed{ \frac{d}{dx}\sin x=\cos x } \]
\[ \boxed{ \frac{d}{dx}\cos x=-\sin x } \]

These may not appear directly in every AI/ML exam, but they are standard members of the calculus toolkit.

20

Chain Rule Preview

Consider:

\[ y=(3x+1)^2. \]

There is an outer function:

\[ u^2 \]

and an inner function:

\[ u=3x+1. \]

The derivative becomes:

\[ \frac{dy}{dx} = \frac{dy}{du}\frac{du}{dx}. \]

Hence:

\[ 2u\cdot3 = 6(3x+1). \]

So:

\[ \boxed{ \frac{d}{dx}(3x+1)^2 = 6(3x+1). } \]

The dedicated chain-rule treatment comes in M20.

21

Local Linear Approximation

When \(h\) is small:

\[ f(x+h)\approx f(x)+f'(x)h. \]

This says:

close to a point, a differentiable function behaves approximately like a straight line.

Thus:

\[ \boxed{ f(x+\Delta x) \approx f(x)+f'(x)\Delta x. } \]

This is one of the deepest interpretations of the derivative.

22

Worked Approximation

Estimate:

\[ \sqrt{4.04}. \]

Let:

\[ f(x)=\sqrt{x}. \]

Choose:

\[ x=4. \]

Then:

\[ f(4)=2. \]

Derivative:

\[ f'(x)=\frac{1}{2\sqrt{x}}. \]

So:

\[ f'(4)=\frac14. \]

Here:

\[ \Delta x=0.04. \]

Therefore:

\[ \sqrt{4.04} \approx 2+\frac14(0.04) = 2+0.01 = \boxed{2.01}. \]

The exact value is close to this approximation.

23

Second Derivative

The derivative itself can be differentiated.

If:

\[ f'(x) \]

exists and is differentiable, define:

\[ \boxed{ f''(x)=\frac{d^2f}{dx^2}. } \]

Interpretation:

first derivative
→ slope

second derivative
→ how slope itself changes

This is closely related to curvature.

24

Example — Second Derivative

Let:

\[ f(x)=x^3. \]

First derivative:

\[ f'(x)=3x^2. \]

Second derivative:

\[ \boxed{ f''(x)=6x. } \]

At:

\[ x\gt 0, \]

the slope is increasing.

At:

\[ x\lt 0, \]

the slope is decreasing.

Critical Points

A point where:

\[ f'(x)=0 \]

or the derivative does not exist is called a critical point under the usual calculus terminology.

For example:

\[ f(x)=x^2. \]

Then:

\[ f'(x)=2x. \]

Set:

\[ 2x=0 \]

to get:

\[ x=0. \]

This is the minimum.

But remember:

\[ f'(x)=0 \]

alone does not prove that a point is a minimum.

26

First-Derivative Sign Test

Suppose around \(x=c\):

f'(x) < 0 before c
f'(x) > 0 after c

Then the function changes:

decreasing → increasing

which indicates a local minimum.

Conversely:

increasing → decreasing

suggests a local maximum.

27

Second-Derivative Intuition

At a critical point \(c\):

If:

\[ f''(c)\gt 0, \]

the curve is locally bowl-shaped, consistent with a local minimum.

If:

\[ f''(c)\lt 0, \]

the curve is locally cap-shaped, consistent with a local maximum.

If:

\[ f''(c)=0, \]

the test is inconclusive.

28

Why This Matters for Machine Learning

Suppose a model has one parameter:

\[ w. \]

Its loss is:

\[ L(w). \]

Then:

\[ L'(w) \]

tells us how loss changes when \(w\) changes.

If:

\[ L'(w)\gt 0, \]

increasing \(w\) locally increases the loss.

To reduce the loss, we would move in the opposite direction.

That leads directly to:

\[ \boxed{ w_{\text{new}} = w-\eta L'(w) } \]

for learning rate \(\eta\gt 0\).

This one-dimensional form is the conceptual bridge to gradient descent.

29

Optimization Landscape

Imagine:

Loss
 ↑
 |        •
 |      /   \
 |    /       \
 |  •           •
 +--------------------→ parameter

The derivative tells us local slope.

At the bottom:

\[ L'(w)\approx0. \]

If the loss landscape is smooth, derivative information can guide us toward lower loss.

30

Derivative vs Gradient

For one scalar input:

\[ f:\mathbb R\to\mathbb R, \]

we use:

\[ f'(x). \]

For a vector input:

\[ g:\mathbb R^d\to\mathbb R, \]

we need one partial derivative for every input coordinate.

The course's Lecture09 describes the gradient as extending the notion of a derivative to vector inputs and stacking the partial derivatives.

That is the subject of M19 and M21.

So:

one input
→ derivative

many inputs
→ partial derivatives
→ gradient

“Parameter ko thoda badhaya, loss upar gaya ya neeche?”

Numerical-Solving Protocol

For a straightforward derivative problem:

1. Identify f(x)
2. Select the derivative rule
3. Differentiate carefully
4. Simplify
5. Substitute the requested x, if any
6. Interpret the sign if useful

For a definition-based question:

1. Write the limit definition
2. Substitute f(x+h)
3. Expand
4. Cancel common factors
5. Evaluate the limit

For an optimization interpretation:

1. Identify the loss L(w)
2. Calculate L'(w)
3. Determine the sign
4. Move opposite the derivative to reduce L locally

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Constant Derivative & Power Rule Trap:** $\frac{d}{dx}[c] = 0$. Many students forget that constants vanish under differentiation! Also, for exponentials $\frac{d}{dx}[e^x] = e^x$, do NOT apply power rule like $x e^{x-1}$.

Mistake 1

Forgetting the exponent reduction in the power rule.

Wrong:

\[ \frac{d}{dx}x^5=5x^5. \]

Correct:

\[ \boxed{ 5x^4. } \]

Mistake 2

Thinking:

\[ f'(x)=0 \]

automatically means minimum.

It does not.

Mistake 3

Setting \(h=0\) before taking the limit in the derivative definition.

That creates division by zero.

Mistake 4

Forgetting the chain rule for a composed function.

Mistake 5

Confusing:

derivative of function

with:

value of function

Mistake 6

Assuming a positive derivative means the function is globally increasing.

The statement is local unless stronger conditions are established.
