01

Why This Lesson Exists

Before vectors, matrices and calculus become comfortable, the underlying algebra must be automatic.

A large part of AI/ML mathematics is not “advanced mathematics” in isolation. It is the ability to:

read an expression
→ rearrange it
→ substitute values
→ simplify it
→ compare equivalent forms
→ solve for an unknown

For example:

\[ w^Tx+b=\hat y \]

later becomes:

\[ w^Tx=\hat y-b \]

and:

\[ w^Tx-y \]

may become part of a loss derivative.

If basic algebra is slow, advanced ML mathematics feels much harder than it actually is.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
School algebra mein hum $y = mx + c$ seekhte the jahan ek straight line banti thi. AI/ML mein bas itna badalta hai ki $m$ ek single number nahi balki weights ka vector $w$ ban jata hai, aur $x$ features ka vector: $f(x) = w_1 x_1 + w_2 x_2 + \dots + w_d x_d + b$. Jab $f(x) = 0$ set karte hain, toh 2D mein ek line, 3D mein ek plane, aur $d$-D space mein ek **hyperplane** ban jata hai jo do classes ko alag karta hai!

Algebra is the language of relationships between quantities.

Arithmetic asks:

What is \(3+5\)?

Algebra asks:

What happens when an unknown quantity \(x\) is added, multiplied, squared or transformed?

AI/ML constantly manipulates unknown parameters.

input
+
parameters
→
prediction
→
error
→
loss
→
gradient
→
updated parameters

Algebra lets us follow that chain.

03

The Three Most Important Algebra Skills

For AI/ML, become very comfortable with:

Skill A — Equivalent expressions

\[ 2(x+3)=2x+6 \]

Skill B — Solving equations

\[ 3x+2=11 \]

Skill C — Substitution

If:

\[ x=4,\quad w=2,\quad b=1 \]

then:

\[ wx+b=2(4)+1=9. \]

These three skills appear throughout the course.

04

Terms, Factors and Expressions

Consider:

\[ 3x^2+5x-7. \]

The terms are:

\[ 3x^2,\quad 5x,\quad -7. \]

In:

\[ 3x^2 \]

the coefficient is \(3\), and \(x^2\) is the variable factor.

An expression does not need an equality sign.

Example:

\[ 3x+4. \]

An equation contains equality:

\[ 3x+4=10. \]

Like Terms

Like terms have the same variable part.

\[ 3x+5x=8x. \]

But:

\[ 3x+5x^2 \]

cannot be combined into a single \(x\)-term because \(x\) and \(x^2\) are different powers.

Similarly:

\[ 2x_1+5x_2 \]

are not normally combined because they refer to different components.

06

Distributive Law

\[ \boxed{ a(b+c)=ab+ac } \]

Example:

\[ 3(x+4)=3x+12. \]

Reverse direction:

\[ 3x+12=3(x+4). \]

This is called factoring.

ML connection

When simplifying objectives, expanding or factoring terms often makes differentiation easier.

07

Common Algebraic Identities

Memorize these.

Square of a sum

\[ \boxed{ (a+b)^2=a^2+2ab+b^2 } \]

Square of a difference

\[ \boxed{ (a-b)^2=a^2-2ab+b^2 } \]

Difference of squares

\[ \boxed{ a^2-b^2=(a-b)(a+b) } \]

These appear in squared loss, variance derivations and optimization algebra.

08

Why Signs Matter in ML

Suppose:

\[ y=5,\quad \hat y=7. \]

Error:

\[ y-\hat y=5-7=-2. \]

Squared error:

\[ (-2)^2=4. \]

If you accidentally change:

\[ y-\hat y \]

into:

\[ \hat y-y, \]

the sign changes.

For squared error, the final value remains the same:

\[ (-2)^2=(2)^2. \]

But during differentiation, the sign can matter.

Therefore:

Never change an expression merely because two forms “look similar.”

Prove equivalence algebraically.

09

Fractions

Basic rules:

\[ \frac ab+\frac cb = \frac{a+c}{b} \]

when the denominator is the same.

For different denominators:

\[ \frac ab+\frac cd = \frac{ad+bc}{bd}. \]

Example:

\[ \frac12+\frac13 = \frac{3+2}{6} = \frac56. \]

ML connection

Fractions are everywhere:

mean
probability
precision
recall
normalization
gradient averages
10

Dividing by a Fraction

\[ \boxed{ \frac{a}{b/c} = a\frac cb } \]

because:

\[ \frac1{b/c}=\frac cb. \]

Example:

\[ \frac{6}{1/2}=12. \]

This becomes useful when manipulating normalization and probability expressions.

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

# Quadratic form calculation: Q(x) = x^T * A * x
A = np.array([[3.0, 1.0],
              [1.0, 2.0]])  # Positive definite matrix (bowl-shaped surface)
x = np.array([1.5, -2.0])

# Compute quadratic form
q_val = x.T @ A @ x
print("Vector x:", x)
print("Matrix A:\n", A)
print("Quadratic Value x^T A x:", q_val)
11

Exponents

⚠️ University Exam Trap & Common Misconception
**Division by Zero / Unknown Parameter Trap:** When simplifying algebraic expressions in AI proofs (like solving for optimal $w$), never divide both sides by an expression without explicitly verifying it is non-zero! In matrix terms, never write $A^{-1}$ without stating $\det(A) \neq 0$.

Rules:

\[ \boxed{ a^m a^n=a^{m+n} } \]
\[ \boxed{ \frac{a^m}{a^n}=a^{m-n} } \]
\[ \boxed{ (a^m)^n=a^{mn} } \]
\[ \boxed{ a^{-n}=\frac1{a^n} } \]
\[ \boxed{ a^0=1 } \]

for nonzero \(a\).

Example:

\[ x^3x^2=x^5. \]
12

Negative Exponents

⚠️ University Exam Trap & Common Misconception
**Division by Zero / Unknown Parameter Trap:** When simplifying algebraic expressions in AI proofs (like solving for optimal $w$), never divide both sides by an expression without explicitly verifying it is non-zero! In matrix terms, never write $A^{-1}$ without stating $\det(A) \neq 0$.
\[ x^{-1}=\frac1x. \]
\[ x^{-2}=\frac1{x^2}. \]

For example:

\[ e^{-z}=\frac1{e^z}. \]

This is useful when reading the sigmoid:

\[ \sigma(z)=\frac1{1+e^{-z}}. \]
13

Square Roots and Fractional Powers

\[ \sqrt{x}=x^{1/2}. \]
\[ \sqrt[3]{x}=x^{1/3}. \]

Therefore:

\[ x^{m/n}=\sqrt[n]{x^m} \]

under the appropriate real-number conditions.

14

Absolute Value

\[ \boxed{|x|} \]

means distance from zero on the real number line.

Thus:

\[ |5|=5 \]

and:

\[ |-5|=5. \]

Piecewise:

\[ |x|= \begin{cases} x,&x\ge0\\ -x,&x\lt 0 \end{cases} \]

AI/ML connection

L1 regularization:

\[ \|w\|_1=\sum_j|w_j|. \]
15

Equation Solving

Suppose:

\[ 3x+5=17. \]

Subtract 5:

\[ 3x=12. \]

Divide by 3:

\[ \boxed{x=4}. \]

Golden rule

Whatever you do to one side of an equation, do the equivalent operation to the other side.

16

Solving a Linear Equation in ML Form

Suppose:

\[ wx+b=y. \]

Solve for \(w\).

Subtract \(b\):

\[ wx=y-b. \]

Divide by \(x\), assuming \(x\ne0\):

\[ \boxed{ w=\frac{y-b}{x} }. \]

This is simple algebra, but the same habit scales to more complicated equations.

17

Rearranging a Formula

Given:

\[ f=g+h \]

solve for \(h\):

\[ \boxed{ h=f-g } \]

Given:

\[ f=g+h \]

solve for \(g\):

\[ \boxed{ g=f-h } \]

This is the same algebra used to isolate variables in A*, linear regression and RL equations.

18

Inequalities

An inequality works much like an equation, except one important rule changes.

If multiplying or dividing by a negative number, reverse the inequality sign.

Example:

\[ 2x\lt 6. \]

Divide by \(2\):

\[ x\lt 3. \]

But:

\[ -2x\lt 6. \]

Divide by \(-2\):

\[ \boxed{x\gt -3}. \]

The direction changes.

19

Why Inequalities Matter in AI/ML

Many theoretical conditions are inequalities.

Examples:

A* admissibility

\[ h(n)\le h^*(n). \]

Consistency

\[ h(n)\le c(n,n')+h(n'). \]

Regularization constraints

Parameter norm may be constrained:

\[ \|w\|_2\le C. \]

Probability

A valid probability satisfies:

\[ 0\le P(A)\le1. \]
20

Ratios

A ratio compares quantities.

Example:

\[ 2:3. \]

Equivalent fraction:

\[ \frac23. \]

Ratios matter in:

class frequencies
feature scaling
probability
train/test splits
precision/recall interpretation

Always determine which quantity belongs in the numerator and denominator.

21

Proportion

If:

\[ \frac{x}{y}=0.2 \]

then:

\[ x=0.2y. \]

This style of reasoning appears constantly when interpreting rates such as:

\[ Recall=\frac{TP}{TP+FN}. \]
22

Cross-Multiplication

Given:

\[ \frac ab=\frac cd, \]

assuming denominators are nonzero:

\[ \boxed{ad=bc}. \]

Example:

\[ \frac{x}{5}=\frac{6}{10}. \]

Then:

\[ 10x=30. \]

So:

\[ x=3. \]
23

Ratios in Confusion-Matrix Metrics

Consider:

\[ Precision=\frac{TP}{TP+FP}. \]

The denominator is not all observations.

It is:

\[ TP+FP \]

because the question is:

Among predicted positives, how many are correct?

Similarly:

\[ Recall=\frac{TP}{TP+FN}. \]

The denominator is:

\[ TP+FN \]

because the question is:

Among actual positives, how many were found?

Algebra alone cannot decide the denominator.

You must understand the meaning of the quantity.

24

Functions as Algebraic Objects

Given:

\[ f(x)=2x+3. \]

Substitute \(x=4\):

\[ f(4)=11. \]

Given another function:

\[ g(x)=x^2. \]

Then:

\[ f(g(x)) = 2x^2+3. \]

This composition idea becomes important in neural networks:

layer 1
→ function
→ layer 2
→ function
→ output

An MLP is essentially a composition of parameterized functions and nonlinearities.

25

Function Composition

\[ \boxed{ (f\circ g)(x)=f(g(x)) } \]

Example:

\[ g(x)=x+1 \]
\[ f(x)=2x. \]

Then:

\[ (f\circ g)(x) = f(x+1) = 2(x+1) = 2x+2. \]

But:

\[ (g\circ f)(x) = g(2x) = 2x+1. \]

Therefore:

\[ f(g(x))\ne g(f(x)) \]

in general.

ML connection

The order of neural-network layers matters.

26

Linear vs Affine Expressions

A common expression is:

\[ wx+b. \]

The exact mathematical terminology is:

affine in \(x\) when \(b\) is included.

The simpler linear form through the origin is:

\[ wx. \]

In many ML contexts people informally call:

\[ wx+b \]

a linear model.

For mathematical precision:

wx
→ linear map in x

wx+b
→ affine map in x

This distinction becomes useful later with matrix transformations and neural networks.

27

Polynomial Expression

A polynomial contains nonnegative integer powers of a variable.

Example:

\[ f(x)=3x^4-2x^2+x+5. \]

A higher-degree polynomial is more flexible as a function class than a simple line.

This connects directly to overfitting:

higher flexibility
→ can fit more complex patterns
→ may fit noise
→ potential overfitting
28

Factoring

Example:

\[ x^2+5x+6. \]

Find two numbers whose product is 6 and sum is 5:

\[ 2,\ 3. \]

Therefore:

\[ \boxed{ x^2+5x+6=(x+2)(x+3) } \]

Factoring is useful in algebraic simplification and solving equations.

29

Quadratic Equations

General:

\[ ax^2+bx+c=0. \]

Quadratic formula:

\[ \boxed{ x= \frac{-b\pm\sqrt{b^2-4ac}}{2a} } \]

The discriminant is:

\[ \boxed{ \Delta=b^2-4ac. } \]

It determines the type of real roots:

Δ > 0 → two distinct real roots
Δ = 0 → one repeated real root
Δ < 0 → no real roots

This is not a central AI/ML formula, but understanding quadratic behaviour helps when interpreting optimization and loss curves.

30

Completing the Square

A quadratic can be rewritten in vertex form.

Example:

\[ x^2+4x+3. \]

Add/subtract 4:

\[ x^2+4x+4-1 \]
\[ =(x+2)^2-1. \]

The minimum occurs at:

\[ x=-2. \]

This is an intuitive bridge to optimization:

objective
→ shape
→ minimum
→ parameter value
31

Substitution as a Core ML Skill

Suppose:

\[ \hat y=2x+1 \]

and:

\[ x=3. \]

Then:

\[ \hat y=2(3)+1=7. \]

Now suppose:

\[ L=(y-\hat y)^2 \]

and:

\[ y=10. \]

Then:

\[ L=(10-7)^2=9. \]

The chain is:

x=3
↓
prediction=7
↓
target=10
↓
error=3
↓
loss=9

This is exactly the computational pattern behind many exam numericals.

32

Order of Operations

Use:

Parentheses
Exponents
Multiplication / Division
Addition / Subtraction

Example:

\[ 2+3(4)=14. \]

Not:

\[ 20. \]

For ML expressions, parentheses are often essential:

\[ \frac12(y-\hat y)^2 \]

means:

difference
→ square
→ multiply by 1/2

Worked Example B — Simplifying a Loss

Given:

\[ L=(y-(wx+b))^2. \]

First remove the nested subtraction:

\[ y-wx-b. \]

Therefore:

\[ \boxed{ L=(y-wx-b)^2 } \]

Both forms are equivalent.

The first is often easier for conceptual interpretation.

The second may be convenient for expansion.

Worked Example D — Derivation Setup

Suppose:

\[ J(w)=\sum_i(y_i-wx_i)^2. \]

Expand each term:

\[ (y_i-wx_i)^2 = y_i^2-2y_iwx_i+w^2x_i^2. \]

Thus:

\[ J(w) = \sum_i y_i^2 - 2w\sum_i y_ix_i + w^2\sum_i x_i^2. \]

The important lesson is not yet the final derivative.

It is learning how to transform a complicated objective into simpler algebraic pieces.

Hinglish Teacher Explanation

Algebra ko AI/ML mein aap model ko manipulate karne ki language samjho.

Agar model hai:

\[ \hat y=wx+b, \]

toh:

  • \(x\) input hai,
  • \(w\) weight hai,
  • \(b\) bias/intercept hai,
  • \(\hat y\) prediction hai.

Ab agar teacher bole:

“\(w\) ko isolate karo.”

Aapko simply:

\[ \hat y=wx+b \]

se:

\[ \hat y-b=wx \]

aur:

\[ w=\frac{\hat y-b}{x} \]

tak jaana hai.

Isi tarah loss:

\[ (y-\hat y)^2 \]

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**Division by Zero / Unknown Parameter Trap:** When simplifying algebraic expressions in AI proofs (like solving for optimal $w$), never divide both sides by an expression without explicitly verifying it is non-zero! In matrix terms, never write $A^{-1}$ without stating $\det(A) \neq 0$.

Mistake 1

\[ (a+b)^2=a^2+b^2 \]

Wrong.

Correct:

\[ (a+b)^2=a^2+2ab+b^2. \]

Mistake 2

Forgetting the sign reversal when dividing an inequality by a negative number.

Mistake 3

Treating:

\[ x^2+x \]

as:

\[ 2x^2. \]

Mistake 4

Removing parentheses incorrectly:

\[ -(a-b)\ne-a-b. \]

Correct:

\[ -(a-b)=-a+b. \]

Mistake 5

Assuming:

\[ f(g(x))=g(f(x)). \]

Not true in general.
