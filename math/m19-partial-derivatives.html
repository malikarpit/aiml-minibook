01

Why One Derivative Is No Longer Enough

In one-variable calculus:

\[ y=f(x). \]

There is only one input:

\[ x. \]

But an ML model usually has many inputs or parameters.

Example:

\[ f(x_1,x_2) = 3x_1+2x_2. \]

Now we can ask:

How does the output change if \(x_1\) changes?

and separately:

How does the output change if \(x_2\) changes?

We need a derivative with respect to each variable.

That is the partial derivative.

02

One-Minute Intuition

👨‍🏫 Teacher Intuition — Bilingual Mental Model
Partial derivative ka simple rule hai: "Baqi sabhi variables ko pathar (constant) maan lo, aur sirf ek variable ko hila kar dekho!" Jab ek neural network mein 10 lakh weights hote hain, hum har weight ke liye ek individual partial derivative $\frac{\partial L}{\partial w_i}$ nikalte hain. Ye har weight ko batata hai ki 'Sirf tumhare hilne se overall model error kitna badha ya kam hua!'

Suppose:

\[ z=f(x,y). \]

Imagine \(f\) as a landscape.

z
                  ↑
              hill
            /      \
          /          \
        /______________\

        x →        y →

There are now multiple directions in which you can move.

A partial derivative asks:

move in x-direction
while freezing y

OR

move in y-direction
while freezing x

So:

\[ \frac{\partial f}{\partial x} \]

means:

rate of change of \(f\) with respect to \(x\), treating \(y\) as constant.

And:

\[ \frac{\partial f}{\partial y} \]

means:

rate of change with respect to \(y\), treating \(x\) as constant.

03

Multivariable Function

A function with multiple inputs can be written:

\[ f:\mathbb R^d\to\mathbb R. \]

For two variables:

\[ f:\mathbb R^2\to\mathbb R. \]

Example:

\[ f(x,y)=x^2+3xy+y^2. \]

Its output is one scalar, but its input has two coordinates.

04

Partial Derivative with Respect to \(x\)

The formal definition is:

\[ \boxed{ \frac{\partial f}{\partial x} = \lim_{h\to0} \frac{f(x+h,y)-f(x,y)}{h} } \]

provided the limit exists.

Notice what changed:

x changes
y stays fixed

This is the multivariable analogue of the ordinary derivative.

\[ \boxed{ \frac{\partial f}{\partial y} = \lim_{h\to0} \frac{f(x,y+h)-f(x,y)}{h} } \]

Now:

y changes
x stays fixed
06

Symbol Meaning

The symbol:

\[ \partial \]

is used rather than \(d\) because the function has multiple variables and we are differentiating with respect to one variable while holding the others fixed.

So:

\[ \frac{\partial f}{\partial x} \]

and:

\[ \frac{df}{dx} \]

should not be treated as interchangeable notation in a multivariable setting.

07

Worked Example — Basic Function

Let:

\[ f(x,y)=x^2+3xy+y^2. \]

With respect to \(x\)

Treat \(y\) as constant.

\[ \frac{\partial}{\partial x}(x^2)=2x. \]
\[ \frac{\partial}{\partial x}(3xy)=3y. \]
\[ \frac{\partial}{\partial x}(y^2)=0. \]

Therefore:

\[ \boxed{ \frac{\partial f}{\partial x} = 2x+3y. } \]

With respect to \(y\)

Treat \(x\) as constant:

\[ \frac{\partial}{\partial y}(x^2)=0, \]
\[ \frac{\partial}{\partial y}(3xy)=3x, \]
\[ \frac{\partial}{\partial y}(y^2)=2y. \]

Therefore:

\[ \boxed{ \frac{\partial f}{\partial y} = 3x+2y. } \]

Python & NumPy From-Scratch Verification

PYTHON
import numpy as np

x1, x2 = 2.0, 3.0
y_true = 10.0
w1, w2, b = 1.0, 2.0, 1.0

y_pred = w1 * x1 + w2 * x2 + b
error = y_pred - y_true
loss = 0.5 * (error ** 2)

dL_dw1 = error * x1
dL_dw2 = error * x2
dL_db  = error * 1.0

print("Predicted y:", y_pred, "Loss:", loss)
print("∂L/∂w1:", dL_dw1)
print("∂L/∂w2:", dL_dw2)
print("∂L/∂b:", dL_db)
08

The “Freeze the Other Variables” Rule

For:

\[ f(x,y,z), \]

when differentiating with respect to \(x\):

x → variable
y → constant
z → constant

When differentiating with respect to \(y\):

y → variable
x → constant
z → constant

When differentiating with respect to \(z\):

z → variable
x → constant
y → constant

This single rule prevents many mistakes.

09

Worked Example — Many Variables

Let:

\[ f(x,y,z) = x^2y+yz^3+5xz. \]

Find:

\[ \frac{\partial f}{\partial x}. \]

Hold \(y,z\) constant.

\[ \frac{\partial}{\partial x}(x^2y)=2xy, \]
\[ \frac{\partial}{\partial x}(yz^3)=0, \]
\[ \frac{\partial}{\partial x}(5xz)=5z. \]

Therefore:

\[ \boxed{ \frac{\partial f}{\partial x} = 2xy+5z. } \]

11

Partial Derivative of a “Constant” Term

⚠️ University Exam Trap & Common Misconception
**The Multi-Term Constant Trap:** When evaluating $\frac{\partial}{\partial w_1} [w_1 x_1 + w_2 x_2 + b]^2$, many students accidentally treat $w_2 x_2$ as a variable. Remember: under $\frac{\partial}{\partial w_1}$, $w_2 x_2$ is a PURE NUMBER whose derivative is 0! The derivative is $2(w_1 x_1 + w_2 x_2 + b) \cdot x_1$.

Consider:

\[ f(x,y)=x^2+y^3. \]

With respect to \(x\):

\[ \frac{\partial f}{\partial x} = 2x. \]

Why does \(y^3\) disappear?

Because when \(x\) changes, \(y^3\) is treated as constant.

So:

\[ \frac{\partial}{\partial x}y^3=0. \]
12

Partial Derivatives as Local Slopes

⚠️ University Exam Trap & Common Misconception
**The Multi-Term Constant Trap:** When evaluating $\frac{\partial}{\partial w_1} [w_1 x_1 + w_2 x_2 + b]^2$, many students accidentally treat $w_2 x_2$ as a variable. Remember: under $\frac{\partial}{\partial w_1}$, $w_2 x_2$ is a PURE NUMBER whose derivative is 0! The derivative is $2(w_1 x_1 + w_2 x_2 + b) \cdot x_1$.

For:

\[ f(x,y), \]

the partial derivatives are directional slopes along coordinate axes.

At a point:

\[ (x_0,y_0), \]
\[ \frac{\partial f}{\partial x}(x_0,y_0) \]

answers:

“What slope do I see if I move only in the \(x\)-direction?”

And:

\[ \frac{\partial f}{\partial y}(x_0,y_0) \]

answers:

“What slope do I see if I move only in the \(y\)-direction?”

13

Evaluate Partial Derivatives at a Point

From:

\[ f(x,y)=x^2+3xy+y^2, \]

we found:

\[ f_x=2x+3y, \]
\[ f_y=3x+2y. \]

At:

\[ (x,y)=(1,2), \]

we get:

\[ f_x(1,2)=2(1)+3(2)=8. \]

And:

\[ f_y(1,2)=3(1)+2(2)=7. \]

Therefore the local coordinate-direction slopes are:

\[ \boxed{ f_x(1,2)=8, \qquad f_y(1,2)=7. } \]
14

From Partial Derivatives to the Gradient

Once we calculate every partial derivative, stack them into a vector.

For:

\[ f:\mathbb R^d\to\mathbb R, \]

the gradient is:

\[ \boxed{ \nabla f = \begin{bmatrix} \frac{\partial f}{\partial x_1}\\ \frac{\partial f}{\partial x_2}\\ \vdots\\ \frac{\partial f}{\partial x_d} \end{bmatrix}. } \]

The supplied Lecture09 states this structure explicitly: the gradient extends the derivative to vector inputs and is obtained by stacking the partial derivatives with respect to the components.

15

Two-Variable Gradient

For:

\[ f(x,y), \]

the gradient is:

\[ \boxed{ \nabla f(x,y) = \begin{bmatrix} \frac{\partial f}{\partial x}\\[4pt] \frac{\partial f}{\partial y} \end{bmatrix}. } \]

For:

\[ f(x,y)=x^2+3xy+y^2, \]

we found:

\[ \boxed{ \nabla f(x,y) = \begin{bmatrix} 2x+3y\\ 3x+2y \end{bmatrix}. } \]

At \((1,2)\):

\[ \boxed{ \nabla f(1,2) = \begin{bmatrix} 8\\ 7 \end{bmatrix}. } \]
16

What the Gradient Is Saying

The gradient contains the coordinate-wise local slopes:

first component
→ slope along x₁

second component
→ slope along x₂

...
d-th component
→ slope along x_d

So it is a compact summary of how a scalar function changes with respect to every input coordinate.

17

Gradient and Optimization

Suppose:

\[ L(w_1,w_2) \]

is a loss.

Then:

\[ \nabla L = \begin{bmatrix} \frac{\partial L}{\partial w_1}\\ \frac{\partial L}{\partial w_2} \end{bmatrix}. \]

This tells us how changing each parameter affects the loss locally.

Gradient descent then uses:

\[ \boxed{ \mathbf w_{\text{new}} = \mathbf w-\eta\nabla L(\mathbf w). } \]

The detailed optimization treatment belongs to M22, but partial derivatives are the mathematical pieces needed to construct the gradient.

18

Why “Partial” Matters in ML

Consider:

\[ L(w_1,w_2,w_3). \]

When calculating:

\[ \frac{\partial L}{\partial w_1}, \]

we ask:

What happens to loss if \(w_1\) changes while \(w_2,w_3\) are held fixed?

Then similarly:

\[ \frac{\partial L}{\partial w_2}, \qquad \frac{\partial L}{\partial w_3}. \]

All three together give:

\[ \nabla L. \]

This is one of the fundamental ideas behind parameter learning.

19

Worked Example — Simple ML-Style Loss

Suppose:

\[ L(w_1,w_2) = (w_1-2)^2+(w_2+1)^2. \]

Then:

\[ \frac{\partial L}{\partial w_1} = 2(w_1-2) \]

and:

\[ \frac{\partial L}{\partial w_2} = 2(w_2+1). \]

Therefore:

\[ \boxed{ \nabla L = \begin{bmatrix} 2(w_1-2)\\ 2(w_2+1) \end{bmatrix}. } \]

At:

\[ (w_1,w_2)=(0,1), \]

we obtain:

\[ \nabla L(0,1) = \begin{bmatrix} -4\\ 4 \end{bmatrix}. \]

This means:

increasing w₁ locally tends to decrease L
increasing w₂ locally tends to increase L

because the corresponding partial derivatives have different signs.

Contour-Line Intuition

A function:

\[ z=f(x,y) \]

can be visualized as a 3D surface.

Another useful visualization is a contour plot:

higher loss
     (       )
   (    •      )
     (       )
       (   )
         •
lower loss

Each contour corresponds to the same function value.

The gradient gives the direction of steepest local increase and is perpendicular to level curves under the usual differentiability conditions.

This geometric interpretation becomes central in optimization.

21

Direction Matters

For:

\[ f(x,y), \]

there are infinitely many directions in the plane.

Partial derivatives only inspect the coordinate directions:

x direction
y direction

The gradient packages this information into a vector that can be used to reason about arbitrary local directions.

The next conceptual layer is the directional derivative.

22

Directional Derivative Preview

Let:

\[ \mathbf u \]

be a unit direction vector.

The directional derivative of \(f\) along \(\mathbf u\) is:

\[ \boxed{ D_{\mathbf u}f = \nabla f^\top\mathbf u. } \]

This formula will connect:

partial derivatives
→ gradient
→ arbitrary direction
→ steepest ascent/descent

A full derivation and geometric treatment belongs to M21.

23

Mixed Partial Derivatives

For:

\[ f(x,y), \]

we may differentiate twice.

First with respect to \(x\), then \(y\):

\[ \boxed{ \frac{\partial^2f}{\partial y\,\partial x} } \]

depending on notation convention.

Or:

\[ f_{xy}. \]

The reverse order gives:

\[ f_{yx}. \]

Under suitable smoothness conditions, these mixed partials are equal:

\[ \boxed{ f_{xy}=f_{yx}. } \]

This is a standard multivariable-calculus result and becomes useful when discussing Hessian matrices later.

24

Worked Example — Mixed Partial

Let:

\[ f(x,y)=x^2y^3. \]

First:

\[ f_x=2xy^3. \]

Then:

\[ f_{xy}=6xy^2. \]

Reverse order:

\[ f_y=3x^2y^2, \]

then:

\[ f_{yx}=6xy^2. \]

Thus:

\[ \boxed{ f_{xy}=f_{yx}=6xy^2. } \]

Differentiability vs Partial Derivatives

A subtle but important point:

Existence of partial derivatives alone does not automatically guarantee full differentiability.

So:

partial derivatives exist

is not always equivalent to:

function is fully differentiable

For the ML mathematics used later, we normally work with sufficiently smooth functions when applying standard gradient and chain-rule formulas.

26

Hinglish Teacher Explanation

Multivariable function ko ek hill samjho.

Suppose:

\[ z=f(x,y). \]

Ab tum hill par ek point par khade ho.

Tum do simple directions dekh sakte ho:

x direction
y direction

Agar sirf \(x\) direction mein move karna hai, \(y\) ko freeze kar do.

Then:

\[ \frac{\partial f}{\partial x} \]

milega.

Similarly:

\[ \frac{\partial f}{\partial y} \]

nikalna hai toh \(x\) ko constant treat karo.

So partial derivative ka core rule:

Jis variable ke respect mein differentiate kar rahe ho, usko variable rakho; baaki sab ko temporarily constant samjho.

Phir saare partial derivatives ko ek vector mein stack karo:

\[ \nabla f = \begin{bmatrix} f_{x_1}\\ f_{x_2}\\ \vdots\\ f_{x_d} \end{bmatrix}. \]

Isi ko gradient bolte hain. Supplied Lecture09 bhi isi structure ko define karta hai.

Machine learning mein \(w_1,w_2,\ldots,w_d\) parameters ho sakte hain, aur \(L\) loss.

Then gradient bata raha hai:

“Har parameter ko thoda move karoge toh loss kis direction mein badlega?”

Numerical-Solving Protocol

For a partial derivative:

1. Write the function
2. Circle the variable being differentiated
3. Treat every other variable as constant
4. Apply ordinary derivative rules
5. Simplify
6. Substitute a point only after differentiating

For a gradient:

1. Calculate ∂f/∂x₁
2. Calculate ∂f/∂x₂
3. Continue for every component
4. Stack them in a vector
5. Evaluate at the required point, if asked

For an ML loss:

1. Write L(w)
2. Find each ∂L/∂wᵢ
3. Stack them into ∇L
4. Inspect signs / magnitude
5. Prepare for gradient-descent update

Common Mistakes

⚠️ University Exam Trap & Common Misconception
**The Multi-Term Constant Trap:** When evaluating $\frac{\partial}{\partial w_1} [w_1 x_1 + w_2 x_2 + b]^2$, many students accidentally treat $w_2 x_2$ as a variable. Remember: under $\frac{\partial}{\partial w_1}$, $w_2 x_2$ is a PURE NUMBER whose derivative is 0! The derivative is $2(w_1 x_1 + w_2 x_2 + b) \cdot x_1$.

Mistake 1

Differentiating every variable at once.

When computing:

\[ \frac{\partial f}{\partial x}, \]

all other variables are held constant.

Mistake 2

Treating a term such as \(y^3\) as variable when differentiating with respect to \(x\).

It is constant in that partial derivative.

Mistake 3

Mixing up the gradient with a scalar.

For:

\[ f:\mathbb R^d\to\mathbb R, \]

the gradient is a \(d\)-component vector.

Mistake 4

Using \(d\) and \(\partial\) carelessly in multivariable notation.

Mistake 5

Forgetting the order of components.

The gradient convention must be kept consistent with:

\[ [w_1,w_2,\ldots,w_d]. \]

Mistake 6

Exam Connection

Common triggers:

“partial derivative wrt x”
→ freeze other variables

“gradient”
→ stack all partial derivatives

“gradient at a point”
→ differentiate first, substitute later

“loss function”
→ partial derivative for each parameter

“vector input”
→ expect a gradient

“direction”
→ directional derivative / gradient dot direction

A common numerical trap is plugging in the point too early and accidentally losing a variable that should still be treated symbolically during differentiation.
